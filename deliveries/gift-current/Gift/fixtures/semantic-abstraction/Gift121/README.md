这个目录只为现有owner的**设计形状与有限证据逻辑**提供可重放对照，不是第二套规范、不是用户需要运行的Method/目标编译器。四个Definition的body分别继承Gift118/120/112的原参考片段，Requirement使用空组合证明codec形状；跨模块Meaning/Policy/Observation均未授权，**整个混合文件不具备真实业务语义资格**。
