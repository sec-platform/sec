# Rust-native Gift author project — source format specimen（历史研究说明）

This independent project preserves a Rust crate's real `Cargo.toml` and `src/lib.rs` as original authoritative implementation source. `design/contracts.module.json` is a separate, valid **structural** composite, currently containing no qualified Rule term. Merely naming this definition does not prove a Rust function meets an independent requirement.

`gift.project.json` registers the native Rust source scope and a separate structure-source module. It does not invent a Rust->Gift AST mirror, `gift.lock.json`, executable TargetProfile, cargo installation, or verified cross-target compilation. Rust `replace_range` uses **byte** offsets with UTF-8 boundaries, unlike the TypeScript example's UTF-16 indices. A target/equivalence claim must preserve this distinction or provide a proven adapter.
