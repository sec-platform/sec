# 治理与参考

本区保存当前设计理由、未决状态、完整研究、未采用候选与有范围的外部依据及这份设计库自身的维护合同；它们不重定义产品、编译或运行事实。目录只表示物理主归属，正式行为仍回到相应 canonical owner。

## 责任入口

- [研究](../../research/README.md) → [来源及采用边界](../../research/sources/README.md)：保留有独立解释、候选、反例或证据价值的完整资料，不以已有当前 Claim 消费为前提；记录和默认范围由[知识检索规则](维护/知识记录与分域检索.md)维护。
- [决策](决策/README.md)：当前采用理由、最强替代、代价与重开条件；不复制完整规范。
- [状态](状态/README.md)：仍会改变下一步行动的跨 owner 未决与验证前沿；不保存已闭合历史账本。
- [维护](维护/README.md)：文档架构、写入准入、内容保全、Contract Unit、派生导航与交付边界。

当前规范从本目录及[规范入口](../README.md)直接阅读；完整研究另见[研究入口](../../research/README.md)。本 README 不手工维护可由文件树/SourceProfile重建的全量清单，机器树与Unit locator按需生成到包外。
