# 设计理由-目标与核心

## 领域作者表面与图解的取舍

对象的有限语法由[对象规范](../../20-语义与组合/基础语义/对象与控制/对象构造与分派.md#采用理由与重新裁决)拥有取舍：直接成员形式用于真实对象语义，不重新采用嵌套作者SDK；基础无对象程序不受影响。流和AD保持普通库入口，避免为每个操作再加关键字。三者共用现行装配、候选、产物与作用边界，不能把模块接口相同误作执行语义相同。

文档图的投入以独立阅读问题为单位：静态结构、数据拥有、时序、状态和算法分别呈现，完整设计不压成一张总图。图源是其所属规范的表达，渲染图册只派生呈现；新增图片数量不是架构或产品质量证明。
