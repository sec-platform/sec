# 实验设计与因果语义

<a id="gift-unit-experiment-causal-semantics"></a>
## 估计什么与依据什么

可选 Experiment/Causal module 区分统计描述、预测、干预效应和反事实。它不自动把业务指标、仿真输出或模型准确率解释为因果，也不内置一个适用于所有领域的估计器。已有[定量与误差](../基础语义/计算基础/定量合同与误差传播.md)、[Claim/Evidence](../../60-保证与证据/保证/要求证据与裁决.md)继续拥有数量及保证资格。

作者输入包含 estimand（估计目标、尺度和对照）、目标总体/时间/样本单位、处理/干预及其版本、分配机制和暴露、结果/测量窗口、关系/因果模型、协变量与可用时间、缺失/失访/选择、干扰范围、识别假设、分析方法及不确定性解释。处理被分配、实际收到、遵从与观察到结果分别记录；组织/设备多层分配不能擅自压成独立个人样本。

估计目标需明确是意向处理、实际处理条件、总体/子群、直接/总效应或其他由领域库定义的对象，不以“提升多少”代替。识别依赖的交换性、支持/重叠、干预一致性、无相交干扰或明确干扰模型等，只有本次所需才形成义务；它们不是文档模板中默认true的布尔值。

<a id="causal-method-boundary"></a>
## 纯方法、真实实验与声明资格

计划生成普通 Definition/Requirement、Assignment/Measurement关系与相交 Claim。固定模型/数据上的代数推导、识别判断与估计可为纯方法；真实随机分配、改变价格/策略/设备设置、触达用户或取得外部数据是 Effect，必须有真正业务和宿主授权。模型内 do-操作的符号变换不自动许可现实干预。

结果分别保留：估计值/范围、统计不确定性、识别前提、数据与方法适用性、未识别部分、测量与选择限制。无法识别时可以返回描述或界，而不是用高精度数字伪装因果；获得识别证明也不证明现实假设已成立。序贯观察、停止/追加样本、多重比较与实验版本变动按所选统计方法记录，不靠事后选择有利窗口继承旧证据。

反事实关系必须绑定其模型和同一主体/上下文解释，不能把群体均值当个体确定结果。跨总体、时间或部署迁移需要明确运输/外推假设；同样字段或同名政策不是足够依据。与ML相接时，特征与预测模型只能承担实际被证明的估计角色，不能从预测精度推出无混杂。

<a id="causal-distinguishing-models"></a>

**语义消费校核：** **实验谱系与停止规则：** 相同模拟器生成的处理组结果和对照组Oracle不自动成为两个独立来源。实验方法、干预、样本选择、事后筛选和环境修订影响Claim适用范围；改写估计目标不能直接复用原置信区间或宣称现实干预已执行。 实现或验证此用例时分别消费[关联证据、Oracle来源与共同失败不重复计票](../../60-保证与证据/验收/方法与独立证据-独立性可信基础与求解.md#gift-proof-independence)、[跨版本证据重用的有效性与被遮蔽失败](../../60-保证与证据/保证/解释与证据接纳.md#gift-evidence-time-reuse)的权威交接，当前机制只拥有本地行为含义。

## 可直接复算的同观测异干预见证

设 U 是取0或1各半的外生变量，观察变量为 X、Y。模型甲定义 X:=U，Y:=X；模型乙定义 X:=U，Y:=U。两模型的观测分布完全相同：只出现 (X,Y)=(0,0) 和 (1,1)，各半。

干预 do(X:=1) 替换的是 X 的生成方程，不修改 U。甲的 Y恒为1；乙的 Y仍随U各半。因此两者具有相同数据拟合与观测相关性，却对同一个干预给出不同结果。这个构造直接说明：只有该观测分布且允许这两个模型时，目标干预分布不能唯一识别；它不是证明所有现实问题不可识别。加入合法的随机分配数据或排除乙的有效结构依据后应重新判断，不能机械保持Unknown。

这个区别见证由模型定义与枚举就能取得，不要求先实现或运行完整Gift。真实产品能否正确解码/派生/显示它、是否把可识别与适用性区别保持到下游，仍需要对应实现证据。

## 演进、失败与恢复

实验注册/计划、真实分配、投递/暴露、测量、分析、批准/停止各由自己的不可变记录或状态owner承担，不组合成万能 ExperimentStatus。丢失分配回执不能重新随机分配同一单位并遗忘旧可能暴露；原Effect按真实身份查询。样本去除、标签修正和方案改版形成后继依据，不覆盖旧分析使它看起来预先计划。

数据不足、采集失败、识别不足、方法预算耗尽和得到与假设相反的结果分开；负结果不自动修设计为通过。部分合法数据可以支持明确较弱Claim，无权数据不以匿名字面值或缓存绕过用途限制。结论进入产品政策需要真实采纳/授权，统计显著性不是价值选择或风险接受。

<a id="design-c20"></a>
## 实验估计目标与因果识别

实验实例先定义单位、处理/对照、分配方式、估计目标、观测终点、时间窗口、纳排与缺失规则、干扰结构和所依赖的识别假设。结果可能是描述差异、条件关联或被明确假设支持的因果效应，三者不得因同一图表或显著性检验混同。

随机化记录真实分配与执行，分析按预声明的意向处理/实际处理口径及偏差说明；非随机数据需要混杂/选择机制和可识别依据，未取得则只报告相关及候选解释。连续查看/提前停止、多重比较和后选分组需对应有效分析，不把探索所得阈值冒充预注册。

实验计划、真实干预、数据、分析版本与发布Claim分开拥有。干预涉及人、资金、设备或权限必须由实际有权主体准入，分析器不能为了收样本自行执行。事故/风险触发停止和恢复，不删除已发生不利结果。复算固定数据cut与排除原因，隐私/同意变化影响后续用途但不能伪造历史随机化。

**验证与反例**：反向因果、共同原因、干扰溢出、退出缺失、提前停止、探索后假预注册、只完成计划却声称干预已执行。

**实际能力边界**：真实实验、法律/伦理授权和识别证据未取得；不生成现实因果结论。
