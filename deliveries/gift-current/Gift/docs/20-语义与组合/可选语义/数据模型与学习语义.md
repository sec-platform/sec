# 数据模型与学习语义

<a id="gift-unit-learning-semantics"></a>
## 可选职责和输入真源

本合同定义可选 ML SemanticModule 对 Dataset、Feature、ModelRevision、Train、Infer、Evaluate、Monitor 的共同解释，不实现训练框架，不把 LLM 放入确定性编译。数据取得、训练/推理服务、设备使用与模型部署按真实 Method/Provider 和 Effect资格接入；固定数据上的纯分析可以直接复用合格方法。

Dataset 引用实际成员/读取切面、schema、单位、样本单位、时间/来源、允许用途、标注依据、缺失/筛选规则与训练/验证/评估分割；名称和一个URL不构成可重建数据集。Feature绑定变换定义、参数/拟合数据基础、类型与预处理版本；统计量拟合也有来源，不能只记录最终权重。ModelRevision引用结构/权重/编码、训练或提供者来源、输入输出合同、预处理、目标/设备要求、许可与已取得支持，不保存一个可变latest模型指针冒充准确身份。

大数据可用有范围的不可变清单、分区与受信摘要，不要求每次复制全量。内容存在不等于用途合格；隐私/删除与保留要求沿产品安全/存储owner，持久模型或日志中的衍生信息不能因“不是原数据”就自动被排除。

<a id="learning-operations"></a>
## 训练、推理、评估与监测的合同

Train固定数据/分割/特征、模型初态、超参数、优化方法、目标函数、停止条件、RNG/种子来源、数值/设备/工具链解释及计算预算；输出候选 ModelRevision、训练/停止观察与真实产物来源。正常提前停止、预算耗尽、取得失败、数值异常、条件收敛和质量不合格不是同一结果。函数返回成功不证明泛化或用户目标成立。

Infer绑定准确模型/预处理、输入域/批次、输出解释、近似/随机/质量条件、延迟/费用和拒绝/回退规则。外部服务只给不透明模型版本时如实记录实际保证，不能虚构权重可复现或所有调用同模型。结果缓存只能在实际确定性、读集、用途和隐私条件成立时共享；种子相同不能代替线程、设备、算法与环境确定性证明。

Evaluate声明总体与样本框、指标/分母/单位、切片、基线、统计解释、误差与不确定性，绑定评估数据和方法。训练/调参/评估数据角色不能仅靠文件名分开；同主体、时间和预处理拟合信息可能交叉，应以实际独立性要求约束。Monitor引用真实运行分布、测量覆盖、窗口、告警规则和外部观察；监测告警不是模型自动获准重训/更新。

<a id="learning-lifecycle"></a>

**语义消费校核：** **训练数据与派生泄露：** 去掉训练样本原文不自动消除向量、检索排序、诊断、成员推断的披露风险；模型权重字节未变也不代表数据授权继续有效。多个模型若由同一有错标注或模拟标签训练，相同预测不是独立真实性Evidence。 实现或验证此用例时分别消费[派生数据、索引和差分结果的披露资格](../../50-执行运行与观测/权限与资源/工具秘密身份与披露.md#gift-confidential-derived)、[关联证据、Oracle来源与共同失败不重复计票](../../60-保证与证据/验收/方法与独立证据-独立性可信基础与求解.md#gift-proof-independence)的权威交接，当前机制只拥有本地行为含义。

## 采用、更新与恢复

训练完成只发布候选模型，不替作者或运行策略批准上线。Deployment/RuntimeAdaptation决定允许的版本切换、输入输出兼容、在途请求、状态/资源与回退；新引用不能把旧会话缓冲或旧证据无条件移到新模型。模型回退只恢复指定模型/配置，不能撤销已向用户发送的判断、触发的订单或设备动作。

数据/标注/特征改变时沿实际读集失效相关模型声明与评估资格；旧 ModelRevision作为历史对象保留原前提。安全/用途撤销可以阻断后续推理，事故与恢复材料按受限责任保留。模型源不可访问时返回缺项或准确有限服务资格，不用近似同名模型隐藏替换；显式允许的降级保留行为与质量变化。

训练检查点需要保存真实恢复所需参数、优化器/调度/随机状态与数据位置；只有权重不等于完整恢复点。全部范围由具体方法说明，不将某框架的状态布局写入Core。中断后重跑纯局部计算与重新发起计费训练/部署分别按 Query/Operation/RetryBasis处理。

## 验证与边界

有可重复差异的设计见证是：预处理均值在全部样本上拟合后再切训练/评估，和只在训练分区拟合，拥有不同信息基础，不能视为同一评估证据。模型版本相同而tokenizer/特征版本不同也不构成同一次推理。方法必须把相交泄漏/错配作为诊断，实际影响大小由相应数据决定，不能凭此宣称所有评估失效。

资格覆盖数据/特征含义、数值与目标工具映射、代表性切片/负例、漂移/外域输入、费用/时延、隐私/安全、检查点恢复、版本切换和外部效果。预测/分类质量与[因果识别](实验设计与因果语义.md)分开。模块合同存在不签发任何框架、硬件或具体模型的运行支持；实际缺少训练方法时仍可保存合法模型/任务要求并返回 Need。

<a id="design-c19"></a>
## 学习系统的数据、评估与部署边界

ML实例声明任务/目标、数据与标签来源、训练/验证/测试隔离、特征变换、模型/权重身份、训练算法与随机流、推断接口、性能/隐私要求及允许的数据域。不能用训练集指标代签未见数据表现，不能把预处理版本与权重分开导致线上输入含义漂移。

推断结果类型区分预测、置信/校准说明、拒绝域外输入、缺数据及模型故障；模型分数不是现实概率或确定事实，只有在相应校准/数据假设下才作限定Claim。延迟、内存、吞吐、公平/安全指标分别绑定工作负载和评估组，不用单总分覆盖全部主体利益。

部署以不可变模型包、依赖、schema、分群证据和目标硬件资格为单位；漂移监测触发重新资格、降级到已核规则/旧模型或人工接管，不能未经权限自动在线训练并覆盖current。训练/反馈收集是新的数据用途和资源作用，受C10及授权约束。回滚模型不撤销此前决策/外部Effect，对实际影响保留纠正路径。

**验证与反例**：数据泄漏、训练/推断预处理不一致、域外输入、自报高置信、分群失败被平均掩盖、自动训练越权、模型回滚后的既有效果。

**实际能力边界**：真实模型、训练数据、评估/漂移指标与部署证据未取得。
