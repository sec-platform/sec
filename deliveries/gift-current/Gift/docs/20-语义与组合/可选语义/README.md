# 可选产品与领域语义

本目录拥有公共消费者需要共同理解、而不应硬编码进 Kernel 的可选语义合同。它们遵循[语义扩展准入](../组合/语义扩展与定义接合.md)和[作者投影](../作者语义/意图描述与作者投影.md)，不组成强制运行时、行业枚举或一组已实现模块。

[产品交互与呈现](产品交互与呈现语义.md)区分生成产品的交互与 Workbench；[数据模型与学习](数据模型与学习语义.md)区分学习过程、模型修订、预测与资格；[实验设计与因果](实验设计与因果语义.md)拥有估计目标、识别假设、分配与干预；[危害防护与安全论证](危害防护与安全论证语义.md)拥有危害、防护和残余风险关系。领域实现、Framework、Target和设备仍从真实供给选择。

这里的状态是**已采用的可选设计合同**。每个实际方法的发布、装配、目标映射、运行表现与 Evidence 分别登记；没有模块实现时返回准确语义/方法 Need，不凭这些文档把研究或未来能力标成已支持。同包研究保留自己的版本、反例和未知；规范采用不能倒改研究时点。
