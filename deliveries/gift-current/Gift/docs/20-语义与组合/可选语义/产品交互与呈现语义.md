# 产品交互与呈现语义

<a id="gift-unit-product-interaction-semantics"></a>
## 边界与作者对象

本合同用于生成产品的交互，不定义 Gift 的工作台布局。业务中立的可选 Application Interaction SemanticModule 只提供公共消费者需理解的交互关系；原生 React/Compose/Flutter、桌面或设备界面仍可由原生作者源拥有。无交互目标不引入该模块。发现/编辑入口使用[意图投影](../作者语义/意图描述与作者投影.md)，只生成普通 Definition/Requirement/原生源与 Target贡献。

逻辑角色包括 `View`（可观察呈现区域及语义）、`Route`（位置/参数/导航状态与恢复）、`Form`（字段、原值/编辑值、提交范围）、`Action`（意图与后继结果）、`Input`（设备事件、组合状态与解析）、`Focus`（当前目标、可达顺序与恢复）、`Validation`（准确输入基础上的局部或远端判定）、`Binding`（到真实产品状态的有类型读取/修改关系）。这些是领域定义角色，不重用 RealizationBinding 的写权，也不要求一个通用 ViewTree 替代所有平台结构。

作者声明可见/隐藏/禁用条件、输入和值类型/单位、校验范围、动作所需角色、导航历史、未保存草稿、局部/远端错误、加载/空/部分/陈旧反馈和可访问性要求。运行状态由真实产品实例拥有，作者定义修订与用户会话数据不混同；路由字符串、DOM id和组件位置不是业务对象身份。

<a id="interaction-transition"></a>
## 一次输入、校验与实际动作

输入先关联具体控件实例、输入代与当前值基础。输入法组合、键盘快捷键、焦点移动、文本选择和粘贴是不同事件；未经相应目标策略允许，不在组合未结束时拆写字符串或提交业务动作。数值、日期、单位等按所选 codec/locale解析，保持原始编辑串与合法语义值的区别，暂时不合法的草稿不自动改成零/空。

局部校验与异步校验绑定同一字段/表单基础；用户继续编辑后，旧返回只能保留为旧观察，不能覆盖新有效性或启用过期提交按钮。表单变更不会自动修改服务端授权。动作形成明确产品命令/Effect，客户端提交后分别显示未发送、已受理、实际已应用、部分/未知和后续协调；直接纯动作可以立即给值，不强制持久工作流。

关闭面板、路由切换或取消等待不会证明请求停止。保留必要草稿、原动作身份及合法恢复入口；重开时按真实服务状态/回执恢复，而不是重发上一个按钮点击。提交后仅一个字段保存成功时，不把整个表单清空并宣称成功。产品自身运行不必伪造 Gift Operation：经 Gift 执行的操作有原 Operation，目标应用独立执行时由其实际产品命令与日志 owner 记录，再通过可确认关系观察。

<a id="interaction-rendering"></a>
## 呈现、焦点与无障碍

Target 映射语义角色、可访问名称/说明、状态、键盘操作、焦点顺序/模态约束、替代输入、视觉/听觉反馈与错误关联。布局/主题可以是表现变化；改变阅读顺序、点击目标含义、焦点陷阱、隐藏可交互区域或状态播报则是可观察语义变化，必须承担保持义务。

导航、列表虚拟化、增量渲染和组件复用必须保持真实对象/输入代；同一列表位置换绑另一业务主体，不得沿用旧确认或未提交值。异步内容改变时焦点恢复到可用且语义对应位置，不能只按旧坐标；不存在对应项时执行明确回退。控件不可见不能替代服务端鉴权，前端删除秘密文本也不证明浏览器缓存/遥测中从未存在。

可访问性由准确需求与目标方法支持，自动结构检查、静态标签和人工/辅助技术实际路径是不同证据。参照具体标准时绑定版本/profile与覆盖，不能仅有 aria/role字段就宣称所有用户可用。多设备/输入方式不支持时返回相交缺项或已接受替代，不悄悄删除功能。

<a id="interaction-localization"></a>
## 地区化、内容与原生互操作

翻译资源、复数/插值、格式、历法、排序、RTL/双向文本、字体资产、缺项回退与单位由各自精确作者/Target合同固定。locale选择不自动选择法域、币种、策略、时区或身份。地区表示改变不得重解释持久数值/Instant；编辑串应在原解析基础下提交或显式重解析，不能中途换locale后静默改变金额。

原生组件可以公开满足共同接口的局部摘要；无法表达的事件或状态保留原生边界，而不是变成 unknown 后生成无效stub。TargetAdapter 给出结构/行为/可访问性映射、控制/资源效果、错误与来源映射；图形编辑必须通过该操作的 identity/round-trip/unknown-preservation 准入。同一已有源不能同时被 Workbench 私有模型和原生代码手写。

## 变换、失败与资格

优化批量渲染、事件合并和跨线程委派时，必须证明所选动作允许合并/重排；“最后画面相同”不证明期间提交、焦点、辅助播报或输入事件可删。冻结的页面预览不等于已部署或运行可访问性通过。

资格分别检查类型/状态关系、真实框架/宿主映射、键盘/IME/焦点/路由/屏幕阅读路径、低带宽与重连、并发编辑和升级中的草稿恢复。强反例是旧异步校验使新输入被错误接受；合法对照是在原基础仍相同时接纳。具体样本归[纵向符合性](../../60-保证与证据/验收/意图覆盖与纵向符合性.md)，不强制每次普通源码修改启动所有 GUI平台。

<a id="design-c23"></a>
## 交互状态、布局和输入事件

GUI实例区分应用状态、交互状态、渲染树和实际像素/可访问树，定义组件身份、状态归属、事件传播/默认动作、焦点、输入法组合、布局约束和异步数据revision。按钮可点击的语义不等于画出了一个矩形；后端API成功不证明真实交互可用。

事件归约以明确顺序更新状态，渲染可批处理但不得吞掉必要反馈/焦点或改变可观察次序。异步请求按当前输入/组件生命周期验revision，旧响应不能覆盖新输入；组件卸载取消等待但不伪装服务器作用已撤销。SSR/hydration必须核初始状态、资源/locale及事件绑定一致，不在不匹配时静默接上错误控件。

布局/媒体资源加载有失败与fallback；骨架/占位是否可操作须明确。验证同时观察值、焦点/键盘路径、可访问树和实际renderer；模拟view model测试只支持状态逻辑。用户编辑与自动格式化/后台同步冲突时保留原输入/组合状态，不能以“统一状态”覆盖尚未提交文本。

**验证与反例**：IME组合中重绘、旧请求返回、组件卸载、focus丢失、SSR不匹配、资源404、画面存在但键盘不可达。

**实际能力边界**：真实Web/桌面/移动renderer、浏览器/设备交互与无障碍观测未运行。

<a id="design-c24"></a>


**文本编辑不是键入字符的无状态转换。** 文本模型身份、未保存草稿、可见编辑器实例、模型版本、输入法合成（composition）代、选区/光标、行列编码和视口布局修订彼此不同。IME 的临时合成不是已提交正文修改；候选展示、替换和取消不能在未确认时重复触发保存或语言服务动作。光标范围必须说明 UTF-8/UTF-16/标量/行列及行末约定，转换要以实际模型版本为依据，不能用 UI 像素或文件 URI 当永久文本位置。重排、折叠、字体与滚动不会自动使语义位置失效，但可使布局坐标失效；事件映射必须在对应发生点重新定位。

**异步消息携带真实新鲜度。** 来自语言服务、搜索、补全、插件或远端数据源的结果至少绑定请求、文档/输入版本、源的读取范围、提供者会话代与取消状态。取消只是撤去本地结果采用资格，不证明远端已停止计算；旧结果即使晚到且内容表面相同，也不能覆盖新文档状态或抢回输入焦点。预览显示的编辑计划与用户接受的计划必须是同一代，提交前仍需目标资源的准确前像；不能在点击“应用”后从已变化的搜索框重新生成另一批编辑。

## 可访问性和地区化的独立语义

可访问性实例指定目标交互设备、键盘/辅助技术、可访问名称/角色/状态、焦点次序、输入替代、视觉/音频反馈及对应标准版本/验收范围。不能将一个label属性或自动扫描通过当作所有用户完成任务的保证。焦点不得无明确退出方式困在组件中；异步变化、错误和模式切换须有被选辅助渠道可感知的反馈。

地区化实例绑定语言/脚本、翻译资源、复数/选择规则、日期历法、时区及数据库版本、数字/单位/货币格式和collation。存储时间Instant、业务LocalDate与显示时间分别类型化；夏令/时区变化造成的无效或歧义本地时间需明确拒绝/选择策略，不能依系统当前locale猜。显示排序不自动改变业务身份或canonical顺序。

翻译缺失、资源版本不齐、右至左布局、字体缺字和辅助技术差异都有显式fallback及覆盖说明。切locale或升级时区数据库可能改变显示/日程含义，需按相交业务合同迁移；对真实地区合法性/文化要求保持来自作者及专业权威的依据，不由编译器凭语言标签断言。

**验证与反例**：键盘陷阱、屏幕阅读器顺序、动态错误反馈、RTL、歧义本地时间、货币显示/存储精度、locale排序与稳定ID。

**实际能力边界**：实际客户端/辅助技术/地区资源和标准符合性测试未取得。

<a id="design-c25"></a>
## 媒体时间、格式与播放连续性

媒体实例声明容器/编码及版本、采样率/帧率、timebase、颜色空间/范围、声道、压缩损失和同步来源。解码帧的展示时间与到达/解码时间不同，变帧率不能由平均fps重建所有时间戳。像素相同位宽不证明颜色相同，音频样本数相同不证明时长/声道含义一致。

管线定义buffer上界、背压、丢帧/降码率/重采样策略和可接受质量/延迟；实时和离线渲染可有不同恢复目标。任何有损变换需要作者接受的误差/质量口径，不能为性能暗降位深/采样率。跨设备流在真实fence结束前不释放缓冲；断流、seek、codec重配和epoch变更清楚区分旧/新时间线。

恢复从关键帧/音频边界及精确状态继续，不能重播已输出外部直播内容而不标重复。DRM、素材许可、设备权限和解码库漏洞风险由真实供应与政策检查；生成媒体代码不创造素材权利。质量结果绑定实际目标设备/编码器和样本，不能由mock帧证明。

**验证与反例**：PTS/DTS错位、变帧率、色域误解、音画漂移、buffer满丢帧、重配旧帧、直播恢复重复和权限缺失。

**实际能力边界**：真实codec/设备/素材许可和质量证据未绑定。

<a id="design-c26"></a>
## 空间坐标、几何精度和渲染资源

空间实例声明坐标系、手性/轴/单位、变换方向、对象身份、几何拓扑、精度与退化处理。点、向量、法线、齐次坐标和地理坐标不是同一类型；变换复合顺序属于公开含义，不能由shader布局方便决定。几何布尔/碰撞/最近点的容差和退化域必须定义，近零判定不能一律使用硬编码epsilon。

场景图分离所有权树与共享引用/实例，防止复制实例自动复制可变资源。GPU缓冲/纹理/material/shader有目标版本、生命周期和同步规则；渲染pipeline重配后旧帧/资源直到不再被实际使用才释放。实时画面近似、物理碰撞精确度和CAD拓扑正确各有独立Claim。

缺后端特性、精度不足、device lost或素材缺失时选择明确fallback或拒绝，不输出占位图却标目标完成。空间数据流更新以对象revision和坐标基线保持一致；切坐标/单位需要显式迁移且保留源精度。视觉相似不证明几何关系或遮挡排序正确。

**验证与反例**：单位错一千倍、矩阵顺序、法线非均匀缩放、退化三角形、共享mesh被双写、device lost、渲染正确但碰撞错误。

**实际能力边界**：真实图形后端、几何算法和目标精度/画面证据未运行。
