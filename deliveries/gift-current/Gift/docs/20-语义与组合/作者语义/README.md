## 责任所有者

- [能力映射与表达边界](能力映射与表达边界.md)：跨语言能力：当前采用与条件扩展；1. 意图可以精确表达，语义不是与意图竞争的另一套内容；2. 控制覆盖、目标生成与逐字恢复是三项不同承诺；3. 固定表达机制，不冻结全部可表达内容 等。
- [作者信息完整性与控制入口](作者信息完整性与控制入口.md)：作者信息完整性：允许省略输入，不允许丢失决定；作者实际控制什么，及唯一修改入口；8. 常用信息自动补齐，强控制按需保留；9. 反例、代价与当前决定 等。
- [开发者决策模型与设定面](开发者决策模型与设定面.md)：开发者心智模型：不是一条层级栈，而是四类局部决策维度；完整开发设定面：用户能决定什么，而不是再造一门编程语言。
