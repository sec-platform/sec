# 数据处理、变换、生成与求解交付边界

本页描述几类高频计算形态的**消费和完成差异**。Query、Batch、Stream、Compiler、Analyzer、Generator、Inference、Optimization 等名称不形成 Core 枚举，也不会选择内置算法；真正的数学/业务含义由作者 Definition、Standard Semantic Module 或明确 Provider 提供。

<a id="gift-unit-781112d0620e5794952767c77c21aced"></a>
## 查询、批数据与持续流

三者共享数据输入不意味着共享时间、完整性和恢复合同。

### 查询

查询必须绑定准确数据/状态 snapshot 或明确的可变化读语义。分页/游标若存在，应绑定查询 Meaning、输入 basis、排序/过滤规则、授权、目标位置和有效期；失效必须返回 stale/expired，而不是从当前 `latest` 静默续接。合法空集合与未读取/无权/失败分开。

实现可以使用索引、数据库或外部 Provider，但优化不能改变排序、重复项、隔离、权限和结果稳定性。完整否定结论必须覆盖声明的查询域；局部索引未命中不能冒充“全局不存在”。

### 有限批处理

批处理输入集合需要准确成员和顺序/身份规则；目录枚举或新文件出现不能偷偷扩大已冻结的作业。中间分片可以复用，但最终发布必须有能重建逻辑结果的完整清单；半个输出目录不是成功 Artifact。

分区、并行和 spill 是实现选择，除非作者语义确实规定其物理形态。取消时可以保留已封存且仍满足 basis 的中间结果，但不能把它们自动发布为最终结果。

### 持续流

持续流必须显式定义事件/处理时间、顺序、成员变化、背压、终结、迟到/修正、重复消息和 checkpoint/replay 语义。超时、沉默或“目前没看到更早事件”不能冒充 watermarks/frontier 保证。

检查点保存恢复所需的准确输入位置、成员代、状态和未结算输出；检查点成功不等于下游效果恰好一次。只有实际共同事务或幂等/去重机制满足时才能声明相应 delivery guarantee。源 retention 已失效时返回恢复缺项，不从 `latest` 假续接。

流回调/订阅的正常 complete、fault、cancel 和异常消失分别结算；下游没有额度时必须背压、有界缓冲或拒绝，不靠无限内存保持“持续”。

<a id="gift-unit-47584e880c365ed6ac1f8b482fc98fce"></a>
## 变换、分析与生成工具边界

这些只是变换/观察工具的一种技术投影：

- **Compiler/Transformer**：输入 Meaning 与 Target，必须说明保持关系、诊断、依赖和生成闭包；“能输出文本”不证明语义保持。
- **Analyzer**：默认观察并产生 Claim/diagnostic/measurement，不取得被分析输入的写权；若提供修复候选，修改仍走原 Candidate/Apply 边界。
- **Generator**：从准确 basis 派生数据/代码/文档/资源，输出身份绑定输入与生成方法；派生结果不能反向成为未声明的上游真值。

多个阶段可以融合为一个实现，也可以复用成熟工具；阶段名称不要求建立独立服务。自举/固定点、增量失效和确定性由编译/目标 owner 负责，不由“Generator”标签自带。

<a id="gift-unit-1a75daeb471c53eaa3a9fe181717d391"></a>
## 学习、概率与优化类求解边界

Gift Core 不提供 ML/概率/优化业务栈。本节只规定：当作者或可选语义模块确实定义了这类 Meaning 时，交付仍需保留一般工程边界。

模型/求解交付至少要区分：模型/目标函数或分布 Meaning；训练/求解/采样 Method；数据/参数/随机源 basis；资源与停止条件；数值/统计误差；不确定性与适用域；Artifact（权重、代码、配置等）；运行环境；及实际 Claim/Evidence。

“有一个模型文件”不证明推理语义、数据兼容、校准或现实适用；“找到一个候选”不证明全局最优；一组样本不自动证明分布性质。随机算法要区分可复现 seed/stream 与统计保证，不能把固定 seed 的逐项相等当成一般正确性。

训练、推理、采样、搜索、规划、优化或数值求解可以由成熟 Provider 承担；Provider 注册不能改变作者 Meaning，也不能用自己的默认损失、单位、停止规则或数据政策补造未声明要求。

## 冻结实例角色

冻结 `Query/BatchData/WindowStream/Compiler/Analyzer/Generator/Inference/Trainer/Sampler/Optimizer` JSON 只作为旧设计的固定验收输入。其字段、算法、默认值和接口不属于现行公共规范；当前工程按自己的语义、Requirement 与 Provider/Target 组合。

## 求解方法的返回与接受

复用已有 BoundaryView、MethodOutcome、Artifact 与 Claim，不新增所有算法必用的 SolverResult 枚举。适配器至少能解释：本次调用有没有按协议完成；方法仍在迭代还是为何停止；已计算的候选/轨迹覆盖到哪里；残差、误差或统计量采用何种单位/范数/样本范围；所求可行性、精度、最优性或稳定性哪些有依据；输入和方法的准确修订。上游的status、converged reason和候选值分别映射，不能只检测进程exit 0或外层调用返回成功。

实际过程是：固定问题与接受条件，选择合格方法及数值/资源策略，准备私有求解状态，运行或复用准确候选，解释方法停止与覆盖，按[数值误差合同](../基础语义/计算基础/定量合同与误差传播.md#numerical-error-acceptance)检查用途，再把有来源的候选和结论交给原输出/保证消费者。子求解失败、预算终止与模型不符合是不同原因；结果可用于允许的近似查看或下一阶段初值，不自动取得最终发布资格。并行规约、硬件或方法选择改变允许差异时回原 Binding/Requirement，不以“优化”暗改精度、概率或确定性。

求解器会在预测点、被拒绝的试步或迭代中重复调用残差/Jacobian/事件函数；这些回调不能顺带提交作者状态、发送设备命令或重复扣费。纯函数或完全私有、可恢复的模型状态可被多次试算；外部状态读取须在明确取得边界冻结，真正有作用的试验经原授权/Operation/预算准入并记真实结果，不能在求解失败时假装未发生。无法回滚的现实观测仍可驱动顺序学习，但不能冒充可任意重放的函数。

### 多模型推进、事件与回滚域

联合计划固定连接、单位/坐标、各模型时钟及实际输入/输出依赖，区分直接馈通代数环、时间推进反馈和真实外部等待。需要迭代回滚的耦合方法，仅对具有合格完整状态取得/恢复能力的私有组件采用；公开变量副本不等于完整求解器历史、随机流、事件队列和回调状态。没有回滚能力时可选择仍满足原误差/进展合同的显式推进、缓冲或其他方法，否则只拒绝相交强耦合，不停掉无关模型。

每次推进消费实际到达时间、事件请求、终止请求、输出覆盖与调用状态，不能把请求终点当已到达，也不把所有early return当故障。某模型先到t2、另一只到t1时，不发布伪造的共同t2切面；按原能力回滚/重新同步、保留各自准确分项结果，或保留未结算。插值/外推是带误差与有效域的方法，不擅自搬动权威状态。零时间事件迭代按语义固定点或有界事件处理；耗尽预算不以强行增加epsilon消除Zeno/不收敛。

候选步的模型状态、输出和误差检查先形成私有接受点，已确认接受后才发布到所声明的模拟时间边界。真正设备、网络作用或外部消费者已观察的输出不进入可撤销的试步域；需要在线物理耦合时，独立声明真实采样、deadline、滞后/超前限制和安全过程。模拟回滚、重新显示与业务补偿各保持原含义。

完整例子与备选算法见[数值与现实反例](../../../research/domains/压力参考/仿真/数值与现实反例研究.md)及[仿真状态、时间与拓扑](../../../research/domains/压力参考/仿真/仿真状态时间与拓扑.md)。这些研究不将仿真主算法塞进Core；成熟Provider按具体能力接入，固定FMI/SUNDIALS/PETSc来源见[求解依据](../../../research/sources/科学计算仿真与保证依据.md#numerical-source-join)。

## 方程、事件与仿真有效性

仿真实例必须绑定方程/初边值、参数单位、时间域、离散化/网格、事件与不连续处理、守恒约束、终止/观测规则及误差要求。ODE、DAE、PDE和离散事件模型不是一个通用“求解”标志；例如代数约束一致初值、空间边界及网格收敛需各自定义。

求解器可自适应步长/精度，但事件定位、跳跃状态、重启条件和采样插值须保持公开意义；跨过事件直接平滑输出不合格。数值未收敛、刚性/病态、约束漂移、网格不足及资源耗尽分别报告。checkpoint保存模型/求解器版本、内部状态、随机流和事件队列，恢复不能只用公开状态忽略方法所需隐变量。

算法误差界支持数学模型的数值求解，不证明模型描述现实。现实Claim另外绑定测量、校准、适用环境及模型检验；仿真器生成事件不是设备事实。耦合多个仿真/控制模块时要明确时间同步、交换顺序、插值和能量/守恒边界，局部误差达标不直接签整体稳定。

**验证与反例**：事件跨步、DAE初值不一致、守恒漂移、网格细化未收敛、checkpoint隐状态丢失、仿真与真实动作误认。

**实际能力边界**：实际物理模型/测量参数和目标求解器资格未提供。
