# 定量合同与误差传播

本篇细化既有[C5组合资源与领域摘要](../../../30-实现解析/组合前提与进展闭合.md)。数值/统计领域提供合格合成规则，编译器按真实连接调用，保证评价保存范围；不新增全局评分或强制预算对象。

<a id="quantitative-composition"></a>
## 定量合同的合成：资源、误差、风险与相关性

内存、时延、误差、失败概率、能耗、隐私损失和金额不是同一种预算。内存峰值取决于对象寿命重叠；顺序时延包含各阶段与队列，流水吞吐由瓶颈和调度决定；并发支路的总资源不能用最大值替代；可靠性依赖故障相关与共同原因；概率风险不能用未校准“信心分”相加。

每个可计算定量合同保留量纲、范围、聚合对象、运行模式、前提、估计/实测/硬界类型，及使用的合成方法。通用组合器仅调用该量的合格组合规则，不自行认为所有指标“越小越好”。峰值预算必须基于生命周期区间或经接受的保守上界；测到平均负载低不允许声称最坏情况下安全。

两个误差`e1,e2`相加时，恒等式为`Var(e1+e2)=Var(e1)+Var(e2)+2Cov(e1,e2)`，前提是这些二阶矩存在。若标准差同为1且完全同向相关，和的标准差是2；当且仅当协方差为0时该例得到√2。不能因来源是两个服务就认为误差独立；共同校准设备、共享训练数据和同一物理扰动均可连接它们。未知协方差应保留未知，或采用有依据且说明范围的保守界。

非线性流水线还会放大上游误差。对具有已证局部Lipschitz界L的后段，输入误差上界ε与该段新增误差δ可在相同域内给出`Lε+δ`的界；不能默认得到`ε+δ`。接近不连续边界、接触切换或奇异点时，该界可能不存在或失效，应缩小已接受域或换方法，不把数值预算标签当证明。

资源核算按物理同一资源避免重复计费，又按同时活跃消费避免漏计。三个任务各占4单位、容量10，任意两项都能并存，三项不能；这说明成对组合测试并不覆盖三阶共享约束。定量解释应输出哪个生命周期区间、误差通路或共同原因造成瓶颈，并保留重新调度、独立校准、改变允许近似或明确拒绝的不同分支。

**适用范围：**不同量有不同合成规则；未知相关性不能自动假设独立。

**重新检查条件：**新共享资源或共同误差源出现，线性/独立/稳定前提失效，或测量口径与消费口径改变。

验收的具体触发与观察见[全域接合检查](../../../60-保证与证据/验收/全域接合检查.md)；这里定义机制与条件，不签发任何实现、执行或现场合格状态。

<a id="quantitative-witness-inputs"></a>

**语义消费校核：** **误差与现实费用的不同累计：** 同源校准误差不能按多个独立误差均方消减；使用同一模拟器生成参考值还可能共同带偏。资源模型预测的成本上界不等于供应商最终账单；效果未知时应区分模拟资源预算、已保留额度与现实计费。 实现或验证此用例时分别消费[外部未知效果、资金/资源结算与去重窗口](../../../50-执行运行与观测/持久化与恢复/事务提交-外部效果与幂等交付.md#gift-external-outcome-ledger)、[关联证据、Oracle来源与共同失败不重复计票](../../../60-保证与证据/验收/方法与独立证据-独立性可信基础与求解.md#gift-proof-independence)的权威交接，当前机制只拥有本地行为含义。

## 可复算见证与输出条件

对总量、最坏界、统计区间和估计值先分型。组合输入引用实际主体、单位、所选模式、有效域、寿命区间、依赖关系与证据，不要求把每个算术节点永久记账。结果给出原Claim范围、使用的合成规则、实际输入和未闭合前提；更新校准或调度时沿这些读取重评。

三个任务同时各占4、容量10时，成对均为8不能支持三方同时准入。若只有两项寿命重叠，峰值8可以支持该调度；若串行违反deadline，不能用较低峰值冒充原任务已满足。报告必须指向实际寿命区间，而不是仅保留三项数字。

对具有有限二阶矩的误差，已知各标准差而未知协方差时，可以按适用的协方差界形成保守区间；不能将未知直接置零。非线性误差界仅在所用局部域、映射与Lipschitz条件成立时传播；越域、接触切换或奇异点交回专门模型，不隐式使用线性界。

验证把三方约束、误差相关、单位换算、寿命重叠和真实目标放在同一输入中。算式可成立而测量或域前提未知；数学计算结果不代签这些外部事实。

## 残差、数值误差与现实准确性的分界

数值结果固定问题 Meaning、输入/边界条件、单位与坐标、离散化/网格、算法和实际方法绑定。接受规则分别说明残差的定义/范数/缩放、前向或后向误差、局部步误差、累计/全局误差、守恒/可行性及模型与现实的偏差；未求某种保证不制造它，求而没有依据则保留相交未知。改变单位时同步容差与缩放，不能把跨量纲分量直接代入无权重范数。

小残差不普遍蕴含小解误差。可复算反例：A=diag(1,10^-12)，b=(1,10^-12)，准确解x=(1,1)，候选x̂=(1,0)。按无穷范数，残差||b−Ax̂||∞=10^-12，而||x−x̂||∞=1。对可逆线性系统，x−x̂=A^-1(b−Ax̂)，因而在相容算子范数下误差≤||A^-1||·残差；界中的逆算子尺度不能被省略，奇异问题还需单独说明解集合和选择。这个代数反例不依赖实现运行，也不说明任何具体库有缺陷。

ODE求解器的局部误差测试、线性/非线性子迭代容差与最终用途的误差要求分开。已接受一个内部步，不直接证明全局轨迹或现实预测准确；模型误差、初值/参数不确定性、离散化和舍入分别沿实际耦合传播。需要全局界时用相应稳定性/估计方法，不能把rtol原数复制为最终相对误差保证。

停止阈值、最大迭代、事件/不连续、NaN/Inf、病态、随机误差和域越界分别处理。方法声明支持有限近似时，准确报告已满足的界和未满足的用途；预算耗尽可以保留候选，不自签收敛或自动降低作者接受阈值。领域约束依赖微小差异时不能只报告舍入后的可视值。

## 费用、配额与迟到计量

计费实例声明计量单位、货币最小单位、精确金额类型、价格/税费规则版本、生效区间、舍入方向、账户和结算周期。相同资源数量在不同价目版本下不是同一金额；展示四舍五入与账务取整可以不同但必须公开定义。浮点近似不能隐式成为金额真值。

资源预留、实际用量、应计金额、已付款和退款分别记录，以操作/计量事件身份去重。超额策略是拒绝、预授权扩额或明确有价降级，不能在后台无限透支。迟到/重放计量按原事件时间和已接受定价版本更正，用新的调整记录而非静默改历史账单。两份预留共享配额需要同一原子/协调域。

预留释放以实际工作结束或明确转移责任为条件，取消等待不立刻归还仍在使用的资源。退款是有权的新效果，引用原费用并有自身幂等/读回；成本未知时保持估计范围/待结算，不当零价。定价策略变更与已发生账务的兼容独立处理。

**验证与反例**：小额多次舍入、迟到计量、重放账单、并发预留、取消后继续消耗、价格跨版本和重复退款。

**实际能力边界**：真实价目、账户和资金/计费Provider未绑定。

## 误差模型与精确/近似数值

数值实例固定数学对象、单位/维度、值域、表示类型、舍入、范数、绝对/相对容差、异常输入与环境画像。精确整数/有理可用精确等式，浮点/定点/区间是不同方法合同；不能因两种表示都叫number自动互换。相对误差在真值接近零时需要明确绝对容差或其它尺度。

算法误差、浮点舍入误差、输入测量误差和模型误差分别给界及传播关系。小残差不自动意味着小解误差：需要算子条件/逆界等依据；缺这种依据时只报告残差而不签精度。区间方法必须控制向外舍入与目标环境，不能把普通浮点两端当严格包络。

方法选择可改精度、迭代、预条件和表示，但要保持目标误差/资源硬界。NaN、溢出、病态、未收敛和资源不足分别返回，不能统一补零。误差声明绑定输入域及工具/硬件浮点环境，fast-math或融合策略变动重核；性能提高但超误差界不合格。

**验证与反例**：残差小但前向误差大、近零相对误差、单位错配、区间内舍入、目标fast-math变化、迭代未收敛。

**实际能力边界**：真实数值环境、输入域界和方法误差证明由实例取得。

## 随机源、概率主张与重放

概率实例区分伪随机流、真实熵源、抽样分布和现实数据生成机制。绑定算法/种子或受权entropy来源、分布参数、样本权重/相关结构、停止规则及概率/置信陈述。给定伪随机种子可重放不意味着样本代表现实总体，也不赋予密码安全性质。

并行随机流按稳定任务身份和明确splitting算法分配，不能让线程完成顺序决定随机数归属而破坏重放；选择顺序相关随机语义时需公开声明。缓存随机计算必须包含流状态/种子及消费范围，不能仅哈希函数输入复用第一次随机结果。真正熵读取属于可观察效果或capture输入。

统计结论声明估计目标、误差/区间、覆盖假设、抽样/依赖/缺失和多重/可选停止处理。只给p值或一次模拟成功不签现实概率。预算不足保留已有样本和精确采样范围，续算从原随机流状态继续；不悄悄重新种子挑更有利结果。分布或来源变更使相交资格失效。

**验证与反例**：同种子不同并行调度、重复随机cache、相关样本当独立、可选停止、丢随机状态的恢复、伪随机冒充真实熵/安全。

**实际能力边界**：真实数据分布及统计证据由所选研究/产品提供，不预设概率或置信数字。
