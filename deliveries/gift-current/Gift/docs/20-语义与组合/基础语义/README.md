## 这里不是行业业务子系统

本目录保存可独立复用、按需装配的 Standard Semantic Modules，例如计算、对象/控制、状态/关系/流与数值；目录身份本身不表示任何行业，也不允许把多个模块在这里预组合成完整应用框架。游戏、仿真、金融、医疗、制造等具体业务由作者定义、库和 Provider 组合，不在这里取得 Core authority。完整行业材料在同包[领域研究](../../../research/domains/README.md)作为非权威研究输入；仿真压力参考和物理工程压力参考只能用于发现本层通用状态、时间、数值和作用边界是否遗漏区别，不能反向成为内置行业模型；提炼后的公共反例见[跨域区别见证](../../60-保证与证据/验收/跨域区别见证.md)。通用定量机制继续由[定量合同与误差传播](计算基础/定量合同与误差传播.md)拥有。
