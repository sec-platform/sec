# 访问投影与不完整类型

本页补充[语义扩展与外部定义接合](语义扩展与定义接合.md)中的相交能力；原章节继续拥有其已采用的有限语义。**当前选择：拆开保留，不整包采纳。** opaque、模块可见性、合法成员访问属于常用能力；protected/friend/成员指针原生语义是条件性接口需求。

访问合同把“谁可访问哪个声明／成员、以什么 receiver、可否再导出”写清。公开／私有继承只控制相应的子对象转换与公开关系，不能自动改变已有成员的其他授权。

`protected` 使用受约束的派生关系与 receiver 路径判定，而不是放开整个包。`friend` 可以授予某个函数、类型或模板声明；授权绑定声明身份和适用版本，不绑定容易撞名的字符串。库明确转交成员能力时允许受控委派，否则生成代码与反射不能扩大授权。这里是语言封装机制，不是抵抗同进程任意机器码的安全沙箱。

成员指针用两种类型化句柄表达：`MemberProjection<Owner, Value, Access>` 与 `MemberCallable<Owner, Signature>`。它们可以携带固定偏移、动态路径、调整 thunk 或受限 accessor；不是普通地址。应用时检查 owner／路径／借用；位域或不可地址化的 packed 成员只能得到读写代理，不能得到假的 `&T`。要求 C++ pointer-to-member 原生字节表示时走指定 ABI 适配。

不完整声明只建立名义身份及可用签名，不伪造 size、align、字段或 Drop。允许经过指针／句柄的相互递归。按值存储、完整布局查询及某些析构实例化会触发定义完成；按值无穷递归的布局 SCC 必须被拒绝。公开不透明类型通过 owner 的工厂、析构和操作使用；把私有完整定义泄露给反射查询不是默认副作用。

Opaque 类型分两类：隐藏表示但实际 Sized 的模块私有类型；真正仅允许通过外部句柄使用的 foreign 类型。不能用大小为零的占位结构冒充真实 foreign 对象，更不能据此执行指针步进或内联分配。

## 再次修改与失效

可见性、名义声明或不完整定义补齐改变时，重查真实访问与布局消费者；公开句柄不能因名字不变获得新的读取权，缺定义的原字节继续可保全。

## 使用点与可检验出口

<a id="cpp-gap-a05"></a>
- **protected 派生家族权限**：承认细粒度封装差异，按插件/扩展用例设计有限接口；不把 protected 当安全沙箱。 硬边界示例：库要求任意下游派生者访问受限成员，但普通用户不得获得同样入口；[具体比较与出口](../../../research/comparisons/Rust与C++能力比较.md#a05)。
<a id="cpp-gap-a06"></a>
- **friend**：普通封装先用已有规则；有实际授权主体差异再加局部机制，不能从 friend 推出全局 capability 平台。 硬边界示例：固定模块边界、公开 API 与单个特权主体都不可改，且确需绕过普通私有性；[具体比较与出口](../../../research/comparisons/Rust与C++能力比较.md#a06)。
<a id="cpp-gap-a10"></a>
- **成员指针**：常规访问器足够时不新造原语；确需字段投影时保留 owner/借用/不可寻址字段约束。 硬边界示例：要求精确 C++ pointer-to-member 表示，或既存泛型接口必须原生接收这种值；[具体比较与出口](../../../research/comparisons/Rust与C++能力比较.md#a10)。
<a id="cpp-gap-a11"></a>
- **不完整类与前置声明**：复用现有 opaque/模块依赖；不是为了模仿 C++ 头文件而增加前置声明系统。 硬边界示例：原生接口要求同一外来名义类型的精确按值布局，但定义未提供；[具体比较与出口](../../../research/comparisons/Rust与C++能力比较.md#a11)。

**语义消费校核：** **投影能算不代表能展示：** 部分类型、投影及按需字段求值可以在受控内核看到内部对象，但调用者是否可读、可枚举、可修改仍取决于当前身份和资源范围。非公开成员不得从错误定位、枚举数量或结构补全侧漏；可见投影不是操作Grant。 实现或验证此用例时分别消费[派生数据、索引和差分结果的披露资格](../../50-执行运行与观测/权限与资源/工具秘密身份与披露.md#gift-confidential-derived)、[委派能力收窄、重定向与执行时再检查](../../50-执行运行与观测/权限与资源/授权与执行准入.md#gift-delegation-attenuation)的权威交接，当前机制只拥有本地行为含义。
