# 结构作者与语义编辑

Code-OSS 连续修改与整条开发链是本章的实际消费者。作者源码批次及其语义读集仍由 workspace 物化；目标工具运行时对搜索命中的替换是另一份 Plan，不能把其模型版本填成作者 Candidate，也不能用纯文本前像匹配代签符号或任务语义保持。

本章拥有基础中立程序的结构体编码、求值区域、管脚投影与结构修改回到作者源的具体合同，接合[作者文件](../../../10-作者与输入/作者源/工程源/README.md)、[语言体系](../../../10-作者与输入/作者源/可替换表示与适用范围.md)、[共同变化](../../../80-开发者与接口/工具协议/候选修改与批量.md#语义增量临时身份与前提)和[转换保持](../../../40-目标与制品/表示/表示族与跨层保持.md)。编码标签不是语言关键字；精确编辑操作通过共同候选协议进入。

## 责任所有者

- [结构模型与绑定读取](结构模型与绑定读取.md)：需求形状的局部编辑与原作者位置；结构编辑与受管目标回源的边界；范围与当前选择；一次出现、一次求值与一个定义分开 等。
- [编辑重构与确定回写](编辑重构与确定回写.md)：三类精确结构编辑沿原协议进入；名称重构的正向算法；从语义改动到文本字节的确定回写；结果、诊断与下一步 等。
- [作者权切换并发与往返](作者权切换并发与往返.md)：结构与文本作者权切换及混合工程；并发、版本与缓存的接合；整批作者变化的落实、重基与发布；预算与较小实现 等。
