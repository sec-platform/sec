# 导入观察与原生资产

大型原生维护的具体边界见 Code-OSS 作者文件与来源：保留 TS 作者区及非源码成员，只在必要独特语义处增加中立源；打开缓冲和磁盘是不同状态层。读取一组源码不能代签全仓捕获，静态引用不证明宿主保存或原子版本能力，后者由实际目标适配取得。

外部库的公开导出可以形成ImportedModuleView，与实际作者ModuleRevision共同进入链接；这是读取所得的只读视图，不是将原生实现提升为一份新作者源。它保留来源、覆盖和未知，不要求有同义Gift函数体。名称/类型读取不执行原生模块顶层，也不证明相同签名的目标行为相同；实际使用点由[供给主链](../../30-实现解析/内核/编译值服务.md#supply-aware-compile)处理。

## 责任所有者

- [原生来源与逆向边界](原生来源与逆向边界.md)：原生作者区域不是必备组成；逆向的目标：恢复行为、结构与意图候选，而不伪造历史。
- [工作区与版本库观测](工作区与版本库观测.md)：Git、索引、工作树、提交与候选树观测；工作区精确观测；编辑器覆盖层、索引、磁盘与写回协调；观测预算、采样与覆盖前沿 等。
- [仓库开发准入与恢复](仓库开发准入与恢复.md)：Gift 自身仓库的任务分流、Work Package、提交／传输恢复；这是 self-hosting 实施控制面，不是目标工程通用要求。
- [源码检查点与正式采用分流](源码检查点与正式采用分流.md)：已授权独立源码的固定 base/scope、提交／审查／传输及向 formal Work 的单向交接；检查点不签发正式采用资格。
- [仓库凭证与传输边界](仓库凭证与传输边界.md)：GitHub 凭证资源选择、秘密最小披露、异步传输与资源结算；凭证可用性不签发仓库作用权。
- [仓库验证与运行观测](仓库验证与运行观测.md)：本地／hosted 运行位置、测试进程生命周期、观察与受信原生检查复用；验证结果由工作控制面消费，但不反向签发工作或作用权。
- [仓库远端维护与退役](仓库远端维护与退役.md)：hosted maintenance、exact ref 退役、maintenance carrier 与评论运输垃圾结算；仅拥有远端维护生命周期，不取得产品采用或普通仓库作用权。
- [外部不透明与动态输入观测](外部不透明与动态输入观测.md)：二进制、本机代码、不透明组件与外部系统观测；人工知识、文档、评论与外部文本可信边界；动态依赖、环境输入与负事实观测；数据模型、数据库、消息与事件流观测 等。
- [存量工程重建与采纳](存量工程重建与采纳.md)：存量工程重建与采纳；工程导入与按模块提升；意图规范化、歧义与安全前沿。
- [语言前端与直接编辑](语言前端与直接编辑.md)：直接编辑与成组捕获：文本是正常作者入口；语言前端与源码程序；原生观察不能替代中立值构造；解码不是用目标对象伪造中立值 等。
