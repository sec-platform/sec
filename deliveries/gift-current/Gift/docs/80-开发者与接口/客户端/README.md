# 工作台编辑与审查交互

跨语言能力进入搜索、重构、构建、调试、观测和协作的共同接合见[跨语言开发面接合](../跨语言开发面接合.md)。它复用本页的工作对象与动作，不新增 IDE 或第二套语言/权限规则。

## 责任所有者

- [客户端产品与适配边界](客户端产品与适配边界.md)：当前范围；人类主客户端的具体采用：Code-OSS / VS Code 扩展优先；后续客户端只适配不重定义；采用条件与退出。
- [开发面与智能投影](开发面与智能投影.md)：完整开发面：工作对象、动作和结果，不是一套新界面；可视图、表单、结构面板与直接操作；Developer Intelligence 是共同工程事实的投影；嵌入语言与结构化搜索复用同一Developer Intelligence 等。
- [运行交互与工作台](运行交互与工作台.md)：动作的完整性不能替代作者成果；Run Configuration、任务图与复合启动；当前可实施的文本、CLI、SDK和代理入口；Notebook、REPL、数据库/API控制台与远程工作台 等。
- [编辑审查协作与大型视图](编辑审查协作与大型视图.md)：未保存缓冲、辅助编辑与接受变化；审查、局部采纳、版本控制与多方协作；审查范围来自语义变化，批准不替代保持依据；编辑坐标与批量失败的实际语义 等。

## 布局与树形浏览的具体合同

[工作台布局与交互](工作台布局与交互.md)拥有Gift人类客户端的侧栏、编辑区、Inspector、审查、命令与宿主放置；[树形导航与结构投影](树形导航与结构投影.md)拥有节点出现、展开分页、搜索/筛选、多选、定位、刷新、键盘和导出。它们不是目标Studio的产品规范，也不以GUI阻断CLI/AI/headless。

当问题是共享对象在两条树枝中出现，进入树形合同；当问题是源编辑/批量失败/实时协作，进入[编辑审查](编辑审查协作与大型视图.md)；当问题是cursor、快照、断线和披露，进入[原客户端协议](../工具协议/客户端与并行会话.md)。不在每个页面再维护同一状态机。
