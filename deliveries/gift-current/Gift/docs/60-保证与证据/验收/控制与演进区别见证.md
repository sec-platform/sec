# 控制与演进区别见证

本页不维护固定编号或固定数量的测试清单。控制、扩展、迁移和未来技术的正确性应由各 canonical owner 的合同与相交 Evidence 负责；Assurance 只保留能让“看起来合理的实现”产生不同可观察结果的**区别见证**。

冻结 `8a07bdb` 中的旧控制与演进案例矩阵保留历史推演，不是当前逐项必跑套件。新的案例只有在产生新的独立区别、真实事故或新的验证盲区时才进入活动材料。

## 选择案例的原则

一个演进反例至少应回答：哪个主体/revision 改了；哪个 owner 的含义或 authority 受影响；哪些消费者真实相交；正常结果、冲突、未知和恢复有什么不同；什么 Evidence 才能裁决。若只是在另一行业/语言/页面重复同一机制，不新增案例。

[验证义务、方法选择与精确下游绑定](方法与独立证据-义务方法与已有知识.md#verification-obligation-selection)拥有验证方法；本页不复制测试框架或工具名字。

## 开放语义与作者控制

| 区别见证 | 必须保持 |
|---|---|
| 新业务/算法不在目录中 | 通过作者 Definition/SemanticModule/Library 扩展，不扩充 Core 业务 enum；表达不了独立差异才形成 distinction witness |
| 显式值恰好等于继承值 | “本层明确写入”与“从上层得到同值”仍是不同来源事实；reset 删除本层记录而不是写 null/默认 |
| 局部控制命中共享定义 | scope 由真实 Subject/consumer closure 决定；不能因操作从某个实例发起就只改一个实例 |
| 新 descriptor 没有 UI facet | Decision 仍可按 owner 发现；facet 缺失只是 presentation gap |
| 旧客户端遇到新字段/状态 | 未理解内容按扩展/兼容合同保留、拒绝或降级；不能默认丢字段、吞 unknown 或映成最近枚举 |
| schema 未变但含义变了 | semantic revision 必须使消费者和 Evidence 正确失效；结构相同不等于语义相同 |
| 插件声明同一接口但含义不同 | 资格取决于真实 contract/Provider/Target 和 Evidence，不按接口名合并 |

## 选择、优化与资源

局部最优不保证联合可行。多个方法共享内存、线程、带宽、许可证、设备或 latency budget 时，应在共同约束上选择；不存在唯一最优时保留 Pareto/作者偏好/硬约束，不伪造全局评分。新候选、新文件、新 Provider 或资源事实改变时，只使真实依赖的负查找、摘要和计划失效。

优化还必须保持实际求值域、错误、Effect、随机性、资源和跨运行性质；不能只比较最终值。性能实验若在搜索过多个候选后挑最好值，探索样本不自动成为确认性 Evidence，见[覆盖与收益判据](覆盖与收益判据.md#adaptive-confirmation)。

## 自动控制、观测与未知完成

自动控制器只能在已授权 policy envelope 内调整。两个控制器修改同一资源时要有共同目标/优先级/稳定性或仲裁，否则可能振荡；观测断流、偏差或延迟不能当“正常 0”。

远端 Effect 超时、连接断开或客户端取消只说明本地 observation 不完整；是否已发生由原 operation identity、Provider readback 和 settlement contract 决定。未知不能被重命名成失败后自动换路线重发。

<a id="s78取消检查点之外仍有不可抢占的大操作"></a>
### 取消检查点之外仍有不可抢占的大操作

即使 runtime 在入口、循环或 epoch 边界检查取消，大型 FFI 调用、bulk copy、内核调用、系统调用或第三方库仍可能在两个检查点之间长时间不可抢占。**“检查得很频繁”不能证明硬取消时界。** 若 Requirement 承诺强时间界，必须同时限制输入/批次、资源、调用粒度，并选择具有真实中断/终止能力的实现；否则只能声明 cooperative/best-effort cancel。发送 signal、设置 flag 或 host future 被取消后，仍要等待真实资源停止/隔离，不能提前释放仍被 guest/native 使用的内存和句柄。

## Identity、迁移与退出

持久实体 identity 不能等同内存索引、路径、provider locator 或当前 hash。身份/规范编码算法迁移需要旧新解析和映射；内容相同也不自动表示同一实体。零拷贝/物理布局只在真实生命周期内有效，不能为了性能锁死未来表示。

迁移必须区分 source revision、old/new schema、实际已迁移实例、并发新写、切换点、回滚资格和长期离线消费者。双写不是原子提交的替代；回滚也不能覆盖切换后新世界产生的合法事实。用户迁出/退役时，作者源、开放格式和必要解释可导出，但历史 Effect、法律留存、共享资产或未结算操作按自己的责任退出，不能用“删除项目”伪造从未发生。

## 权限、安全与 Assurance

AI、插件、Provider 或被测实现不能修改自己的 Requirement/Evidence 门槛来证明自己。签名只证明签名所证明的对象/签发者关系，不证明实现正确、供应链完整或当前产品资格。硬预算若底层只能软观测，就不能升级成硬保证；强非干扰/隐私要求也不能用“结果值正确”代替时间、内存、日志、cache 或 side-channel 观察。

参考实现与生产实现若共享 parser、encoder、fixture 或错误逻辑，不构成独立验证。新验证器只有减少共同原因时才增加 assurance value，见[独立性评估](方法与独立证据-独立性可信基础与求解.md#independenceassessment)。

## Target、运行环境与未来机制

新 GPU/加速器、分布式 runtime、开放世界插件、持续物理系统或未来计算模型不因为“新技术”自动进入 Core。先检查现有 Definition/SemanticModule/Target/Provider/Effect/Resource/Evidence 是否能表达真实差异：

- 若只是新的实现/ABI/设备约束，扩展 Target/Provider；
- 若出现新的可观察计算语义，扩展 Standard Semantics；
- 只有多个独立场景都需要、且现有通用 owner 无法保持的最小差异，才考虑 Core promotion；
- 公共 ABI、协议或格式一旦对外承诺，兼容/迁移成本必须计入，不能把“稳定”理解为永远冻结内部结构。

## 组合攻击而不是笛卡尔积

无需把所有控制 × 语言 × Provider × Target × 故障做全排列。优先构造会改变裁决的联合攻击，例如：

- **未知字段 × 离线编辑 × 解释升级 × 权限变化**：旧作者源不能被新版偷偷补义，也不能因曾经可写继续获得新权限；
- **自适应并行 × 资源预算 × 超时重试 × 外部费用**：性能控制不能通过增加不可逆 Effect 次数来满足吞吐；
- **identity 迁移 × snapshot 复用 × 隐私删除 × backup restore**：恢复旧备份不能复活已退役身份或无权数据；
- **远程 I/O × solver cancel × native borrowing**：求解停止不等于外部调用和借用资源已结算；
- **自动发现候选 × 不可信插件 × 有界搜索 × 自我验证**：新候选不能自己扩大搜索预算、Grant 或验收准则；
- **协议/规则升级 × 长期离线消费者 × rollback**：兼容窗口和 migration owner 必须显式，不能靠 latest 名称重解释旧数据。

这些联合反例的价值在于击穿“每个部件单独都绿”的假安全。只有出现新的耦合机制才新增组合攻击；不按场景数量追求覆盖率。

下表是现行合同的可区分条件，不是新增强制测试套件，也不表示Gift已运行过这些场景。实现验收需要取得表中实际链路与可观察结果；只搜到关键字、检查器返回0或字段能序列化不能替代相交行为。

## 观察接合、占用与恢复的交叉见证

这些构造检验现行设计的不同结果，不新增固定测试题库、必达案例数量或产品执行声明。实现采用时以真实边界/状态/字节与所求保证为观察对象，不能只让一个future超时或检查文档含某词。

| 构造与对照 | 应当得到的区别、恢复与责任位置 |
|---|---|
| 一个源revision R修改X/Y，分片X后断线；对照R完整应用并持久提交但消费ack丢失 | [投影检查点](../../80-开发者与接口/工具协议/客户端与并行会话.md#projection-checkpoint-resync)前者不得推进越过R或丢Y，后者原批重投不重复应用；不能按revision相同删除不同成员 |

| 新快照第一页读完后位置失效/第二页失败；对照空页带More最终取得完整新范围 | 前者旧值仅能按仍合法的陈旧用途保留，不半包替换；后者继续同切面翻页，安装内容/依赖/覆盖/位置时不清新增dirty。草稿与原operation不重置 |
| A变B再变A而中间通知丢失；对照需要每次变更的审计/业务事件订阅 | 全量重扫只能恢复当前A；它不证明没有B，也不能重建缺失事件身份或准许重发命令。相交历史来源缺项明确保留 |
| 捕获期间ACL撤销，或离线端不能取得当前撤销前沿；对照明确有效的有界离线委派 | 已受控端立即撤掉相交披露资格，不等新快照完成；失联端只在所接受范围内继续，不能宣称即时撤销；仍需保留的恢复材料不因显示关闭删除 |
| 远端读租约到期，本地只有未完成view；对照已校验自有副本，以及仍被FFI/DMA使用的缓冲 | [借用边界](../../50-执行运行与观测/持久化与恢复/持久状态与存储协议.md#lease-retention-and-borrow-boundary)分别拒绝无保护后续读、允许仍有权用途的本地副本、等待真实读者/设备结算；不由TTL回收在用内存，也不永久pin所有远端历史 |
| 父进程退出或Job通知未到；对照实际成员查回已停止，以及子进程已脱离组 | [进程环境](../../50-执行运行与观测/运行生命周期/资源登记物化与回收.md#进程树)按真实成员和原身份结算，组名/单PID/信号成功不证明完整停止；未知范围不误杀其他工作，也不自动成为可回收 |
| 两个Action有独立快照却向同一业务库提交；对照限定临时schema和只读分析；另让池连接事务状态未知 | [数据库画像](../../50-执行运行与观测/运行生命周期/资源登记物化与回收.md#数据库)分别执行正常共享业务事务、准确临时清理、稳定读取与隔离未知连接；不把全部Action统一建库，也不以snapshot isolation保证无污染 |
| 预演事务回滚但曾消费非回滚序列或调用外部系统；对照全部写入确可回滚且无逃逸作用 | 只有后一画像可依据完整回滚宣称所需无残留；前者保留真实效果与恢复身份，不删原要求让预演看似纯 |
| 旧迁移命令含不支持字段；对照命令合法但原数据有可保全unknown repeated成员 | [安全变换](../../50-执行运行与观测/持久化与恢复/迁移备份与权威恢复.md#安全变换)前者拒绝命令，后者在保持存在/位置/重数条件下允许已知局部变更；需要未知语义时只阻塞相交部分，不能默默丢载荷 |
| 全部内容本地齐备但本次所需信任元数据过期，分别允许/禁止联网；对照内容和有效依据齐备且有充分离线资格 | [离线物化](../../50-执行运行与观测/运行生命周期/资源登记物化与回收.md#offline-materialization-freshness)依次取得最小必要依据、报告相交缺项、直接零网络复用；不得重选版本/全量下载、偷开网络或把过期材料说成当前有效 |

轨迹对照须同时观察实际成员、内容、依赖、连续覆盖、授权范围、应用/耐久位置和仍在使用的资源。完整旧切面结果、所要求的新鲜结果与当前允许展示/执行分别判定；观察任务取消不能自动关闭原业务恢复责任。

## 演进质量的真正判据

一个设计更可演进，不是因为“新增控制只改一个文件”或“测试条目更多”，而是因为：新独立语义有明确 owner；已有不相交内容不失效；真实消费者可通过 dependency/impact 找到；旧读取者/旧产物有兼容或拒绝路径；迁移可中断恢复；权限与 Evidence 不被自动继承；退出不会留下只能靠聊天解释的隐藏状态。

若新增能力持续要求修改中央枚举、固定产品家族、万能 context、所有客户端和全仓测试，那么应先重开抽象/owner 边界，而不是继续增加案例来适应坏架构。

## 研究、求解、控制与现实接合的区别见证

以下是可直接用于设计推演或相交实现验收的条件构造，不是固定强制题库或已执行产品测试。模型算术可独立复算；真实调用、设备和时序行为只有对应运行证据才能报告为已发生。

| 构造与对照 | 必须能区别的结果与处理 |
|---|---|
| `A=diag(1,10^-12)`、`b=(1,10^-12)`、候选`(1,0)`对比准确解`(1,1)` | 前者残差无穷范数为10^-12，但前向误差为1；不得仅由小残差签发用户误差合格。后者在同一模型下两项均为0。阈值、范数和条件性回原数值owner，不为通过而放宽 |
| 同一调用返回成功，迭代reason分别为converged、diverged、仍iterating | 保留调用取得与方法停止的不同结果，再检查本任务接受条件；不得把读取停止原因成功当作求解成功。合格已收敛结果无需额外制造失败 |
| 两个单独增益6/5的控制器共同作用，和两个增益3/5共同作用 | 依[明确离散模型](../../20-语义与组合/共同语义/反馈控制与稳定性.md#coupled-feedback-counterexample)，前组联合乘子-7/5失稳，后组-1/5收敛。单个稳定证书不能代签联合性；也不拒绝后组合法组合 |
| 外层求解试算一次后拒绝该步，再次试算相同输入；回调是纯数值函数或会发送命令 | 纯回调可按方法重复；命令不能躲在试算中自动重复。真实实验必须通过显式授权的Effect和接受/读回合同，恢复模型不抹去已发生作用 |
| 联合仿真请求t=10，一参与者实际仅到t=9.5；对照所有参与者到同一合格切面 | 前者保留准确时间和事件，按协商推进/回滚/插值能力处理，不能把不同时间样本拼成共同t=10；后者可交付该切面，不要求无限追赶“绝对现在” |
| 取回可见位置/速度相同，但求解历史、随机状态或事件队列不同 | 只有能恢复被请求继续语义的完整状态才适合精确重放／AD检查点；单值展示可继续，不把它升级为完整恢复证据 |
| 已有匹配模型证明，当前任务只问模型内性质；对照任务声称真实设备满足硬期限 | 前者可直接复用准确证明和适用前提，零新执行合法；后者另需实际映射、时间链和资源证据。未知物理映射不取消前者的模型结论 |
| 证明有界且存在未解除环境假设，同时部署runtime shield | 三个事实同时保留；不选一个AssuranceOutcome标签覆盖其余，也不由shield自动解除假设或把范围扩大 |
| 领域专有研究为一个明确Claim提供合格推导，但尚未成为公共Core接口 | 可直接通过原义务与Evidence资格满足该Claim；不是先强制增加公共语义或把同领域例子复制成全域测试 |
| 原生扩展拿到可直接访问外部系统的权限；对照所有作用确实经受控端口 | 仅写Broker接口不能证明前者所有作用被拦截；选择真实隔离或保留信任边界。后者可消费其实际可执行约束，不为了统一强制新增容器或进程 |
| 凭证已泄露且远端撤销确认未知；对照确认撤销且无需清理独立合法证据 | 前者不得宣称全部副本已消失，沿准确身份限制新作用并保持恢复；后者按真实覆盖关闭相交风险，不删除事故证据或其他主体合法数据 |

这些构造和既有63—65的结果、绑定、观察、缓存、重试与退役见证共用原owner。判断顺序是准确目标与basis、方法/能力、语义保持、作用准入、结果和证据接纳；纯计算路径可跳过不相交作用阶段，不能机械要求每个对象走全链。
