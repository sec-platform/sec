## 系统架构阅读与实现边界

本主题拥有Gift的系统边界、完整职责交接和运行装配。具体作者形式、编译方法、操作协议与领域语义继续由各自主题负责。

| 层次 | 阅读位置 | 完整内容 |
|---|---|---|
| 图谱 | [全体系架构图谱](统一多层工程模型.md) | `L0—L6 × ASMRVE` 统一多层工程模型、共享工程语法、限定信息、端到端因果与revision/time演化 |
| 设计方法 | [设计综合、必要性与结构保全](设计方法/设计综合与必要性.md) | ASMRVE 六段设计闭合、必要性/替代/验证/演进、旧结构信息保全与全体系综合优化算法 |
| 总体 | [总体设计](总体架构.md) | 产品与环境、责任分解、状态、部署、跨版本变化与主要取舍 |
| 交接 | [协作与状态边界](../70-工程系统与演进/协作与状态边界.md) | 原系统总装的精确结果、输入、需补信息、根成员、失败和共享规则 |
| 实施接合 | [装配](../70-工程系统与演进/实现与装配/README.md) | 模块依赖、工厂、运行实例、解释映像与具体函数责任 |
