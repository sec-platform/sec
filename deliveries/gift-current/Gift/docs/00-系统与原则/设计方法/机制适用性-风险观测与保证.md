# 风险、观测与保证

## 风险、观测与保证

### 危害、风险边界与防护

**规范入口：**[可选领域设计合同](../../20-语义与组合/可选语义/危害防护与安全论证语义.md)。

**需要识别的输入：**危害、触发链、暴露、控制和残余风险

**适用性检查：**安全约束先于优化；接受主体明确

**失败恢复检查：**防护失效进入有定义的降级或停止

**验证方向：**故障树/危害场景、独立防护与恢复演练

**不承担的责任：**不把无事故样本视为绝对安全

**业务作者目的：**识别危害、风险链、控制、残余风险和紧急停止。

**作者投影与落实：**可选Safety语义以hazard/scenario/control/safe-state/independence/residual-risk/approval生成普通Claim/Requirement；行业标准与物理证据按准确Method/Provider取得，不由模块声明签发安全资格。

**可区分的见证：**异常在危险命令发送后被捕获，不证明危害已阻止；真实前置阻断有不同结果。独立防护共享故障源时不能按独立成功率合成。

### 日志、指标、追踪与诊断

**规范入口：**[解释与证据接纳](../../60-保证与证据/保证/解释与证据接纳.md)

**需要识别的输入：**观测点、采样、标识关联与开销预算

**适用性检查：**真实观察、估算和推断区分；秘密最小化

**失败恢复检查：**监控失效不伪装正常；丢样范围可见

**验证方向：**探针开销、关联一致性、漏测与误报

**不承担的责任：**不让观察默认取得修改或终止权限

**业务作者目的：**记录产品日志、指标、追踪、业务指标与诊断。

**作者投影与落实：**Telemetry facet 定义 event/metric/trace schema、cardinality、privacy、sampling、retention、SLO；Target 注入 instrumentation，Gift runtime metrics 保持独立。

**可区分的见证：**采样遥测未见错误不等于零故障；完整计数范围才支持该分母统计。产品指标不能从Gift自身编译日志自动推得。

### 验证、确认与支持声明

**规范入口：**[要求证据与裁决](../../60-保证与证据/保证/要求证据与裁决.md)

**需要识别的输入：**命题、对象修订、方法、环境与证据

**适用性检查：**实现符合规格与规格适合用途分别评价

**失败恢复检查：**失效证据只降级相交声明；未知不签成功

**验证方向：**独立oracle、反例、变形关系与真实环境

**不承担的责任：**不允许生成器用自己生成的期望独立自证

**业务作者目的：**证明/测试产品满足功能、性能、安全、兼容和业务要求。

**作者投影与落实：**每个 IntentFacetDescriptor 可附 ClaimTemplateRef；实例化后生成 ProofObligation，Method 选择现有 Assurance，不把模板本身当 PASS。

**可区分的见证：**合格反例使Claim受反驳而取得过程可成功；不得把反例当工具运行失败。已有准确证据可零新动作复用，但模板存在不PASS。

### 来源、归属与依赖证据

**规范入口：**[对象关系与配置基线](../../70-工程系统与演进/信息与生命周期/对象关系与配置基线.md)

**需要识别的输入：**实体、活动、作者、来源与变换

**适用性检查：**事实来源、版权归属和验证可信度分别记录

**失败恢复检查：**来源缺失与来源冲突可追踪，不补造历史

**验证方向：**来源链断裂、修改、撤回与精确产物对应

**不承担的责任：**不以签名或原创声明证明技术质量

**业务作者目的：**追踪代码、数据、模型、资产、依赖和决策从哪里来。

**作者投影与落实：**Provenance facet 引用 source/revision/license/evidence；compiler 自动传播实际 dependency/provenance，但来源不自动取得事实 authority。

**可区分的见证：**有来源关系只证明该关系范围；签名/许可/可信事实需各自依据。内容重组保持精确归属，不以文件名相同替代身份。
