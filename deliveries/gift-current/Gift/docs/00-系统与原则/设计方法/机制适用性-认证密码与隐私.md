# 认证、密码与隐私

## 认证、密码与隐私

### 认证、授权与委派

**规范入口：**[权限与资源管理](../../50-执行运行与观测/权限与资源/README.md)

**需要识别的输入：**主体、凭据、角色、范围、时段和目的

**适用性检查：**能力存在与当前有权使用分离；最小授权

**失败恢复检查：**撤销、凭据过期、代理链断裂后拒绝相交动作

**验证方向：**越权、混淆代理、跨租户、旧token与紧急访问

**不承担的责任：**不由Provider自报字段签发权力

**业务作者目的：**最终产品用户登录、会话、角色、权限、委派和资源访问。

**作者投影与落实：**Product Security facet 定义 Principal/credential/session/policy/resource scope；运行时可复用共同身份/Policy机制，但 Gift 工具权限绝不传给产品用户，反之亦然。

**可区分的见证：**产品管理员能批准产品动作不代表有宿主文件权；Gift授权也不赋予产品用户角色。委派/撤销检查对象、受众、用途与时间，不靠同名role。

### 密码、密钥与可信通信

**规范入口：**[权限与资源管理](../../50-执行运行与观测/权限与资源/README.md)

**需要识别的输入：**密钥、算法画像、证书、秘密与轮换

**适用性检查：**使用合格实现，保密/完整性/身份验证分别声明

**失败恢复检查：**泄露吊销、轮换、密钥丢失按明示恢复

**验证方向：**已知向量、轮换、降级、秘密泄露与熵边界

**不承担的责任：**不自创密码算法或把哈希当真实性证明

**业务作者目的：**加密、签名、密钥、证书、秘密和可信通道。

**作者投影与落实：**Crypto facet 只引用批准的 cryptographic profile/capability；密钥 Material 由 secret Provider，源码只持引用与用途，真实轮换/证书状态需 readback。

**可区分的见证：**声明密钥引用/用途后由合格Provider签名；把私钥串放descriptor不允许。轮换请求成功不证明全部旧凭据/会话已失效。

### 隐私、同意、目的与保留

**规范入口：**[权限与资源管理](../../50-执行运行与观测/权限与资源/README.md)

**需要识别的输入：**个人数据、使用目的、共享、保留及删除

**适用性检查：**最小披露、用途边界、撤回和派生物关联

**失败恢复检查：**删除请求与法定留存冲突交有权决议

**验证方向：**日志/缓存/备份泄露、再识别与退出审计

**不承担的责任：**不把去掉姓名自动视为匿名

**业务作者目的：**收集/使用/共享/删除个人数据，管理同意、目的和保留。

**作者投影与落实：**Privacy facet 为数据类别、purpose、consent basis、retention、sharing、deletion/DSR 建 Requirements；storage/log/analytics providers 必须消费，不能只放文档。

**可区分的见证：**撤销用途阻断相交新使用；不能以备份/遥测是衍生物为由绕过保留政策。删除结算只覆盖受控副本，不可达范围保留未知。
