# 实现解析与设计搜索

## 责任所有者

- [实现要求与正常绑定](实现要求与正常绑定.md)：从要求形状选择实现，而不是从业务词选择轮子；需求到作者变更的可落实计划；候选类别与选择发生的时点；锁定路线与开放发现的不同失效 等。
- [实现解析与候选资格](实现解析与候选资格.md)：实现解析算法；固定输入下的实现选择算法；开发者不点名轮子时的正向实现绑定；完成语义与选择实现之间的可执行门槛 等。
- [设计空间搜索与求解](设计空间搜索与求解.md)：等价重写、电子图与受限搜索；约束求解、不可判定分类与不满足解释；候选生成与设计空间搜索；工程意图到设计的合成算法；DesignCandidate 结构、精确基础、提案版本、局部失效、冻结与正式采纳门槛 等。
- [责任重建与修复搜索](责任重建与修复搜索.md)：失败最小化、复现、归因与修复候选编译；领域边界与责任重建算法。
- [成本优化与联合剪枝](成本优化与联合剪枝.md)：界的核算范围与联合剪枝；条件等价、撤回与多根成本的接合；代价维度与有状态优化的切面。
