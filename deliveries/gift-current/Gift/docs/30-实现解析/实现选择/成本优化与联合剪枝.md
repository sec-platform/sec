# 成本优化与联合剪枝

<a id="cost-bound-accounting"></a>
## 界的核算范围与联合剪枝

原J4使用可靠界之前先绑定场景、目标函数、计量单位/主体、方法与输入域、冷热/共存状态、实际调度及该界覆盖的支出集合。它们引用原成本证据和SearchNode，不新增统一评分。一个估计可用于探索排序，不能因字段叫lowerBound就获得证明资格；缺界的维度保持未知。

**组合先定同一物理支出再算界。** 两个部件各把同一初始化算8份，联合只初始化一次时，8+8不是联合总成本的可靠下界；用16剪掉真实为8的方案会误删。反过来，相同内容的两个独占缓冲仍是两份分配。累计量只对不重复且确属该总量的支出相加；未来批量、折扣或共享可能改变已估部分时，不把未经保持的局部和作为任何完成方案的下界。峰值按同时存活，墙钟按实际关键路径与等待，不能用一个加法覆盖全部维度。

对未完成分支，先证明下界在其允许的每一种后继中成立；对已完成可行方案，所用上界须覆盖同一目标和条件。再按原层级/Pareto关系比较，高层未定不由低层替代。可靠界区间相交只表示当前不能定序，不自动相等；两个分别成立但场景不同的界不得拼成一个联合保证。统计覆盖另由所选统计方法组合，不继承硬界结论。

新增共享边、布局、调度或恢复要求使核算前提变化时，失效相交界与剪枝理由；可重开被该理由排除的候选前沿，不能只调整最后评分。预算结束准确报告搜索不完整及已检可行方案；既有合格方法可按稳定采用规则继续，不为缺最优证明重做全部实现。

## 条件等价、撤回与多根成本的接合

等价搜索只在准确理论、语义修订、对象域和共同前提中合并候选。整数x/x=1需要x非零；局部获得这个前提，不允许把等式装入所有上下文共享的无条件类。规则删除、前提撤回或目标改变时，已合并的类不会天然分裂，需按原依赖重建相交搜索，或采用仍显式保存条件的表示。浮点NaN、无穷、舍入及陷阱不能直接借用整数见证。

解释路径证明使用了哪些步骤，不独自证明规则健全。接受者检查规则和前提是否适用；生成器、推导记录、独立接纳和生产发射不共享一个自签verified。批量修改后的rebuild恢复结构不变量，与语义保持分别评价。预算终止只能交付所求范围内实际取得的候选及未完成边界，不将未饱和写成全局最优。

抽取代价须匹配实际部署和共享语义。假设两个表达式已由独立依据证明等价，f(x,x,x)的树出现数为4、共享DAG节点数为2，g(g(x))分别为3和3，两种计数会选不同候选；它们都不是实测延迟。多个输出根还可能共享固定成本：独立实现各6，共同准备8、每根追加1时，两个根独立为12，合法共享为10；逐根贪心未必得到共同合格最优。

上述共享只有在输入、主体、寿命、隔离、目标布局、峰值内存及首请求期限允许时成立。原coupledGroups处理真实相交根；没有共同条件的根保持独立，不为了求解外观把全工程装进总优化器。通用表示与有限专门路径可以并存；专门化同时计入编译耗时、目标代码体积、缓存驻留、维护和取消延迟，不默认枚举参数表示的全部组合。

<a id="cost-scope-and-controlled-adaptation"></a>
## 代价维度与有状态优化的切面

源码量、符号/实例化、关系边、候选分支、输出根、资产字节、运行实体、事件率与保留历史分别度量。百万行不代表百万个服务，小模型也可能展开巨大状态空间。按实际根、索引和紧凑值加载；恶意元程序、深递归、指数候选及巨大格式分别使用真实预算，不先全量装进全局对象。

代价资料区分估计、静态界、基准与现场观察，并绑定样本、输入分布、设备、并发、冷热缓存和目标环境。编译、验证、启动、运行、能耗、体积、维护及供应风险不能无单位相加；一次小例优势不外推全部负载。按实际保持合同选择布局、算法、并行、缓存或特化；用隐私、误差、共享状态或证据强度换成本属于原任务必须允许的取舍。

有状态自适应先形成允许包络内的新候选，在可迁移切面处理回调、资源和未结算状态后切换。触发、冷却/滞回、切换费用和回退按目标定义；硬件/调度变化使相交依据重评。无稳定收益或真实缺陷可以保持原实现，不为了持续优化制造漂移。
