# 查询影响与性能

## 责任所有者

- [依赖与失效模型](依赖与失效模型.md)：需求关系与作者投影的依赖；作者类型推导的真实依赖与差异；直接编辑的版本合并与按需分析；逆向编辑与内容保留的缓存责任 等。
- [查询固定点与缓存](查询固定点与缓存.md)：增量编译、依赖与缓存正确性；快照查询与增量失效算法；程序分析查询系统与固定点引擎；编译缓存、远程执行与内容寻址存储 等。
- [性能预算与复杂度](性能预算与复杂度.md)：端到端预算的组合规则；编译器性能模型与复杂度防护；作者体量、派生体量与模型上下文；作者交互的成本合同 等。
- [复用资格与失效案例](复用资格与失效案例.md)：业务变更的设计影响与运行状态不要共用缓存资格；编译依赖与目标算法工作不是同一种增量；封装下的接口与实现失效；控制与资产变化的真实增量边界 等。
