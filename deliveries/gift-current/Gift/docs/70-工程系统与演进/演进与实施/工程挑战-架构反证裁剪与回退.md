# 架构反证、裁剪与回退

## 架构反证、裁剪与回退

### 根设计反例的可重复生成方式

从一个能成功完成的完整任务开始，固定要求、输入域、实际来源、所选实现和输出。每次只扰动一个会改变结论的关系，再检查原因能否定位到准确责任，而不是重新列行业名单。之后组合两项相关扰动，检查局部结论是否仍可组合。

| 扰动 | 必须观察到的正确设计行为 |
|---|---|
| 修改候选前置使难输入不再合法 | 原任务接受域不变，产生要求违反或新的目标变更候选 |
| 两模块类型相同、值域不相容 | 产生具体连接义务，选择明确修复而非默默Clamp/截断 |
| 两组件互相引用保证，没有初态或归纳规则 | 留下开放假设，不自证；合法递归仍可采用对应方法 |
| 删除局部较慢但布局不同的方案 | 检查支配前提，保留真实可能更优的完整路径 |
| 源数值未变，设备/布局或证据前提改变 | 值消费者可复用，预算/资格消费者重新判断 |
| 合并两个旧独立分区的新约束 | 在新图范围联合检查，不只重算一个旧分量 |
| 运行任务被取消但异步借用未结束 | 保留真实资源和恢复责任，不将取消标记当释放 |
| 新方案只通过转移费用或风险取得低分 | 保留主体和不可补偿要求，拒绝错误标量比较 |
| 更优候选不断出现 | 有范围比较与显式切换，不在活跃操作中抖动 |

反例期望分别来自已接受要求、公开方法合同或本规范的可复核推导。此表不证明全部问题已发现，也不是待执行的产品测试代码。检查原合法任务仍能结束：未知只阻断对应保证，设计、纯生成或独立根仍应得到准确结果。详细机制由其各自规范拥有，不在本篇重复字段与算法。

### 反过度设计与最小适用性

#### 最大化设计不等于最大化运行复杂度

本设计库持续扩大有机制依据的问题空间，但不声称存在已完成的最大集合。每个具体请求按已选择路线处理适用依赖；无相交影响的能力不进入运行和默认阅读路径。决定某能力“不适用”所需的选择信息本身仍可能是依赖，不能先删掉它再声称没有影响。

#### 过度设计信号

- 没有真实 consumer 的字段/服务/registry；
- 为没有真实消费者的内部临时对象创建发布流程或迁移层；持久化、跨边界交换的合同即使只有一个实现，也需要明确版本；
- 每个任务默认全仓扫描；
- 所有项目加载 browser/container/AI；
- 文档元数据反向控制产品；
- 把外部产品 topology 原样复制；
- universal helper 吞掉领域语义；
- 证明成本长期超过避免的问题；
- 未来假设占据当前 critical path。

#### 最小准入

新增机制需要真实问题、不可由已有模型表达、独立 consumer、可观察 failure、owner、生命周期和退出条件。否则采用现有 relation/binding、延后 trigger 或删除。

#### 画像裁剪

纯库、本地 CLI、团队服务、云平台、AI 运行、实时嵌入式分别选择适用领域。Core 保持相同，但 deployment 和 assurance 不同。

#### 反欠设计

最小化不能省略可达的权限、Effect、资源、恢复、数据和用户结果。简单系统不是把未知默认掉，而是有更小的真实闭包。

#### 性能证据

任何治理机制需要测量它减少的返工、事故、重复执行和认知成本；若长期净负担更高，收缩、自动化或退役。

### 未来问题发现、架构攻击与回退协议

#### ChallengeLoop

完整发现流程由[自主发现主循环](工程挑战-发现推导与覆盖.md#目标到义务的自主发现主循环)拥有。旧入口保留为导航：变化触发DISC0—DISC9，先形成设计裁决与相交修订；实现、运行验证、迁移和退役仅在实际任务另有授权时启动。发现一项缺陷本身不授权执行产品。

#### ChallengeRecord

记录预期与实际结果、参与主体、环境、因果链、潜伏条件、失效控制、二阶效应、未知、owner 映射、反证、可证伪条件和结论反转条件。

#### 回退层级

- 事实缺口：回到 Observation；
- 表达缺口：回到 Semantic Kernel/Dialect；
- 候选/约束错误：回到 Design/Resolution；
- 前像/权限错误：回到 Admission；
- 事务错误：回到 Runtime；
- 证明错误：回到 Assurance；
- 兼容/退出错误：回到 Evolution；
- 目标错误：回到 Product/Stakeholder。

不能在已失效下游末尾加例外维持旧模型。

#### 来源多样性

持续轮换真实事故、用户失败、性能、Security/Privacy、标准、论文、语言、平台、嵌入式、分布式、AI、组织、运营和成功但高成本路径，避免一个技术文化自证。

#### 停止和重开

当前 epoch 在独立搜索不再产生新机制/根约束/反转条件且 frontier 有界时关闭。新 evidence、consumer、environment 或 owner retirement 自动重开相关部分。
