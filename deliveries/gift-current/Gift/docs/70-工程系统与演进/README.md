# 工程系统与演进

从零实现 Gift 的主入口为[完整工程构造手册](工程构造手册/README.md)，包含物理构建、十职责签名、通用语言、实现选择、目标生成、客户端、现实作用、自举及领域扩展。它是**施工算法和项目装配设计**，不是另一个业界“规范目录”，也不是已运行产品的声明。

本主题维护信息生命周期、实现装配、协作状态和工程演进四组真实责任。它们经常跨因果角色，但“跨了几个角色”不决定归属；这里不是未分类信息的杂物桶。

- [信息与生命周期](信息与生命周期/README.md)：identity、configuration、provenance、retention、retrieval 与长期信息责任。
- [实现与装配](实现与装配/README.md)：Gift 自身和生成工程的物理模块/实例/接合。
- [协作与状态](协作与状态边界.md)：并行协作、状态 owner 与交接。
- [演进与实施](演进与实施/README.md)：compatibility、migration、retirement、self-hosting、实施前沿。

各责任按自身需要给出owner、状态和生命周期；相邻职责以准确接口连接。只有发现竞争owner、独立消费边界或更合理的责任划分，才调整位置；不因能贴某个单层标签就移动正文。
