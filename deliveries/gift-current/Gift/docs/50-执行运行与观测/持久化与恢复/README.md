# 持久化提交与恢复

Code-OSS 分项恢复将本章前后像与查回合同用于编辑器：模型编辑、磁盘保存及保存参与者分别结算。多模型撤销分组不提供多文件磁盘原子性；模型为意图后像而磁盘尚为前像时，只在当前守卫成立下继续保存，不重放整份替换。断电耐久性只按实际提供者能力声明。该实例不把持久队列或数据库强加给普通内存预览。

## 责任所有者

- [事务提交与不确定完成](README.md)：任务合同改变时的持久关系；事务化变更、读回与恢复；外部效果、不确定完成与权威读回；幂等授权与出站交付协议 等。
- [分布式一致性与协调](分布式一致性与协调.md)：分布式事务、消息、重试、补偿与幂等；副本收敛与全局不变量；流与并行运行的恢复切面及控制状态。
- [版本库与文件系统提交](版本库与文件系统提交.md)：分支、引用、工作树、候选与收口；文件系统无跟随能力对象与安全删除；源码写回与目标运行的边界；输入捕获必须绑定实际消费，前后相等不排除ABA。
- [迁移备份与权威恢复](迁移备份与权威恢复.md)：迁移、升级、修复与恢复事务；备份恢复与权威重新加入；受理历史、检查点代际与去重有效期。
- [持久状态与存储协议](持久状态与存储协议.md)：核心数据存储与提交协议；持久控制面与运行协调；数据库、内容寻址存储、日志与索引设计；高层变更的物理履约与参与者范围 等。

事务子合同分别由[任务意图、事务改动和持久读回](事务提交-任务合同与事务读回.md)、[外部作用、旧尝试与幂等交付](事务提交-外部效果与幂等交付.md)、[恢复状态机及发布顺序](事务提交-恢复状态机与发布顺序.md)拥有。普通纯计算不因此承担事务日志和外部作用。
