# 跨层闭合与物理索引迁移反例

本文件是可否证样本，不拥有业务/Core规范。正确处理责任由链接中的 canonical owner 担任。各测试需同时有正常正例，防止通过一律拒绝来获得假安全。

<a id="witness-schema-old-layout"></a>
## 旧SQLite布局不是自动兼容

**前像：** 有有效查询行的旧SQLite表中 `plain_text` 已改名为 `legacy_text`，meta版本也可能过旧。**错误：** `CREATE TABLE IF NOT EXISTS` 未改列，随后 `SELECT/INSERT` 报错或先删后建丢缓存。**正确：** 旧物理库完整保留，全部新源码解析合格后在一个事务内升级布局、行与代际；故意在解析阶段加入非法UTF-8时旧库仍完整。可复现局部见`sqlite-physical-schema-upgrade-rollback-and-commit`。权威：[索引](../../docs/30-实现解析/增量与性能/查询固定点与缓存.md#gift-index-migration-and-query-incarnation)。

<a id="witness-db-aba-cursor"></a>
## 数据库重生后旧游标的ABA

**前像：** 旧库 generation=1 给出第二页 cursor；删除整个库并从相同源重建，新库也 generation=1。**错误：** 只比较页号、源和generation，接受旧游标。**正确：** 原游标绑定前一库incarnation而拒绝；新的IndexGeneration和数据库物理身份不能混淆。受控同信任域校验摘要不等于可供网络多租户使用的认证。权威：[查询和索引](../../docs/30-实现解析/增量与性能/查询固定点与缓存.md#gift-index-migration-and-query-incarnation)。

<a id="witness-permission-page-epoch"></a>
## 分页间撤权与不可见行计数

**前像：** 主体A可读第1页，下一页前租户/Grant被撤销；缓存仍保存源和总行数。**错误：** 仅初次登录检查或无密钥SHA校验的游标继续向A返回第2页、总数/错误中的敏感存在性。**正确：** 每次披露前重查授权epoch、范围与源资格；失效时不返回敏感元数据，并保留历史已披露内容无法撤回的真实限制。权威：[分页](../../docs/20-语义与组合/基础语义/状态关系与流/关系查询-数据源快照与分页.md#gift-relational-cut-cursor-closure)、[客户端](../../docs/80-开发者与接口/工具协议/客户端与并行会话.md#gift-client-secure-cursor-and-epoch)。

<a id="witness-cross-file-invariant"></a>
## 两个局部CAS都通过而整体非法

**前像：** 不同作者编辑者分别修改两个文件，共同谓词要求公开API名唯一。**错误：** 两文件字节独立，两个CAS都成功就发布到同一当前目录。**正确：** 共同谓词版本成为事务读域，使用真实原子Head或拒绝/分项状态；不具可共同发布的原生读取工具只能报告部分安装及恢复。权威：[多作者保存](../../docs/10-作者与输入/作者源/工程源/作者编辑保存与迁出.md#gift-author-joint-commit-closure)。

<a id="witness-old-backup-rights"></a>
## 旧备份恢复把撤销权限复活

**前像：** 某密钥已撤销、某记录已删除，旧快照仍含明文和旧writer epoch。**错误：** 备份SHA完整就当现行可读写库，直接恢复公开服务。**正确：** 隔离检查、恢复删除前沿与Policy、栅栏旧writer、核在途Attempt，合格后才转换Head，否则 `RESTORED_FOR_INSPECTION_ONLY`。权威：[恢复](../../docs/50-执行运行与观测/持久化与恢复/迁移备份与权威恢复.md#gift-authoritative-restore-fence)。

<a id="witness-multiple-targets"></a>
## 一根完成与跨根整体完成不同

**前像：** API构建已过，worker目标缺依赖；作者只请求设计产物，没有授权部署。**错误：** API绿灯即`SUCCESS`，或者强行发起部署补完流程。**正确：** 保留API `ARTIFACT_READY`，worker `TARGET_CAPABILITY_MISSING`，多根交付总状态未完成，但不擅自部署。权威：[Target](../../docs/40-目标与制品/目标/具体降低与目标输出.md#gift-target-production-commit-closure)、[请求完成](../../docs/80-开发者与接口/需求到交付主链.md#gift-request-acceptance-closure)。

<a id="witness-billing-cancel"></a>
## 取消客户端不代表取消费用

**前像：** 远端Provider已接受按量计费任务，客户端取消时没有终态回执。**错误：** 清零预算并用新attempt重试。**正确：** 原attempt保留`OUTCOME_UNKNOWN`与负债，不超范围重复操作，等查询/对账再结算。权威：[资源](../../docs/50-执行运行与观测/权限与资源/资源核算调度与交接.md#gift-resource-escrow-and-cancel-closure)。

<a id="witness-positive-control"></a>
## 必须同时保留的正常正例

纯本地单文件、无外部Effect的函数定义修改，取得当前SourceRevision并通过真正CAS后，应能直接产生合法Target候选和确定性检查；不需要启用分布式事务、租户远程认证、持久Outbox或人工应急流程。第二次只改注释，若语义revision与真实依赖不变，缓存可复用相交语义值但仍更新作者源字节前像。若执行器为“防止任何风险”一律拒绝这个正例，则该设计实现也不合格。
