# 接缝反例研究

> **研究输入，非现行规范。** [采用、证据与保全边界](../../research/README.md#research-use-boundary)。

本目录保存**非权威、可删减、按机制组织的具体反例**，用于检查通用合同组合后是否出现身份错贴、authority 提升、阶段混同、失效遗漏、未知完成、资源/寿命错误或证据越界。它不是测试套件，也不维护稳定案例编号。

稳定机器身份只在某个真实 Requirement/Claim 被实例化后进入 ProofObligation、Verification Method、Evidence、Operation 等产品对象；研究行的名称只用于人类定位。删改或合并研究行不能直接改变产品合同，真正发现的新区别必须回写 canonical owner。

- [实现与运行反例](实现与运行反例.md)
- [信息与完成边界反例](信息与完成边界反例.md)
- [跨语言与原生反例](跨语言与原生反例.md)
- [组织与连续变化反例](组织与连续变化反例.md)
- [公共语义反例](公共语义反例.md)

选择规则：只保留能够区分两种看似都成功的实现、或能够反转合法性/恢复/Evidence 结论的构造。仅换行业名、品牌、文件名或数量而机制相同的场景不新增一行；需要产品长期执行的验证应由 ProofObligation 生成，而不是从这里按编号抄题。
