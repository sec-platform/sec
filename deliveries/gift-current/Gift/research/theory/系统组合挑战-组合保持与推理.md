# 组合、保持与推理正确性

## 组合、保持与推理正确性

<a id="challenge-a05"></a>
### fixpoint标签不提供存在性或求值算法

**问题性质：** 撤回标签式闭合；原规范已有相应责任。

**触发：** 对任意规则填least_fixpoint，并默认不断执行直到稳定。

**机制与损失：** 在U={0}上令F(X)=U\X，没有不动点，迭代在空集和全集间振荡。即使某域中不动点存在，也不自动得到有限计算过程；无限域、近似和预算另有语义。

**研究处理：** 普通目标递归可保留；证明规则/规范化规则需绑定实际语义与合格求解方法。无限循环、未证存在、资源耗尽、不支持与反证分开；需要时复用成熟逻辑内核，不让任意definition成为公理。

**边界及剩余：** Lean严格正性是其可信类型系统的一种具体纪律，不是要求Gift照搬全部依赖类型系统。

**规则归属：** [组合前提与进展闭合](../../docs/30-实现解析/组合前提与进展闭合.md)；[解释与证据接纳](../../docs/60-保证与证据/保证/解释与证据接纳.md)。

**有限构造：** 不动点振荡模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R13、R12、P02；完整来源记录见本篇末尾。

<a id="challenge-a06"></a>
### 相互条件保证不是初始事实

**问题性质：** 原仓库明确已覆盖；复算其反例。

**触发：** A保证B成立的前提是A，B保证A成立的前提是B；没有初始支持，或初始支持已撤回。

**机制与损失：** 循环图连通不证明任何节点为真。撤销种子后若只保留双向依赖，就会留下互相自证的旧结论；安全不变量也不能代替系统启动与活性。

**研究处理：** 复用C3稀疏支持、剩余分量重算和C4的有根据循环检查。初态、每个转移、环境进展和同拍代数反馈分别处理。

**边界及剩余：** 小模型重算通过不证明全部真实线程/设备模型；不为复算新增一套全局证明器。

**规则归属：** [组合前提与进展闭合](../../docs/30-实现解析/组合前提与进展闭合.md)。

**有限构造：** 无种子相互支持模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R13；完整来源记录见本篇末尾。

<a id="challenge-a10"></a>
### 逐项存在方案不等于共同存在一个方案

**问题性质：** 有限量词反例；原共同选择规则应复用。

**触发：** 对每个输入或根分别找到方法，随后宣称一个共同制品已满足全部要求。

**机制与损失：** 输入{0,1}，方法m0仅满足0、m1仅满足1。forall x exists m成立，exists m forall x不成立。运行时分派可能解决，但它是带观察、成本和接口条件的真实实现，不是交换量词。

**研究处理：** 保留共同选择的见证、适用域与阶段；允许合法分派/多制品时显式构造并验证组合；否则报告共同义务缺项。

**边界及剩余：** 本反例不意味着所有方法必须单选；分开主体的合法独立输出仍可分别成功。

**规则归属：** [组合前提与进展闭合](../../docs/30-实现解析/组合前提与进展闭合.md)；[总体设计](../../docs/00-系统与原则/总体架构.md)。

**有限构造：** 逐项存在而无共同见证模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R13、R04；完整来源记录见本篇末尾。

<a id="challenge-a12"></a>
### 单运行细化不自动保持跨运行安全

**问题性质：** 原规范明确已覆盖；复算已有反例。

**触发：** 源对每个秘密h允许输出{0,1}，目标返回h。

**机制与损失：** 每个h下目标输出集合都是源的子集，但h=0和h=1的公开观察可区分。一般输出集合包含检查不能签发所有非干扰或隐私保证。

**研究处理：** 沿原Claim固定观察与跨运行关系，匹配相应保持方法。常量目标可保持这里的可能性非干扰，但不满足独立公平随机的更强要求。

**边界及剩余：** 这只是明确给出的可能性模型；强线性化等成果也只能在其准确模型下复用。

**规则归属：** [性质保持与开放环境](../../docs/30-实现解析/性质保持与开放环境.md)。

**有限构造：** 单运行细化但跨运行泄漏模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R11、P05；完整来源记录见本篇末尾。

<a id="challenge-a13"></a>
### 边际、联合分布、复现和调度不同

**问题性质：** 原规范明确已覆盖；精确分数复算。

**触发：** 将两个独立随机调用缓存成一次抽样并重复返回，或用固定seed通过代替分布保持。

**机制与损失：** 独立(A,B)与(R,R)每项都公平，但相等概率从1/2变成1。非确定选择不等于概率，调度者是否可见秘密/未来随机值也会改变保证。

**研究处理：** 按数值/随机合同保留样本身份、联合结构和允许耦合；方法选择和缓存自身也进入被要求的观察范围。

**边界及剩余：** 没有统计采样或概率编译器测试；这里是四个结果上的精确枚举。

**规则归属：** [性质保持与开放环境](../../docs/30-实现解析/性质保持与开放环境.md)。

**有限构造：** 相同边际而联合分布改变模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R11；完整来源记录见本篇末尾。

<a id="challenge-a14"></a>
### 保持证明不能自行选择一个过弱的观察

**问题性质：** 原规范明确已覆盖。

**触发：** 原要求关心时间/日志/设备写，但证明只投影最终返回值。

**机制与损失：** 投影删除了义务所关心的信息，得到的等价不能回填成原保证；有证明的编译器也有明确阶段和观察边界。

**研究处理：** 观察由独立要求和合格域解释固定；lowering回执只列实际保持的Claim，资源/时限/安全各取对应证据。

**边界及剩余：** CompCert手册不把执行时间和内存消耗纳入该观察定理；这不削弱它在已证明范围中的价值。

**规则归属：** [性质保持与开放环境](../../docs/30-实现解析/性质保持与开放环境.md)；[解释与证据接纳](../../docs/60-保证与证据/保证/解释与证据接纳.md)。

**研究依据：** R11、R12、P03；完整来源记录见本篇末尾。

<a id="challenge-a15"></a>
### 实现和证明器一起使用错误编码仍会一致

**问题性质：** 原规范明确已覆盖；复算已有反例。

**触发：** 原要求是数学整数加法，候选与检查器同时用有符号64位回绕。

**机制与损失：** 对2^63-1加1，两者可共同输出-2^63并互相“验证”，但真实要求是2^63。两个后端一致、自编译固定点或签名都不消除共同模型错误。

**研究处理：** 原要求、语义解释、公式映射、候选与验证依据分别保留来源；缺少关键输入时保留相交义务，不让实现者改掉唯一判据。

**边界及剩余：** 例子不说明当前Gift已产生该错误；也不要求清楚的普通函数额外复制一份需求文档。

**规则归属：** [解释与证据接纳](../../docs/60-保证与证据/保证/解释与证据接纳.md)。

**有限构造：** 实现与检查器共享错误编码模型；仅可支持对应模型，不证明产品实现。

**研究依据：** R12；完整来源记录见本篇末尾。

<a id="challenge-a17"></a>
### 隔离任意检查器不等于获得可信逻辑

**问题性质：** 原规范明确已覆盖。

**触发：** 无I/O、确定执行、签名齐全的检查器总返回true；或把未经核验公理重命名为definition。

**机制与损失：** 宿主隔离保护资源与权限，不保证推理规则健全。源到公式映射、理论、公理、检查器和实际选项都是某项Claim的可信依赖。

**研究处理：** 复用EVID0—EVID7；建立材料资格、执行资格、逻辑支持与任务采用的分界。允许有条件信任，不能把信任写成已完成的形式证明。

**边界及剩余：** 证明可用性与业务适合性不同；原研究没有独立重证第三方证明器。

**规则归属：** [解释与证据接纳](../../docs/60-保证与证据/保证/解释与证据接纳.md)。

**研究依据：** R12、P02；完整来源记录见本篇末尾。

<a id="challenge-a19"></a>
### 跨理论同签名不代表可组合

**问题性质：** 原规范已有防线；扩展消费义务。

**触发：** 把不同域的Int、引用、时间、关系或“相同”运算按同名签名接起来。

**机制与损失：** 数学整数和位向量、集合和多重集、值相等和对象身份、逻辑时间和物理时钟不同；单个部件正确不提供桥接的保持定理。直接把两组公理相加还可能改变原结论。

**研究处理：** 通过版本化接口固定值域、单位、别名、效果、观察与误差；转换本身产生准确义务。能保全不等于能转换，无法证明只限制相交用途。

**边界及剩余：** 不为所有潜在理论组合预先建立全球求解器；按真实被选边界处理。

**规则归属：** [语义扩展与外部定义接合](../../docs/20-语义与组合/组合/语义扩展与定义接合.md)；[组合前提与进展闭合](../../docs/30-实现解析/组合前提与进展闭合.md)。

**研究依据：** R09、R13；完整来源记录见本篇末尾。
