## 大型现有工程的固定源码证据

### Code-OSS 搜索、替换预览、模型编辑与保存

**记录日期：** 2026-09-10。固定源码为 `microsoft/vscode` commit `3e078a39dc95d262123da38f916225a126fb1ccf`，提交时间 2026-09-09 16:47:47 UTC；它是源码快照，不代表最新发行号、本地安装版本或未来行为。

<a id="source-evidence"></a>
**原始定位与实际读取范围：**

| 来源 | 实际读取 | 直接支持的事实及设计用途 |
|---|---|---|
| [S1 `searchModel.ts`][k1] | 120—320 | `search` 取消原搜索、建立查询和替换模式；`doSearch` 组合普通文本和笔记本的同步/异步结果。用于区分搜索请求代与异步工作寿命。 |
| [S2 `searchService.ts`][k2] | 前部至 `searchWithProviders`；450—文件末尾 | 已打开模型先搜索；Provider 按 scheme 分派；模型零命中也写入占位，使磁盘进度不能覆盖它。用于打开缓冲优先、身份与范围覆盖。 |
| [S3 `fileMatch.ts`][k3] | 100—280 | 模型变更调度命中刷新；移除命中保留排除记录；单命中替换经队列再刷新。说明事件刷新不是提交前版本校验。 |
| [S4 `match.ts`][k4] | 全文件 | 搜索位置转编辑器位置时加一；替换字符串经过完整命中、CRLF 归一、周边上下文等路径，仍可能采用回退模式。不能只拿截短展示串计算替换。 |
| [S5 `replaceService.ts`][k5] | 全文件 | 预览克隆源模型并在独立模型中应用编辑；真实替换先 `bulkEditorService.apply`，随后分别保存文本或笔记本；`createEdit` 在该调用处未填 `versionId`。 |
| [S6 `bulkTextEdits.ts`][k6] | 全文件，分段读取 | 可按版本核模型；未给版本时该门槛不生效；多模型逐任务编辑并共用撤销分组。分组撤销不等于多文件磁盘事务。 |
| [S7 `ripgrepTextSearchEngine.ts`][k7] | 1—160 | 本地路径启动 ripgrep、报告进度、命中上限后取消；取消请求与进程 `close` 分开。用于真实停止和资源结算。 |
| [S8 `searchResult.ts`][k8] | 1—190 | 批量替换处理父/子重复选择并调度实际对象；批量移除是结果树操作，不能解释为删除文件。 |
| [S9 `textSearchHeading.ts`][k9] | 1—215 | 根目录/其他资源分组、URI 身份比较、旧结果清理及查询变化。用于多根和结果集合生命周期。 |
| [S10 `searchActionsRemoveReplace.ts`][k10] | 全文件，1—230 与 225—末尾 | 单项/文件/文件夹动作共用 `performReplace`，取得当前选择后调用 `batchReplace`；随后刷新树、处理焦点并按配置打开文件或替换预览。用于保留真实动作入口与可访问性行为。 |

以上十项不是完整安全审计，也没有证明整仓、全部工作区/视图入口、完整构建或测试闭包已经取得。尤其不能仅由 `createEdit` 未填版本推断整个产品已发生数据损坏；模型更新、其他入口与目标保存策略都可能改变可达性。能直接支持的是：新增强版本保证不能只依赖下游存在可选检查，必须证明实际调用提供并消费该前提；同理，Promise 完成、命中树消失或模型变为 clean 都不能单独证明磁盘字节仍与先前预览相同。

**当前采用与排除推论：** Gift 可以复用真实搜索、模型、差异、撤销与保存服务，同时在需要更强保证的路径增加准确计划、版本/范围和分项恢复接缝。源码观察不证明已发生缺陷、整产品安全性、跨文件事务、任意宿主等价、断电耐久性或 Gift 实现完成；冻结计划及强模式是 Gift 的设计选择，不误归为上游承诺。换上游 revision、修改 Provider/保存参与者或新增相交消费者时重核对应命题。

**使用与维护位置：** 本页拥有这组固定源码坐标与证据边界，不拥有 Gift 产品合同。共同要求分别由[物理职责][k11]、[恢复][k12]、[保证][k13]及相交客户端规范拥有；尚未闭合的实际前沿由[状态入口][k14]汇总。没有因此引入新的公共工具或统一替换平台。
