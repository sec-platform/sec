# 实验测量、联合仿真与现实耦合（压力参考）

本页是非权威领域研究压力参考，不把实验系统、联合仿真器、数字孪生或设备控制作为 Gift Core 的默认业务能力。具体模型、仪器、控制律与行业政策由作者/库/Provider 定义；公共执行、权限、Evidence 和定量合同仍由各自通用 owner 拥有。

本页聚合仿真与测量、实验、外部仿真器及现实控制之间的边界。测量校准与联合/现实耦合共享外部观察和作用接口，但证据、同步和控制责任分别保留。

## 测量、校准与实验解释

本压力样本固定仿真/科学计算消费测量、估计与实验时需要检查的区别，不取得这些业务规则的 Core ownership。数据身份来自原信息模型，当前读取/释放/设备作用由原执行层承担；一般 Claim 和证据接纳不在此重复定义，具体实验设计由作者/语义方法拥有。

<a id="measurement-calibration-identifiability"></a>
### 测量、校准、可识别性与模型适用域

测量至少连接被测量、设备/方法、单位/参考框架、量程、采样与时间、校准修订、缺失/饱和/异常状态及适用的不确定性说明。测量值和对真值的估计分开；设备标称精度不自动覆盖安装、环境、处理算法或当前校准漂移。

区分随机波动、系统偏差、参数不确定、模型不足、数值离散误差和观察缺口。它们可能相关、非对称、非高斯或没有可靠分布。报告“95%区间”必须有方法与对象，不得把参数后验区间、重复采样置信区间、预测区间和工程安全界混用；资料不足时使用范围/候选/未知，而不编造概率。

估计模型参数之前，先检查观测能否区分参数或状态。例如两个参数只以和出现时，仅凭这个输出无法分别确定它们；优化器返回一组数值不证明唯一可识别。可以加有依据先验、增加测量、固定一项或保留等价解族，但不能把正则化选择当现实真值。

校准数据、模型拟合数据、验证数据和实际用途数据分别管理。用同一批样本反复调模型再评测容易把拟合当泛化；重用场景、共同数据源和共同参考实现不构成独立证据。改变校准、观测映射或用途，会使相交模型资格失效，即使源代码没有变。

数字孪生的观测状态、估计状态、预测状态与实际物体仍是独立对象。发生传感丢失时，模型可以继续给条件预测，但必须显示适用边界与不确定增长，不维持原“实时已知”标签。工况超出已验证域时可请求新证据、转低资格模型或停止依赖该预测的高风险动作。

**适用范围：**模型、参数、观测和现实用途分别有身份与资格。

**重新检查条件：**校准、测量布局、模型结构、数据分布、验证目的或实际使用环境改变。

<a id="experiment-selection-and-cumulative-effects"></a>
### 实验、因果、学习与累计风险预算

实验输入包括研究问题、估计目标、总体与样本、干预/观察方式、比较基线、随机分配或随机流、重复与停止规则、测量方式和允许作用。模型参数搜索、性能调优、A/B实验和临床研究不共享同一权限或证据模型；纯离线仿真也不自动具有现实因果解释。

自适应地看结果再改参数、选择子群、决定何时停止，改变了统计推断的条件。方法应预先声明或准确记录这种选择，并使用适用的调整或独立验证；不能只展示最佳run和成功完成者，删除负结果、失败轨迹与未完成样本。共同训练数据或同源生成器要计入证据依赖，不能因有多个模型就自动视为独立支持。

优化目标由作者接受：误差、延迟、资源、成本、隐私、可维护性和公平要求常互相约束。硬条件先保持；软偏好无明确权重则保留多种可行取舍。不存在依据时不能宣布唯一全局最佳；预算内最优、某成本模型最优和实际使用效果最优分别表述。优化器若修改了任务或基线，结果不再是原问题的改进。

涉及个人数据或实际资源的重复实验可能累计披露、费用、设备损耗和参与者负担。重启会话、回滚模型或换一个实验ID不会撤回已发生的消耗。对应预算归真实主体与已执行作用管理，不能藏在可重放仿真快照内。跨项目的共同数据、同一参与者或同一设备，按适用责任合并核算，不按界面数量拆开逃避。

ML目标继续使用真实训练/推理供给、数据与权重身份、特征版本和评测范围；Gift的正式编译解释不由模型自由补完。漂移触发的是相交资格重评和受控新候选，不允许在线学习静默改写已接受需求、权限和安全包络。

**适用范围：**计算设计不代替参与者授权、专业责任或未取得的现实数据。

**重新检查条件：**样本、选择/停止机制、估计目标、模型更新政策或累计风险主体变化。

验收的具体触发与观察见[全域接合检查][k1]；这里定义机制与条件，不签发任何实现、执行或现场合格状态。

### 差异压力：仪器读回不是理论模型的独立真值

实验仪器的校准模型、数据清洗、数值估计可能与被验证模拟共享同一错误假设；多个输出一致不保证它们独立。为了对比新旧模型，应固定实验装置、温度、采样率、测量不确定性与延迟，在真实观测缺失时保留尚待实测而不是默认为吻合。

**对应公共合同（本页不取得定义权）：** [关联证据、Oracle来源与共同失败不重复计票](../../../../docs/60-保证与证据/验收/方法与独立证据-独立性可信基础与求解.md#gift-proof-independence)；[跨版本证据重用的有效性与被遮蔽失败](../../../../docs/60-保证与证据/保证/解释与证据接纳.md#gift-evidence-time-reuse)。本段是条件情景和可反驳的预期，不是已执行的产品测试。

## 联合仿真与现实控制

联合模型结果、参数估计、影子运行和真实控制是不同用途。仿真部分由实际模型/方法实现；真实操作仍进入原[执行与结算协议][k2]，时限由原[资源与准入][k3]承担，不新建设备权限入口。

<a id="cosimulation-coupling"></a>
### 联合仿真的耦合、守恒与误差闭环

联合仿真连接需明确每条边交换的是状态、流量、势量、累计量、事件还是控制命令，单位、方向与参考框架各自固定。力与速度的相容配对可以表示机械功率；热流率积分才对应交换热量，温度通常进入本构/边界条件，不能将温度与热流率的乘积冒充功率。交换方向、面积及符号必须与具体接口一致，不能只因两个值都是float就相连。守恒应检查正确的物理总量与边界通量，而非要求每个中间数值都不变。

主算法固定通信点、输入保持/插值、事件同步、代数依赖、收敛判据、拒步与回滚路线。存在代数环时，只有有实际可迭代接口、收敛依据和状态恢复，才允许重复步或求不动点。一个子模型不能回滚却被当可回滚求解器调用，会产生静默错误；可选非迭代路线需要原任务接受其误差，不能无条件替换。

误差验收不只有单体求解器的容差，还要考虑采样、通信、耦合延迟、插值、离散化、参数和模型误差。至少通过相交的通信步/网格变化、守恒残差和独立小例检查；有强非线性、刚性或不连续切换时不能直接外推平滑区间的误差界。某些稳定性条件依赖耦合步，改并行调度也可能改变它。

多尺度模型应显式说明快慢变量交换与平均化前提。低保真代理替换高保真模型时，适用域、边界行为、罕见事件和置信/误差资格必须随路线带入；代理在已知数据上准确，不证明对新工况安全。动态切换保真度必须迁移模型状态，并重评控制/优化消费者的假设。

实验失败应保留最后接受步、每个模型的准确状态切面、拒绝原因、资源消耗与可恢复范围。不能把一个求解器的终态同另一个的旧中间态混成“联合结果”。分项成果仍可用于诊断，但整体用途保持未通过。

**适用范围：**耦合算法是实际方法，不由接口标准或命名推得。

**重新检查条件：**耦合拓扑、通信步、同步方式、状态映射或代理域改变。

<a id="real-control-response-boundary"></a>
### 真实控制、运行假设监测与安全响应期限

将离线模型接到真实控制之前，需要区分模型内可测试假设、在线可观察假设和无法及时观察的现实条件。监测器可以发现某些条件不再成立，但不能因此宣称全部模型前提实时成立。未测量的状态、传感盲区和数据延迟保持未知，不能由模型预测代填。

对需要在危害发生前响应的保护，必须有检测延迟、传输与调度、动作完成时间及剩余安全裕度的有依据界。设这些真实上界合计为τr，当前模型支持的最早失控时间下界为τh；只有原条件下τr小于τh且保护动作本身有效，才可能支撑该及时性要求。这个条件不是通用安全证明：边界模型、故障检测和执行器失效仍需独立依据。没有这些界就只能提供监控功能，不能承诺硬实时防护。

当前授权、设备身份、配置和安全互锁在真实执行入口检查，探索性仿真与影子模式不得持有能产生现场动作的能力。控制任务错过期限时不能默认补跑所有过期输出；按项目合同丢弃、保持、受控降级或转交安全控制。设备停止、保持扭矩、释放制动和持续冷却是不同动作，不能统一为一个stop布尔。

运行时适应只在已接受的包络内切换：允许替代方法、观测前提、状态迁移、资源、deadline和退出路径必须同时具备。选择器本身有错误/延迟与权限，不能因被称为“智能”就越过原约束。迁移失败时保留旧可用路线或进入准确降级，不在新旧控制同时活跃时制造双写。

监测与动作可能共享电源、网络或传感器；保护系统也需要故障域分析。人工接管需要真实可理解的信息、足够时间、可用操作员和接管资格；一条告警已发送不等于人已完成接管。

**适用范围：**具体危害边界、专业模型、硬件时序和安全态由项目及适当主体确定。

**重新检查条件：**控制域、环境、传感时效、保护动作、实时上界或接管组织条件改变。

验收的具体触发与观察见[全域接合检查][k1]；这里定义机制与条件，不签发任何实现、执行或现场合格状态。
