# 仿真压力参考

> **研究输入，非现行规范。** [采用、证据与保全边界](../../../README.md#research-use-boundary)。

本目录是**非权威仿真研究材料**，不是 Assurance 套件，也不是 Gift 内置 Simulator、科学计算产品线或标准业务库；它保存由用户/领域库可以定义的高耦合实例，用于发现公共时间、状态、数值、Provider、现实作用与 Evidence 接缝中的潜在区别。只有被提炼并绑定公共合同的区别见证才可进入 Assurance；下面的仿真名词和模型族本身不取得 Core 或 Assurance authority。

模型、场景、推进方法、时间、资源、观察、实验及现实接口分别承担自己的责任。统一的是准确输入、绑定、接合、输出与证据，不是一套固定行业 Simulator。以下是**压力参考与检查问题**；这些内容按挑战/区别/失败边界组织，不形成可直接部署的 Simulator 方案；真正的公共规范 authority 仍在链接到的通用 owner，具体领域模型由作者/库拥有，实际实现和支持资格另按原保证记录取得。
