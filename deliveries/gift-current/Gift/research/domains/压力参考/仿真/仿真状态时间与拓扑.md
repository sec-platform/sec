# 仿真状态、时间与拓扑演进（压力参考）

本页是非权威领域研究压力参考，不定义 Gift 内置仿真运行时。具体模型、推进器、求解器和拓扑规则由作者工程/库/Provider 拥有；本页只用这些差异检验通用状态、时间、恢复、效果和证据合同。

本页聚合仿真世界内部随时间推进的状态、恢复、接触历史与拓扑演进。两个合同共享同一仿真状态闭包，但时间恢复与历史/拓扑语义仍保留独立稳定单元。

## 仿真时间推进与状态恢复

模型、场景、时间、方法、资源、观察与现实效果分别拥有状态。本压力样本把[计算结构与算法][k1]的通用计算合同放进仿真场景检验；事件、方程和随机方法仍由具体业务/库/Provider定义，统一编译器不成为万能仿真运行时。

<a id="simulation-progress-and-checkpoints"></a>
### 仿真内核族、时间推进与并行事件提交

仿真最小可消费边界包括模型/场景、初态与边界、输入输出、时间和事件语义、状态拥有者、推进方法、停止条件、观察、错误与恢复资格。数值积分、事件日历、约束求解、状态空间探索和群体更新分别拥有具体进展规则。统一实验组织可以安排它们，但不能替它们决定一个步长或一条更新顺序。

连续求解器需区分接受步、拒绝步、事件定位、模型终止与数值失败；离散事件需区分时间、阶段与同刻优先；同步离散系统明确旧值同步更新还是顺序更新；非因果方程先由合格方法得到因果计算安排，不能按源码排列替代求解。未取得一致初态时保留失败，不把所有变量设0。

并行离散事件有保守推进与乐观推进两种实际路线。保守路线需要已知不会有更早事件到达的安全前沿及进展条件；乐观路线需要可恢复状态、消息撤回或等价协议、真实全局提交前沿和足够历史预算。没有这些能力就不能因可并行而宣称可回滚。未提交模拟事件不得触发真实设备/资金；历史回收不能越过仍可能收到回溯事件的范围。

每次检查点区分进程局部句柄、可序列化模型状态、求解器内部历史、随机流、事件日历、通信消息和外部世界的已提交效果。序列化必须绑定格式/方法/模型修订；单纯保存可见变量可能不足。FMI 3.0.2明确将延迟缓冲及内部状态纳入完整FMU状态，并由实际支持能力控制取/设/序列化；其同一实例函数也不默认线程安全。[Functional Mock-up Interface 3.0.2][k2]

实验可以在不同核数和分区下运行；若承诺位级重放则排序、归约、随机和事件竞争都需满足相同观察合同；若只承诺统计一致性，应按对应分布与误差检验。不能将因分区引入的人工顺序效应解释成被研究系统的真实规律。

**适用范围：**接口投影沿现有方法与资源合同，不新建所有项目必须加载的Simulator。

**重新检查条件：**模型事件语义、并行策略、通信前沿、内部状态可恢复性或确定性要求改变。

验收的具体触发与观察见[全域接合检查][k3]；这里定义机制与条件，不签发任何实现、执行或现场合格状态。

### 差异压力：拓扑变化不只使邻接索引过期

空间边界重网格化可以改变单元身份、连接与时间进展；旧cache即使保留相同数值，也必须证明拓扑关系和相关边界条件没有变化。某子模型返回“这个窗口已算完”不能自动消除跨边界迟到消息或物理设备尚未结算的作用。

## 模型历史、接触与拓扑演进

本压力样本固定仿真模型历史与结构演进时必须被检验的区别；基本值、时间、微分规则继续由原[自动微分与线性化][k4]及对象身份规范拥有，具体领域规则仍由作者定义。求解器可以复用成熟供给，以下条件不是要求作者重写求解器，也不成为新的 Core owner。

<a id="history-contact-topology"></a>
### 记忆、延迟、接触、拓扑变化与不光滑模型

**延迟与记忆模型**不只依赖当前状态。延迟微分、历史核或分数阶等模型需要初始历史区间、记忆截断/压缩策略、插值、历史误差及检查点格式。重新启动时只有`x(t)`通常不足以继续同一问题；未经接受截断过去会改变模型。对无法承受无限记忆的任务，明确有限时域、近似或外存路线与误差，不假称任意精度。

**接触与互补约束**包含非穿透、力/速度符号、激活集合和切换；不同摩擦/碰撞模型不是同一力函数调参。方法应声明冲击、能量处理、约束稳定、容差及无解/多解边界。迭代残差低不证明物理接触选择正确；为了终止偷偷允许穿透会改变任务。可视化平滑也不是接触精度保证。

**移动网格、断裂、相变与拓扑变化**需要把几何、离散自由度、材料历史和观察映射一起迁移。新网格不只改数组大小：守恒量如何投影、哪些误差引入、旧实体如何对应、过去指标是否仍可比较都须明确。材料损伤与塑性历史不能在重划网格后恢复为新材料；物理不可逆性不随模拟检查点复位而在现实消失。

**不光滑或离散事件的微分**需要明确梯度究竟针对哪个模型和变量。自动微分程序得到的导数、连续方程的敏感度、离散化后目标的梯度以及经过替代光滑模型的梯度，可能不同。接触切换点可能不可微；有限差分也受步长、数值误差和分支切换影响。可以提供分段、广义/近似、随机估计或无梯度方法的合格路线，但不统一包装为“精确梯度”。

这些模型仍通过普通数据、时间、关系、资源、来源与验证接口组合。真正新增的业务内容归作者定义/领域库，编译内核只要求所选方法暴露足够的公共合同并履行目标要求。具体求解方法的选择与真实性能必须由所选问题和实现证据决定。

**适用范围：**是现有仿真族的具体子合同，不按每个术语新增核心能力枚举。

**重新检查条件：**模型记忆、网格拓扑、接触规律或所求导数定义改变。

验收的具体触发与观察见[全域接合检查][k3]；这里定义机制与条件，不签发任何实现、执行或现场合格状态。
