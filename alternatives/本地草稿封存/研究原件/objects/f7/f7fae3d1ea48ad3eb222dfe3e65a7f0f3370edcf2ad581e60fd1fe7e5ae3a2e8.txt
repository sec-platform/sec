## 使用方式

首先打开`Gift_统一多维结构工作台.html`。完整内容已嵌入，不需要网络或服务器。直接file://导航在本次环境被策略阻止，界面测试采用同一HTML内容载入；未冒称本地文件地址已测试。浏览器需支持DecompressionStream/gzip，不能使用时可直接阅读docs或JSON/SQLite。

在本目录执行：

```sh
python tools/check_all.py
python tools/build.py
python tools/make_ui.py
```

构建与参考检查不会运行原仓库代码或访问外部系统。独立Schema复核使用已安装的jsonschema时启用；浏览器检查需Playwright及Chromium。
