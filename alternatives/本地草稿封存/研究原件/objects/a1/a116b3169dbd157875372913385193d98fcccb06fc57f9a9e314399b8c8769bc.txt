## 1. 本轮实质：让不同理论对同一任务给出能合用的结果

上一轮把纯完成步、共同要求、选择时点、策略进展和后继修改接起来了。它已经明确：概率、连续、规范、知识、因果、跨运行性质不能不加解释地变成那个完成关系。本轮处理这个实际缺口：不是再列一批概念，而是把这些专业内容通过有具体构造和方向的桥接到同一个任务。

这里的“统一”取得的是一种共同工作方式：每种内容保留准确的原解释；需要跨域时，交付确切的映射、前提和可取得的结论；所有结论最终指向同一个候选、同一原要求和相容的观察范围。不同数学理论不因都能编码成JSON或图而自动同义。对用户而言，仍可以只提出要求和必要选择；公共字段、专业模型和证明条件由系统按准确已有定义取得，不能把本报告的数学记法变成每个人的新问卷。

本轮给出一般的有条件推导，也给出有限参考计算和一个完整的共同候选选择。后者是数学研究程序，不是Gift产品、传感器控制器、因果实验或授权系统。所有实测范围单独列明。

## 3. 同一任务的多种解释，必须由同一个见证承接

对一个固定任务，可以用数学记号写出其共同候选域Ω。Ω不是“全世界数据库”，只是本次确切的程序/策略、配置、环境解释和需要的对象对应。每个专业视图有一个在适用范围内定义的投影或关系映像 `v_i`，以及它自己的满足关系 `⊨_i`。

当视图能用函数表示时，共同合格集合为：

```
Accept = { w ∈ Ω : 每个所需 v_i(w) 都有资格定义，且 v_i(w) ⊨_i φ_i }。
```

函数不足时保留关系映像及其共同见证，不能任选方便目标。原要求中对合法输入、环境和历史的量词须在各φ_i中保持；共同候选不能为自己挑选一个友好环境、删掉其他原先承诺的环境。这个式子只是判断的数学组织，不强迫所有专业结果存入一类对象。

必须同时保留三个区分：

**同一实现。** “有p满足时序、有q满足概率、有r符合资源”不构成一个共同实现。所选方法、守卫、调度、适配和真实输出全部属于被比较候选。

**同一环境基础。** 一个分析以正常电源为前提，另一个以独立备用电源为前提，不能自动说明现场两者同时成立。共享时钟、随机源、资源、角色和接受来源都要对齐。

**缺解释不同于冲突。** 某视图未定义或前提未取得时，当前Accept尚不能按所需语义求值；不能把缺解释当空集，也不能把缺项当true。只有取得相应完整依据后，才可报告该范围不可满足。

这让普通图、关系表、公式、状态机、分布、原文及实际记录能够共同进入一个任务；它不要求世界本体只有一种数学对象。

## 4. 第一种桥：准确解释、单向保证和保守近似

### 4.1 完整翻译需要实际的对应，不仅是接口签名

设源内容为S，目标专业表示为A。一个桥需要给出：源/目标主体和解释版本；对象和角色映射；表达翻译；前提；明确观察范围；结论方向；真正取得结果的方法。已由原上下文确定的信息可以引用，不在每个值上重复。

准确翻译的一个形式是：对于适用模型和赋值，

```
m ⊨_S φ  ⇔  F(m) ⊨_A τ(φ)。
```

实际运用中常常只能取得一个方向。例如 `F(m)⊨τ(φ) ⇒ m⊨φ` 可以搬运正面保证，但不自动允许把目标反例搬回源世界。若另有可提升的具体反例，它可以通过另一条桥传递。桥的两个方向可以有不同方法和不同代价。

Institution理论把模型、语句和满足的一致翻译作为组织大规格的基础；同一逻辑中的签名重命名，与跨不同逻辑的翻译仍要分开。[INST] 本稿使用的是上面的实际保持命题，不把它冒称已经构成一个全域Institution实现。

### 4.2 桥的组合定理

若B1在前提A1下把目标证明ψ的效力传回源命题φ，B2在A2下把更下游证明χ传回同一ψ，那么只有在下列条件共同成立时，二者才能组合：

- 中间ψ的符号、主体、时间、变量绑定和解释确为同一个；
- 两桥要求的模型对应能同时建立；
- A1与A2在当前共同输入下取得，且未循环借用待证结论；
- 第二桥没有丢掉第一桥需要的观察、量词、时间、错误或相关性。

证明是两次有条件蕴含的接续。它不是“沿任意有关联路径传递true”。如果有两条路线得到不同范围或强度，保留各自结论与前提；无法证明同义时不按搜索先后择一覆盖。

### 4.3 上下近似给出正向判断规则

在同一个已固定且非空的具体可能集合C上，取得 `L ⊆ C ⊆ U`。L为已经具有具体资格的可实现情形，U覆盖全部可能；判断性质P时：

| 目的 | 足够的依据 | 未得到时的意义 |
|---|---|---|
| 证明全部情况满足P | U的每个成员都满足P | U内的坏点可能是抽象造成，不能直接说实际违规 |
| 反驳全部满足P | L中取得一个不满足P的成员 | L没找到坏点不证明安全 |
| 证明存在满足P的情况 | L中取得一个满足P的成员 | U内有满足点不保证它能具体实现 |
| 证明不存在满足P的情况 | U中没有任何满足P的成员 | 部分搜索没有找到不够 |

这些是集合包含的直接推论。C本身不存在或模型前提冲突时，经典全称命题可空真，但不能据此取得有实际输入/结果要求的功能资格。本稿的自动例程先检查这项用途需要的基础，不否认纯逻辑中的空真。

例如实际C={−1,1}，上近似U={−1,0,1}，性质x²=1：上近似中的0不是实际反例；欠近似只取得{−1}时，未找到+1也不能否认它存在。

这一桥把概念“粗而快”和“精而慢”变成具体可用的判断方向。抽象解释提供这种保守推导的成熟理论，代价是精度和未决，不能用样本全绿替代。[AI]

## 5. 第二种桥：多个抽象如何互相补足，而不互相自证

U1090的约化积不只是把两份报告并排放置。设两个抽象的共同具体含义是：

```
γ(a,b) = γ₁(a) ∩ γ₂(b)。
```

一个约化步骤ρ若满足 `γ(ρ(a,b))=γ(a,b)`，便可以收紧内部表示而不增加或删除真实允许的情况。

例：整数区间[0,3]与“偶数”共同使用，可把区间收紧为[0,2]，交集仍为{0,2}。这与用一个域的可靠信息改善另一个域的精度相符。[AI]

正向工作方式是：取得准确公共变量及其单位；各域在共同前提上产生保证；只用已成立保证执行保持共同含义的约化；在规则适用处迭代。有限域上单调细化可终止；无限域需要实际求解、加宽/收窄或其他收敛方法。

两份报告互相引用不能补出没有基础的事实。若一个域不健全或前提在另一时刻成立，相交后甚至可能排除真实世界。若交集为空，要定位不相容的输入、模型或证据；不能以“没有坏情况”取得成功。

这条桥可以复用在类型约束＋范围分析、时间界＋资源计划、路径可行性＋权限模型等地方。但具体的γ和约化保持需要每个专业模型自行提供，不把所有域强制改写为整数区间。

## 6. 第三种桥：把抽象策略落实成遵守真实观察的动作

上一轮已有有限观察策略与共同秩。这里补上“模型中选到一个动作以后，如何传给更具体系统”。

设当前维护的抽象状态a可以从合法观察历史得到；B是这段历史仍允许的具体状态集合。抽象策略选动作α。动作适配器必须由**当时实际可用的历史**取得同一个具体动作u，而不能对B内隐藏状态分别挑选。

充分条件为：

1. u在B中的每个可能具体状态都启用，且获得实际能力与作用许可是独立义务。
2. 每个允许具体后继c′都能映到抽象后继；更强地，后继抽象记忆 `a′=η(a,α,obs(c′))` 能由新合法观察确定。
3. 对同一个观察结果，η不偷偷读取隐藏c′来换一个更有利的a′。
4. 相应公开观察、资源和误差的映像保持；抽象安全条件蕴含原目标安全。

安全保持证明按步归纳：当前相容，实际动作所有后继仍相容，抽象后继安全因而具体也安全。若要搬运完成秩，需要进一步保证一次抽象推进确会在有限实际步骤内完成，或内部停顿有独立良基依据；不能将无限内部等待隐藏掉。

这是一项可实现的动作/记忆接合，而不只是状态图模拟。若B中两个隐藏状态分别只能left/right，且没有一个动作共同启用，不能生成读不到隐藏状态的分派。新增一个真正可用、在截止前到达的sense操作可能改变问题；在模型里加一个观察字段不等于得到设备和权限。

本节是给定充分条件的书面证明，不声称已解决所有部分观察随机博弈。更广目标继续用专业方法。

## 7. 第四种桥：概率顺序、相关性、比较耦合与整次风险

### 7.1 以条件核组成程序，而不是默认每次独立

对有限明确状态，K(x,y)给第一阶段分布，L(y,z)给**在完整中间状态y下**的后继条件分布：

```
(K;L)(x,z)=Σ_y K(x,y)L(y,z)。
```

归一化与结合律由有限求和次序得到。这个式子不要求两个阶段无条件独立；它要求y确实保留决定后继分布的有关记忆或上下文。如果第二阶段还依赖未记录的共享随机种子U，仅凭可见y的一般分布不能套用当前核；要扩充状态或按历史条件化。

缺失概率质量不能静默重新归一化。发散、失败、拒绝等可以作为已解释结果或次概率语义保留；只有在任务确实询问“已成功条件下的结果”时，才可做对应条件化。本轮数值程序只使用明确归一化的有限分布，质量不等于1就拒绝输入。

### 7.2 相同边际，不提供真实联合；证明耦合也不是物理相关

同一Bernoulli失效源U以0.1概率失败，两次调用都受U支配时，两次都失败仍为0.1。若有合格的独立性，才得到0.01。仅有两个“失败率10%”不能取乘积。

概率耦合用于比较两个分布：π(x,y)的两侧边际必须分别为p和q。它可以是为证明特意构造的共同空间，而不必是现实系统的同时运行机制。用这个比较见证证明两个程序结果接近，不意味着它们实际共享随机数。[COUPLE]

### 7.3 两条概率桥可以真正粘合

设π比较p与q，ρ比较同一个q与r；所有状态有限，且q的身份、值解释和概率完全一致。构造：

```
ω(x,z)=Σ_{y:q(y)>0} π(x,y)ρ(y,z)/q(y)。
```

对q(y)=0的纤维，两边相应质量都为零，不作除法。对z求和得到p，对x求和得到r，因此ω是p与r的耦合。也可以保留三元见证λ(x,y,z)再投影。

如果第一桥满足度量界d₁₂(x,y)≤ε₁的坏事件概率至多δ₁，第二桥相应坏事件至多δ₂，且三个空间具有相容的三角不等式，那么在该粘合模型内：

```
Pr[d₁₃(x,z)>ε₁+ε₂] ≤ min(1,δ₁+δ₂)。
```

证明：两项好事件共同成立时由三角不等式得到距离界；坏事件包含在两项坏事件并集中。无需它们独立。没有相同中间分布，不能仅凭“两个桥都说Int”粘合。

### 7.4 整个任务的风险不能直接沿用单次风险

若一次任务中的坏事件F_i在共同分布及策略下满足Pr(F_i)≤δ_i，则：

```
Pr[至少一次坏事件] ≤ min(1,Σ_i δ_i)。
```

若更强地，对每个尚未失败且实际到达的历史，下一步条件失败率均≤δ_i，则成功概率至少为 `∏(1−δ_i)`。这是条件化保证，不是从边际概率自行推出独立性。

只在固定输入或离线平均下取得的δ，不自动覆盖依赖历史的选项。有限时域、无限服务、可选停止和新策略分别重新核其量化范围。单窗口风险≤0.007，连续100个窗口的一般并集上界为0.7，不仍是0.007。要有长期总预算，可以设计可求和的δ_i分配；是否有方法承担对应精度和成本是另外的问题。

概率0的坏事件不等于没有坏路径。原要求是“所有允许路径安全”时，即使一个概率方法给出δ=0，也不能自动签发全路径保证；需要在原允许行为域上另取得排除依据。

### 7.5 筛选与自适应选择改变概率问题，不能自动沿用原界

设F是错误事件，A是筛选/接纳事件。即使有 `Pr(F)≤δ`，能够直接取得的也只是 `Pr(A∩F)≤δ`。若要宣称已接纳结果的错误率，需要 `Pr(A)>0`，且：

```
Pr(F|A) = Pr(A∩F)/Pr(A) ≤ min(1,δ/Pr(A))。
```

若有接纳概率下界p_min>0，才可进一步用δ/p_min；若没有，不能默认保持δ。例：100个等概率情形中仅1个错误，筛选器恰只接纳这个情形。总体错误率0.01，接纳后的错误率却是1。这个反例不是说筛选一定有害，而是证明需要原界对实际筛选、历史和候选选择仍然适用。

可直接复用原δ的正向条件包括：已给出在每个实际可达接纳历史下的统一条件界；或该任务原来要求的就是未条件化的整次程序错误事件；或有其他准确的选择后校准证明。离线平均覆盖、被动测量覆盖与当前被选计划的风险不是同一主张。多个候选按结果挑最优时，还须保留选择器对风险的影响，不能每次都只引用获胜者的未选择前证书。

## 8. 第五种桥：数值误差和离散观察怎样支撑连续要求

### 8.1 误差必须经过实际敏感度传播

设准确定义阶段f_i在相交域内是L_i-Lipschitz；实际阶段有独立局部误差界ε_i。若前阶段误差≤e_{i−1}，则：

```
e_i ≤ L_i e_{i−1}+ε_i。
```

证明使用同一距离、相容单位和三角不等式。输入误差0.1经过乘10的阶段，再增加0.05局部误差，结果界为1.05，不是0.15。

L_i只在所声明域成立。要确认扰动后的值仍留在该域；跨越奇异点、饱和或不同分支时，旧局部界不能热用。不同误差分量共享来源时，要保留相关性；此处保守确定界不依赖独立，统计方差合成则有不同条件。

### 8.2 从一次观察取得一个可使用的安全时间窗

固定连续量q(t)，要求在相交时段 `q(t)≤H`。已取得一次采样，在真实采样时点t₀给出y。已知：

- 样本在该用途下满足 `|q(t₀)−y|≤ε`；
- q在整个待用区间内满足变化率界L，即 `|q(t)−q(s)|≤L|t−s|`；
- 现在距离t₀至多a；最晚h后重新观察，之后保护动作最迟τ内到达其合同要求的状态；
- 这段等待、排队、通信和动作之前的状态都在该模型覆盖内，单位及时间基已经对应。

则对当前到下一次反应完成前的区间，有：

```
q(t) ≤ y+ε+L(a+h+τ)。
```

证明是 `q(t)≤q(t₀)+L(t−t₀)≤y+ε+L(a+h+τ)`。因此，当这个上界≤H时，能在这些前提下保证整个窗口，而非只保证采样点。

这不是把插值曲线当现实。没有L或其他足够动态模型时，两端都低于阈值的采样完全可能遗漏中间尖峰。

### 8.3 观测有效期可以从用途反推

L>0时，上式可反解样本年龄：

```
a ≤ a_max = (H−y−ε)/L − h − τ。
```

这不是任意TTL。更紧阈值、更慢动作、更大误差或更快变化都会缩短使用窗口。a_max<0说明即便刚采样也不能靠该条件支撑这项窗口要求；应改善方法、响应或已获权的策略，不改原H掩盖问题。

L=0时另判 `y+ε≤H`；没有除零。这个数学静态模型也不赋予“永远新鲜”：校准、对象、解释和现场假设仍可能改变。

概率测量界需要保持事件语义。如果只知误差落在ε内的概率至少1−δ，以上得到的是在该事件和动态前提上的保证；还须与其他失败风险共同计算，不能升级为无例外安全。

### 8.4 多传感器可共同收紧，但冲突不能生成空真

每个合格传感器给出同一对象、同一时点的区间约束时，可以取共同交集。若有传输、时钟或位置差异，先用真实对应扩张误差；不直接比较两个名为temperature的数。

非空交集能收紧范围。交集为空意味着至少有某些模型、时域、映像或来源不相容；不说明真实物理量不存在。独立噪声是否允许更强统计融合需要另证，不能由设备编号不同取得。

## 9. 第六种桥：从被动统计到因果问题的准确查询

前面已区分观察与干预。本轮给出一个正面可计算片段，而不是只说不能推因果。

固定离散无环结构因果模型：Z→X、Z→Y、X→Y，三个方程各自外生噪声独立；Z为干预前变量，干预只替换X的生成机制，Y机制保持。目标总体固定，且对所需z有 `P(X=x|Z=z)>0`。

在这些前提下：

```
P(Y=y | do(X=x)) = Σ_z P(Y=y | X=x,Z=z)P(Z=z)。
```

证明：干预保留Z的分布，将X固定为x；Y方程在给定x,z后使用原独立噪声分布。观察条件化下的同一条件分布与之相同，再按Z全概率求和。这个证明只针对明确的模型，不把相关性当作图本身的依据。一般调整集由成熟因果图条件处理；DAGitty文档也把因果图正确列为前提。[CAUSAL]

有限例：Z=0/1各占一半；`P(X=1|Z=0)=0.1`、`P(X=1|Z=1)=0.9`。四项成功率分别为：

| 条件 | Y=1概率 |
|---|---:|
| X=1,Z=0 | 0.9 |
| X=0,Z=0 | 0.8 |
| X=1,Z=1 | 0.4 |
| X=0,Z=1 | 0.3 |

观察比较得到X=1组0.45、X=0组0.75，看似−0.30；干预比较是0.65与0.55，效应+0.10。参考程序还用200组独立等概率外生赋值直接执行结构方程和干预，分别得到同样结果，不只计算一遍调整式。

这不是现实实验结果。若Z受干预影响、遗漏混杂、选择机制改变、群体不一致或某层没有正值性，就不能消费这条桥。识别公式存在、有限数据估计精度和现实实施资格分别报告。

这个接合说明：信息组织保留因果结构和假设有实际正向价值，它能决定应提出什么查询、怎样重新加权以及哪种信息需要补取得。不能用“因果难”把全部内容永久停在未知。

## 10. 第七种桥：规范文本怎样成为对现实事件的可核履行要求

### 10.1 从规范到可核内容，不从文字到执行权

一项义务先由相应有权来源固定其承担者、触发、行为内容、范围、期限、解除和补救。选定解释以后，才能形成要监测的命题；没有合法效力的条款不由格式校验器提升为现行规范。

对一个明确的有限义务片段，规定“在激活后且不晚于D，合格主体完成指定行为”。候选事件必须绑定同一义务/代、承担者、动作和对象；成功回调还须按实际合同解释其是否就是完成行为。

满足谓词可以由 `∃e: matches(e) ∧ activation≤time(e)≤D` 形成。源策略若允许替代履行、解除或转移，必须按其自身规则增加相应分支，不能在公共层默认添加。

### 10.2 履行、违规和未知具有不同取证条件

- 找到一项合格的及时履行事件，可支持相应存在性结论，前提是所要求其他条件也已取得。
- 时间已经过去但记录范围不完整，没有找到事件仍是未知。
- 若已证明相关域到D（含边界）完整，且没有及时履行、没有未决时间对齐或有效解除，才支持该画像中的逾期判断。
- 时间不确定区间跨过D时，不能凭记录排序强判及时或迟到。
- 迟到履行可能满足补救或后续责任，但不能自动把原来的及时履行命题改成true。

本轮计算仅消费已解释、已取得资格的示例事件；函数中的字符串不产生真实规范权威或事件可靠性。

### 10.3 监测的三值结论与证据四态不能互换

对一个正确绑定、非空的可能完整历史集合Ext(p)：全部历史满足φ，可以判断肯定；全部违反φ，可以判断否定；两者都有，则当前前缀不确定。Ext为空时说明基础或模型有问题，不借空全称同时肯定和否定。

这是按可能完成历史判断，不是U1782中“是否有支持/是否有反驳”的两个证据分量。证据彼此冲突时，可以同时有支持与反驳；未结束的持续义务，也可能只有当前前缀合格而尚不能宣告整个未来履行。LTL/TLTL运行监测研究提供了有限前缀下true/false/inconclusive的成熟语义。[RV]

### 10.4 外部标准中相同状态词，要按其合同解释

核对ODRL 2.2固定2018推荐文本发现：它以不同关系表达permission、duty、obligation、consequence和remedy，且规定了补救后的政策评价状态。[ODRL]

例如某remedy完成后，标准允许把对应禁止的当前政策状态设为not infringed。将其翻译到需要保留历史违规的Gift任务时，不能用一个布尔值覆盖过去：至少需要能分别回答“是否曾发生侵害”“补救是否完成”“该标准当前评价状态是什么”。这不是认定ODRL删除了历史事实，而是承认它的状态词用于自己的政策评价问题。

同样，ODRL对某些consequence结构施加的嵌套限制，不能未经映射就成为所有Gift规范的全局限制。这是一项真实的跨理论语义适配问题，不是再新增一条泛泛的“不要混淆”。

### 10.5 准入与历史结算继续独立

政策允许、任务主体接受、宿主Grant、实时资源、动作发生和作用结算分别取得。后续撤权可以阻止新的动作，却不使过去动作从未发生。对未知结果、超时、重试和补偿沿原Operation/Execution合同处理；监测真值不调用现场动作。

## 11. 第八种桥：跨运行性质不能由逐次允许输出代签

上一轮C17已给出反例：对秘密h=0/1，源均允许输出{0,1}；目标固定输出h，每一次输出仍合法，却暴露秘密。本轮把它补成一种正向构造。

在固定公开输入x和有限合法隐藏态集合H_x中，令A(x,h)为完整允许公开交付集合。如果不允许公开结果透露h，一种充分构造是：

```
选择 f(x) ∈ ⋂_{h∈H_x} A(x,h)，并使公开结果只依赖x。
```

有限且相应关系可决定时，可以真正求这个共同值。对随机结果，可以选择只依赖x的同一分布μ_x，且其支撑完全位于每个A(x,h)。这给出了该输出分布观察下的保密，而不是仅凭每条执行输出合法。

若交集为空，这种单次、零附加泄露的构造不成立；可在原授权下取得新公开信息、协商披露或调整任务，而不能把秘密态分派藏进实现。此处不是所有信息流策略的必要充分定理。

公开观察必须包含任务实际要求的时间、错误、日志、结束和资源外部影响。源层输出值一致但目标出现秘密相关运行时间时，仍需目标层证明，不能提前把时间排除。多次执行性质属于比单条轨迹更丰富的验证对象，不能通过删去某些轨迹无条件保持。[HYPER]

## 12. 一份共同任务如何形成结果，而不是几份局部PASS

以下是用于连接前述理论的完全明确的研究模型，不是替用户增加新的业务要求。

目标：对同一信号X形成一个观察—反应计划。原阈值H=100；本任务要求整个待用窗口的超界概率不高于0.01，并保留准确报告、当前规范和现场授权边界。采样误差界的事件概率、反应延迟保证和变化率模型均被作为给定前提。这里每个δ明确作为在本任务当前观察与选择语境下仍适用的条件界输入，不从总体覆盖率反推选择后风险；变化率L及时间对应则在本例作为确定前提。不存在来自真实设备的观察。

三个技术计划和一个错误绑定候选如下。时间和数值使用本模型的共同单位，cost是为演示选择而明确给出的合成成本单位。

| 候选 | y | ε | L | 样本年龄a | h | τ | 窗口上界 | 本任务风险上界 | cost |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| A标准 | 94.5 | 0.5 | 2 | 0.25 | 1 | 0.5 | 98.5 | 0.007 | 2 |
| B低成本 | 94.5 | 2 | 2 | 0.5 | 2 | 0.5 | 102.5 | 0.002 | 1 |
| C大余量 | 94.5 | 0.2 | 2 | 0.1 | 0.5 | 0.2 | 96.3 | 0.003 | 3 |
| D错误来源 | 同A | 同A | 同A | 同A | 同A | 同A | 98.5 | 0.007 | 0 |

D引用的是信号Y的测量依据，不能用于X。B的界不能满足原H；在仅有这些变化约束的模型里可构造超过100的允许轨迹，但这不表示现实已经超界。A和C在给定模型中合格；已给成本政策选A。

本次计算还完成了两次改动：

- 将整次任务风险界从0.01收紧为0.005，A的0.007不再合格，C保留。
- 撤回A的校准资格，A的数学式仍可计算，但不能支撑实际用途；C的独立前提仍在，则可以作为新的计划候选。

如果原要求改成全路径绝不超界，而现有误差/反应依据只有概率保证，这些候选都不能自动签强结论；代码准确留下该残余。即使把δ数字填成0，资格仍取决于是否有全路径前提。

A的样本年龄上限由公式反推为1。其输入a=0.25时当前窗口有依据；等待到a=1.25而不取得新数据，原窗口界变为100.5，旧资格不能继续沿用。它具体连接了测量、动态模型、期限、依赖与刷新，不需要任意TTL。

同一个报告义务用事件身份与完整性检查：及时事件8满足截止10；只有迟到事件11而覆盖仅到9时不构成逾期证明；覆盖到10且无及时事件才获得模型内逾期判断。它们独立于控制计划“数学可行”。

所有候选的现场状态都保留为 `NOT_RUN_NO_REAL_GRANT_OR_SENSOR_OBSERVATION`。选择了一个数学候选不表示安装、授权、运行或部署已经发生。
