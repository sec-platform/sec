```sh
python tools/check_constructions.py
python tools/validate_delivery.py
```

第一条复算11组有限研究检查，其中顺序前置等式覆盖两元素模型的1024个完整有限组合；还包含方法切换、隐藏状态共同动作、前缀义务、共同预算调度、跨运行性质及旧决定保留。一般书面证明在主报告中，不用有限样例取代。
