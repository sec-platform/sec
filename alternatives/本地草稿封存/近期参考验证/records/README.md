# 近期本地资料处置记录

本目录收录带有明确日期的本地来源入口、差额核查和执行回执快照。记录用于回答“某一时点本地看到了什么、作了什么决定”，不是当前产品规范。

- `2026-11-12/`：原始入口、差额核查报告和执行回执，按原始文本字节保存。过期结论只代表当时状态。
- `2026-11-17/`：当前 Library 可访问范围内的新旧资料收口台账和最新入口。
- 同一执行回执的重复根目录副本经 SHA-256 确认逐字节相同后，只保留 Archive 原件；去重不改变历史快照。

现行产品设计仍由 `docs/` 中的唯一规范 owner 承担。候选 PR 未合并时，不能把快照中的候选提交描述为 main 已采用。
