# SEC: Engineering Workspace Compiler

[English](README.md)

SEC 是一套正在开发中的本地优先工程系统，目标是把软件需求和现有工程内容转为可维护的程序，并执行明确获准的修改。它连接结构化创作、实现选择、编译、验证与交付。

项目目前处于**开发预览阶段**。现有源码示例、使用入口和限制见 [PROJECT_STATUS.md](PROJECT_STATUS.md)。

仓库沿用历史名称 `sec`，该名称不是当前项目定义的缩写。设计目标是让人和 AI 表达需求、行为和约束，复用现有语言、库与工具生成传统源码；新建软件和维护现有工程都在范围内。

## 核心边界

设计将作者内容、编译、验证、外部作用、恢复和发布分开。操作需要明确输入、权限、预期修改与验证依据；计划和生成源码本身不能授权写入，也不能证明修改已被采用。外部操作还须回读实际结果。

SEC 不是低代码运行时、模板市场或自由式整仓 AI 编码器。规范描述目标设计，具体能力的实现与验证状态需要分别核对。
