# SEC — Engineering Workspace Compiler

[English](README.md)

SEC 是一套面向软件工程的本地优先开发与编译系统：把工程目标、可持续维护的作者内容和可用实现连接起来，形成具有明确来源与边界的目标工程，并支持持续修改、检查及明确获准的运行与交付。

仓库沿用历史名称 `sec`，但该名称不再作为当前项目定义或缩写。长期方向是让人和 AI 主要工作在意图、语义、约束、责任、作用与证据层，让传统编程语言源码逐步成为较低层的实现目标。现有语言与生态仍是必要的实现和互操作边界。

## 核心边界

SEC 不是低代码运行时、模板市场或自由式整仓 AI 编码器。文件、生成结果、测试、工具输出与 AI 陈述不会因为存在就自动取得权威；其身份、来源、范围、作用与证据必须在实际消费边界保持明确。

作者内容、语义解释、编译、保证评价、外部作用、恢复和发布由不同责任承担。计划不签发写权限，生成不证明采用，进程退出不证明外部作用已经结算，目标设计也不等于对应能力已经实现。
