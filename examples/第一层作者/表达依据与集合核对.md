# 通用作者集合：推导、充分性证明与反例

本文件为[第一层语言的理论与声明](../../docs/作者/第一层语言.md#intent-language-theory-and-claims)提供可复核的推导。产品规则仍由该正文及其原领域owner拥有；以下符号是书面论证记号，不是新增作者字段、JSON协议、运行引擎或另一套语言。论证相对于明确模型成立，不把有限样本、可扩展性或审查通过称为现实万物完备。

## 成熟研究怎样交出成果，本设计怎样采用

下表记录原作者实际交付的对象和保证；它不是要求Gift改用某种现成语言，也不推测研究者为什么没有选择本产品全部目标。

| 原始成果 | 实际出成果的过程与交付 | 已论证范围和未取得内容 |
| --- | --- | --- |
| [Dijkstra程序推导，EWD418](https://www.cs.utexas.edu/~EWD/transcriptions/EWD04xx/EWD418.html) | 从结果谓词出发，构造不变量、下降量、守卫与程序；以最大值、最大公约数等给出完整推导 | 保持不变量、退出推出结果、下降保证终止；不是总能自动发现不变量的算法，也未证明规格符合现实或所有程序都应这样开发 |
| [Event-B/Rodin精化](https://stups.hhu-hosting.de/handbook/rodin/current/html/tut_refinement.html) | 先给context、抽象状态/事件与不变量，再用状态对应关系逐层加入细节，交付模型及[明确证明义务](https://stups.hhu-hosting.de/handbook/rodin/current/html/generated_proof_obligations.html) | WD/FIS/INV/GRD/SIM等分别检查有定义性、可行性、不变量、守卫与模拟；官方[门禁案例](https://stups.hhu-hosting.de/handbook/rodin/current/html/tut_initial_model.html)仍另证无死锁，不能由一般精化通过自动得到全部进展或最终代码 |
| [Sketch有限程序综合](https://people.csail.mit.edu/asolar/papers/Solar-LezamaTBSS06.pdf) | 人给参考规格与部分实现策略，系统生成剩余候选，验证器提供反例；交付综合算法、工具、有限程序范围的论证及AES等实际结果 | 人与系统分工及作者负担确实进入设计取舍；有限空间内的保证不扩大为任意现实目标可自动求解，也不证明部分程序是所有作者最好的输入 |

这些研究已经处理“规定结果、留下自由、由系统推导”的问题，不能把这条思想本身当成Gift首次提出。Gift当前要验证的增量是：新建、组合、工程结构、精确控制与后继修改能否在同一第一层以更少独立维护信息完成。学术成果可能选用程序骨架、事件模型或求解片段；它们各自的范围与取舍有证据，不等于整个目标已被证明不成立或已经完成。

本轮采用同一条交付流程：**独立任务及观察 → 作者源 → 精确解释 → 构造/精化 → 明确证明 → 一次真实修改及信息消去**。作者不必操作这条内部研究流程；这是语言设计者交付依据的方式。下面的问题清单给出当前承诺范围内应交出的完整类别，具体构造出现新义务时沿同一类别补全，不能把表中行数当成全世界需求数量。

| 必须论证的具体问题 | 应交出的对象或结论 | 当前证据边界 |
| --- | --- | --- |
| 作者想保留什么区别，语义是否失真 | 独立输入、结果、环境、观察与接受者；两个语义不同的任务不能被无差别合并 | 已有信息不可省略反例及工程合同；全部现实词义没有封闭模型 |
| 每个合法表达怎样形成和解释 | 完整文法、绑定/类型/作用/寿命规则；解释按构造有定义 | 既有结构文法、本页有限映射及嵌套Set值形成已给出；一般准确观察点仍缺形成分支，不能只报Reader未实现 |
| 参照域是否都能表达 | 对独立参照域的构造翻译、每一分支的语义保持及组合归纳；必要时反向解释 | 经典关系片段、有限工程图各有书面证明；异类语义的全语言映射未完成 |

| 新领域是否破坏旧语言 | 新定义解释与旧模型约化/扩张对应；产品新要求与语言扩展分开 | 本页给保守扩展充分判据；任意插件、递归或外部效果不自动通过 |
| 后继修改是否保持指定内容 | 改名/抽取的身份保持；要求变更的差额、失效与旧实例责任 | 已有完整工程A—D与绑定样本；实际编辑工具未实施 |
| 每个核心构造是否必要 | 在固定局部编码限制下给消去式或不可消去反例，不把整程序模拟当廉价替代 | 已有若干保义消去式；全语言独立性和全局最小未证明 |
| 人是否真的少写、少理解、少维护 | 唯一决定位置、信息删除反例、首次领域定义成本及真实创作/修改实验 | 已有结构消重；人类时间、错误率和全生命周期总成本未实测 |
| 自举与工具可信性是否成立 | 完整编译器作者源、阶段构建/比较与对应正确性证据 | 有名称绑定/改名表达样本；完整自举和运行验证未完成 |

已有正确性证明不替代现实任务验证；真实任务反例也不必推翻每个已证明片段。若新增构造或改变语义，失效沿实际证明依赖定位；不同问题的“完备”继续按[统一声明边界](../../docs/作者/第一层语言.md#intent-language-theory-and-claims)分别判断。

## 论证必须交出可检查的构造和结论

“论证”不是用几句理论名称支持一个直觉。这里要求给出明确对象、形成或运行规则、前提、结论，以及从前提到结论的推导；若结论是“存在实现”，还应实际构造实现或准确调用已有存在定理。若结论是“所有合法表达都保持某性质”，证明须覆盖形成规则的每个分支，不能只展示成功例。书面推导、机械核证和程序运行仍是不同证据。

[图灵原论文](https://www.cs.virginia.edu/~robins/Turing_Paper_1936.pdf)第1、6、9节分别给出计算机器、通用机器与模型理由。模型把人按固定规则进行符号计算的动作理想化为有限状态、有限符号表、纸带和局部读写移动。现代等价记法可以写为有限转移表`δ: Q×Γ ⇀ Q×Γ×{L,R}`；纸带可继续扩展，机器描述与每步规则却是有限的。这是实际可执行规则，不是一份业务概念词典。

例如一元自然数以n个连续`1`表示，读头从其首位开始（零从空白开始）：`δ(q,1)=(q,1,R)`，`δ(q,空白)=(停,1,R)`。它给出的具体算法是加一。处理k个原符号后，原n个符号未变、读头位于第k个后继位置；到达空白写入一个`1`后停机，结果恰有n+1个`1`。规则与不变量共同给出结果和终止的证明，不需要现代语言的`while`关键字。

通用机更进一步：将任意一台这种机器的有限转移表和当前配置编码到纸带上，由固定机器解释该编码；证明模拟一步后，编码仍对应被模拟机器的下一配置，再按步数归纳。这样证明的是一台机器能够模拟模型中的所有机器。形式模型之间可计算能力等价是数学定理；“这种模型涵盖直觉上所有有效计算”还涉及对非形式概念的解释，即Church–Turing论题，不能与前一个定理混为一谈。原论文并没有替所有未来语言规定关键字，更没有把所有现实意图变成可自动求解问题。

Gift已有[通用计算合同](../../docs/领域/计算基础/通用计算与任务语义.md)承担相交计算表达；本任务新增价值在[统一语言定义](../../docs/作者/第一层语言.md#intent-unified-language-contract)的作者含义与实现保持。`执行给定程序p`与`由要求A取得合格p`是两种问题；有通用执行器不意味着后者总能决定、终止或产生合格结果。确定领域词义、保留工程身份和减轻人的修改负担也不是模拟器自带的能力。

## 一段完整推导：同一作者工程如何接到实现与目标

使用[完整作者工程](完整作者工程.md)已经定义的条目、资料、阈值关系、资料仓与两个视图，不增加业务要求。作者源只在`按阈值保留`处定义一次结果关系；资料共享关系来自两条明确连接，两个阈值则来自两个独立成员发生。

| 统一合同的环节 | 该工程中的实际对象与判断 |
| --- | --- |
| 构造与静态形成 | 资料是允许重复的有限有序序列，评分与阈值属于0..9整数；关系角色分别绑定输入、阈值、输出；视图来源绑定同一资料仓快照，两个视图阈值状态独立 |
| 产品含义 | 读取结果为输入中评分达到阈值的出现位置，按原次序保留，每个合格位置恰好一次；读取不改变资料和阈值，借用不越过调用；错误、关闭与隔离仍由原完整合同约束 |
| 一个可构造的实现片段 | 对序列作下述有限递推即可实现筛选关系；这只取得纯筛选片段，不能替资料仓、关闭和失败语义取得整项资格 |
| 目标保持 | 所选目标若用数组/对象表示，须保持序列发生、精确评分、阈值、共享资料与独立视图的对应；输入验证、所有权、错误优先级及完整产物继续核原合同，不能只跑筛选例 |
| 再次修改 | 预览初值5改8只改变该成员参数；共享关系的`≥`改`>`改变所有采用处的政策；无损抽取组件须保持连接和状态身份，三者不共用一个“等义”结论 |

一个明确的数学实现见证F如下，`x::xs`表示首项及尾序列，`[]`为空序列：

```text
F([], t) = []
F(x::xs, t) = x::F(xs,t)    当 score(x) ≥ t
F(x::xs, t) = F(xs,t)       当 score(x) < t
```

这里的F是本节为证明实现存在而构造的计算，不是要求开发者再填写的一份作者源，也不新增核心关键字。对序列长度归纳：空序列的合格位置为空，结果正确；非空序列中，首项合格时必须先保留其这一次出现，不合格时必须排除，尾序列由归纳假设按原位置正确保留。递推每次减少一个位置，因此在有限输入上终止。相同值在不同位置分别处理，所以`[a,a]`且a合格时结果仍为`[a,a]`。读取的本次快照和阈值固定后，纯F不写它们，得到该片段的正确结果、终止和无写入性质。

若实现改为从左到右遍历，已处理前缀长度k时保持：输出恰为前k个位置中的全部合格出现，按原序保留，原输入未变；追加下一个合格出现保持不变量，结束时k等于输入长度。由此可证明两种实现对该片段具有相同含义。该推导没有证明递归实现的宿主栈界、数组分配成功、墙钟时限或整个工作区的生命周期；原容量限制也不自动给出目标平台内存上界。选择迭代、索引或缓存仍需履行相交目标与资源合同。

当完整实现p已经分别且共同履行整个工程的合同，且目标保持关系能把这些合同运输到目标T时，可以由两步推出T满足作者要求：先由`p ∈ AcceptK(A)`取得这些性质，再由`T ≼θ,ρ p`逐项保持。这个组合证明说明应该证明什么以及如何相接；本例只实际给出了F片段的构造与书面证明，没有产出完整p、T或机械证明。不能把两个箭头的名字当成其前提已经成立。

[CompCert的真实编译器合同](https://compcert.org/man/manual001.html)提供成熟参照：其定理针对明确源/目标语义及编译成功结果，同时划清解析/链接与时间、内存等保证边界。Gift需为自己的要求和目标补足相交观察，不能从使用LLVM、某编译器或一个正确后端，倒推前端已经忠实表达了人的意图。采用这套论证方式不意味着本任务引入CompCert或新证明工具依赖。

当前未完成项准确分开：本页有限映射保留一般准确观察点的形成缺口；各语义拥有者的完整形式化及全链正确性证明未取得；生产读取、实现取得、目标生成和自举未实施。现有完整结构文法、已固定语义规则和上述局部证明继续有效，不因这些缺口而被重写成另一套语法。

## 真实编码闭合：有型Bool关系片段

[完整源文件](经典关系编码.module.json)只使用既有codec，给出Booleans、EqualBody、Equal和Law四个实际定义，无外部库或未解释的关系名。这里的计算主体是为明确语义提供的证明见证，不要求应用作者每次重复写Bool库，也不据其JSON长度声称作者负担已经下降。首次定义和维护的成本仍存在。

独立参照片段是Bool域D={false,true}上的有型等式公式：原子x=y，非空有限合取/析取、否定、蕴含和∀/∃；变量由词法量词绑定。研究对象包含任意有限嵌套的闭公式，不只这个文件中的一个公式。本节不给其他领域或任意函数项偷加解释。

精确编码E先为每个binder选择全局新鲜合法名，保留源binder身份到目标名的对应；嵌套体中的引用只随其真实绑定改变。然后按下表形成既有短Formula，纯展开规格取得右列。所有量词域固定为`local:Booleans`，该无参纯函数返回完整的`[false,true]`；此处使用domainRef原已允许的纯集合生产函数，不自行把普通constant扩大成量词域。

| 参照构造 | 现codec短形 | 完整形的准确字段 |
| --- | --- | --- |
| x=y | `{"local:Equal":{"left":"x","right":"y"}}` | `op:call, meaningRef:local:Equal, bindings:{left:x,right:y}` |
| 全部Pᵢ；任一Pᵢ | `{"all":[E(Pᵢ)]}`；`{"any":[E(Pᵢ)]}` | `op:all/any, items:[…]`，本片段列表非空 |
| ¬P | `{"not":E(P)}` | `op:not, item:E(P)` |
| P⇒Q | `{"implies":[E(P),E(Q)]}` | `op:implies, if:E(P), then:E(Q)` |
| ∀x∈D.P；∃x∈D.P | `{"quantify":{"quantifier":"forall或exists","binder":"x","domainRef":"local:Booleans","predicate":E(P)}}` | 增加`op:quantify`，保留quantifier/binder/domainRef/predicate |

表中x/y为选择后的实际名字、E(P)为递归替换记号，不是可以原样粘贴的JSON值；完整文件才是可读取的源。`bindings`的值是角色/binder名称字符串，不能在该槽塞Expr或`{bound:x}`。域在新binder生效前解析，binder只约束predicate；新鲜化使本片段不依赖尚未明确的Goal同名遮蔽策略。

**编码定理及证明。** 对该参照域的每个闭公式P，E在有限步内给出合法结构，并在原角色绑定及本节确定的经典解释下保持P的真值。构造每次递归到真子公式，因此终止；每个产物都对应表中已有Schema分支，子节点由归纳假设合法。原子Equal的interpretationRef准确指向EqualBody，四输入结果依次为FF→T、FT→F、TF→F、TT→T；主体只有参数读取、有限if及Bool字面值，所以纯且总，`termination:total`标记不被拿来证明自身。对应环境给绑定变量同一个Bool，因此原子保持。连接词按其相同真值规则保持；每个量词枚举相同完整二元素域，对每个成员应用归纳假设，合取/析取结果相同。由形成归纳覆盖任意有限嵌套。反向按完整节点的op及字段还原即可得到P的α等价式，限定在本节编码像内，不声称反解任意Goal。

本模型原子没有未知或冲突，原证据投影只产生T/F，四态组合在此子域限制为经典代数。NEITHER/BOTH、外部未观察事实或不完整域不满足此前提，不能由本定理变为经典假/真。书面绑定与类型判断也不代签生产Linker执行。

文件中Law的谓词是`∀x∈D ∃y∈D: Equal(x,y) ∧ (Equal(x,x) ∨ ¬Equal(x,x)) ∧ (Equal(x,y)⇒Equal(y,x))`；每个x取y=x即成立。把量词顺序改成`∃y∀x`即不成立：无论y取哪个Bool，都存在另一个x不等于它。这是一项实际政策/依赖变化，不是等义整理。把内层binder和仅绑定于它的引用一起改为新鲜名则等义，不能只全局替换同名字符串。

反例必须分层：`any.items=[]`是结构错误；把一个bindings值改为未绑定的`z`仍可能通过Schema，却必须在绑定阶段拒绝；改变EqualBody真值表仍可能通过结构与类型，但破坏本节已证明的相等解释。模块仅公开Law；其achieve是否在某Root和完成观察点真实达成仍需原上下文与运行证据，本定理不伪造horizon引用，也不宣布Goal已执行。

## 一般组合定理：有初值反馈的有限同步网络

此处独立参照一类交互系统，取得比“图能被写下来”更强的实现存在结论。模型是有限组件网络，每个组件i有非空有限状态、输入、输出域Sᵢ/Iᵢ/Oᵢ、已定初态sᵢ⁰，以及总函数Fᵢ:Sᵢ×Iᵢ→Oᵢ×Sᵢ；例如完整有限表给出的函数。端口传递可复制纯值，不含隐藏外部效果或唯一资源转移。状态发生分别所有，同一状态只通过其准确拥有者访问。

每个输入只有一个准确供给，来自外部输入、常量、同刻上游输出或延迟旧值；端点有型且完整。同刻依赖图无环。每条延迟连接保存一个已定初值rₑ⁰，第t刻给旧值rₑ(t)，本刻输出确定后形成rₑ(t+1)。外部本刻输入在输出前可得。所有新组件状态与延迟值只用于下一刻；这是数学状态转换的意义，不要求采用物理同步、线程、事务或某种目标源码架构，也不将该参照模型变成作者必填阶段函数。

**定理。** 每条合法外部输入流对应唯一完整运行；一个总的有效因果策略能产生该运行。将网络合成为单一状态机，双向保持完整运行及任何外部观察投影。

**构造。** 全局状态S取全部Sᵢ和延迟寄存域的积，初态取其给定初值。每刻给定旧S与外部输入，按同刻依赖图的任一拓扑序取得各组件输入，计算Fᵢ，保存本刻输出及下刻状态；最后以全部结果形成下一刻S。有限无环图的拓扑序有限，每个Fᵢ总定义且有效，故全局转移在每刻结束。

**证明。** 初态存在，每刻构造取得下一刻，按时间递归得到运行。若两次计算有相同旧S和当前输入，按拓扑序归纳，每个组件所得外部值、旧寄存值与前驱输出相同，故输出和下一状态相同；再按时间归纳取得唯一运行，也说明拓扑序的任意选择不改变结果。若两条输入流截至t刻相同，同一时间归纳给出截至t的相同输出，故策略不依赖未来。构造结果逐刻满足全部局部转移与连接方程；反过来，任何满足这些方程的运行由同样的两重归纳必等于构造运行。因此运行集合相等，投影后外部观察相等。定理覆盖任意有限规模的合法网络和无限输入历史，不是从有限测试次数外推。

条件性局部保证还需接合依据：给出全局状态不变量J，初态满足J；每刻由J、合法外部输入及已取得的前驱保证，按拓扑顺序推出当前组件前提；全部后条件再推出下一刻J。时间归纳于是同时保证所有相交局部合同。两个组件互称“只要对方最终响应，我就响应”没有这种非循环依据，不能凭各自合同推出整体进展。

两节点的完整正例为`A:xₜ=¬rₜ`、`B:yₜ=xₜ XOR uₜ`，外部uₜ先可见，反馈`r₀=0,rₜ₊₁=yₜ`。全局转移直接是`(r,u)↦(x=¬r,y=¬r XOR u,r′=¬r XOR u)`，四种输入均有唯一值；恒零输入产生1,0,1,0,…。删去一刻反馈改成同刻`r=y`后，方程变为`x=¬y,y=x XOR u`：u=0无解；u=1有(0,1)/(1,0)两解。后者若按合法输入域与已接受政策选定一解，可以实现；多解不等于不可能，但也不等于已经唯一决定。初值未定同样不自动无解，只是不能直接取得本定理的唯一性。

这个反例要求准确连接时序与选择，不要求增加新业务关键字。定理给出逻辑时刻进展，没有证明墙钟时限、平台内存、异步故障、概率合同或真实授权。它完成的是独立参照模型的组合证明；其全部时序和状态语义到Gift具体codec的映射仍须另证，不能仅凭已有“成员/连接”概念代签整门语言表达完备。

<a id="conservative-extension-criterion"></a>
## 新领域不必增加核心：保守扩展的准确判据

设旧签名/理论为(Σ,T)，新定义后为(Σ⁺,T⁺)，r忘掉新符号的解释。若`r(Mod(T⁺)) = Mod(T)`，则对每个旧句φ，`T⁺⊨φ ⇔ T⊨φ`。证明：每个新模型约化后是旧模型，故旧结论在新模型中仍成立；每个旧模型又有新模型扩张，故若所有新模型满足旧句，则全部旧模型也满足它。这是一个足够的语义保守性判据，不声称每种保守扩展都必须由当前方法找到扩张。

新鲜、有限无环的纯关系定义`R(x) ⇔ P_old(x)`为每个旧模型给唯一扩张，所以满足判据。已有领域关系按此组合成新业务词汇时无需增改核心；产品选择采用新配额或新政策后缩小接受集合，是产品要求变化，不能要求它仍保持全部旧产品行为。递归、外部效果、不同身份组件及改变调用次数不自动满足此前提，要由各自原合同判断。

这补充前文对普通定义展开的证明，给出新定义是否会改变旧结论的具体检查。表达成本还须考虑局部翻译是否引发全程序重写，参照[Felleisen对表达力与局部消去的论述](https://felleisen.org/matthias/4400-s20/lecture27.html)。上述模型扩张判据已在本节直接证明，不依赖引用名称来代签；此处没有引入新证明框架或要求作者填写模型扩张表。

## 先固定与Gift记法无关的参照

关系片段的参照是带有型项、相等、关系、变量赋值与满足关系的经典多域一阶逻辑。其函数/关系签名Σ和允许模型类M先独立给出，不从“Gift恰好能写什么”反向定义。语义基础可参照[SMT-LIB逻辑标准](https://smt-lib.org/language.shtml)；本设计不因此采用SMT-LIB载体或求解器。

下列数学对象说明状态和历史如何有实际解释，不以未知的`R(...)`包住所有问题：

- 值域V、对象身份域O、位置域L、事件域E分别确定；一个状态σ是L到相应有型值的映射。O上的相等判断对象身份，不能被V上的值相等替代。
- 一条完整离散历史h具有有限初始段或自然数时间域Th，`state(h,t)`给出观察点状态；事件发生关系`occur(h,e,t)`按已确定的产品观察边界解释。若采用真实时钟，还须另有准确时钟域、单位与对应关系，本样本不替它作证明。
- 受控位置、环境输入、允许行为及信息可得时间由实际任务合同给出；它们不是候选实现可自行缩小的量。授权事实来自其独立来源，公式中出现一个授权谓词不产生权限。
- 各量化类型有可准确指称的完整域；限定范围D可以为空。未知范围、分页前缀和只观察到的几个对象不能冒充完整D。

源端没有相应项的准确含义、无法指称论域、或尚未接合专业解释时，下面定理的前提不满足。声明一个同名关系并不能补齐它。概率、规范冲突、主观接受、连续模型、跨历史性质各自还需相应解释；本关系片段没有替它们统一选择模型。

## 论证一：经典关系片段的相对表达充分性

在上述Σ和M中，参照公式由原子式、否定、合取和存在量词构造；其他经典连接词可定义。这是标准关系逻辑的一个基底选择，不声称它是Gift全语言唯一最小核心。

作者片段具备相同解释的有型项和关系、词法绑定及`非/全部/存在`。定义逐式翻译T：

```text
T(R(t1,…,tn)) = R(T(t1),…,T(tn))
T(t1=t2)      = T(t1)=T(t2)
T(¬P)        = 非 T(P)
T(P∧Q)       = 全部 { T(P); T(Q) }
T(∃x:s P)    = 存在 x 属于完整域Ds：T(P)
```

**命题。** 对每个有型参照公式P、每个M中的模型及同型变量赋值ν，参照P成立，当且仅当作者表达T(P)在同一模型/赋值下成立。

**证明。** 先对项结构归纳：常量和变量取同值，函数应用使用同一函数解释，故复合项取值相同。再对公式结构归纳：原子式使用同一关系和相等解释；否定与合取由子式归纳假设立即保持；存在量词的两端在同一个完整Ds中寻找见证，对每一赋值应用归纳假设即可。全部有限公式因此保义。

这里得到的是**该要求片段相对于已解释一阶参照的表达覆盖**。它没有证明任意现实概念已进入Σ、模型正确、所有公式可判定或满足公式的程序可自动得到。含无限论域的有限公式可被表达，不表示其论域能枚举完。当前JSON编码的节点支持、Reader及执行方法仍是另行取证的实现问题。

| 若P则Q | 非(全部{P;非Q}) | P含义已确定；尚未观察到P不能直接取假；未知词义更不成为可用原子。 |
| 每个x属于D：P | 非(存在x属于D：非P) | 同一个D、同一binder；不交换量词。 |
| 有限完整D上的所有/存在 | 对D的各出现作卫生代换，再全部/任一 | 空域分别真/假；采用中的私有发生和显式共享仍对应，不按值去重。 |
| 集合上恰好一个x满足P | 存在x：P(x)且每个y：若P(y)则y=x | x/y按该集合真实成员相等解释。 |
| 序列上恰好一次满足P | 存在合法位置i：P(D[i])且每个合法位置j：若P(D[j])则j=i | `[a,a]`且P(a)为真有两次，不能用D[i]=D[j]替代i=j。 |

有限反例：取D={甲,乙}，令P(x,y)为x=y，则`每个x存在y：P`为真，`存在y每个x：P`为假。把量词次序调换会改变允许结果，不能作为语法压缩。另取某个已解释但尚未观察的P；当与现有信息相容的模型既有P真也有P假时，语义等价仍可比较相同模型集合，运行观察却不能直接宣布P假。

这些是书面等价与反例，不是新运行测试。真实副作用表达如`next()`、可能除零或不终止的计算不在纯关系等价的适用前提中。

## 论证二：时间和帧短写具有展开内容

固定同一完整历史h及起点t，Δ是同一时间域和单位下的非负期限。`P@u`指在h的u观察点解释P；期间限制已体现在Th中，展开引入新鲜局部名避免捕获。

```text
始终P@t ≡ 每个u属于Th：若u≥t则P@u
最终P@t ≡ 存在u属于Th：u≥t且P@u
(P直到Q)@t ≡ 存在u属于Th：
                 u≥t且Q@u且
                 每个v属于Th：若t≤v<u则P@v
(P除非Q)@t ≡ (P直到Q)@t 或 始终P@t

每次e属于已定事件域E后Δ内P(e)
  ≡ 每个e属于E、每个t属于Th：若occur(h,e,t)则
       存在u属于Th：t≤u≤t+Δ且P(e)@u

只改变S ≡ 每个l属于受控位置域减去S：σ后(l)=σ前(l)
```

**证明。** 始终/最终分别量化全部后继观察点或某个后继观察点；直到同时给出终点与此前保持，除非允许终点永不到来。事件式为每个真实发生分别给期限见证；帧式逐位置排除未授权状态变化。它们与[原时间及帧含义](../../docs/作者/第一层语言.md#intent-author-core)逐项相同，嵌套以结构归纳保持。事件重复出现仍各有义务，同一响应可否满足多个义务由P(e)的身份关系决定。

**边界反例。** 永久P且Q从不发生时，“除非”成立，“直到”不成立。只观察到有限前缀时，不能把当前没看到Q等同于完整历史上永远没有Q；已结束的有限期间与未结束观察前缀是不同对象。`只改变S`不说明S内必须改变，不授予写权限，也不等于“没有执行任何写指令”；临时写回原值可能保持前后相等，却违反另有的无写入效果要求。

这些展开说明时间与帧并非未知黑盒，但不证明时限可兑现、无死锁或现场事件完整。状态/行为及活性的独立规格基础见[Specifying Systems](https://lamport.azurewebsites.net/tla/book.html)。

## 论证三：普通关系定义与局部组合可以保义

对一个新鲜关系名`R(x1,…,xn)=P`，假定定义纯、有型、有限、非递归，P的其余自由引用均已由固定上下文准确绑定。对每个旧模型，把R解释为所有使P成立的实参元组集合，便得到唯一相应扩张；旧签名的解释不变。

**证明。** 该集合唯一确定R；原公式没有R，故真值不变。含R的公式中，每个R应用与对P的捕获避免代换具有相同真值，再对组合公式归纳。若P和Q在全部允许模型及赋值中等义，则把它们放进同一个纯关系上下文，按上下文结构归纳仍等义。

因此，命名关系、采用和纯关系重组有实际保义依据。展开的身份/来源/接受及私有发生映射仍按[原采用合同](../../docs/作者/第一层语言.md#intent-construction-reduction)保留；这项真值证明不单独签发其保全，也不准许突破opaque或私有边界。

递归定义、运行调用、组件创建、资源与效果不满足上述全部前提。`v=生产一次；两处引用v`与`两处各生产一次`可能具有相同值，却有不同作用次数。不能用宏等价消掉这些区别。Felleisen的[局部表达能力方法](https://felleisen.org/matthias/4400-s20/lecture27.html)为这种比较提供依据；全程序模拟不能代替局部消去。

## 论证四：有限工程发生结构可以直接构造

独立给定一个有限、有型、接口合法的工程发生图G：节点是组件使用发生，带准确可引用的定义和实参；边是具有端点、交互、身份和寿命合同的绑定；有限封装层级及公共边界另有标记。定义及端点必须已解释，非法多供给、独占资源复制或不合法跨私有边界的图不属于前提。图可含按原合同合法的递归引用，不把声明环自动当可运行反馈。

**构造与证明。** 在各自封装中为每个节点建立一个新鲜成员发生；每条边形成一次相应连接，边引用其原节点对应的成员。多个边原来指向同一节点，就复用同一成员；独立节点分别建立。按原图标记公开边界，跨层只通过其合法端点。节点和边的逐项对应给出读回图与G的同构，仅局部显示名可不同。先建立符号再接引用，不需要把有限环无限展开。

此命题证明作者可以构造这些结构，不依赖“存在一张合格图”的求解结果；也不证明图能运行、动态实例数量有界或已存在生成器。[完整作者工程](完整作者工程.md)具体给出一个资料仓、两个视图发生、两条共享来源连接，以及保持图中身份的组合抽取。动态创建和无限运行继续按原计算/组件合同解释，没有因本定理只讨论有限源码结构而被排除出产品目标。

## 论证五：必要信息不能被无损省略

固定上下文k，把意图i的准确接受含义记作S_k(i)，作者编码记作E_k(i)，解释记作D_k。忠实表达要求`D_k(E_k(i))=S_k(i)`；S包含本次确实独立的行为、工程及允许选择区别，不是只记录某次碰巧合格的实现。

**命题与证明。** 若两项意图的接受含义不同，而编码和上下文相同，同一个解释D_k只能得到同一个结果，无法同时等于两个不同的S；矛盾。因此，有接受意义的独立区别必须在源或准确上下文中保留。区别可以从已有合同推导或由有效委派取得，不要求用户每次手写，更不要求每个区别独占一个关键字。

例如阈值5时`≥`与`>`对评分5的条目有不同结果；共享仓与两份独立仓在替换后的跨视图观察不同；固定默认5与继承当前默认5在默认升级后不同。如果把这些差别从源及上下文一起抹掉，系统不可能准确恢复两种原意图。一个实现满足两项意图不代表两项意图相同；若系统只须在已委派共同允许区间选一个实现，则应按该实际授权解释，不能伪造未要求的独立区别。

**更强不可定义性的一个例子。** 对同一用户、动作、资源和时刻，取两个外部世界模型，其已有计算/状态事实完全相同，只有实际授权关系不同。没有授权信息或等价来源的剩余签名，其每个公式在两模型中真值相同；故不可能据它定义区分两者的授权性质。这证明外部独立信息不能从无关事实推导，不证明`授权`必须成为一个核心关键字。

全局最小需要进一步固定允许编码与成本，再比较不同基础。此处没有把“找不到更短写法”作为不可定义性证明，也没有用信息不能丢推出所有现有构造都必须保留。

## 历史参照的正确作用

早期语言没有先取得“描述全部现实”的证明。Lovelace的1843年[分析机笔记](https://www.yorku.ca/pclassic/Lovelace/lovelace.htm)是早期程序与操作分析文献，不等于一个现代高层语言的唯一发明记录；Zuse在1942—1945年设计的Plankalkül与后来实际实现分开判断，见[柏林自由大学资料](https://www.fu-berlin.de/presse/informationen/fup/2000/fup_00_036/index.html)；Backus领导团队的FORTRAN在1950年代形成并于1957年商业发布，见[IBM历史](https://www.ibm.com/history/fortran)。这些分别回答程序记法、语言设计和实际采用，不能混成一个“第一”。

[Turing的1936年论文](https://www.cs.virginia.edu/~robins/Turing_Paper_1936.pdf)给出通用机模拟和计算的界限。计算通用性证明通过模拟一个已知通用模型承担，不是逐个列尽所有未来程序或保证机器理解现实词义。需求的现实解释另有责任；[Zave与Jackson](https://www.pamelazave.com/4dc.pdf)明确区分领域知识、机器规格与客户需求，并保留对领域事实和客户期望的外部验证。这些史实和理论支持本设计的责任划分，未替Gift本身签发计算通用、自举或现实充分性。

## 依赖域与符号实参：可检查的完整作者源码

[依赖域与关系实参.module.json](依赖域与关系实参.module.json)选择`gift.author-module/design-converged`，完整定义Reading、Bounds、Group、Dataset、WithinBounds及其纯解释，Goal的开发者含义是：

```text
对 dataset.groups 中的每个 group：
  group.readings 中存在 reading，满足
    group.bounds.lower + dataset.offset ≤ reading.score ≤ group.bounds.upper
```

作者决定的是域、阈值关系与量词次序；没有规定先扫描哪组、并发度、存储或阶段函数。完整结构将两个域写为原field Expr，reading用binding实参，bounds用record值实参；加法和比较引用原冻结`std:IntAdd`、`std:IntCompare`，没有假造标准库。WithinBoundsWitness是此自足样本为关系提供的有限纯解释，可由明确合格的已有关系定义替代；它不是要求每个应用重复实现通用比较。Bounds由准确形参预期型及本模块表示权限构造，不用新增类型出口机制。

**绑定与值证明。**外域在η(dataset)下取得groups的完整有限序列；group进入谓词后，内域才取该group.readings。reading进入内谓词，两个record字段依次取得Int；IntAdd是精确数学和且纯总，随后三分比较穷尽Ordering。令l为lower+offset、u为upper、s为score，函数第一步恰判s≥l，第二步恰判s≤u，所以结果当且仅当l≤s≤u。若l>u，结果对所有s为false，不静默修正阈值或删组。所有字段存在由本地封闭记录型给出；此有限结构递归及冻结整数原语提供本例纯性/总性的书面依据，标签本身不提供证明。

**组合边界。**空groups在完整域上满足forall；某组readings为空则该组exists为false。两个组各有不同合格条目时，`forall group, exists reading`可以成立；不能改成寻找跨组共用的一条reading。序列中两个相等出现保留，不自动去重；当前forall/exists的经典真值虽可相同，改为exactly 2会观察出差别。域在量词处解释，不能越过时间或实例观察边界提前求值。

**再次修改。**将该组的要求改成“恰有两次合格出现”，只把内层quantifier改为`exactly`并新增`count:2`；域、绑定和关系定义不变。将下界改成严格大于，则修改WithinBoundsWitness的下界Equal分支为false，并重算所有真实Meaning消费者；不能只改文案或另一份目标源码。前者是消费处量化决定，后者是共享关系定义，两种修改的影响范围不同。

上述证明依赖固定普通值/快照、准确记录类型和有限完整序列。未取得观察不能当作空序列，Subject身份不能冒充Dataset值；若字段改成Option或外部opaque，原投影资格失效并须重新设计。结构检查只验证候选编码和严格拒绝边界；生产绑定、类型/纯性检查、自动生成及运行仍未执行。本例闭合的是通用值/域接合，不代表所有集合简写、工程组合或自举义务已经完成。
