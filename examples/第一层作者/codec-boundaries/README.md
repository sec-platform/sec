# 按上下文分派的实际源例

同一compact codec中，Bool保留精确原形Definition，Label使用短形；二者都只有一份作者源。annotations中all/core:type/kind/op/ref与中文、空键、斜线、波浪线全部是数据，不进入声明/公式/引用解析。该例没有Target，不代表已运行或自动获得任何外部能力。

不能在解码某个真正的Formula失败后把它降成annotations；这里的数据身份来自其真实槽位。重复的JSON键仍须在构造对象前拒绝，不能凭“数据”允许覆盖。完整规则见[按槽位的准确分派](../../../docs/作者/紧凑结构与同源编辑.md#compact-exact-domain-preservation)。
