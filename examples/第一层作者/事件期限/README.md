# 每次事件的期限：实际值源码与有限模型

本例交付[range值接合](../../../docs/作者/需求含义与实现责任.md#dependent-temporal-range)及它的普通时间值源码。主作者仍描述“每次编辑后1秒内给出对应预览”；不要求作者写监听器、循环或计时器。此处只把这句话的时间范围落实，**不是完整互动模块，也没有闭合真实事件参与、观察与Goal角色的桥梁**。

## 同一源码怎样写与修改

[ranges.module.json](ranges.module.json)是完整候选模块，三个本地名义值类型、一项纯函数及一项期限常量。`ClosedAfter(start, span)`只将结束点构造为同钟的`start.nanoseconds + span.nanoseconds`；它使用已有精确整数加法，不调用宿主时钟、不查询事件、不产生效果。记录是被检查的值表示，构造函数本身不会签发Time或事件资格。

[range.formula.json](range.formula.json)是**有指定词法环境的Formula校准输入**，不是可独立加载的模块或产品根。`local`指上述模块；`e`是外层量词已绑定的发生模型值，具有`at:SessionReading`。`clock:session-model`与`model:Responded`只指下述完整有限模型解释，不是冒充已存在的标准库、Provider或真实会话。生产互动使用它还必须将对应真实时钟、发生和观察解释接入，不能直接把这两个测试标识粘贴为生产引用。

准确写法的关键片段是：

```json
{
  "range": {
    "op": "call",
    "callee": {"op": "symbol", "ref": "local:ClosedAfter"},
    "arguments": [
      {"op": "field", "record": {"op": "var", "name": "e"}, "name": "at"},
      {"op": "symbol", "ref": "local:ResponseDelay"}
    ]
  }
}
```

“改成500毫秒”只将`ResponseDelay.value`内的精确整数字面量`"1000000000"`改为`"500000000"`，函数、事件绑定和其他要求不变。只改一个采用处时绑定不同局部期限值，不改共享定义；这里的常量是一项作者决定，不是语言内置秒数菜单。`std:IntAdd`属于支持层的小型普通值计算，不用它替代预览、确认或发布的产品合同。

## 有限模型解释

模型只有一个选定时钟身份C，坐标为精确整数纳秒、单调且无环绕。`SessionReading.clock`是该模型中身份的编码，字符串相等仅在此已固定模型内对应身份相等；真实系统中的同名字符串不提供来源认证。`Duration`表示纳秒持续量。`IntervalValue`经本模型接纳时要求两端都属于C且start≤end，固定为绝对坐标闭区间。负跨度仍可被普通函数算成反向记录，但该记录不成为合格范围，不能变成false或空域。CalendarPeriod不是此Duration，不能转成整数后悄悄使用。

轨迹点为`(clock, time, occurrence, responseTo)`；发生身份独立于内容和时间，点序独立于时间戳，同时间允许多个不同发生。e的身份和at由给定模型输入固定。`model:Responded(event=e)`在一个轨迹点成立，当且仅当该点是与e同钟、严格在e发生次序之后且`responseTo=e.occurrence`的响应；事件内容相同不合并身份。这个原子解释是测试模型的精确定义，没有未知业务算法。

在e的词法环境构造一次I，然后在已观察的点前缀中查找I内满足原子的点。当前前缀不包含未来点。独立的覆盖声明表示I的哪些时间及同时间全部点已闭合；只看到最大时间戳不自动获得完整覆盖。对本例只有正面原子事实且无冲突的模型：有合格见证则支持；没有见证而I全部闭合则反证；否则未定。一般Gift四态冲突仍归原语义，本有限检验不假称覆盖BOTH。

| 区别 | 正确结果 |
|---|---|
| e₁在0，e₂在10秒；期限均1秒 | 分别为[0,1秒]与[10秒,11秒]，不共用一个窗口 |
| 对应响应恰在闭合上端点且次序在e之后 | 计入见证 |
| 响应晚1纳秒，原窗口已经完整 | 不能满足该窗口 |
| 尚无响应且当前前缀／覆盖未到上端点 | 未定；不提前失败，也不声称已经满足 |
| 另一时钟上同时间同身份编码的响应 | 不满足；跨钟输入资格错误另报 |
| 两个同时间、同内容的e，仅一个收到响应 | 第二个义务仍独立 |
| 内层量词另用名字e | 不能改写外层已固定的窗口 |
| 到新观察点后用“现在”重算终点 | 滑动续期改变原义，必须拒绝该变换 |

## 保持依据与边界

对任意模型整数t及d≥0，源码中的第一次字段直接保留start；第二次保留同一个clock并使用精确加法得到t+d，所以所接纳窗口恰为`[t,t+d]`。这项代数论证覆盖所有该模型整数，不靠少数样本宣称一般证明。有限校验另执行源码中实际出现的var/field/record/symbol/literal/call片段，检查后继期限修改、边界与破坏变换；它不是通用Gift解释器、生产编译器、真实时钟测试或运行保证。

旧rangeRef及horizon源保持原义；新值槽只让已可计算的有型区间进入原时间消费者。这里没有新增方向字段或relativeRange关键字。仍未做：互动四种eventParticipation到同一会话与观察点的真实绑定、完整连续交互作者模块、一般Frame接合、Method/Time供给实现及目标运行期限验证。原工程的发生映射也继续开放，不能因本例通过而宣布整个V1完成。
