# 第一层怎样表达编译器自身：名称绑定与避免捕获的改名

本例使用[同一作者构造](../../docs/作者/第一层语言.md#intent-author-construction)，核对第一层能否创作编译器职责本身的准确含义，而非只把原生编译器调用包进一个名字。样本选择有限源码的词法绑定和后继改名；这是自举表达的具体见证，**不是完整Gift编译器、现行全部AST或已运行的自举程序**。全语言能力及阶段声明归[确定性与自举](../../docs/编译/内核/确定性与自举.md#bootstrap-author-expression)。

## 有限、递归的输入由普通定义表达

```text
定义「表达式」：有限归纳结构，恰为以下一种
  字面(值)
  引用(名称)
  应用(被用表达式, 参数表达式序列)
  配对(左表达式, 右表达式)
  绑定(声明名, 初值表达式, 体表达式)
  抽象(参数声明序列, 体表达式)

定义「函数声明」：结构
  名称、参数声明序列、体表达式

定义「模块」：结构
  函数声明的有限序列

定义「绑定结果」(源码)：值域
  对源码每个引用出现给出一个结果：绑定到实际声明，或未绑定，或歧义
  歧义结果附全部最近候选；另给出全部非法重复声明的位置组
  无结构错误、重复声明、未绑定及歧义时，模块才取得有效绑定资格
```

递归结构描述任意有限深度的表达式，不枚举未来程序，也不把自引用的运行对象图混成归纳值。每个声明、引用和结构出现有该源码修订中的真实身份；相同文本的两次出现不是一个节点。身份由源系统承接，作者不维护一份ID/位置JSON。结构必须无环、成员归属合法；不合法先报告源结构错误，不作为空模块通过。多个节点的公共子结构即使在存储中共享，源出现及绑定语境仍分别解释。

本样本只处理模块内值名称。类型空间、模块导入、公开/私有访问和宏卫生沿原语言合同另行接合，不能从本样本自动取得支持资格。表达式中的应用仅作为待分析的源码数据；分析不会执行被描述的函数。

### 作用域与可见区域的固定含义

模块的全部函数名在该模块各函数体中可见，允许前向引用和相互递归；同一模块重复函数名非法。各函数参数在该函数体中可见，同一参数序列内不许重复。抽象引入其体内的参数作用域；绑定的声明仅在它的体中可见，**在其初值中不可见**，初值仍使用外层环境。内层可以遮蔽外层，同一层非法重复不能靠序列后写覆盖。

可见区域由上述真实构造导出，不要求作者再给每个引用填符号表。各非根区域有唯一父区域，形成有限无环关系；对同一引用生效的区域在它的祖先链上。这里的区域只解释源码绑定，不与运行时调用栈、实例身份或权限混同。

```text
定义「候选」(声明d, 引用r)：关系
  d与r的名称相同，且r在d的可见区域内

定义「更近」(声明e, 声明d, 引用r)：关系
  候选(e,r)且候选(d,r)
  e的可见区域是d的可见区域的严格内层，且包含r

定义「最近」(声明d, 引用r)：关系
  候选(d,r)，且不存在源码中的声明e满足更近(e,d,r)

定义「名称绑定」(源码：模块, 输出：绑定结果(源码))：关系
  每个引用r：
    恰好一个声明d满足最近(d,r)时，输出在r处绑定到d的真实身份
    无候选时，输出在r处为未绑定并定位该引用
    多个声明满足最近时，输出在r处为歧义并附全部最近候选
  全部非法重复声明组都在诊断中给出；歧义不得任择一个声明
  输出不遗漏任何引用，不含源码以外的引用或声明
```

无歧义的其他引用仍可给诊断性结果，但含非法重复声明的整个模块不取得有效绑定资格，即使重复组从未被引用。结果域为`绑定/未绑定/歧义`，无需给每种诊断创立新核心能力。顺序与加载时机不能消除同一层冲突。

这里的有限关系定义可以通过成熟作用域分析实现，作者没有规定遍历次序或哈希表。祖先关系若需要展开，是沿唯一父链的有限路径，长度受区域数量界定；不要求枚举递归表达式类型的所有可能值。名称绑定处理的是当前有限源码出现，不推导任意程序是否终止。

## 在同一源上表达避免捕获的改名

开发者行为是“把实际声明d改名为新名，并保持绑定关系”。不能用全文件字符串替换定义该行为。

```text
定义「保持绑定改名」(原源, 声明d, 新名, 后源)：关系
  原源名称绑定有效；d是原源中的实际声明；新名是合法名称
  后源与原源具有同一出现结构、声明与引用身份
  d以及原来绑定到d的所有引用改为新名
  其他声明与引用拼写、字面值、结构、效果和公共边界保持
  后源名称绑定有效；每个引用前后的实际目标身份相同
```

这是一项精确的变换关系，给定合法原源、目标声明与新名，允许的候选是上述唯一局部拼写改动。若改动造成捕获或同层冲突，返回冲突及相交出现位置，不先移动别人的声明或顺便改名以通过。重命名公共入口另有外部消费者/兼容义务；本样本只对模块内的非公共声明使用此关系。

`后源`是所求源码值；关系成立不直接写文件。开发者接受候选后才形成新的源修订，旧分析结果不冒充新修订的证据。其他变换可以新建/删除出现或改变结构；需有各自的准确关系，不能把本例“保留全部身份”误升为所有源码修改的限制。

## 实际组合和有限判别

```text
定义「改名检查」(原源, 目标声明, 新名)：意图
  对象：求得 后源：模块
  要求：保持绑定改名(原源, 目标声明, 新名, 后源)
  实现：绑定分析和诊断布局交由系统，产品关系不得放宽
```

样本记法`绑定x=初值于体`、`抽象(x).体`只是前述结构的易读投影，不是新增实现语句。下列有限例可手工核对，当前没有执行工具：

| 源或修改 | 唯一解释/拒绝理由 |
| --- | --- |
| 函数f的体引用后来声明的g；g的体引用f | 分别绑定到模块内真实g/f声明；分析不展开调用，无需执行递归。 |
| 函数参数x；体为`绑定x=引用x于引用x` | 初值的x绑定函数参数；体内x绑定新声明。相同拼写的两次引用不可合并。 |
| `配对(抽象(x).引用x, 抽象(x).引用x)` | 两侧各自绑定自己的参数，跨子树不泄漏。 |
| 函数f参数x,y；把x改名为y | 同参数域冲突，拒绝；不能取参数顺序决定目标。 |
| `抽象(x).抽象(y).引用x`；把外层x改名为y | 引用会绑定内层y，产生捕获，拒绝并定位遮蔽声明及引用。 |
| `抽象(x).配对(引用x, 字面("x"))`；把x改名为z | 声明及引用改z，字面字符串保持；目标身份保持。 |
| 出现没有可见声明的z | 返回未绑定，不从库、宿主环境或相似拼写猜目标。 |
| 同模块两个同名函数 | 返回全部冲突位置及相关歧义引用；模块无有效绑定资格。 |
| 空模块；深层但有限嵌套；伪造父关系环 | 前者得到空的完整结果；中者按有限源码域解释；环是结构错误，不是未绑定或空成功。 |

分析入口若有实际时间/内存预算，资源耗尽必须单列为未完成并明确已覆盖范围；不能返回不完整诊断集却宣称全部绑定成功。这是实现接合义务，不让本样本增加一套调度系统。诊断、关系完整性和现实执行资源分别解释。

## 自举表达的检查结果

样本具体组合了有限递归数据、同名但不同身份、递归定义引用、作用域、全称与存在关系、结果数据、诊断，以及保持身份的源码变换。它证明这些作者区别能在同一设计中写出，不需要新增`CompilerBind`/`CompilerRename`核心枚举或隐藏原生函数来代替含义；没有证明任意关系可自动合成、实现已经存在或整个编译器表达已逐项完成。

完整编译器还需要词法/文法、全部类型与效果、跨模块解析、真实目标生成、资源与文件作用、构建依赖等职责。它们使用同一语言的结构/计算/关系/组件合同及专业定义；逐项核对位置与剩余证据见[自举作者表达核对](../../docs/编译/内核/确定性与自举.md#bootstrap-author-expression)。本轮不实现这些职责，不用一个名称绑定例代签完整自宿主。
