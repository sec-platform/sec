# 跨语言能力的连续开发

> 设计情景；不是已编译、部署或实测工程。

作者仍维护自己的 Definition、参数、关系及真实 require/prefer；下列具体句子是需求输入含义，不引入新的作者语法。编译器内部选择、目标实现与本次执行权限分别绑定。

## 三个完整使用情景

**异构序列化器。** 作者选择既定序列化定义，固定字段顺序、wire format、允许字段与错误合同。反射在合法权限下取得字段集合；pack expansion 产生具体读写；特化选择整数、字符串和用户类型的已绑定实现；字节序及范围检查由 [布局、位域、padding 与 volatile](../../docs/编译/目标/布局与设备访问.md) 消费；错误通过 [效果、异常与契约](../../docs/领域/计算基础/错误传播与契约保持.md) 传播。Rust／TS 都可输出普通函数。要求私有字段却无授权时只阻断相交字段路线；增加字段使“全部字段”集合依赖失效；第三个字段生成失败不能发布前两个字段组成的半个 serializer；序列化格式变更按独立 wire 兼容合同处理旧读写者，不能偷偷覆盖旧协议版本或把新字段默认为旧协议理解。

**固定地址异步资源。** 作者要求对象地址稳定、使用指定区域、跨挂起持有句柄并必须异步关闭。[place、初始化、复制／转移／赋值](../../docs/领域/对象与控制/位置初始化与转移.md) 先在最终 slot 完成部分初始化及失败清理，地址稳定后才公开 self/reference；[分配器、资源域与 TLS](../../docs/运行/分配域与退出责任.md) 校验区域寿命，[协程、取消与 CFG](../../docs/领域/对象与控制/协程帧与控制流降低.md) 让 frame 保存真实借用、线程/TLS 与资源 owner，[foreign ABI、C 变参、回调与卸载](../../docs/运行/原生边界与模块驻留.md) 校验回调注销。正常完成和取消都要先停止新回调、注销/join，再由仍存在的 owner 完成异步 close；调用者取消而 close 仍 pending 时不能标成 Closed。若还要求无堆分配而目标只有堆分配桥接帧，返回具体资源冲突，不默认放宽其中一项；旧回调、对象或析构代码仍在时也不能卸载旧模块。

**共享复合计数状态。** 作者要求 `(count, generation)` 一致读取、跨线程 CAS、无锁且在 C ABI 中有精确对齐。[原子值、原子视图与内存模型](../../docs/领域/计算基础/原子存储与进展条件.md) 联合检查实际原子宽度、表示、memory order、lock-free 进展、地址复用与回收；[布局、位域、padding 与 volatile](../../docs/编译/目标/布局与设备访问.md) 判断布局，[foreign ABI、C 变参、回调与卸载](../../docs/运行/原生边界与模块驻留.md) 判断导出。真正宽原子同时满足这些条件才可绑定；只有锁模拟则不满足硬性无锁，CAS 成功也不能替代节点回收。TS 普通对象路线直接不合格，但工程中其他纯计算仍可生成 TS，不能把整个工程笼统标为失败。


## 开发操作、保存和第二次修改

对每个情景，先 query 当前定义、支持范围和原始要求；在作者唯一源上形成候选，preview 只生成/解释所请求范围而不隐式安装或运行。check 以固定候选、目标与独立期望判断相应层。仅明确请求且具备当前准入时，apply 保存作者源或写入已绑定的产物；运行继续由 operation 和真实提供者处理。输出返回实际 source/candidate/artifact 引用，不要求作者编造哈希。

字段新增使序列化器的成员集合依赖重新展开，并按独立 wire 兼容合同处理旧读者；改变资源区域或关闭协议先检查活动旧对象，不能用新源删除旧 close 责任；共享计数状态从 64 位改为更宽布局时，重新核原子宽度和 ABI，缺无锁供给只阻断相交目标。生成物编辑有准确来源才走受管回源，缺映射保留为独立目标草稿，不用下一次生成覆盖它。

## 从不同失败继续

语义无效返回该使用点诊断；缺供给返回实际 Needs；候选歧义保留可选择范围；工具或设备不可用与无权不同。编译失败保全作者源与已有完整成果；已开始的构建/运行断线沿原 operation 查回，不换身份重放。一个目标的物理硬条件不成立，不宣告其他独立根失败。有限分支的通过不消解尚未处理的原要求。
