# Support

SEC is an active development preview without a stable support or compatibility commitment.

- Use a GitHub issue for a reproducible defect in the current `main` branch.
- Use a feature request for a concrete product need or a bounded design proposal.
- Include the exact commit, environment, inputs, minimal reproduction, observed result, expected result, and relevant logs with secrets removed.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Questions that depend on private environments, unsupported historical revisions, customized forks, or unprovided external services may not be reproducible by the maintainer. The repository documentation and issue tracker are the public support record; no response-time guarantee is currently offered.
