## 具体机制

| 入口 | 责任 |
|---|---|
| [编译内核](内核/README.md) | 公共输入与结果、生成规则、遍管理、诊断和领域方法 |
| [目标组织](目标/README.md) | 完整成员、布局、目标降低与连续生成 |
| [表示保持](表示/README.md) | 作者、需求、实现和目标的不同含义，来源对应及受管回源 |
| [有条件实现与公共行为保持](有条件实现与公共行为保持.md) | 对完整需求联合选择专用/通用实现，保留适用域、一次求值、分支成员和证据 |
| [性质保持与开放环境](性质保持与开放环境.md) | 单轨迹、跨运行、分布、开放链接及观察关系的保持资格 |
| [组合前提与进展闭合](组合前提与进展闭合.md) | 假设支持、合法反馈、正常进展、真实共享预算与分根结果 |
| [查询增量与性能](查询增量与性能.md) | 准确读集、解释、缓存、失效和成本 |
| [递归并行与远程编译](递归并行与远程编译.md) | 声明关系、执行前置、任务与资源的独立调度条件 |
