# 仿真数值与现实的组合反例

[全域接合检查](../全域接合检查.md)定义这些验收设计的用途。每项是触发、预期与观察方案，执行状态未由本文签发；必须绑定实际实现、输入、方法和环境后才能形成产品证据。

## 病态求解

**触发条件：**残差很小但问题条件差

**应保持结果：**保留残差与误差界的区别及适用条件

**验证设计：**病态矩阵与已知解比较

## 量纲或坐标错接

**触发条件：**仿真器交换毫秒/秒或不同坐标帧

**应保持结果：**显式转换，缺语义映射则拒绝连接

**验证设计：**时间、温度、角度与坐标方向案例

## 并行随机流重复

**触发条件：**不同实验意外复用同一随机流

**应保持结果：**按流身份与实验划分检测/避免

**验证设计：**并行度变化、重启与子流复用

## 浮点归约次序

**触发条件：**并行数目或硬件变化改变归约

**应保持结果：**按所需位级或容差合同处理，不假称绝对一致

**验证设计：**不同并行度和目标执行对照

## 零时事件与Zeno

**触发条件：**同一时间无限触发模式或事件

**应保持结果：**报告无进展/预算前沿，不偷偷推进时间

**验证设计：**零延迟反馈和guard反复触发

## 联合仿真失稳

**触发条件：**两个局部收敛模型耦合后发散

**应保持结果：**检查耦合策略和交换步，失败轨迹不当预测

**验证设计：**通信步缩小及守恒检验

## 检查点遗漏状态

**触发条件：**只存业务状态却遗漏RNG或求解器历史

**应保持结果：**检查点包含所声称重放需要的闭包

**验证设计：**恢复后与不中断运行对照

## 墙钟与仿真钟误用

**触发条件：**倍速仿真调用真实超时或授权时钟

**应保持结果：**显式时间接口，权限仍基于正确真实时间

**验证设计：**倍速、暂停和时钟跳变

## HIL危险边界

**触发条件：**仿真试验连入真实执行器

**应保持结果：**独立准入、隔离、急停与安全态

**验证设计：**断连、越期、异常输入与物理确认

## 校准过期

**触发条件：**传感器漂移或校准记录失效

**应保持结果：**降级相交观察和控制资格

**验证设计：**过期、饱和、缺样和重校准

## 模型用途越界

**触发条件：**训练或局部模型结果用于不同现实场景

**应保持结果：**报告用途和证据缺口，不扩大发布声明

**验证设计：**样本外、极端工况和不同人群

## 成对通过仍有三方容量冲突：有限设计见证

<a id="finite-可报警不等于能及时制止"></a>
## 可报警不等于能及时制止：有限设计见证

**给定模型：**假设检测/传输/动作可靠上界5/2/8，危害发生下界10，单位一致。

**该模型的可复算结果：**

```json
{
  "response_bound": 15,
  "hazard_lower_bound": 10,
  "timely": false
}
```

**适用与限制：**这些数值是反例输入；没有计算任何真实设备安全余量。这些上/下界不足以支持及时制止；允许各阶段达到该上界且危害在下界发生，才构成具体迟到执行。不能从界限比较直接断言每次真实执行都迟到。

**机制入口：**[真实控制、运行假设监测与安全响应期限](../../../领域/仿真/联合仿真与现实控制.md#real-control-response-boundary)。

这里保存具体设计见证；不是SEC、实际Provider或硬件执行通过记录。
