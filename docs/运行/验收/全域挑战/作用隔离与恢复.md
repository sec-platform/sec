# 作用隔离与恢复的组合反例

[全域接合检查](../全域接合检查.md)定义这些验收设计的用途。每项是触发、预期与观察方案，执行状态未由本文签发；必须绑定实际实现、输入、方法和环境后才能形成产品证据。

## 旧异步结果覆盖

**触发条件：**旧编辑版本计算晚于新版本完成

**应保持结果：**仅关联正确修订，不覆盖当前结果

**验证设计：**打乱完成顺序并检查UI和缓存

## 生成覆盖人工源

**触发条件：**生成布局与用户文件发生冲突

**应保持结果：**按作者权和前像拒绝或产生明确合并候选

**验证设计：**手改文件、重命名和部分生成

## 路径别名与符号链接

**触发条件：**不同路径指向同一物理对象或越界

**应保持结果：**实际路径边界与所有权检查一致

**验证设计：**符号链接、大小写和路径穿越

## 源码注入

**触发条件：**字段名或内容含代码、SQL、命令字符

**应保持结果：**结构化生成和严格编码，不拼接执行

**验证设计：**特殊字符、保留字和畸形载荷

## 未授权安装脚本

**触发条件：**发现依赖时试图执行安装代码

**应保持结果：**获取、安装、执行各自准入

**验证设计：**恶意包脚本和离线查询

## 插件泄露秘密

**触发条件：**规则试图读取环境凭据或联网外传

**应保持结果：**按能力隔离拒绝，观测不泄露秘密

**验证设计：**文件、网络、日志与错误通道负测

## 资源耗尽

**触发条件：**插件或大模型无限分配、递归或产出

**应保持结果：**预算停止并保留正确前沿，无半成品污染

**验证设计：**CPU、内存、GPU与输出字节极限

## 取消与清理

**触发条件：**操作在资源取得后取消

**应保持结果：**结束/隔离在途工作并准确结算释放

**验证设计：**每个资源阶段触发取消

## 无关变化全局失效

**触发条件：**无关领域文档变化触发所有编译

**应保持结果：**按真实依赖失效，不绑定全库全局版本

**验证设计：**非相交变化与性能读集核验

## 接口同形语义不同

**触发条件：**两个方法同签名但一方有副作用

**应保持结果：**必须依据完整合同判断替代资格

**验证设计：**排序稳定性、错误和效果差异

## 回滚越过现实

**触发条件：**游戏或仿真回滚覆盖了真实支付/设备动作

**应保持结果：**只回滚合格区域，外部作用独立结算

**验证设计：**混合虚拟与真实效果场景

## 支付未知完成

**触发条件：**远端已完成但响应丢失

**应保持结果：**按请求身份查询/对账，禁止盲重试

**验证设计：**提交后断连与重复客户端请求

## 消息重复投递

**触发条件：**同事件多次投递或换载荷重用ID

**应保持结果：**去重和语义冲突处理，不额外产生效果

**验证设计：**消息重复、乱序、过期与相同ID不同内容

## 错误的幂等缓存

**触发条件：**旧逻辑结果缓存含当前无权披露内容

**应保持结果：**执行幂等与当前披露权限分别检查

**验证设计：**撤权后重取已完成结果

## 多文件提交中断

**触发条件：**发布部分文件后进程崩溃

**应保持结果：**使用真实提交协议并给准确恢复状态

**验证设计：**每个写入/切换/落盘位置中断

## 纯查询暗含写入

**触发条件：**分析期间创建缓存、装插件或修改索引真源

**应保持结果：**纯阶段不产生未授权效果

**验证设计：**只读文件系统和权限沙箱运行

## 跨租户缓存污染

**触发条件：**相同内容摘要用于不同可见范围

**应保持结果：**纯计算可共享，披露与授权不共享

**验证设计：**秘密、错误诊断与缓存键负测

## 离线撤销冲突

**触发条件：**设备离线仍要求即时获知撤权

**应保持结果：**说明条件冲突并按采用离线政策限权

**验证设计：**断连期间撤销再重连

## 热替换状态不兼容

**触发条件：**运行时换方法而状态表示不同

**应保持结果：**需要迁移和切换协议，否则保留旧路

**验证设计：**切换中断、旧句柄和状态恢复

## 旧消费者继续写

**触发条件：**迁移后老客户端或进程恢复上线

**应保持结果：**拒旧、桥接或明确迁移，不破坏新不变量

**验证设计：**长离线与旧写者复活

## 源回滚误当数据恢复

**触发条件：**回滚程序版本但数据库已迁移

**应保持结果：**检查数据兼容与独立迁移，不直接运行旧源

**验证设计：**升级后降级与混合版本

<a id="finite-最终目标拒绝旧世代写入"></a>
## 最终目标拒绝旧世代写入：有限设计见证

**给定模型：**目标原子执行世代检查与写入；世代2先到，1晚到。

**该模型的可复算结果：**

```json
{
  "naive_final": "stale",
  "fenced_final": "new",
  "decisions": [
    {
      "epoch": 2,
      "accepted_by_target": true
    },
    {
      "epoch": 1,
      "accepted_by_target": false
    }
  ]
}
```

**适用与限制：**模型假设目标确有原子拒旧；不证明任何实际服务支持该能力。

**机制入口：**[租约、栅栏、当前授权与旧写者复活](../../持久化提交与恢复.md#receiver-fencing-and-stale-writer)。

这里保存具体设计见证；不是SEC、实际Provider或硬件执行通过记录。

<a id="finite-副本收敛不保证库存不超卖"></a>
## 副本收敛不保证库存不超卖：有限设计见证

**给定模型：**每笔销售占1；两节点从同库存1独立接受不同ID，合并用集合并。

**该模型的可复算结果：**

```json
{
  "local_valid": true,
  "merged_sales": 2,
  "remaining": -1
}
```

**适用与限制：**仅说明这个合并规则与不变量不相容；并非所有CRDT都不能保持所需不变量。

**机制入口：**[分布式合并、全局不变量与离线预算](../../持久化提交与恢复.md#merge-invariant-and-offline-budget)。

这里保存具体设计见证；不是SEC、实际Provider或硬件执行通过记录。

<a id="finite-多层重试相乘而非相加"></a>
## 多层重试相乘而非相加：有限设计见证

**给定模型：**三层每次调用各最多4次尝试，最坏情况下每个上层尝试展开完整下层。

**该模型的可复算结果：**

```json
{
  "enumerated_bottom_attempts": 64,
  "sum_of_limits": 12
}
```

**适用与限制：**假设完整展开的最坏情况；不预测实际重试流量。

**机制入口：**[故障域、重试放大与恢复资源预留](../../保证/系统不变量与组合.md#recovery-capacity-and-common-causes)。

这里保存具体设计见证；不是SEC、实际Provider或硬件执行通过记录。

## 满载正常工作没有恢复预算：有限设计见证

**给定模型：**资源容量10，正常已占10，恢复另需2；替代正常占8。

**该模型的可复算结果：**

```json
{
  "recovery_fits_at_full_load": false,
  "recovery_fits_with_reserve": true
}
```

**适用与限制：**说明需要预算/拒新策略；2不是实际通用恢复预留值。

**机制入口：**[内容存储、保留根、删除与恢复闭包](../../../信息/存储保留与恢复.md#recovery-bootstrap-retention)；[故障域、重试放大与恢复资源预留](../../保证/系统不变量与组合.md#recovery-capacity-and-common-causes)。

这里保存具体设计见证；不是SEC、实际Provider或硬件执行通过记录。

## 回滚本地快照不能撤回已披露结果：有限设计见证

**给定模型：**一个允许最多1次发布的玩具会计；r1已经被外部观察，本地回到空记录后又发布r2。

**该模型的可复算结果：**

```json
{
  "restored_local_count": 0,
  "actual_releases": 2,
  "limit": 1
}
```

**适用与限制：**不是差分隐私组合定理，仅检验实际释放不能随本地回滚消失。
