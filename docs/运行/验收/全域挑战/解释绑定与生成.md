# 解释绑定与生成的组合反例

[全域接合检查](../全域接合检查.md)定义这些验收设计的用途。每项是触发、预期与观察方案，执行状态未由本文签发；必须绑定实际实现、输入、方法和环境后才能形成产品证据。

## 未知方言节点

**触发条件：**旧读者读取含新语义的源

**应保持结果：**保全允许的未知载荷，拒绝依赖未知含义的变换

**验证设计：**检查旧读写往返及相交根诊断

## 插件装载顺序

**触发条件：**同一组插件改变注册顺序

**应保持结果：**冻结选择下输出与裁决不受加载顺序影响

**验证设计：**排列装载次序并比较精确输出

## 未知字段与重复键

**触发条件：**模块携带重复键或未协商规范字段

**应保持结果：**拒绝歧义编码；保全路线不签语义成功

**验证设计：**畸形输入、未知扩展和旧读者

## 同名异物

**触发条件：**两个租户或设备使用相同显示名

**应保持结果：**按准确主体处理，不能误合并权限或状态

**验证设计：**同名不同ID的跨域引用负测

## 句柄槽位复用

**触发条件：**已释放槽位被新对象复用

**应保持结果：**旧generation句柄必须拒绝

**验证设计：**反复分配释放并重放旧句柄

## 相同内容不同实例

**触发条件：**两个运行实例共享相同代码摘要

**应保持结果：**可复用纯代码，不共享各自可变状态

**验证设计：**实例交叉写入与生命周期测试

## 默认值漂移

**触发条件：**升级定义后默认值改变

**应保持结果：**旧候选保持原解释，新候选明确迁移

**验证设计：**固定旧快照与升级后重读

## 作用域捕获

**触发条件：**模板或生成规则插入同名局部符号

**应保持结果：**卫生代换，不捕获用户变量

**验证设计：**多层作用域与影子变量案例

## 仅声明已处理

**触发条件：**方法报告全部义务handled但漏真实实现

**应保持结果：**不授予完整输出根资格

**验证设计：**核对真实导出、成员和前提

## 预算耗尽冒充无解

**触发条件：**求解器未在预算内找到候选

**应保持结果：**返回前沿/未知，不报告不可满足证明

**验证设计：**已知有解的大搜索空间

## 局部根与整体根

**触发条件：**一个独立根失败，另一个已闭合

**应保持结果：**返回精确分根结果；共同发布组不得假拆

**验证设计：**独立组与有共同不变量组对照

## 局部可行整体不可行

**触发条件：**多个方法争用同一资源或时序

**应保持结果：**联合检查并给冲突原因

**验证设计：**单项均通过但总容量超限

## 循环保证自证

**触发条件：**组件互相假设对方已提供安全前提

**应保持结果：**证明初始基础或保持未决，不能互签成功

**验证设计：**无外部基础的假设环

## 不同种类的环

**触发条件：**递归函数与初始化依赖均成环

**应保持结果：**前者按语言合法，后者需真实启动协议

**验证设计：**递归类型、事件环、构建环分测

## 生成新增依赖

**触发条件：**降低后才出现helper或运行库

**应保持结果：**回到贡献检查与选择，不在封存后补文件

**验证设计：**故意迟发现依赖的目标方法

## 负依赖缓存

**触发条件：**原来不存在的候选现在加入目录

**应保持结果：**受影响选择重新评价，旧结果不假装仍最优

**验证设计：**仅改候选集合而不改源

## 时间戳误作因果

**触发条件：**不同时间域事件值相同

**应保持结果：**不能据此判断先后或授权时效

**验证设计：**墙钟回拨与逻辑时钟混用

## 数值精度丢失

**触发条件：**大整数或高精度值跨JS/JSON边界

**应保持结果：**采用合格编码或拒绝目标，不能静默截断

**验证设计：**边界值和往返检查

## ABI布局不符

**触发条件：**目标结构对齐或调用约定变化

**应保持结果：**拒绝旧绑定或生成明确桥接

**验证设计：**目标工具链和布局变化

## 所有权释放错误

**触发条件：**外部库返回由不同分配器持有的对象

**应保持结果：**遵守原释放与寿命合同

**验证设计：**跨语言分配、取消及反复装载

## 异常穿越FFI

**触发条件：**原生异常或panic越过不支持边界

**应保持结果：**转换为合法边界结果或隔离

**验证设计：**异常触发、析构和资源清理

## 目标硬要求缺失

**触发条件：**目标无所需原子、地址或实时能力

**应保持结果：**报告相交缺项，不改要求冒充支持

**验证设计：**受限目标与原生目标对照

## 先选输出与看见未来后逐点选输出：有限设计见证

**给定模型：**b,y∈{0,1}; 必须先固定y再收到b。

**该模型的可复算结果：**

```json

  "exists_y_forall_b": false
```

## 多文件读取得到从未存在的组合：有限设计见证

**给定模型：**实际状态依次(0,0)→(1,0)→(1,1)；先读旧A，后读新B。

**该模型的可复算结果：**

```json
{
  "states": [
    [
      0,
      0
    ],
    [
      1,
      0
    ],
    [
      1,
      1
    ]
  ],
  "captured": [
    0,
    1
  ],
```

**适用与限制：**这个交错反例证明普通分项读取不自然形成原子快照。
