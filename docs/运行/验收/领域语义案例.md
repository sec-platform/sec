## 有限状态画像的差分与故障切点

对相同声明的公共子域，可使用上游SCXML断言和独立参考解释，避免重建全部基础测试；不同事件匹配、错误或完成规则不直接作等价oracle。语义测试的预期来自已选合同和手算，不能让同一个生成器的表自己认证。

| 切点/变化 | 需要区分的期望 |
|---|---|
| 一个正交区域final，另一个未完成 | 没有整体Done |
| 父不退出但内部完成见证被移除后重建 | 新完成轮次；旧队列通知不复活 |
| deep改shallow | 恢复叶/恢复直接子后取默认，行为明确改变 |
| 父退出过程中捕获history | 从退出前完整配置取记录，不边删边记录 |
| entry构造输出后下一动作报错 | 原稳定状态与未发计划保持，不出现半次外部作用 |
| 无事件自循环 | 受控中断且非Stable，不靠业务cancel排队自救 |
| 根final但worker未停止 | 状态完成、资源仍占有并有负责者 |
| 提交成功但回复丢失 | 原输入回读，不生成新命令身份 |
| 模型改名/顺序/语义加强 | 名称不改优先，顺序改优先，加强要求需重核旧完成 |
| timer重复创建或进程重启 | 同一逻辑deadline不因重试延期，不能跨boot误比单调时钟 |

实作时分别核文本/结构到模型、模型到目标、driver到真实提供者，取得哪层证据就标哪层范围。


## 有限关系的算法和故障判据

设计期望见[关系正常与反例表](../../领域/状态关系与流/关系查询与维护.md)。至少覆盖重复左右行、空组与全局聚合、ON/WHERE位置、嵌套Option和右存在位、含NUL Text、超范围Int、同键排序、错误回调和take零。它们是待实现的验证输入。

增量故障点依次放在接收闭合批次、更新左索引、更新右索引、输出差量、校验新状态、提交引用和返回之间。每个切点只允许旧完整代或新完整代，不能混合offset与结果。按原批次重试不重复推进；乱序/丢失批次要求补齐或重建；删最后支持、同时删左右、自连接与delta额外求值有独立期望。

真实目标检查应固定codec、数据库版本/角色、快照、参数和排序，记录故障分类及当前权限。默认不复制上游数据库全测试；适配实际采用哪部分才核哪部分。没有相应工具和授权时只交付这些可执行的判据，不编造已运行结果。


## 私有函数抽取的独立期望

验证对象是同一基础上的选区、新helper和调用点，不是任意两份程序。分别检查自由Binding替换、类型参数、原激活区、实参先后、调用次数、原契约、源码未改范围和身份对应。safeQuotient的x=0不执行helper、x=2得到5；next两次不能共享、已有v两次不能重求；lambda体不能提升到构造期；未用实参中的错误或不终止不能因内联消失。

结构保持检查与运行案例分开。先以绑定/代换检查承担有限规则，实际实现后再运行这些独立期望；运行样例不证明无限域等价。源码字节保持通过实际前后切片核对，公开ABI与硬资源约束另有对应方法，不能由函数类型通过代签。


## 有限对象、流与微分的可区分判据

对象复核要区分构造前参数效果、构造中this泄漏、父子私有字段、虚槽契约、方法后半失败后的真实写入及两个同值实例的身份；不能只看目标生成了class。

流复核要区分需求信用、计数与字节上限、早项阻塞、有序发布、估计/严格进展、窗口负时间、修正截止、取消/End及热源丢样。相同最终数值不掩盖丢失或窗口过早关闭。

微分复核使用独立数学结果、相同输入的原值、JVP/VJP对偶配对、共享变量贡献、不光滑点、边界未判与数值故障；有限差分只在适用光滑域与步长范围作辅助，不作为唯一正确答案。检查点和取消另核实际资源与重复作用。

这些是明确的设计期预期与后续符合性对象，不是本版已经执行的产品测试。文档图的渲染检查不替代上述运行和数学判据。


## 语言组合与对象入口的独立核查

验证对象首先固定语言组合、规则内容、方法与目标，不以`/1`或安装名相同推断同义。新默认支持class而旧基础解释不支持时，两者应给各自准确结果；普通import不能偷偷切换旧parser。组合没有发生变化的普通函数与未用领域，不应新增运行设施。

有限对象至少区分：两分支各初始化一次允许；只在一分支初始化后读取拒绝；可能初始化后再次写入拒绝；Unit构造出口、父构造先行和this无逸出分别成立。before仅接受实例ensure中的合法不可变字段投影；伪同名函数无特权；getter、result、对象引用和构造器before拒绝。add从2增加3时后置前态为2、当前为5；方法更新后错误保留真实当前更新而非回滚成2。构造/方法片段尚未运行时这些只是验收期望，不能写成执行通过。

设计准入先具备这类独立判据；程序实现以后才执行符合性。没有采用数据库、租户、远程或增量的代码任务，不为填写固定检查清单而先实现那些设施；真实写回、披露、取消与资源释放仍按实际发生的动作核查。


## 作者控制、保存与目标消费的联合验收设计

本组检查从[完整作者轨迹](../../../examples/连续开发/组合结构与任务轨迹.md#同一作者源的复用与短操作轨迹)与[控制合同](../../作者/组合/稀疏控制与目标限定.md#6-控制描述符与实际使用过程)派生；它是验收设计，不表示已运行产品。成熟上游的解析、容器与编译实现按前提复用，重点检查本项目增加的映射、组合和实际控制。

| 输入或扰动 | 必须能够区分的结果 | 修复归属 |
|---|---|---|
| first→last，同一id多次出现 | 取项和输出位置顺序共同改变，类型通过不代签 | 源/库合同与目标降低 |
| 同id最高分、同分最后；附未启用高分项 | 所选结果不受disabled高分影响，不把新政策塞进未定义枚举 | 作者算法及定义检查 |
| 仅Java Item声明形式与公开名覆盖 | Java产物履行二者；TS按其范围处理，不能代签Java互操作 | 控制合并、目标和产物检查 |
| CONTROL值合法，生成器忽略它 | 控制未满足而非“配置已经保存所以完成” | 后端消费与检查 |
| reset类形式，保留公开名 | 删除一项当前覆盖，另一项及上级要求仍在 | 控制记录/合并 |
| 本地覆盖恰好等于默认，随后默认升级 | 显式固定保留；reset后的继承按准确新基础变化 | 来源与增量失效 |
| 控制保存后换会话、移动源文件 | 读取原精确映射与绑定；丢失映射不按同名猜回 | 作者保存与恢复 |
| 同键重复记录，或把targetRef当target | 先核原重复与字段，再返回结构/目标错误，不忽略后继续 | 协议读取器 |
| 私有本地例外与共享类型ABI耦合 | 只改允许使用者；不能为局部控制修改其他未获准消费者 | 精化、类型身份与布局 |
| 旧基线上的编辑与当前头不同 | 形成明确分支；写回比较真实前像 | 候选与执行 |
| 上游更新与本地行为不同 | 判断B→L、B→U与接口条件，冲突保留双方，不自动覆盖 | 库演进与合并 |
| 纯生成返回成功 | 没有产生文件、安装、执行或部署的虚假记录 | 应用与作用边界 |

行为期望来自固定合同和独立推导。比较作者成本时同时计算首次说明、完整源码/控制、已定位与冷启动两类交互、维护库的投入、错误修复及连续修改；不能用两字段请求长度代替完整产品收益。


## 需求抽象的正常关系与实现基线对照

对[按键取极值](../../作者/组合/模块封装与复用库.md#有限可复用合同按键取极值并保留来源次序)按准确Task/Definition/Artifact分别检查，而不是以接口可解析认证简化。A1=(A,true,9)、B1=(B,true,5)、A2=(A,true,7)、B2=(B,true,5)的最高分且同分最后结果为A1/B2；disabled高分项不得参与排名；所有分数为负也应选真实最大值；空输入返回空，非法keep先失败。

次序反例使用A1=(A,true,1)、B1=(B,true,2)、A2=(A,true,3)：胜出应按原位置输出B1/A2，不能采用字典中A首次插入的顺序。额外反例包括key成功而score失败、第二遍不能重调回调、非终止不能当无元素、同值不同出现、计算取消与结果尚未完整。证明或检查只覆盖明确值域；泛型回调可能改变旧程序的失败顺序，不能未经依据将任意递归替成新调用。

作者收益另作完整对照：同样的成熟库可用于原生语言；比较初次建立定义、调用方、一次参数修改、改变排名、失败修复及库维护。不能把库内部成本删除、把已读warm请求与全新模块比较，也不能因私有实现含循环判定抽象失败。文档期望与算法不变量可由推导给出，真正实现和任务效果仍须相应授权及观察。

## 作者成果与语法接合的书面验收

以下SRC01—SRC26是需要真实语言/宿主核验的设计案例，不是已运行的产品测试。独立语法识别、导入/公开名核对只覆盖其中有限的结构条件，不为效果、并发、磁盘写入或类型算法代签。

| ID | 输入或变化 | 需要观察的结果及反例边界 |
|---|---|---|
| SRC01 | 产品使用者只改historyLimit | 只改变完整应用差异与受影响检查；不改库定义或手写推导镜像 |
| SRC02 | 调用高层definition.define | 能定位Program、配置校验、真实函数和叶原语；缺体不是被范本名掩盖 |
| SRC03 | r with {x:f(),y:g()} | receiver一次，f后g各一次，原r不写；任一失败顺序保持 |
| SRC04 | r with {x:1,y:r.x} | y读取旧r.x，不是从更新中的临时字段取值 |
| SRC05 | 更新未知/重复/空字段或尾逗号 | 文法或字段检查拒绝，不静默覆盖/忽略 |
| SRC06 | 两个同布局名义类型 | 更新保留原身份，不能借字段一样转换 |
| SRC07 | 模块外更新opaque字段 | 拒绝，使用真实公开操作 |
| SRC08 | 记录内含Own或越界Borrow | 没有资源保持证明时拒绝快捷更新，不复制或丢弃句柄 |
| SRC09 | 字段更新违反min<=max等约束 | 结构合法不等于合约满足；相交检查或公开构造承担 |
| SRC10 | 静态Command.Search()与普通factory() | 前者真实数据构造器可被动建值；后者即使声称纯也不作为普通StaticExpr放行 |
| SRC11 | let id=x=>x试图跨Int/Text隐式多态 | 当前规则不作隐式全称泛化；`明确fn<T>`或各自单态包装 |
| SRC12 | a😀a的搜索与宿主坐标 | 标量[1,2)准确映射，不混用UTF-16单元 |
| SRC13 | 查aaaa中的aa | 非重叠[0,2),[2,4)，不得偷偷改成重叠替换 |
| SRC14 | 旧query完成或查询内容ABA | epoch与固定范围拒绝旧结果，不能仅比needle |
| SRC15 | 重开实例后旧SaveFinished相同request.id | 旧session根dispatcher拒绝，不认定新保存完成 |
| SRC16 | 预览后文档修改或undo回同文本 | corpus和单调修订使旧Plan失效，同字节不恢复旧身份 |
| SRC17 | 批量内存替换第二文件失败 | 新值未采用，无局部可见写；不因此承诺磁盘事务 |
| SRC18 | 保存修订1期间用户改成修订2 | Written只更新savedText/stamp，不覆盖新text，dirty正确 |
| SRC19 | 保存Unknown后点击重试/关闭 | 保留原未决，不新ID盲重发，也不无记录退出 |
