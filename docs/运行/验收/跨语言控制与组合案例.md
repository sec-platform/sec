# 跨语言控制与组合验收

> 书面验收合同；不是已执行产品测试、ABI 验证或性能报告。

只有适用条件已激活的用例才成为当前输出义务。取消某能力不抹去其已发生作用与恢复责任；未启用不等于通过。共同证据接纳仍见[方法与独立证据](方法与独立证据.md)。

## 共享基与别名

**适用条件：** 仅需要共享子对象/动态视图时；普通组合不自动引入虚继承。

**输入与触发：** 构造 Diamond，经两条基路径申请并行独占可变 view。

**预期结果：** 不能形成两个不相容独占借用；串行访问观察同一状态。

**所需观察层：** type_check、runtime_trace。选择具体实现后绑定版本、环境和实际输入，不由同名测试代签。

**预期结果：** 接口不满足；必须改成真实 SEC 泛型分发、可表达原生接口或明确有限实例。

**所需观察层：** interface_check、downstream_compile。选择具体实现后绑定版本、环境和实际输入，不由同名测试代签。

<a id="v39"></a>
## 目标限制局部化

**适用条件：** 多目标生成采用局部约束的实际项目。

**输入与触发：** 模块同时包含普通纯函数及需原生稳定地址的外部设备操作。

**预期结果：** 仅设备操作的 TS 路线不合格；保留可用纯函数结果及明确混合边界。

**所需观察层：** capability_check、artifact_check。选择具体实现后绑定版本、环境和实际输入，不由同名测试代签。

<a id="v40"></a>
## 旧源语义保全

**适用条件：** 实际导入、改写或往返原生源程序时。

**输入与触发：** 导入未知 native 构造，尝试自动提升并承诺原文字节往返。

**预期结果：** 没有映射／来源就保留原生片段或报告缺项，不把行为近似当无损编辑。

**所需观察层：** source_mapping_check、roundtrip_check。选择具体实现后绑定版本、环境和实际输入，不由同名测试代签。

## 跨机制组合

| 组合 | 容易出现的错误 | 设计决定 |
|---|---|---|
| 虚共享基＋可变借用 | 左右路径被当成不同存储 | 投影先归约到同一 owner／subobject，再判断别名 |
| override＋部分初始化 | 基构造期间调用未建立派生字段 | 构造阶段限定分派；默认完整初始化后才调用 |
| 重载＋隐式转换＋默认参数 | 参数选择反过来改变效果而不重新检查 | 选定 conversion plan 后组合效果并固定调用 |
| 特化＋开放插件 | 新导入的 impl 改变已编译调用含义 | 有界 owner／显式 witness；实例化绑定不由载入顺序重选 |
| 特化＋擦除寿命 | 编译时走不同分支，代码生成时却合并 | 禁止未保留判据的分派；必要 witness 进入实例身份 |
| 反射＋访问控制 | 生成代码成为读取私有成员的后门 | 反射权限与生成后权限都检查，授权不因生成放大 |
| 反射＋增量缓存 | 只记录已看到字段，漏掉新增字段 | 集合查询本身成为依赖，包括成员集合的变化 |
| 复制／移动＋异常 | 半完成转移被当成完整对象清理 | 初始化 mask、源状态和失败保证共同驱动 cleanup |
| 固定地址＋容器增长 | 地址敏感元素被 reallocate 搬走 | 固定存储／间接句柄／非增长区域，或拒绝增长 |
| allocator＋赋值／swap | 指针换了但释放 owner 没换 | 保留传播政策；必要重新分配，失败不误报强保证 |
| 尾部 padding＋原子视图 | 对一个成员的宽访问覆盖另一个 | 按真实 byte range 与生命周期检查，禁止冲突覆盖 |
| volatile＋重载／借用 | 转换到普通引用后丢掉 volatile | 访问属性传播到最终操作，禁止静默丢 qualifier |
| 协程＋TLS＋线程迁移 | 唤醒后访问原线程的资源 | thread-bound 进入任务类型／调度要求 |
| 协程＋异步析构＋取消 | Future 丢弃后没有人执行 close | 关闭续体有确定 owner；未完成显式留为 outstanding |
| 浮点＋SIMD＋const-eval | 编译期宿主与运行目标舍入不同 | 使用目标数值合同；常量结果不由构建宿主偶然决定 |
| 外部异常＋Rust callback | 展开越过不允许的 ABI 边界 | 在正确异常域捕获并按协议转译 |
| 类型反射＋动态库卸载 | 元数据引用指向已卸载代码 | 运行世代与活跃引用阻止提前卸载 |
| 原子操作＋对象回收 | CAS 成功后仍访问已释放节点 | 回收协议独立存在，CAS 不替它签发有效性 |
| 契约忽略＋unsafe lowering | 删除唯一保护条件形成 UB | 需有效证明或保留检查，否则不能采用该 lowering |
| separate compilation＋泛型 | 未分发实例化定义却承诺任意下游类型 | 分清 SEC 泛型、原生可表达泛型和有限实例 API |

这些不是要求开发者每次手写二十项清单，而是编译器与适配器在真实使用点消费已有合同。


## 逐项验收定位

64 项单项出口随[比较记录](../../依据/来源/Rust与C++能力比较.md)保留，防止只保留组合例而丢掉 proxy、默认参数、const 值身份、泛型公开接口等独立要求。单项的运行、目标、ABI 与负例证据分别取得，不能由文档存在相互代签。

<a id="extension-acceptance-cases"></a>
## 扩展消费链的相交验收

以下场景沿现有解码、语义、编辑、影响、降低、保证及执行拥有者核对；是书面预期，不是当前实现通过记录。

| 情形 | 必须观察到的结果 | 不能冒称 |
|---|---|---|
| 新增普通函数/类型 | 不修改核心业务枚举也能沿已有作者定义路径处理 | 不代表任意新物理语义自动支持 |
| 有限画像收到未知谓词 | 原有限解码/校验规则准确拒绝其语义消费 | 拒绝不能推出用户无权保全原始资产 |
| 明确选择的新领域关系 | 引用、签名、解释、消费者能力和版本一起绑定 | 仅解析成功不是完整资格 |
| 未知效果或影响方法 | 保守边界或精确缺项；不当作无效果 | 不能为省分析把缺项写成false |
| 新成员加入被枚举的集合 | 依赖该全集/否定查询的派生结果失效 | 固定旧绑定无需无条件全库重算 |
| 移除循环的唯一种子 | 相交派生支持重算，不互相自证 | 缓存对象存在不是证明 |
| 低级输出保持但泄露秘密 | 强Claim不获得接纳，合格旧方法可保留 | 不阻断无关弱要求的独立成果 |
| 概率样本被错误复用 | 检出联合合同改变 | 边际与固定seed不签分布保持 |
| 检查器总返回true | 不获得任意Claim逻辑支持 | 沙箱完成不等于可信证明 |
| 源/公式/实现数值模型不一致 | 回到独立语义和适用域裁决 | 双后端一致不掩盖共同错误 |
| 新规则/公理解释旧证据 | 产生相交重评或迁移要求 | 不静默沿用旧保证 |
| 构建取消而远端作用未结算 | 保留操作身份与回执恢复责任 | cancelled不等于never-happened |
| 原生语言导入选择规则 | 保留其规定的调用/诊断，不用中立策略改义 | 共用候选结构不等于共用政策 |
| 纯短函数 | 只创建实际需要的内存对象和必要检查 | 不强迫新服务、永久实体和全量证据 |
