## 医疗服务、临床系统与健康信息

**关键对象：**患者、医护、就诊、医嘱、结果、设备与同意

**共同不变量：**患者身份、单位、临床事实、建议和最终专业判断分开

**失败与恢复：**错配身份、缺失结果、警报疲劳和设备异常须升级到真实责任人

**共同验证：**危害场景、代表性临床任务、设备联调和专业验证

**相关机制：**[主体身份与引用](机制适用性.md#主体身份与引用)；[隐私、同意、目的与保留](机制适用性.md#隐私同意目的与保留)；[传感、计量与校准](机制适用性.md#传感计量与校准)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[危害、风险边界与防护](机制适用性.md#危害风险边界与防护)；[协议、格式与标准符合性](机制适用性.md#协议格式与标准符合性)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[幂等、补偿与操作结算](机制适用性.md#幂等补偿与操作结算)；[人员、组织、责任与申诉](机制适用性.md#人员组织责任与申诉)

**任务：**交换和维护就诊、诊断及观察资料

**任务：**协调专业人员、药品、检查和护理

**独特需求：**建议、批准、执行、实际观察分别记录

<a id="医疗服务临床系统与健康信息-医学影像与诊断辅助"></a>
### 医学影像与诊断辅助

**任务：**管理图像、检测结果与分析

**独特需求：**设备校准、样本身份和适用人群明确

<a id="医疗服务临床系统与健康信息-医疗设备与远程监测"></a>
### 医疗设备与远程监测

**任务：**接收测量并支持报警和响应

**独特需求：**缺数据不当成正常，失联和误报可操作

<a id="医疗服务临床系统与健康信息-患者服务与护理协作"></a>
### 患者服务与护理协作

**任务：**预约、转诊、随访和信息共享

**独特需求：**患者权益、知情同意、无障碍和紧急流程同时考虑
## 生命科学、实验室与研发

**关键对象：**样本、实验、仪器、方法、数据与伦理批准

**共同不变量：**样本身份、实验过程、观测和推断精确对应

**失败与恢复：**污染、批次效应、仪器漂移、无效同意和样本失踪可追踪

**共同验证：**盲样、对照、独立复现、数据来源与伦理边界

**相关机制：**[来源、归属与依赖证据](机制适用性.md#来源归属与依赖证据)；[随机、统计与不确定性](机制适用性.md#随机统计与不确定性)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[传感、计量与校准](机制适用性.md#传感计量与校准)；[隐私、同意、目的与保留](机制适用性.md#隐私同意目的与保留)；[验证、确认与支持声明](机制适用性.md#验证确认与支持声明)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[微分、敏感度与逆问题](机制适用性.md#微分敏感度与逆问题)

<a id="生命科学实验室与研发-实验室信息管理"></a>
### 实验室信息管理

**任务：**登记样本、分配实验并保存结果

**独特需求：**样本链路、冻融、批次与保留不能靠文件名代替

<a id="生命科学实验室与研发-组学与生物数据分析"></a>
### 组学与生物数据分析

**任务：**处理序列或多维实验数据

**独特需求：**质量控制、批次、参考版本与人群隐私明确

<a id="生命科学实验室与研发-临床研究数据系统"></a>
### 临床研究数据系统

**任务：**管理入组、访视、数据和审查

**独特需求：**方案版本、同意、偏离和适用人群必须可追踪

<a id="生命科学实验室与研发-药物与材料研发信息"></a>
### 药物与材料研发信息

**任务：**组织候选、实验和证据

**独特需求：**计算预测不当成疗效或现实安全证明

<a id="生命科学实验室与研发-科学仪器自动化"></a>
### 科学仪器自动化

**任务：**按受控流程采集和整理实验观察

**独特需求：**仪器动作权限、样本风险和真实执行回执分开
## 教育、学习与学术研究

**共同不变量：**学习效果、完成记录、评分和资格认证分别判断

**失败与恢复：**评价偏差、数据泄露、不可访问内容和机构退出可补救

### 学习平台与课程

**任务：**组织内容、练习、讨论和学习路径

<a id="教育学习与学术研究-考试与评价"></a>
### 考试与评价

**任务：**生成任务、收集答卷并形成评价

<a id="教育学习与学术研究-教学管理"></a>
### 教学管理

**任务：**协调招生、排课、成绩和资格

**独特需求：**课程变更、资源冲突和学生隐私需联合处理

<a id="教育学习与学术研究-科研计算与协作"></a>
### 科研计算与协作

**任务：**组织数据、方法、代码和结论

**独特需求：**可重跑计算不自动证明科学结论真实

<a id="教育学习与学术研究-学术出版与引用"></a>
### 学术出版与引用

**任务：**管理投稿、审查、版本和资料来源

**独特需求：**评审、作者归属、撤稿和修订可追踪
## 公共服务、司法行政与长期记录

**关键对象：**申请人、事项、材料、记录、决议、机构和申诉

**共同不变量：**权限主体、程序状态和事实判断必须分开；不自动代替人类公共决定

**失败与恢复：**身份错配、材料缺失、跨机构冲突和长期格式失效有补救

**共同验证：**全流程、弱势用户可达性、可解释性、记录保真及人工复核

<a id="公共服务司法行政与长期记录-公共服务申请"></a>
### 公共服务申请

**任务：**接收材料、核对资格并通知进度

**独特需求：**软件规则来自有权解释，缺材料不自动判无资格

<a id="公共服务司法行政与长期记录-司法与案件管理"></a>
### 司法与案件管理

**任务：**组织证据、流程、期限和文书

**独特需求：**证据来源、主张、裁判与送达事实分别维护

<a id="公共服务司法行政与长期记录-公共档案与登记"></a>
### 公共档案与登记

**任务：**保存具有长期效力的记录

**独特需求：**更正、撤销、历史效力和查看权限可追踪

<a id="公共服务司法行政与长期记录-公共资源与基础设施管理"></a>
### 公共资源与基础设施管理

**任务：**安排设施、维护和服务

**独特需求：**服务连续性、公平获取和透明记录需分别评价

<a id="公共服务司法行政与长期记录-公共参与与信息公开工具"></a>
### 公共参与与信息公开工具

**任务：**呈现资料、收集意见和记录过程

**独特需求：**准确表达不同意见，不由系统替参与者作政治选择

### 医学记录的更正、身份与用途边界

**关联领域：**[医疗服务、临床系统与健康信息](健康研究与公共责任.md#医疗服务临床系统与健康信息)；[安全、身份、密码与隐私工程](数据智能与安全.md#安全身份密码与隐私工程)

**相交规范：**[工程事实、世界上下文与双时间](../../信息/对象关系与配置基线.md#world-valid-record-time)；[稳定身份、内容去重与对象演变](../../信息/对象关系与配置基线.md#identity-transformation-boundary)；[测量、校准、可识别性与模型适用域](../../领域/仿真/测量校准与实验.md#measurement-calibration-identifiability)；[人类任务、组织权责、异议与不可自动化的接受](../../运行/人类任务与责任交接.md#human-task-responsibility)

**任务：**让记录交换与真实临床判断保持不同职责。

**具体输入与触发：**同名记录被误合并，晚到检验结果修正此前观察，某使用者只有研究用途授权。

**应保持行为与输出：**保留候选身份、原结果和更正；用途限制随派生内容，不自动形成临床决定。

**失败与恢复：**冲突隔离并交适当有权主体处理；撤销的是错误关联，不删除原资料。

**验证方法：**错配、晚到、更正、跨用途披露及专业接收流程的独立验收。
