## 地理信息、遥感与空间数据

**关键对象：**坐标、影像、地形、要素、时间和地理对象

**共同不变量：**坐标系统、精度、日期和现实对应必须一致

**失败与恢复：**坐标混用、旧地图、云遮挡、配准失败与缺样显式

**共同验证：**控制点、坐标往返、时序对照、现场数据和精度评估

**相关机制：**[空间、几何与坐标](机制适用性/空间仿真测量控制.md#%E7%A9%BA%E9%97%B4%E5%87%A0%E4%BD%95%E4%B8%8E%E5%9D%90%E6%A0%87)；[传感、计量与校准](机制适用性/空间仿真测量控制.md#%E4%BC%A0%E6%84%9F%E8%AE%A1%E9%87%8F%E4%B8%8E%E6%A0%A1%E5%87%86)；[数据查询与变换](机制适用性/持久化通信与数据.md#%E6%95%B0%E6%8D%AE%E6%9F%A5%E8%AF%A2%E4%B8%8E%E5%8F%98%E6%8D%A2)；[显示、渲染与图形计算](机制适用性/媒体交互与地区呈现.md#%E6%98%BE%E7%A4%BA%E6%B8%B2%E6%9F%93%E4%B8%8E%E5%9B%BE%E5%BD%A2%E8%AE%A1%E7%AE%97)；[来源、归属与依赖证据](机制适用性/风险观测与保证.md#%E6%9D%A5%E6%BA%90%E5%BD%92%E5%B1%9E%E4%B8%8E%E4%BE%9D%E8%B5%96%E8%AF%81%E6%8D%AE)；[时间域、时钟与历法](机制适用性/时间状态与资源.md#%E6%97%B6%E9%97%B4%E5%9F%9F%E6%97%B6%E9%92%9F%E4%B8%8E%E5%8E%86%E6%B3%95)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[持久化、查询存储与索引](机制适用性/持久化通信与数据.md#%E6%8C%81%E4%B9%85%E5%8C%96%E6%9F%A5%E8%AF%A2%E5%AD%98%E5%82%A8%E4%B8%8E%E7%B4%A2%E5%BC%95)

<a id="地理信息遥感与空间数据-gis与空间查询"></a>
### GIS与空间查询

**任务：**管理、查询和展示地理要素

**独特需求：**投影、地球模型、边界和拓扑语义完整

<a id="地理信息遥感与空间数据-遥感影像处理"></a>
### 遥感影像处理

**任务：**配准、分类、变化检测和产品生成

**独特需求：**传感校准、采集时间、遮挡和误差保留

<a id="地理信息遥感与空间数据-地图与导航数据"></a>
### 地图与导航数据

**任务：**生成地图、路线和位置服务

**独特需求：**显示地图不等于实时可通行或合法可达

<a id="地理信息遥感与空间数据-空间资产与基础设施"></a>
### 空间资产与基础设施

**任务：**定位设施并维护关系和历史

**独特需求：**资产身份、几何变化和维护记录准确对应

<a id="地理信息遥感与空间数据-测绘与三维重建"></a>
### 测绘与三维重建

**任务：**由观察生成几何和地理模型

**独特需求：**坐标基准、尺度、误差和未观测区域明确
## 建筑、土木、BIM与工程设计

**关键对象：**构件、图纸、模型、材料、工程量、施工与验收

**共同不变量：**设计状态、施工状态、实测状态和竣工状态分别建模

**失败与恢复：**模型冲突、现场偏差、变更遗漏与资料缺失可追溯处理

**共同验证：**专业计算、模型碰撞、现场测量、工序与竣工资料核验

**相关机制：**[空间、几何与坐标](机制适用性/空间仿真测量控制.md#%E7%A9%BA%E9%97%B4%E5%87%A0%E4%BD%95%E4%B8%8E%E5%9D%90%E6%A0%87)；[方程、数值求解与离散化](机制适用性/随机优化与数值.md#%E6%96%B9%E7%A8%8B%E6%95%B0%E5%80%BC%E6%B1%82%E8%A7%A3%E4%B8%8E%E7%A6%BB%E6%95%A3%E5%8C%96)；[文档、记录与结构化出版](机制适用性/协作流程与组织.md#%E6%96%87%E6%A1%A3%E8%AE%B0%E5%BD%95%E4%B8%8E%E7%BB%93%E6%9E%84%E5%8C%96%E5%87%BA%E7%89%88)；[版本、快照与配置基线](机制适用性/身份表示与计算.md#%E7%89%88%E6%9C%AC%E5%BF%AB%E7%85%A7%E4%B8%8E%E9%85%8D%E7%BD%AE%E5%9F%BA%E7%BA%BF)；[流程、任务与人工交接](机制适用性/协作流程与组织.md#%E6%B5%81%E7%A8%8B%E4%BB%BB%E5%8A%A1%E4%B8%8E%E4%BA%BA%E5%B7%A5%E4%BA%A4%E6%8E%A5)；[危害、风险边界与防护](机制适用性/风险观测与保证.md#%E5%8D%B1%E5%AE%B3%E9%A3%8E%E9%99%A9%E8%BE%B9%E7%95%8C%E4%B8%8E%E9%98%B2%E6%8A%A4)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[协作、共享与多作者编辑](机制适用性/协作流程与组织.md#%E5%8D%8F%E4%BD%9C%E5%85%B1%E4%BA%AB%E4%B8%8E%E5%A4%9A%E4%BD%9C%E8%80%85%E7%BC%96%E8%BE%91)；[逻辑约束与规则求解](机制适用性/身份表示与计算.md#%E9%80%BB%E8%BE%91%E7%BA%A6%E6%9D%9F%E4%B8%8E%E8%A7%84%E5%88%99%E6%B1%82%E8%A7%A3)

<a id="建筑土木bim与工程设计-建筑与结构设计"></a>
### 建筑与结构设计

**任务：**组织空间、构件和设计参数

**独特需求：**荷载、材料、单位、边界和规范适用须专业确认

<a id="建筑土木bim与工程设计-bim与多专业协同"></a>
### BIM与多专业协同

**任务：**连接结构、机电、建筑和工程资料

**独特需求：**同一构件多视图保持身份，不把几何相碰当唯一冲突

<a id="建筑土木bim与工程设计-工程量与造价"></a>
### 工程量与造价

**任务：**从配置和规则计算数量与成本

**独特需求：**计量口径、变更、价格时点和税费独立

<a id="建筑土木bim与工程设计-施工与质量管理"></a>
### 施工与质量管理

**任务：**安排作业、检查并记录实际状态

**独特需求：**隐蔽工程、现场证据、责任和验收不能靠模型替代

<a id="建筑土木bim与工程设计-竣工与设施移交"></a>
### 竣工与设施移交

**任务：**交付模型、设备、手册和维护资料

**独特需求：**设计完成不等于现场一致或实际可运维
## 城市、建筑运营、物业与公共设施

**关键对象：**建筑、住户、设施、表计、工单、资源和服务

**共同不变量：**账面资产、现实设施、居民权益和服务责任分开

**失败与恢复：**断电断水、门禁异常、传感失效和服务争议有人工通道

**共同验证：**设施联调、紧急流程、计费对账、隐私和真实居民任务

<a id="城市建筑运营物业与公共设施-建筑自动化"></a>
### 建筑自动化

**任务：**协调照明、暖通、能耗和环境

**独特需求：**舒适度、设备寿命与安全约束不能被单一节能指标压掉

<a id="城市建筑运营物业与公共设施-物业与维修服务"></a>
### 物业与维修服务

**任务：**受理、分派、施工和验收

**独特需求：**维修完成声明与实际修复、住户接受分别核对

<a id="城市建筑运营物业与公共设施-水务废弃物与市政"></a>
### 水务、废弃物与市政

**任务：**规划、监测和维护公共设施

**独特需求：**流量计量、污染、排放和服务中断责任明确

<a id="城市建筑运营物业与公共设施-房产与空间运营"></a>
### 房产与空间运营

**任务：**管理房源、租约、空间和费用

**独特需求：**所有权、使用权、合同期限与实际入住分开

<a id="城市建筑运营物业与公共设施-城市数据与协同"></a>
### 城市数据与协同

**任务：**关联多部门数据支撑公共任务

**独特需求：**用途授权、分域权威、隐私与退出可检查
## 旅游、酒店、活动、文娱与体育

**失败与恢复：**取消、超订、天气、场地故障和人员安全有改退与现场接管

**共同验证：**资源并发、全旅程、现场演练、无障碍与争议处理

### 旅游与行程服务

**任务：**组合交通、住宿、活动和约束

**独特需求：**不同供应商确认和退款责任不能合并成一次提交

<a id="旅游酒店活动文娱与体育-酒店与住宿运营"></a>
### 酒店与住宿运营

**任务：**管理房态、预订、入住和结算

**独特需求：**可售房态、实际房态、维护与隐私一致

### 活动与票务

**任务：**安排场地、席位、入场和服务

**独特需求：**容量、票权转移、取消和现场安全联合检查

<a id="旅游酒店活动文娱与体育-体育训练与赛事管理"></a>
### 体育训练与赛事管理

**任务：**组织队伍、赛程、记录和评价

### 文娱与文化消费

**任务：**组织演出、内容、会员和权益

**独特需求：**版权、年龄适用、可达性和消费者保护明确
## 个人生活、消费设备与辅助服务

**关键对象：**个人目标、设备、记录、日程、偏好与授权

**共同不变量：**建议、用户选择和实际执行保持边界；个人数据默认最小披露

**失败与恢复：**错误自动化、设备失联、账号恢复和授权撤销有手动路径

**共同验证：**真实生活任务、离线、辅助技术、失误恢复和数据导出
