## 地理信息、遥感与空间数据

**关键对象：**坐标、影像、地形、要素、时间和地理对象

**共同不变量：**坐标系统、精度、日期和现实对应必须一致

**失败与恢复：**坐标混用、旧地图、云遮挡、配准失败与缺样显式

**共同验证：**控制点、坐标往返、时序对照、现场数据和精度评估

**相关机制：**[空间、几何与坐标](机制适用性.md#空间几何与坐标)；[传感、计量与校准](机制适用性.md#传感计量与校准)；[数据查询与变换](机制适用性.md#数据查询与变换)；[显示、渲染与图形计算](机制适用性.md#显示渲染与图形计算)；[来源、归属与依赖证据](机制适用性.md#来源归属与依赖证据)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[持久化、查询存储与索引](机制适用性.md#持久化查询存储与索引)

<a id="地理信息遥感与空间数据-gis与空间查询"></a>
### GIS与空间查询

**任务：**管理、查询和展示地理要素

**独特需求：**投影、地球模型、边界和拓扑语义完整

<a id="地理信息遥感与空间数据-遥感影像处理"></a>
### 遥感影像处理

**任务：**配准、分类、变化检测和产品生成

**独特需求：**传感校准、采集时间、遮挡和误差保留

<a id="地理信息遥感与空间数据-地图与导航数据"></a>
### 地图与导航数据

**任务：**生成地图、路线和位置服务

**独特需求：**显示地图不等于实时可通行或合法可达

<a id="地理信息遥感与空间数据-空间资产与基础设施"></a>
### 空间资产与基础设施

**任务：**定位设施并维护关系和历史

**独特需求：**资产身份、几何变化和维护记录准确对应

<a id="地理信息遥感与空间数据-测绘与三维重建"></a>
### 测绘与三维重建

**任务：**由观察生成几何和地理模型

**独特需求：**坐标基准、尺度、误差和未观测区域明确
## 建筑、土木、BIM与工程设计

**关键对象：**构件、图纸、模型、材料、工程量、施工与验收

**共同不变量：**设计状态、施工状态、实测状态和竣工状态分别建模

**失败与恢复：**模型冲突、现场偏差、变更遗漏与资料缺失可追溯处理

**共同验证：**专业计算、模型碰撞、现场测量、工序与竣工资料核验

**相关机制：**[空间、几何与坐标](机制适用性.md#空间几何与坐标)；[方程、数值求解与离散化](机制适用性.md#方程数值求解与离散化)；[文档、记录与结构化出版](机制适用性.md#文档记录与结构化出版)；[版本、快照与配置基线](机制适用性.md#版本快照与配置基线)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[危害、风险边界与防护](机制适用性.md#危害风险边界与防护)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[协作、共享与多作者编辑](机制适用性.md#协作共享与多作者编辑)；[逻辑约束与规则求解](机制适用性.md#逻辑约束与规则求解)

<a id="建筑土木bim与工程设计-建筑与结构设计"></a>
### 建筑与结构设计

**任务：**组织空间、构件和设计参数

**独特需求：**荷载、材料、单位、边界和规范适用须专业确认

<a id="建筑土木bim与工程设计-bim与多专业协同"></a>
### BIM与多专业协同

**任务：**连接结构、机电、建筑和工程资料

**独特需求：**同一构件多视图保持身份，不把几何相碰当唯一冲突

<a id="建筑土木bim与工程设计-工程量与造价"></a>
### 工程量与造价

**任务：**从配置和规则计算数量与成本

**独特需求：**计量口径、变更、价格时点和税费独立

<a id="建筑土木bim与工程设计-施工与质量管理"></a>
### 施工与质量管理

**任务：**安排作业、检查并记录实际状态

**独特需求：**隐蔽工程、现场证据、责任和验收不能靠模型替代

<a id="建筑土木bim与工程设计-竣工与设施移交"></a>
### 竣工与设施移交

**任务：**交付模型、设备、手册和维护资料

**独特需求：**设计完成不等于现场一致或实际可运维
## 城市、建筑运营、物业与公共设施

**关键对象：**建筑、住户、设施、表计、工单、资源和服务

**共同不变量：**账面资产、现实设施、居民权益和服务责任分开

**失败与恢复：**断电断水、门禁异常、传感失效和服务争议有人工通道

**共同验证：**设施联调、紧急流程、计费对账、隐私和真实居民任务

**相关机制：**[传感、计量与校准](机制适用性.md#传感计量与校准)；[控制、执行器与安全状态](机制适用性.md#控制执行器与安全状态)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[数量、账本、价值与对账](机制适用性.md#数量账本价值与对账)；[路由、履约、路径与交付](机制适用性.md#路由履约路径与交付)；[隐私、同意、目的与保留](机制适用性.md#隐私同意目的与保留)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[运行适配与受控重配置](机制适用性.md#运行适配与受控重配置)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[幂等、补偿与操作结算](机制适用性.md#幂等补偿与操作结算)

<a id="城市建筑运营物业与公共设施-建筑自动化"></a>
### 建筑自动化

**任务：**协调照明、暖通、能耗和环境

**独特需求：**舒适度、设备寿命与安全约束不能被单一节能指标压掉

<a id="城市建筑运营物业与公共设施-物业与维修服务"></a>
### 物业与维修服务

**任务：**受理、分派、施工和验收

**独特需求：**维修完成声明与实际修复、住户接受分别核对

<a id="城市建筑运营物业与公共设施-水务废弃物与市政"></a>
### 水务、废弃物与市政

**任务：**规划、监测和维护公共设施

**独特需求：**流量计量、污染、排放和服务中断责任明确

<a id="城市建筑运营物业与公共设施-房产与空间运营"></a>
### 房产与空间运营

**任务：**管理房源、租约、空间和费用

**独特需求：**所有权、使用权、合同期限与实际入住分开

<a id="城市建筑运营物业与公共设施-城市数据与协同"></a>
### 城市数据与协同

**任务：**关联多部门数据支撑公共任务

**独特需求：**用途授权、分域权威、隐私与退出可检查
## 旅游、酒店、活动、文娱与体育

**关键对象：**行程、资源、场地、参与者、票权、合同与现场状态

**共同不变量：**预约、支付、服务承诺和实际体验分别记录

**失败与恢复：**取消、超订、天气、场地故障和人员安全有改退与现场接管

**共同验证：**资源并发、全旅程、现场演练、无障碍与争议处理

**相关机制：**[预占、配额、排队与匹配](机制适用性.md#预占配额排队与匹配)；[路由、履约、路径与交付](机制适用性.md#路由履约路径与交付)；[数量、账本、价值与对账](机制适用性.md#数量账本价值与对账)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[交互、界面与输入](机制适用性.md#交互界面与输入)；[危害、风险边界与防护](机制适用性.md#危害风险边界与防护)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[隐私、同意、目的与保留](机制适用性.md#隐私同意目的与保留)

<a id="旅游酒店活动文娱与体育-旅游与行程服务"></a>
### 旅游与行程服务

**任务：**组合交通、住宿、活动和约束

**独特需求：**不同供应商确认和退款责任不能合并成一次提交

<a id="旅游酒店活动文娱与体育-酒店与住宿运营"></a>
### 酒店与住宿运营

**任务：**管理房态、预订、入住和结算

**独特需求：**可售房态、实际房态、维护与隐私一致

<a id="旅游酒店活动文娱与体育-活动与票务"></a>
### 活动与票务

**任务：**安排场地、席位、入场和服务

**独特需求：**容量、票权转移、取消和现场安全联合检查

<a id="旅游酒店活动文娱与体育-体育训练与赛事管理"></a>
### 体育训练与赛事管理

**任务：**组织队伍、赛程、记录和评价

**独特需求：**测量、规则、公平性和参与者健康责任分开

<a id="旅游酒店活动文娱与体育-文娱与文化消费"></a>
### 文娱与文化消费

**任务：**组织演出、内容、会员和权益

**独特需求：**版权、年龄适用、可达性和消费者保护明确
## 个人生活、消费设备与辅助服务

**关键对象：**个人目标、设备、记录、日程、偏好与授权

**共同不变量：**建议、用户选择和实际执行保持边界；个人数据默认最小披露

**失败与恢复：**错误自动化、设备失联、账号恢复和授权撤销有手动路径

**共同验证：**真实生活任务、离线、辅助技术、失误恢复和数据导出

**相关机制：**[交互、界面与输入](机制适用性.md#交互界面与输入)；[隐私、同意、目的与保留](机制适用性.md#隐私同意目的与保留)；[流程、任务与人工交接](机制适用性.md#流程任务与人工交接)；[传感、计量与校准](机制适用性.md#传感计量与校准)；[无障碍与包容性交互](机制适用性.md#无障碍与包容性交互)；[幂等、补偿与操作结算](机制适用性.md#幂等补偿与操作结算)

<a id="个人生活消费设备与辅助服务-个人日程与任务"></a>
### 个人日程与任务

**任务：**组织提醒、计划和可执行行动

**独特需求：**提醒送达不等于事项完成，时区和冲突明确

<a id="个人生活消费设备与辅助服务-家庭自动化"></a>
### 家庭自动化

**任务：**连接设备和生活情景

**独特需求：**家庭成员权限、安全态和本地离线运行可控

<a id="个人生活消费设备与辅助服务-个人信息与文件管理"></a>
### 个人信息与文件管理

**任务：**整理记录、照片、文档和关系

**独特需求：**原件保全、去重冲突、隐私和长期可读性明确

<a id="个人生活消费设备与辅助服务-健康与生活记录"></a>
### 健康与生活记录

**任务：**跟踪个人观察和目标

**独特需求：**测量、经验和专业结论分开，不伪造健康效果

<a id="个人生活消费设备与辅助服务-辅助技术与自适应工具"></a>
### 辅助技术与自适应工具

**任务：**帮助不同能力用户完成任务

**独特需求：**用户控制、替代输入、误触恢复和设备兼容真实验证
