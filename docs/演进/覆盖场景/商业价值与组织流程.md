## 零售、电商与多方市场

**关键对象：**商品、卖家、买家、订单、库存、支付和履约

**共同不变量：**实物、资金、合同承诺和平台记录是不同事实

**失败与恢复：**超卖、支付未知、取消竞态、退货和部分履约各自结算

**共同验证：**订单全周期、并发预占、金额守恒、多方争议与恢复

**相关机制：**[预占、配额、排队与匹配](机制适用性/规则账本分配履约.md#%E9%A2%84%E5%8D%A0%E9%85%8D%E9%A2%9D%E6%8E%92%E9%98%9F%E4%B8%8E%E5%8C%B9%E9%85%8D)；[数量、账本、价值与对账](机制适用性/规则账本分配履约.md#%E6%95%B0%E9%87%8F%E8%B4%A6%E6%9C%AC%E4%BB%B7%E5%80%BC%E4%B8%8E%E5%AF%B9%E8%B4%A6)；[路由、履约、路径与交付](机制适用性/规则账本分配履约.md#%E8%B7%AF%E7%94%B1%E5%B1%A5%E7%BA%A6%E8%B7%AF%E5%BE%84%E4%B8%8E%E4%BA%A4%E4%BB%98)；[政策、资格、计价与规则版本](机制适用性/规则账本分配履约.md#%E6%94%BF%E7%AD%96%E8%B5%84%E6%A0%BC%E8%AE%A1%E4%BB%B7%E4%B8%8E%E8%A7%84%E5%88%99%E7%89%88%E6%9C%AC)；[事务、并发控制与一致性](机制适用性/持久化通信与数据.md#%E4%BA%8B%E5%8A%A1%E5%B9%B6%E5%8F%91%E6%8E%A7%E5%88%B6%E4%B8%8E%E4%B8%80%E8%87%B4%E6%80%A7)；[供应链、许可、来源与可分发性](机制适用性/构建交付与演进.md#%E4%BE%9B%E5%BA%94%E9%93%BE%E8%AE%B8%E5%8F%AF%E6%9D%A5%E6%BA%90%E4%B8%8E%E5%8F%AF%E5%88%86%E5%8F%91%E6%80%A7)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[幂等、补偿与操作结算](机制适用性/持久化通信与数据.md#%E5%B9%82%E7%AD%89%E8%A1%A5%E5%81%BF%E4%B8%8E%E6%93%8D%E4%BD%9C%E7%BB%93%E7%AE%97)；[认证、授权与委派](机制适用性/认证密码与隐私.md#%E8%AE%A4%E8%AF%81%E6%8E%88%E6%9D%83%E4%B8%8E%E5%A7%94%E6%B4%BE)

<a id="零售电商与多方市场-商品与内容目录"></a>
### 商品与内容目录

**任务：**组织实体商品、数字内容及服务

**独特需求：**规格、价格、可售性和权利范围分别有时效

<a id="零售电商与多方市场-订单与结算"></a>
### 订单与结算

**任务：**从购买请求形成订单和支付

**独特需求：**下单、支付成功、到账与履约不能合成一个布尔值

<a id="零售电商与多方市场-库存与履约"></a>
### 库存与履约

**任务：**预占、拣选、发货和确认交付

**独特需求：**物理库存、账面库存和可售库存必须区分

<a id="零售电商与多方市场-促销优惠与会员"></a>
### 促销、优惠与会员

**任务：**按规则计算价格和权益

**独特需求：**叠加次序、资格、舍入和退款规则可解释

<a id="零售电商与多方市场-平台交易与售后"></a>
### 平台交易与售后

**任务：**协调商家、消费者、物流和争议

**独特需求：**责任主体、证据、申诉和不可逆交付显式
## 银行、支付、账户与结算

**关键对象：**账户、授权、分录、支付指令、清算与对账

**共同不变量：**金额、币种、舍入、唯一效果和交易阶段准确

**失败与恢复：**外部超时不等于失败；先查结算再重试，补偿不删除历史

**共同验证：**守恒、幂等、重复回执、部分清算和故障时序

**相关机制：**[数量、账本、价值与对账](机制适用性/规则账本分配履约.md#%E6%95%B0%E9%87%8F%E8%B4%A6%E6%9C%AC%E4%BB%B7%E5%80%BC%E4%B8%8E%E5%AF%B9%E8%B4%A6)；[事务、并发控制与一致性](机制适用性/持久化通信与数据.md#%E4%BA%8B%E5%8A%A1%E5%B9%B6%E5%8F%91%E6%8E%A7%E5%88%B6%E4%B8%8E%E4%B8%80%E8%87%B4%E6%80%A7)；[幂等、补偿与操作结算](机制适用性/持久化通信与数据.md#%E5%B9%82%E7%AD%89%E8%A1%A5%E5%81%BF%E4%B8%8E%E6%93%8D%E4%BD%9C%E7%BB%93%E7%AE%97)；[认证、授权与委派](机制适用性/认证密码与隐私.md#%E8%AE%A4%E8%AF%81%E6%8E%88%E6%9D%83%E4%B8%8E%E5%A7%94%E6%B4%BE)；[隐私、同意、目的与保留](机制适用性/认证密码与隐私.md#%E9%9A%90%E7%A7%81%E5%90%8C%E6%84%8F%E7%9B%AE%E7%9A%84%E4%B8%8E%E4%BF%9D%E7%95%99)；[验证、确认与支持声明](机制适用性/风险观测与保证.md#%E9%AA%8C%E8%AF%81%E7%A1%AE%E8%AE%A4%E4%B8%8E%E6%94%AF%E6%8C%81%E5%A3%B0%E6%98%8E)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[事件、反应与消息语义](机制适用性/时间状态与资源.md#%E4%BA%8B%E4%BB%B6%E5%8F%8D%E5%BA%94%E4%B8%8E%E6%B6%88%E6%81%AF%E8%AF%AD%E4%B9%89)；[版本、快照与配置基线](机制适用性/身份表示与计算.md#%E7%89%88%E6%9C%AC%E5%BF%AB%E7%85%A7%E4%B8%8E%E9%85%8D%E7%BD%AE%E5%9F%BA%E7%BA%BF)

<a id="银行支付账户与结算-账户与钱包"></a>
### 账户与钱包

**任务：**维护余额、冻结、额度和账户状态

**独特需求：**可用余额与已结算余额不得混同

<a id="银行支付账户与结算-支付网关"></a>
### 支付网关

**任务：**发起支付并接收异步结果

**独特需求：**未知完成及同请求不同载荷必须防重复扣款

<a id="银行支付账户与结算-清算与结算"></a>
### 清算与结算

**任务：**计算参与方义务并完成资金交割

**独特需求：**批次、截止、净额、最终性及外部依赖明确

<a id="银行支付账户与结算-对账与差错处理"></a>
### 对账与差错处理

**任务：**比对内部记录和外部资金事实

**独特需求：**差异保留来源，人工调整形成新记录

<a id="银行支付账户与结算-争议退款与撤销"></a>
### 争议、退款与撤销

**任务：**处理交易后的权益变化

**独特需求：**授权撤销、退款发起和到账结果分别观察
## 会计、财务、税务与审计

**关键对象：**科目、分录、凭证、期间、报表与审批

**共同不变量：**会计口径、适用规则和报告期间必须固定

**失败与恢复：**冲销、关账重开、规则变化和缺凭证不得改写历史来源

**共同验证：**借贷平衡、来源穿透、期间边界、重算和人工复核

**相关机制：**[数量、账本、价值与对账](机制适用性/规则账本分配履约.md#%E6%95%B0%E9%87%8F%E8%B4%A6%E6%9C%AC%E4%BB%B7%E5%80%BC%E4%B8%8E%E5%AF%B9%E8%B4%A6)；[政策、资格、计价与规则版本](机制适用性/规则账本分配履约.md#%E6%94%BF%E7%AD%96%E8%B5%84%E6%A0%BC%E8%AE%A1%E4%BB%B7%E4%B8%8E%E8%A7%84%E5%88%99%E7%89%88%E6%9C%AC)；[文档、记录与结构化出版](机制适用性/协作流程与组织.md#%E6%96%87%E6%A1%A3%E8%AE%B0%E5%BD%95%E4%B8%8E%E7%BB%93%E6%9E%84%E5%8C%96%E5%87%BA%E7%89%88)；[来源、归属与依赖证据](机制适用性/风险观测与保证.md#%E6%9D%A5%E6%BA%90%E5%BD%92%E5%B1%9E%E4%B8%8E%E4%BE%9D%E8%B5%96%E8%AF%81%E6%8D%AE)；[流程、任务与人工交接](机制适用性/协作流程与组织.md#%E6%B5%81%E7%A8%8B%E4%BB%BB%E5%8A%A1%E4%B8%8E%E4%BA%BA%E5%B7%A5%E4%BA%A4%E6%8E%A5)；[版本、快照与配置基线](机制适用性/身份表示与计算.md#%E7%89%88%E6%9C%AC%E5%BF%AB%E7%85%A7%E4%B8%8E%E9%85%8D%E7%BD%AE%E5%9F%BA%E7%BA%BF)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[验证、确认与支持声明](机制适用性/风险观测与保证.md#%E9%AA%8C%E8%AF%81%E7%A1%AE%E8%AE%A4%E4%B8%8E%E6%94%AF%E6%8C%81%E5%A3%B0%E6%98%8E)

<a id="会计财务税务与审计-总账与辅助账"></a>
### 总账与辅助账

**任务：**记录经济事项并组织核算

**独特需求：**相同交易在现金、权责和其他口径下解释不同

<a id="会计财务税务与审计-应收应付与资金管理"></a>
### 应收应付与资金管理

**任务：**追踪债权债务和现金安排

**独特需求：**发票、付款承诺与实际收付分别建模

<a id="会计财务税务与审计-成本与资产核算"></a>
### 成本与资产核算

**任务：**分配成本并处理折旧和价值变动

**独特需求：**分摊依据、计量单位和估计变更可追踪

<a id="会计财务税务与审计-税务与申报辅助"></a>
### 税务与申报辅助

**任务：**按已确认规则形成计算和申报材料

**独特需求：**法域、有效期与专业确认必须明确，不默认法律正确

<a id="会计财务税务与审计-审计与财务报告"></a>
### 审计与财务报告

**任务：**核对证据并生成可复查报告

**独特需求：**证据完整性和解释正确性分开评价
## 投资、信贷、保险与风险系统

**关键对象：**合同、头寸、现金流、风险因子、模型与责任

**共同不变量：**模型结果、市场观察和实际权益不得混同

**失败与恢复：**极端情景、数据陈旧、模型漂移和对手方失效要显式处理

**共同验证：**历史与压力情景、模型校准、尾部风险及独立复核

**相关机制：**[随机、统计与不确定性](机制适用性/随机优化与数值.md#%E9%9A%8F%E6%9C%BA%E7%BB%9F%E8%AE%A1%E4%B8%8E%E4%B8%8D%E7%A1%AE%E5%AE%9A%E6%80%A7)；[优化、规划与运筹](机制适用性/随机优化与数值.md#%E4%BC%98%E5%8C%96%E8%A7%84%E5%88%92%E4%B8%8E%E8%BF%90%E7%AD%B9)；[数量、账本、价值与对账](机制适用性/规则账本分配履约.md#%E6%95%B0%E9%87%8F%E8%B4%A6%E6%9C%AC%E4%BB%B7%E5%80%BC%E4%B8%8E%E5%AF%B9%E8%B4%A6)；[政策、资格、计价与规则版本](机制适用性/规则账本分配履约.md#%E6%94%BF%E7%AD%96%E8%B5%84%E6%A0%BC%E8%AE%A1%E4%BB%B7%E4%B8%8E%E8%A7%84%E5%88%99%E7%89%88%E6%9C%AC)；[实验、因果分析与反事实](机制适用性/知识学习与因果.md#%E5%AE%9E%E9%AA%8C%E5%9B%A0%E6%9E%9C%E5%88%86%E6%9E%90%E4%B8%8E%E5%8F%8D%E4%BA%8B%E5%AE%9E)；[验证、确认与支持声明](机制适用性/风险观测与保证.md#%E9%AA%8C%E8%AF%81%E7%A1%AE%E8%AE%A4%E4%B8%8E%E6%94%AF%E6%8C%81%E5%A3%B0%E6%98%8E)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[微分、敏感度与逆问题](机制适用性/随机优化与数值.md#%E5%BE%AE%E5%88%86%E6%95%8F%E6%84%9F%E5%BA%A6%E4%B8%8E%E9%80%86%E9%97%AE%E9%A2%98)；[来源、归属与依赖证据](机制适用性/风险观测与保证.md#%E6%9D%A5%E6%BA%90%E5%BD%92%E5%B1%9E%E4%B8%8E%E4%BE%9D%E8%B5%96%E8%AF%81%E6%8D%AE)

<a id="投资信贷保险与风险系统-金融合同与估值"></a>
### 金融合同与估值

**任务：**计算合同现金流和条件价值

**独特需求：**估值假设、日期、市场数据和不确定性可复查

<a id="投资信贷保险与风险系统-信贷与授信流程"></a>
### 信贷与授信流程

**任务：**评价申请并管理额度和还款

**独特需求：**模型建议、人员决定、解释和申诉分开

<a id="投资信贷保险与风险系统-保险承保与理赔"></a>
### 保险承保与理赔

**任务：**管理风险合同、保费和事故赔付

**独特需求：**责任范围、证据、例外及争议处理明确

<a id="投资信贷保险与风险系统-投资运营与风控"></a>
### 投资运营与风控

**任务：**记录指令、头寸、限额和暴露

**独特需求：**风险限额、交易结果与事后对账不能互相替代

<a id="投资信贷保险与风险系统-情景与压力测试"></a>
### 情景与压力测试

**任务：**分析市场或违约变化下的损失

**独特需求：**相关性、尾部假设和样本外适用性不隐去
## 客户、销售、服务与营销运营

**关键对象：**客户、联系、机会、合同、服务事件与渠道

**共同不变量：**客户事实、评分、推测和营销同意分别保存

**失败与恢复：**错误合并、过期授权、重复触达和不公平分配可追踪补救

**共同验证：**全旅程、隐私边界、指标口径、申诉与效果评估

### 离线门店库存与额度转移

**关联领域：**[零售、电商与多方市场](商业价值与组织流程.md#零售电商与多方市场)；[物流、仓储与供应链](物流交通与自主设备.md#物流仓储与供应链)；[去中心化、联邦与点对点系统](科学仿真与开放系统.md#去中心化联邦与点对点系统)

**相交规范：**[分布式合并、全局不变量与离线预算](../../运行/持久化提交与恢复.md#merge-invariant-and-offline-budget)；[租约、栅栏、当前授权与旧写者复活](../../运行/持久化提交与恢复.md#receiver-fencing-and-stale-writer)

**任务：**断网期间的承诺不超出已分配权利。

**具体输入与触发：**两门店从同一库存1各卖出1；随后并发转移一份额度。

**应保持行为与输出：**协调或互不重叠额度；转移不能让两端同时花；保留原不变量。

**失败与恢复：**无余量只接订单提案；旧副本重连拒旧并对账，不制造负库存后再称成功。

**验证方法：**枚举分区/合并/额度交接与重复消息；证明所选合并规则保持所需范围。

### 跨系统预占、支付与取消竞争

**关联领域：**[零售、电商与多方市场](商业价值与组织流程.md#零售电商与多方市场)；[银行、支付、账户与结算](商业价值与组织流程.md#银行支付账户与结算)；[旅游、酒店、活动、文娱与体育](空间设施与个人服务.md#旅游酒店活动文娱与体育)

**相交规范：**[真实操作的状态机、未知结果与有界恢复](../../运行/持久化提交与恢复.md#attempt-finality-and-retry)；[分布式合并、全局不变量与离线预算](../../运行/持久化提交与恢复.md#merge-invariant-and-offline-budget)

**任务：**处理资源与资金不同步完成的真实责任。

**具体输入与触发：**席位预占超时释放，付款回执晚到，用户同时取消。

**应保持行为与输出：**分别记录预占、确认、支付和补偿身份；钱包、订单库存、物流及退款各有真实状态，不能把付款成功当席位仍在。声称所选支付通道费用最低前，按[搜索与选择合同](../../编译/实现选择与设计搜索.md)固定可选通道覆盖、可用性、费用basis与共同口径；通道不全或费用未知时只给准确覆盖范围内的选择，不签全局最优。

**失败与恢复：**准确对账并按允许政策退款/替代/人工处理；扣款成功但订单超时仍沿原幂等身份查回。补偿是新操作，退款受理不表示到账，也不抹掉旧扣款或已经履约的事实。

**验证方法：**覆盖各切点排列、退款受理后未到账、履约后迟到取消及缺失通道费率，确认没有重复扣款、重复占用、伪最优结论或丢失责任。
