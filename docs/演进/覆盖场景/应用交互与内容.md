## Web应用与浏览器软件

**关键对象：**页面、路由、表单、会话、缓存与浏览器能力

**共同不变量：**前端可见状态不替代后端授权和持久事实

**失败与恢复：**断网、刷新、重复提交、旧页面和不兼容浏览器可恢复

**共同验证：**端到端任务、键盘、不同终端、安全边界与弱网

**相关机制：**[交互、界面与输入](机制适用性.md#交互界面与输入)；[无障碍与包容性交互](机制适用性.md#无障碍与包容性交互)；[通信、会话与传输](机制适用性.md#通信会话与传输)；[认证、授权与委派](机制适用性.md#认证授权与委派)；[持久化、查询存储与索引](机制适用性.md#持久化查询存储与索引)；[实现选择、降低与完整产物](机制适用性.md#实现选择降低与完整产物)

<a id="web应用与浏览器软件-内容与信息门户"></a>
### 内容与信息门户

**任务：**生成、导航和检索信息页面

**独特需求：**可访问结构、来源、缓存和内容更新一致

<a id="web应用与浏览器软件-事务型web应用"></a>
### 事务型Web应用

**任务：**提交表单并查看业务结果

**独特需求：**重复提交、错误回显、权限和未知完成显式

<a id="web应用与浏览器软件-富交互应用"></a>
### 富交互应用

**任务：**编辑复杂对象并实时预览

**独特需求：**当前输入修订与异步结果对应，不覆盖新编辑

<a id="web应用与浏览器软件-离线pwa"></a>
### 离线PWA

**任务：**在受限连接下缓存和继续任务

**独特需求：**可离线行为、同步冲突和撤销时效明确

<a id="web应用与浏览器软件-浏览器扩展"></a>
### 浏览器扩展

**任务：**对用户授权的页面或数据提供功能

**独特需求：**页面内容不授予扩展额外主机权限
## 移动端、穿戴与个人终端

**关键对象：**应用、设备、传感器、后台任务和个人数据

**共同不变量：**设备权限、用户同意、后台限制和电池成本都属合同

**失败与恢复：**进程被系统终止、权限撤回、弱网和设备丢失可恢复

**共同验证：**真机、后台切换、安装升级、无障碍、续航和离线

<a id="移动端穿戴与个人终端-手机和平板应用"></a>
### 手机和平板应用

**任务：**结合界面、网络、存储和设备能力

**独特需求：**前后台切换不能丢用户未提交内容

<a id="移动端穿戴与个人终端-穿戴与健康记录"></a>
### 穿戴与健康记录

**任务：**采集、展示并同步个人指标

**独特需求：**测量数据和医疗结论分开，隐私目的明确

<a id="移动端穿戴与个人终端-位置与现场应用"></a>
### 位置与现场应用

**任务：**采集位置和现场资料并协调任务

**独特需求：**精度、离线、授权与地理围栏误差明确

<a id="移动端穿戴与个人终端-推送与后台工作"></a>
### 推送与后台工作

**任务：**提醒用户并处理有限后台任务

**独特需求：**推送送达不等于用户收到或任务执行成功

<a id="移动端穿戴与个人终端-应用安装与更新"></a>
### 应用安装与更新

**任务：**维护设备上的版本和本地数据

**独特需求：**签名、存储迁移、撤销与卸载残留可检查
## 桌面、个人生产力与本地工具

**关键对象：**窗口、文件、剪贴板、快捷键、插件和本地配置

**共同不变量：**本地优先不意味着任意读写整个文件系统

**失败与恢复：**崩溃恢复、文件冲突和格式不支持不得吞数据

**共同验证：**大文件、长会话、快捷键、输入法、屏幕阅读与恢复

**相关机制：**[交互、界面与输入](机制适用性.md#交互界面与输入)；[文档、记录与结构化出版](机制适用性.md#文档记录与结构化出版)；[持久化、查询存储与索引](机制适用性.md#持久化查询存储与索引)；[检索、索引与排序](机制适用性.md#检索索引与排序)；[原生接口、ABI与异质目标](机制适用性.md#原生接口abi与异质目标)；[幂等、补偿与操作结算](机制适用性.md#幂等补偿与操作结算)

<a id="桌面个人生产力与本地工具-办公与笔记软件"></a>
### 办公与笔记软件

**任务：**编辑文本、表格、演示和个人记录

**独特需求：**格式保真、撤销、自动保存与手工源保护明确

<a id="桌面个人生产力与本地工具-文件与搜索工具"></a>
### 文件与搜索工具

**任务：**索引、预览、移动和整理文件

**独特需求：**显示名不等于物理路径身份，链接和权限要核对

<a id="桌面个人生产力与本地工具-截图图像与辅助工具"></a>
### 截图、图像与辅助工具

**任务：**获取用户选定区域并编辑或标注

**独特需求：**捕获权限、隐私范围、颜色和高DPI正确

<a id="桌面个人生产力与本地工具-终端与系统控制面"></a>
### 终端与系统控制面

**任务：**运行用户指定命令并展示结果

**独特需求：**终端内容不得自动成为下一条可信命令

<a id="桌面个人生产力与本地工具-离线知识工作台"></a>
### 离线知识工作台

**任务：**整合本地资料与结构化关系

**独特需求：**数据可导出，退出不依赖持续在线许可验证
## 协作、知识工作与团队沟通

**关键对象：**团队、共享文档、讨论、决议、任务与历史

**共同不变量：**草稿、讨论、正式接受和外部执行分开

**失败与恢复：**并发编辑、人员退出、离线和权限变化保留来源

**共同验证：**多作者冲突、权限负测、交接、撤销与导出恢复

<a id="协作知识工作与团队沟通-协作文档与白板"></a>
### 协作文档与白板

**任务：**多方共同编辑结构和内容

**独特需求：**对象级合并必须保持各自语义与作者贡献

<a id="协作知识工作与团队沟通-项目与任务系统"></a>
### 项目与任务系统

**任务：**分配任务并追踪交付和依赖

**独特需求：**任务打勾不等于依赖或真实工作已经完成

<a id="协作知识工作与团队沟通-会议与决策记录"></a>
### 会议与决策记录

**任务：**保存讨论、决议和待办

**独特需求：**转录、推断、批准和正式决策主体区别明确

<a id="协作知识工作与团队沟通-团队知识库"></a>
### 团队知识库

**任务：**维护可检索的定义、经验和文档

**独特需求：**相互转述同一来源不算独立证据

<a id="协作知识工作与团队沟通-跨组织协作"></a>
### 跨组织协作

**任务：**共享最小所需内容并协调交付

**独特需求：**各方权限、保密、责任和退出条件独立
