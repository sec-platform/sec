## 能源、电网、储能与公用事业

**关键对象：**发电、负荷、网络、设备、能量、价格和操作

**共同不变量：**物理潮流、安全界限、计量和经济结算分开

**失败与恢复：**测量失真、负荷突变、设备故障和通信失联有保护与专业接管

**共同验证：**物理模型、极端工况、硬件联调、计量对账和现场资格

**相关机制：**[方程、数值求解与离散化](机制适用性/随机优化与数值.md#%E6%96%B9%E7%A8%8B%E6%95%B0%E5%80%BC%E6%B1%82%E8%A7%A3%E4%B8%8E%E7%A6%BB%E6%95%A3%E5%8C%96)；[控制、执行器与安全状态](机制适用性/空间仿真测量控制.md#%E6%8E%A7%E5%88%B6%E6%89%A7%E8%A1%8C%E5%99%A8%E4%B8%8E%E5%AE%89%E5%85%A8%E7%8A%B6%E6%80%81)；[传感、计量与校准](机制适用性/空间仿真测量控制.md#%E4%BC%A0%E6%84%9F%E8%AE%A1%E9%87%8F%E4%B8%8E%E6%A0%A1%E5%87%86)；[优化、规划与运筹](机制适用性/随机优化与数值.md#%E4%BC%98%E5%8C%96%E8%A7%84%E5%88%92%E4%B8%8E%E8%BF%90%E7%AD%B9)；[危害、风险边界与防护](机制适用性/风险观测与保证.md#%E5%8D%B1%E5%AE%B3%E9%A3%8E%E9%99%A9%E8%BE%B9%E7%95%8C%E4%B8%8E%E9%98%B2%E6%8A%A4)；[数量、账本、价值与对账](机制适用性/规则账本分配履约.md#%E6%95%B0%E9%87%8F%E8%B4%A6%E6%9C%AC%E4%BB%B7%E5%80%BC%E4%B8%8E%E5%AF%B9%E8%B4%A6)；[数值、量纲与单位](机制适用性/身份表示与计算.md#%E6%95%B0%E5%80%BC%E9%87%8F%E7%BA%B2%E4%B8%8E%E5%8D%95%E4%BD%8D)；[微分、敏感度与逆问题](机制适用性/随机优化与数值.md#%E5%BE%AE%E5%88%86%E6%95%8F%E6%84%9F%E5%BA%A6%E4%B8%8E%E9%80%86%E9%97%AE%E9%A2%98)；[运行适配与受控重配置](机制适用性/构建交付与演进.md#%E8%BF%90%E8%A1%8C%E9%80%82%E9%85%8D%E4%B8%8E%E5%8F%97%E6%8E%A7%E9%87%8D%E9%85%8D%E7%BD%AE)；[时间域、时钟与历法](机制适用性/时间状态与资源.md#%E6%97%B6%E9%97%B4%E5%9F%9F%E6%97%B6%E9%92%9F%E4%B8%8E%E5%8E%86%E6%B3%95)

### 电网监测与调度

**任务：**估计状态并安排运行

**独特需求：**模型误差、保护约束和指令权限必须明确

<a id="能源电网储能与公用事业-新能源与储能管理"></a>
### 新能源与储能管理

**任务：**协调发电、充放电和资源限制

**独特需求：**老化、效率、热边界和不确定预测独立

<a id="能源电网储能与公用事业-能耗与需求响应"></a>
### 能耗与需求响应

**任务：**采集计量并安排节能策略

**独特需求：**节能收益、舒适度、服务连续性和外部性一起检查

<a id="能源电网储能与公用事业-能源交易与结算"></a>
### 能源交易与结算

**任务：**记录合同、计量和费用

**独特需求：**交易承诺与真实物理交付不可混为同一状态

<a id="能源电网储能与公用事业-设备维护与安全管理"></a>
### 设备维护与安全管理

**任务：**安排巡检、停送和恢复

**独特需求：**隔离、现场确认和复电授权不由软件结果代签
## 材料、化工、采掘与过程工程

**关键对象：**材料、批次、过程、设备、样本、环境和危害

**共同不变量：**配方/模型、现场过程、检测和安全资格分别管理

**失败与恢复：**异常温压、混料、污染和模型超范围有隔离与安全状态

**共同验证：**专业工艺审查、测量校准、危害场景及受控实验

<a id="材料化工采掘与过程工程-材料数据库与研发"></a>
### 材料数据库与研发

**任务：**组织成分、结构、性质和试验

**独特需求：**预测性质与实测结果、样本状态分别记录

<a id="材料化工采掘与过程工程-过程监测与优化"></a>
### 过程监测与优化

**任务：**分析物料、能量和设备运行

**独特需求：**守恒、工况范围、设备限制和异常联锁明确

<a id="材料化工采掘与过程工程-生产批次与追溯"></a>
### 生产批次与追溯

**任务：**跟踪物料、工序、质量和责任

**独特需求：**批次混合、返工、抽样和保留链路可核对

<a id="材料化工采掘与过程工程-资源与现场作业管理"></a>
### 资源与现场作业管理

**任务：**协调采掘、设备、人员与环境

**独特需求：**地质不确定、作业许可和现场安全不可隐藏

<a id="材料化工采掘与过程工程-安全环保与合规记录"></a>
### 安全环保与合规记录

**任务：**管理排放、风险、检验和处置

**独特需求：**规则适用与专业责任明确，不由优化器放宽安全条件

**共同验证：**现场校准、季节差异、批次追溯、对照和食品安全专业验收

**任务：**追踪个体、群体、环境和健康记录

**独特需求：**天气、病害、市场和供应风险不能压成单点预测

### 重网格后材料历史与守恒丢失

**关联领域：**[材料、化工、采掘与过程工程](工业能源与环境.md#材料化工采掘与过程工程)；[建筑、土木、BIM与工程设计](空间设施与个人服务.md#建筑土木bim与工程设计)；[物理、工程与多物理场仿真](科学仿真与开放系统.md#物理工程与多物理场仿真)

**相交规范：**[稳定身份、内容去重与对象演变](../../信息/对象关系与配置基线.md#identity-transformation-boundary)；[记忆、延迟、接触、拓扑变化与不光滑模型](../../领域/仿真/历史接触与拓扑演进.md#history-contact-topology)；[物理工程、物料谱系、制造与寿命闭合](../../领域/物理对象制造与寿命.md#physical-genealogy-and-life)

**任务：**网格变化只改变表示，不抹去材料状态和守恒责任。

**具体输入与触发：**自适应细化创建新单元，默认初始化将损伤重置为0。

**应保持行为与输出：**映射几何、材料历史、质量/能量与误差，明确旧新自由度对应。

**失败与恢复：**映射不合格拒绝该推进，保留最后一致模型与诊断。

**验证方法：**恒定场/解析场、积分量、损伤状态和新旧观察可比性。

### 无回滚子模型的联合迭代

**关联领域：**[能源、电网、储能与公用事业](工业能源与环境.md#能源电网储能与公用事业)；[物理、工程与多物理场仿真](科学仿真与开放系统.md#物理工程与多物理场仿真)；[数字孪生、在环试验与训练环境](科学仿真与开放系统.md#数字孪生在环试验与训练环境)

**相交规范：**[仿真内核族、时间推进与并行事件提交](../../领域/仿真/时间推进与状态恢复.md#simulation-progress-and-checkpoints)；[联合仿真的耦合、守恒与误差闭环](../../领域/仿真/联合仿真与现实控制.md#cosimulation-coupling)

**任务：**联合主算法只使用子模型真实支持的推进能力。

**具体输入与触发：**耦合迭代要求重做一步，某FMU只能继续前进。

**应保持行为与输出：**选择不需回滚且被接受的算法/误差路线，或准确报告缺能力。

**失败与恢复：**不得用旧可见变量伪装内部状态恢复；失败保留逐模型切面。

**验证方法：**两种不同能力FMU组合，核拒步、代数环和事件同步边界。
