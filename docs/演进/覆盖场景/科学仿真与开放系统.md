## 数学、基础科学与高性能计算

**关键对象：**数学对象、算法、数据、模型、计算资源与结果

**共同不变量：**形式定义、数值近似和物理解释分别评价

**失败与恢复：**病态、发散、资源爆炸和前提不成立保留准确状态

**共同验证：**形式证明或适用测试、解析例、差分、收敛与复现实验

**任务：**固定输入、算法和输出说明

**独特需求：**可复现范围要包含工具、硬件相关性与随机流
## 物理、工程与多物理场仿真

**关键对象：**方程、几何、网格、材料、初边值、求解器与观察

**共同不变量：**数学模型、离散化、代码实现与现实适用性分别判断

**失败与恢复：**网格退化、求解失败、能量漂移和耦合不稳定不能显示为正常成功

**共同验证：**制造解、网格/步长收敛、守恒、独立求解与实验对照

<a id="物理工程与多物理场仿真-流体与传热仿真"></a>
### 流体与传热仿真

**任务：**计算流场、温度和物质输运

<a id="物理工程与多物理场仿真-多体粒子与分子仿真"></a>
### 多体、粒子与分子仿真

**任务：**推进相互作用对象的运动

**独特需求：**力模型、碰撞、长程作用和统计采样条件可解释

<a id="物理工程与多物理场仿真-多物理与多尺度耦合"></a>
### 多物理与多尺度耦合

**任务：**组合不同方程、尺度和求解器

**独特需求：**单位匹配之外还需检查耦合稳定、守恒与误差传递
## 离散、社会、经济与系统仿真

**关键对象：**个体、事件、队列、网络、规则、参数与指标

**共同不变量：**模型行为是作者假设，不将涌现图像当现实因果证明

**失败与恢复：**事件爆炸、参数不可识别、顺序偏差和外推失效显式

**共同验证：**解析小例、事件重放、敏感度、校准与样本外对照

### 排队、物流与运营仿真

**任务：**模拟到达、服务、排队和资源竞争

**独特需求：**同时间事件次序、暖启动和截尾偏差需指定

<a id="离散社会经济与系统仿真-基于个体的仿真"></a>
### 基于个体的仿真

**任务：**让异质个体按规则交互

**独特需求：**行为参数、网络结构、更新顺序和涌现指标明确

<a id="离散社会经济与系统仿真-经济与市场仿真"></a>
### 经济与市场仿真

**任务：**模拟参与者、资源与交易规则

**独特需求：**参与者策略和制度假设不是自动成立的现实规律

<a id="离散社会经济与系统仿真-网络与分布式仿真"></a>
### 网络与分布式仿真

**任务：**注入延迟、丢包、分区和节点故障

**独特需求：**真实线程、硬件和未虚拟化效果保持验证缺口

<a id="离散社会经济与系统仿真-政策与规划情景分析"></a>
### 政策与规划情景分析

**任务：**比较假设改变下的条件性结果

**独特需求：**模型结果用于信息支持，不替人类作价值或政治选择

### 延迟模型只恢复当前状态

**关联领域：**[物理、工程与多物理场仿真](科学仿真与开放系统.md#物理工程与多物理场仿真)；[数字孪生、在环试验与训练环境](科学仿真与开放系统.md#数字孪生在环试验与训练环境)

**相交规范：**[仿真内核族、时间推进与并行事件提交](../../领域/仿真/时间推进与状态恢复.md#simulation-progress-and-checkpoints)；[记忆、延迟、接触、拓扑变化与不光滑模型](../../领域/仿真/历史接触与拓扑演进.md#history-contact-topology)

**任务：**记忆模型的恢复保留历史而非仅可见变量。

**具体输入与触发：**两条历史的当前x都等于0，但过去一个时刻分别为1和-1。

**应保持行为与输出：**将相关历史、插值与记忆误差纳入状态；后续演化允许不同。

**失败与恢复：**快照不全就拒绝等价续算；可从更早合格切点重放。

**验证方法：**解析小例、不同历史同当前值和历史截断的误差比较。
