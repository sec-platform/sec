## 物流、仓储与供应链

**关键对象：**货物、批次、容器、仓位、承运人、订单与交接

**共同不变量：**物理移动、账面变化、所有权和保管责任分开

**失败与恢复：**丢货、温控异常、断连、交接争议和部分履约可追溯

**共同验证：**端到端追踪、库存对账、异常履约、实时观测及恢复

**相关机制：**[路由、履约、路径与交付](机制适用性.md#路由履约路径与交付)；[预占、配额、排队与匹配](机制适用性.md#预占配额排队与匹配)；[数量、账本、价值与对账](机制适用性.md#数量账本价值与对账)；[事件、反应与消息语义](机制适用性.md#事件反应与消息语义)；[传感、计量与校准](机制适用性.md#传感计量与校准)；[跨组织、跨域与多权威协作](机制适用性.md#跨组织跨域与多权威协作)；[数值、量纲与单位](机制适用性.md#数值量纲与单位)；[时间域、时钟与历法](机制适用性.md#时间域时钟与历法)；[幂等、补偿与操作结算](机制适用性.md#幂等补偿与操作结算)

<a id="物流仓储与供应链-仓储管理"></a>
### 仓储管理

**任务：**入库、上架、盘点、拣选和出库

**独特需求：**批次、保质、位置和可用库存保持一致

<a id="物流仓储与供应链-运输管理"></a>
### 运输管理

**任务：**分配运力、路线和时间窗口

**独特需求：**法定或业务限制作为已确认约束，不靠最短路径替代

<a id="物流仓储与供应链-供应链计划"></a>
### 供应链计划

**任务：**协调需求、产能、采购和库存

**独特需求：**预测偏差、提前期和风险缓冲必须显式

<a id="物流仓储与供应链-冷链与高价值交付"></a>
### 冷链与高价值交付

**任务：**监控环境并保存交接证据

**独特需求：**传感器校准、缺样与责任转移不能被平滑隐藏

<a id="物流仓储与供应链-追溯召回与退运"></a>
### 追溯、召回与退运

**任务：**沿批次和流向定位受影响对象

**独特需求：**上游事件与下游实际处置分别结算
## 交通、出行、铁路与水运

**关键对象：**乘客、车辆、班次、路线、票权、设施和事件

**共同不变量：**计划时刻、实时位置、可达性和安全资格分别维护

**失败与恢复：**延误、取消、设施故障、位置漂移和突发需求有降级

**共同验证：**极端流量、调度冲突、真实时序、仿真与现场对照

<a id="交通出行铁路与水运-出行与票务"></a>
### 出行与票务

**任务：**查询、预订、支付和改退行程

**独特需求：**座位、票权、承运责任和资金退款分开

<a id="交通出行铁路与水运-交通控制与优化"></a>
### 交通控制与优化

**任务：**协调信号、路网和车辆流

**独特需求：**安全约束优先于通行效率，现场接口独立验收

<a id="交通出行铁路与水运-铁路与公共交通运营"></a>
### 铁路与公共交通运营

**任务：**管理运行图、车辆和乘务

**独特需求：**资源冲突、运行间隔与实时变更需专业验证

<a id="交通出行铁路与水运-港航与航运服务"></a>
### 港航与航运服务

**任务：**安排船舶、泊位、货物和航次

**独特需求：**气象、港口、海图与实时状态的适用范围明确

<a id="交通出行铁路与水运-共享出行与车队"></a>
### 共享出行与车队

**任务：**分配车辆、订单、维护和充能

**独特需求：**平台状态不自动证明车辆现实安全可用
## 航空、航天与空间系统

**关键对象：**飞行器、任务、轨道、设备、地面站与遥测

**共同不变量：**模型、任务计划、指令和真实飞行状态分别管理

**失败与恢复：**长时延、链路丢失、异常遥测和不可逆指令有严格准入

**共同验证：**模型验证、硬件联调、故障场景和专业工程审核

<a id="航空航天与空间系统-任务与地面运营"></a>
### 任务与地面运营

**任务：**规划观测、通信、维护和调度

**独特需求：**时间窗、资源、指令授权和回执身份一致

<a id="航空航天与空间系统-轨道与航迹计算"></a>
### 轨道与航迹计算

**任务：**在明确模型下计算运动和窗口

**独特需求：**坐标、时间基、摄动假设和误差需显式

<a id="航空航天与空间系统-航空运营与维护"></a>
### 航空运营与维护

**任务：**协调航班、机组、部件和适航记录

**独特需求：**维护记录、实际作业和运行资格不能相互替代

<a id="航空航天与空间系统-遥测处理与异常诊断"></a>
### 遥测处理与异常诊断

**任务：**关联设备数据、状态估计和事件

**独特需求：**迟到、丢包、校准与模型不确定性保留

<a id="航空航天与空间系统-训练与工程仿真"></a>
### 训练与工程仿真

**任务：**组合飞行模型、操纵和环境

**独特需求：**训练用途、工程用途和真实控制资格分别验证
## 机器人、自动化与自主设备

**关键对象：**机器人、姿态、环境、任务、规划、传感和执行器

**共同不变量：**感知推断、规划意图和实际动作分开，人的安全边界独立

**失败与恢复：**遮挡、定位漂移、规划失败、执行饱和和通信失联可安全停止

**共同验证：**场景覆盖、仿真对照、SIL/HIL和代表性真机任务

<a id="机器人自动化与自主设备-移动机器人"></a>
### 移动机器人

**任务：**感知、定位、规划并执行移动任务

**独特需求：**地图、当前障碍和定位置信范围不能混同

<a id="机器人自动化与自主设备-工业操作与抓取"></a>
### 工业操作与抓取

**任务：**协调机械臂、工件和动作

**独特需求：**可达性、碰撞、力限和工具坐标需联合检查

<a id="机器人自动化与自主设备-多机器人协作"></a>
### 多机器人协作

**任务：**分配任务并共享环境信息

**独特需求：**通信失败、资源争抢和局部计划冲突要处理

<a id="机器人自动化与自主设备-服务与辅助机器人"></a>
### 服务与辅助机器人

**任务：**与人共同完成现实任务

**独特需求：**同意、可解释反馈、紧急接管和环境差异明确

<a id="机器人自动化与自主设备-机器人开发与测试平台"></a>
### 机器人开发与测试平台

**任务：**接入模型、设备、日志和试验

**独特需求：**仿真通过不直接授予真机执行资格
