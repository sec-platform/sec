# Gift：完整值结构定义

Ref[T]固定id、revision、kind；只证明引用结构，解析和资格另核。Option[T]的null表示明确无该可选值，未知必须在回答状态中表达，不可拿null代未知。Set按编码唯一仅是结构检查，语义相等使用相应定义。

## Rational

denominator>0；约分用于值相等，不吞原始表示、单位或发生身份。

```json
{
  "kind": "record",
  "fields": {
    "numerator": {
      "kind": "primitive",
      "name": "int"
    },
    "denominator": {
      "kind": "primitive",
      "name": "nat"
    }
  },
  "additional_fields": false
}
```

## TypedValue

精确值依类型和编码解释。值载荷保存在受解释的对象中；未知编码可以保全但不得进入已解释求值。

```json
{
  "kind": "record",
  "fields": {
    "type_ref": {
      "kind": "reference",
      "target_kind": "Type"
    },
    "encoding": {
      "kind": "reference",

    },
    "exact_value_ref": {
      "kind": "reference",
      "target_kind": "EncodedValue"
    }
  },
  "additional_fields": false
}
```
