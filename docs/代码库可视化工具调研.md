# 📊 代码库可视化工具全汇总

## 一、通用型可视化工具

### 1. **Mermaid** ⭐ 最流行
| 属性 | 详情 |
|------|------|
| **官网** | https://mermaid.js.org |
| **语言** | Markdown/JSON |
| **输出格式** | SVG, PNG, PDF |
| **特点** | 实时预览，IDE集成丰富 |
| **适用场景** | 文档、README、技术博客 |

**支持图表类型**：
- Flowchart（流程图）
- Sequence diagram（时序图）
- Class diagram（类图）
- Entity relationship diagram（ER图）
- Gantt chart（甘特图）

---

### 2. **PlantUML**
| 属性 | 详情 |
|------|------|
| **官网** | https://plantuml.com |
| **语言** | 文本 DSL |
| **输出格式** | PNG, SVG, LaTeX |
| **特点** | 语法简洁，图表类型全面 |
| **生态** | VS Code插件, IntelliJ插件 |

---

### 3. **Graphviz** (DOT语言)
| 属性 | 详情 |
|------|------|
| **官网** | https://graphviz.org |
| **语言** | DOT |
| **输出格式** | PNG, SVG, PDF |
| **特点** | 开源，布局算法强大 |
| **适用场景** | 大型复杂图，网络拓扑 |

---

### 4. **D2** (Diagrams as Code)
| 属性 | 详情 |
|------|------|
| **官网** | https://d2lang.com |
| **语言** | D2 DSL |
| **输出格式** | SVG, PNG, PDF |
| **特点** | 现代语法，2023年发布 |
| **优势** | 比 Mermaid 更强大，比 DOT 更易读 |

---

## 二、代码专用分析工具

### 📌 函数/方法调用图

| 工具 | 语言支持 | 特点 | 输出格式 |
|------|----------|------|----------|
| **Code2flow** | Python, JS, Ruby, PHP | 自动生成调用图 | PNG, SVG | 
| **pycallgraph** | Python | 函数调用追踪 | PNG, DOT |
| **gprof2dot** | 多语言 | 性能分析可视化 | PNG, SVG |
| **ncc** | Node.js | 编译后分析 | - |

| **madge** | JS/TS | 循环依赖检测 | PNG, SVG |
| **pydeps** | Python | 依赖分析 | PNG, SVG |

## 十、选择指南

```
需要什么 → 推荐工具
─────────────────────────────────────
快速生成流程图 → Mermaid (在线编辑器)
复杂架构图 → Graphviz + DOT
代码调用关系 → Code2flow
模块依赖分析 → dependency-cruiser
技术文档 → PlantUML + VS Code
企业级架构治理 → Structurizr
实时交互式探索 → D2 + Web界面
跨语言通用 → Graphviz
```
