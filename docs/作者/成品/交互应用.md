# Web、桌面与移动交互应用

本篇把已有Panel补成三个完整、不同宿主边界的有限应用；并非把整个IDE等同于表单。复杂工作台仍由[工作台结构源](../../../examples/结构化工作台/README.md)及其编辑、搜索、调试等规则组合。本例的产品意图是：离线编辑区间JSON，执行准确规范化，保留草稿与明确结果，不默认上传。

## 共同的可见产品与状态

一屏包含标题、带可访问标签的多行输入、Run/Cancel/Reset、结果只读区、错误与状态区。作者title默认`Interval Workbench`；输入接受原Command线格式，算法默认MergeTouching。已有具体消息与CSS在[资源](../../../examples/开发成品/assets/messages.json)，图像不是功能前置。

公共状态为Editing、Running、Succeeded、Rejected、Cancelled；输入修订与请求代独立。Run在输入非空且无当前活动请求时可用，点击后捕获完整文本并显示忙状态；Cancel只在Running可用，立即撤当前安装资格再请求真实停止。运行期间可编辑：原结果若到达只作准确旧结果，不覆盖新输入。运行时Run禁用；先取消或等原任务结算后才允许下一次Run，不把取消确认当真实资源结束。取消后新请求可在实际预算允许时接纳，原任务仅保留自己的清理责任。空输入保留Editing，不自动转换成[]。

业务失败保留原草稿和旧结果，标明旧结果对应哪个输入；操作不成功不能显示成功空列表。Reset只有确无未保存改动时直接清空，否则先确认；取消确认不改变输入。键盘Tab顺序为输入、Run、Cancel、Reset、结果，焦点可见；运行完成不抢输入焦点。错误链接可定位行列但坐标依据真实解码器，IME组合尚未结束时不按单个Enter提交。

状态通过文本和aria-live礼貌区域提供，错误用明确关联而不只变红。输入允许换行、缩放及水平查看长原文；总体在320 CSS px下重排为单列，控制可键盘操作，文本200%缩放不丢操作。这里采用[WCAG2.2](https://www.w3.org/TR/WCAG22/)相交标准，不声称仅有几个aria属性就全面合规。精确对比度和真实辅助技术需目标验收。

## WebPanel：纯离线页面

公开`mount(element) -> Result<Presenter,Fault>`，只有根元素和必需本地资源可以建立完整实例时才返回Presenter；输出index.html、应用脚本/样式、消息与必要工作器/算法，资源同一发行组，不依赖CDN。默认无账号、无cookie、无遥测、无后台请求、无localStorage持久化；刷新会丢草稿，输入有改动时仅在浏览器实际允许的离开提示机制中警示，不保证强制阻止关闭。

开页不自动计算或加载任意插件。计算必须在所选输入预算内保持交互：有界切片或工作器；不是纯函数就可任意阻塞UI线程。默认拒绝HTML注入，输出只作为文本。Content-Security-Policy限定实际资产与所需worker来源；不通过unsafe-eval求解需求。

导出图/结果、剪贴板和上传不在这个根内；需要时追加相应明确能力。构建字节、开页成功、用户可操作分别核验；静态截图不能满足本合同。

## Desktop：有文件打开与保存的独立应用

`start(files) -> Result<Handle,Fault>`在文件桥和展示实例建立成功后返回；共同交互之外提供Open、Save Input、Save Result与Close。原文件只有通过用户选择器取得的资源句柄才可访问，不因为路径字符串已知就获得权限。Open有未保存草稿时确认保留/丢弃/取消；取消选择器是NoChange。解码失败保留原草稿，并显示文件与原因；不把二进制硬转UTF-8。

保存固定待写字节及原文件戳，条件写入失败为Conflict：保留草稿，允许另存为或重新比较，不默认覆盖外部新内容。Save Result仅保存明确选择的结果版本，旧结果有醒目标注。临时文件与原子替换能力按实际宿主，不假定跨卷rename原子。窗口关闭、算法停止与最后文件写入分别结算；保存未知时不自动重发。

产物包含真实桌面入口/渲染/文件桥、算法、配置和平台所需成员。Linux/Windows/macOS分别检查原生依赖和包结构；本例选择现成宿主，不要求SEC自己实现窗口系统。应用可运行与安装包完整是不同根；桌面默认不建更新服务器，不要求管理员权限。

## Mobile：后台与现场状态不能照抄桌面

共同UI采用触摸与键盘可达控件；软键盘显示时输入及主操作仍可见，旋转不重复Run。支持系统文档提供者打开/导出；不以应用私有路径冒充用户授权文件。默认将草稿保存在应用私有持久区，成功写入后才标“已保存”；明确清除本应用数据与卸载可能使其消失，不承诺跨设备备份。

移动宿主的`DraftStore.load/save`、`Mobile.start`及`suspend/resume`都把可预期的存储、权限和生命周期故障作为有类型`Result`返回；正常Promise解析不再被用作“操作必然成功”的暗示。启动加载草稿失败时保留可诊断的启动失败，不创建一份看似空白但其实丢失旧草稿的会话。suspend失败不伪造“已安全后台化”，resume失败也不把旧句柄自动认成当前授权。

前台运行捕获请求与输入版本。进入后台先停止新交互和可取消计算；没有真实后台执行资格，不承诺继续运算。系统杀进程后从最后成功草稿恢复为Editing或Cancelled提示，不把旧Running恢复成已完成。重回前台重核授权文件句柄；失去权限仍可查看保留的私有草稿，不偷读原文件。

配置变化可在内存中保留任务但需准确绑定活动会话，进程重建不能凭同id认领旧消息。包包含实际移动入口、权限声明、资源、算法与平台桥；签名身份、应用ID和商店资格是实际发布输入，不捏造。输入法、多窗口/旋转、后台杀进程、存储满、撤权和导出失败是独立验收项。

## 第二次修改及结构保证

改title仅改当前应用参数，不改算法；增加自动保存引入持久作用而非“UI开关”；加入远程计算改变数据离域、离线与隐私，不能由性能偏好自动启用。取消返回不释放仍在用的缓冲，旧结果不安装，输入/保存/产物三种版本分别绑定。上述机制由框架适配与已有运行合同承担，不要求产品作者写回调或新.sec源码。

## 可调用的动作与生命周期

目标接口的Desktop.Handle公开open/saveInput/saveResult/requestClose，Mobile.Handle复用这些动作并增加suspend/resume。返回no-change只用于用户取消选择器或已确认的无改动；冲突、失权和I/O错误有明确失败结果。保存输入与保存结果使用不同的文件绑定，不将Save Result默写入原输入文件。saveAs=true重新取得用户选择；false且未绑定目标时也启动选择器，取消仍为NoChange。

requestClose先执行本页的保留/丢弃/取消交互。结果closed仅在草稿决定与相交资源结算完成后返回；cancelled继续编辑；blocked保留可查原因。底层close只关闭此展示实例的资源，不能作为“用户确认丢弃”的替代；窗口Close动作先走requestClose，不默认调用close越过草稿。

presenter的run/cancel/reset、文件动作与完成回调在同一实例的状态拥有者处串行接纳；算法可以在外部并行。文件选择器回调回来时再核当前请求和草稿版本，不能覆盖选择器打开期间新输入。UI必须让所有必需动作可达；这份类型合同不把提供HTML元素或窗口句柄的真实渲染能力说成已经实现。

## 本页规则字段与源码对应

`on`对每条Rule都是必需的Product主体。下表参数由复合定义在声明处提供默认，实例化到Rule时必须全部有准确值；Rule字段不再另存默认。所用形态为[同一字段类型合同](../结构化源码.md#规则值字段沿同一类型检查)。

| Rule | 其他必需字段／类型 | 完整作者根 |
|---|---|---|
| WebPanel | operation:Operation（与Canonical相同主体）；title:Text | [WebPanel](../../../examples/开发成品/model/webpanel.json) |
| Desktop | operation:Operation（与Canonical相同主体）；title:Text | [Desktop](../../../examples/开发成品/model/desktop.json) |
| Mobile | operation:Operation（与Canonical相同主体）；title:Text | [Mobile](../../../examples/开发成品/model/mobile.json) |

整数词元无损解码，布尔不能当Int，ListInt在实际Type里就是`list`的`Int`元素，不新增内置类型；正值、范围、字段间关系及硬性限制由上文完整规则处理。目标接口的精确类型在[公共边界文件](../../../examples/开发成品/公开边界.d.ts)，完整资源/失败含义仍由本页和[共同数据](共同数据与完整性.md)拥有。
