# 模型、学习、概率与优化成品

本页给出四份互不偷换的完整有限合同，而不是用“AI模型”概括数据、权重、推理和训练。Inference、Trainer、Sampler、Optimizer实际源可分别选用；不是要求所有工程都训练模型。共同精确数值见[数据定义](共同数据与完整性.md)。

## Inference：精确线性评分组件

作者`weights`默认[2,-1]，`bias`默认0，全部为精确Int。运行输入有限Int向量x，长度必须等于weights长度。公开`score(x) -> Result<Int,ShapeMismatch|Fault>`，结果恰为bias+Σ(weights[i]×x[i])；无随机、外部状态与暗含归一化，不裁剪/回绕/饱和。权重属于本次作者选择，不是从网络latest取得。

方法可以用现成TS bigint或合格原生核；若原生只能定宽，使用已证明的输入条件分派到通用方法，不能缩小原输入域。并行归约在精确整数域等义，浮点替代必须有另行接受的误差合同。结果、单位、shape、错误顺序和预算同时检查。

产物必须含实际模型参数、公开输入输出schema、score实现或准确推理依赖、模型身份与方法；只有名叫model.onnx的文件不证明runtime支持其opset与算子。ONNX区分图、初始化参数与版本，本例据此分清模型材料与运行能力，不强制采用ONNX。[ONNX概念](https://onnx.ai/onnx/intro/concepts.html)。验收包括[3,4]→2、维度错误、空权重、超定宽整数和权重升级后旧实例仍用旧值。

## Trainer：可复现的有限岭回归

原意图从固定有理数矩阵X和响应y训练带截距线性模型。作者`regularization`默认1，是严格正Int；惩罚所有参数，包括截距，以使所选方程唯一。输入N>0、固定特征维D>=0，X扩增常数1列，所有值按规范分数编码{num:Dec,den:正Dec}，约分且den>0；重复样本按真实重数保留。

输出θ唯一满足`(XᵀX+λI)θ=Xᵀy`，并给目标值`||Xθ−y||²+λ||θ||²`和准确输入/λ绑定。λ>0使矩阵正定，有限有理数据可用精确消元完成；资源超限是运行故障，不输出半组权重为成功。公开`train`返回`Promise<Result<Model,Fault>>`：取消、预算、读取或内部故障是显式失败，不通过Promise正常解析一份旧模型或半组权重冒充成功。取消保留输入与准确未完成状态，不自动发布旧检查点模型。检查点必须绑定矩阵、λ、算法阶段和解释，不能只保存参数数组后声称可复现。

模型导出原子采用：先封存完整参数与schema，再独立评价，再在获准边界发布。训练成功不证明泛化，训练集误差不作为留出性能；选择λ若看过确认数据，会改变统计解释。已看过数据不得换个文件名冒充独立确认。此产品可输出有理模型，不能直接加载到只收整数的Inference根而不适配；这是不同的模型类型。

完整成品含读取器、实际训练方法、检查点/恢复（若请求）、参数/shape/schema和训练报告；无数据源权限不能把空数据训练当成功。例原特征为0维、X的一行为空列表、y=2、λ=1，增添截距后θ=[1]；重复样本会改变正常方程。验收含分母零、λ非法、shape错误、续跑一致、精确残差与取消不误发布。更广神经网络/自动微分沿其独立合同，不借本线性例声称全部学习已完成。

## Sampler：概率目标与随机源分别固定

作者`numerator`默认1、`denominator`默认2，要求0<=a<=b且b>0。公开`sample(count,randomBits,cancel) -> Promise<Result<readonly boolean[],Fault>>`，count为非负Int；随机源的`next()`同样返回有类型结果；a=0和a=b不消费随机位。其余通过合格独立公平比特源，抽k=ceil(log2 b)位形成u，u>=b则拒绝该轮，u<b时输出u<a。每次结果独立所需的随机源条件明确，不以伪随机同一种子重复运行证明独立。

有限运行预算到期返回准确中断，不伪造完整count条；已抽取的位不能因取消又退回另一调用重复使用。合法完整结果位于`ok:true`；取消、预算和随机源故障位于`ok:false`，不以普通Promise rejection作为这些预期运行结果的唯一通路，也不伪装为业务false。默认全结果返回，不偷偷把已生成前缀标成成功；需要在线抽样则选有顺序与消费规则的流接口。记录位流可作确定回放，安全种子不写普通日志；随机源不可用为MissingCapability，不自动改用时间戳。

输出实现、概率参数、随机源进口及其信任/隔离要求。只有a/b的值域正确不证明分布；必须核拒绝算法和随机源模型。验收0、1、非二次幂分母、连续拒绝、共享源竞争、不同样本相关性及边际相同但重复抽样的反例。安全用途需另行限定密码学源和攻击模型，不把本功能标为默认安全随机。

## Optimizer：有限候选域内真正的最佳值

公开输入为有限Candidate序列，Candidate={id:Text, feasible:Bool,cost:Int}，id唯一。`choose(candidates,cancel?) -> Result<Answer,Fault>`完整读取域后输出最小cost的可行候选；平局取原位置最先；无可行者返回NoFeasible。作者无额外必填选项。每个字段必须已在同一准确场景下取得，不能把未知可行性或未知成本编码成false/0。

完整读取和比较所有候选后才返回OptimalForDeclaredDomain；当前choose接口要求完整域检查，预算不足或取消只返回独立故障，不返回半成品。需要Incumbent时必须明确采用另一带部分结果的接口，不能把它塞进当前optimal联合分支。候选域是输入，不推导为世界全部实现；增加新候选影响最优范围，即使旧赢家仍可行。Pareto多目标和有优先级未知比较继续沿原定义，不在本单目标例中私自加权。

消费方取得实际赢家id、原位置、cost、完整域与规则身份；证书/报告是对应结果材料，不授予执行所选对象的权限。运行性能测量生成cost时遵守探索/确认规则；复制报告不增加样本。验收全负成本、平局、全部不可行、重复id、中途候选源改变及未知值不得填零。

## 本页规则字段与源码对应

`on`对每条Rule都是必需的Product主体。下表参数由复合定义在声明处提供默认，实例化到Rule时必须全部有准确值；Rule字段不再另存默认。所用形态为[同一字段类型合同](../结构化源码.md#规则值字段沿同一类型检查)。

| Rule | 其他必需字段／类型 | 完整作者根 |
|---|---|---|
| Inference | weights:ListInt；bias:Int | [Inference](../../../examples/开发成品/model/inference.json) |
| Trainer | regularization:Int | [Trainer](../../../examples/开发成品/model/trainer.json) |
| Sampler | numerator:Int；denominator:Int | [Sampler](../../../examples/开发成品/model/sampler.json) |
| Optimizer | 无 | [Optimizer](../../../examples/开发成品/model/optimizer.json) |

整数词元无损解码，布尔不能当Int，ListInt在实际Type里就是`list`的`Int`元素，不新增内置类型；正值、范围、字段间关系及硬性限制由上文完整规则处理。目标接口的精确类型在[公共边界文件](../../../examples/开发成品/公开边界.d.ts)，完整资源/失败含义仍由本页和[共同数据](共同数据与完整性.md)拥有。
