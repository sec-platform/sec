# 编译器、分析器与生成器成品

这三个形态用一份明确的有限规则语言作完整例，不是再造SEC作者语言。它们所消费的产品输入是普通JSON文档，SEC作者源只规定该产品怎样理解和输出。

## 共同输入：ThresholdRules

一个UTF-8 JSON对象恰含`version:1`和`rules`数组。每项恰为`{name:Text,limit:Dec}`；name必须匹配ASCII `[A-Za-z_][A-Za-z0-9_]*`且不为目标保留字。名字唯一，limit为精确Int；数组顺序属于公开规则顺序。重复JSON键、非法编码、未知version/字段先诊断；不得先解析覆盖重复键再校验。

正常含义：给定name与整数x，查找对应规则并返回x>=limit，未知name为UnknownRule。运行不读环境、随机或网络。该有限含义用于准确检验编译保持，不宣称覆盖任意用户语言。

## Compiler：从规则到可调用程序

作者选择根Compiler即可；其TS目标公开`evaluate(name:string,x:bigint): {ok:true,value:boolean}|{ok:false,error:'UnknownRule'}`。输出`rules.ts`或目标要求的JS/声明、公共入口、必要依赖及完整diagnostics/source map。常量以bigint或等义表达保持，不先用Number；名字经合法引用或正确转义，不能拼接成代码注入。

诊断包含文件身份、UTF-8字节范围、code、message与相关重复位置；字节范围不等于编辑器显示列。遇到非法输入不产生合格运行制品，但可以返回私有候选供定位。map从目标规则入口和常量指向准确源名字/limit，不能只记行号近似而声称exact。

方法可直接生成查表或保持错误与顺序的分支；目标公开接口不因优化变异步。生成器种子使用已有工具链，不能要求待生成规则先编译其自身才启动。全工程原P0—P7、Pass私有失败和证据接纳继续生效。完整编译器产品要有真实读取、检查、发射、CLI/库入口和版本解释，只有变换示例不算。

## Analyzer：观察不偷改输入

Analyzer的公开`analyze(document) -> Result<Report,Fault>`返回一份绑定准确source的Report；Report含`complete`和全体可定位的结构/名字/类型问题。`ok:true,complete:true,diagnostics:[]`才是该输入范围的完整空诊断；工具崩溃、取消、预算结束或未覆盖范围不能返回空数组冒充通过。错误排序按源字节位置，再code稳定排序；不承诺任意不完整JSON都有完整语义诊断，语法断点后的未知范围标明。warnings只有实际已定义规则，例如名字未被请求的输出根使用时才能标unused，不能把动态用途猜成无用。

本例没有作者参数，不自动运行被分析内容、安装包或应用修复。建议改名是包含准确前像的可选候选，取得当前源后才能采纳。完整空diagnostics只清本生产者的同输入范围；崩溃/超时/未分析不是空成功。

产物是可调用分析器、诊断协议、规则集和必要解析依赖。`complete:false`只允许在所选接口明确接受部分分析时返回，并必须保留未覆盖范围；要求完整分析的消费方不能据此清空旧诊断。检查引用版本变化使旧结果陈旧；同字节用不同语言解释不复用语义结果。

## Generator：从同一规则生成文档和数据

Generator输出`thresholds.json`与`README.md`，分别列完整name/Dec limit与人可读说明，顺序按输入数组。不生成新的行为，不允许文档正文与数据各自推导不同默认。Markdown中的值作为代码/表格安全转义，不把输入当链接或HTML执行。

所有输出有一个准确成员清单，生成到私有目录，检查完整后才由既有作用协议发布；遗留文件删除需确认上次拥有者和本次不再被消费，用户文件不在清理范围。输入相同而locale/时间不同不得改排序和内容；确需时间字段时它是明确输入，不暗混当前时间。

这类工具可以自用，但文档生成成功不证明SEC主体已自举。规则文件非法时不覆盖上次好结果。调用外部模板引擎要绑定模板、工具和环境，不因“只是文档”获得任意脚本权限。

## 完整的独立核对

共同输入例`{version:1,rules:[{name:'adult',limit:'18'}]}`（示意值，实际文件是严格JSON）：x=17为false，18为true，未知name为UnknownRule。编译与解释需对同一输入、编码和量词比较，不能两个错误编码互证。Analyzer检查重复名与对应两处范围；Generator检查Dec与转义、原顺序、同源重建、输出部分失败和无关文件保留。

扩展规则到浮点、任意表达式、动态导入或宏时必须明确新增语义与诊断，不能把本有限编译器名称变成通用编译已完成的证明。

## 本页规则字段与源码对应

`on`对每条Rule都是必需的Product主体。下表参数由复合定义在声明处提供默认，实例化到Rule时必须全部有准确值；Rule字段不再另存默认。所用形态为[同一字段类型合同](../结构化源码.md#规则值字段沿同一类型检查)。
