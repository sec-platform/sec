# 规格、纯值与静态资产

本篇覆盖两种已有成品家族。它们都有可消费成果，但不伪装成运行服务。结构根见[Definitions、StaticValue与Resources](../../../examples/开发成品/README.md)。基础值见[共同合同](共同数据与完整性.md)。

## Definitions：可复用要求与策略包

**原意图。** 分发可被别的工程使用的区间规范化要求，公开Normalize和Adjacency，默认合并相接区间；使用者可明确选择保留仅相接区间。完整含义直接复用原Canonical，不重新发明同名关系。作者参数为包公开名`packageName`（默认`interval-policy`）；改名只改分发门面，不重建类型身份。

**公开合同。** 消费者可枚举公开定义，准确实例化参数，读取每条规则的字段、完整含义与依赖。私有定义不通过知道内部ID导出。包含实际作者模块、公开出口表、语义说明、定义所需解释绑定及许可材料；示例与机器目录必须引用同版规则。没有实现时，包仍是完整规格包，但不得附“已可运行”入口。

**生成与使用。** 从原outputRoots取得公开闭包，保留精确类型/默认来源及共享主体，检查全部公开依赖可取得，再封存规范包。获取不执行初始化脚本。独立库作者可以替换私有组合，但不能加强调用前提、削弱要求或改变默认而不显示采用差异。

**失败及后继。** 缺公开依赖、字段冲突、两个同ID不同内容均为不完整包；未使用私有研究不强制分发。读者已固定旧内容时保持旧解释。第二次将默认变成KeepTouching，仅未显式固定且接受新包的消费者改变；公开名更改不自动修复调用方。验收必须用一个新消费工程在无原编辑会话下读入并实例化，再检查合并/不合并、空输入和反向输入；不是只数文件。

## StaticValue：一个确定配置值，而非配置程序

**原意图与作者参数。** 产生客户端配置`{version:1, title, historyLimit}`，title默认`Workspace`，historyLimit默认200且为非负Int。公开输入是这些设计参数，运行时无输入、无环境读取。title为完整Unicode标量文本，拒绝NUL；不将它解释为HTML。historyLimit=0明确关闭新增撤销历史，不代表无限。

**字节合同。** 输出`config.json`：UTF-8无BOM，字段顺序version/title/historyLimit，version写JSON整数1，historyLimit写Dec字符串，title用JSON正确转义，最小分隔符，末尾LF。不把排版选项影响到值含义。规范也允许消费方直接取得内存值，但文件根必须交准确字节；二者是不同请求终点。

**方法与失败。** 对全部参数先校验再一次序列化；输出不读cwd、时间、网络或随机。非法默认在定义检查时即报错。要写文件时，生成与实际保存分开；短写/断连不能报告完整文件。重复生成同源同解释字节相同，但写权限仍重新核验。第二次改title不改变historyLimit来源；消费者要求数字而本合同输出字符串时必须更换明确编码合同，不能暗转。

**独立验收。** 双引号、反斜线、换行、表情和超安全浮点范围的Int往返正确；负历史值拒绝；文件和内存结果解码相同；未授权写入不发生。

## Resources：有真实成员的资源包

**原意图。** 交付本例提供的英文消息文件与默认CSS，以`messages.json`和`theme.css`两个公开路径使用。资源在[assets](../../../examples/开发成品/assets/messages.json)实际存在；不是只有两个虚构文件名。作者只能通过实际资源内容和显式公开名修改它们，摘要由工具计算。

包成员精确为这两个文件及工具生成的成员清单；消息键精确为实际messages.json中的25项，覆盖输入、执行、取消、重置、结果、打开/保存/关闭、保留/丢弃/继续编辑、五种执行状态、旧结果、冲突、已保存/未保存、草稿恢复、丢弃确认与能力不足。重复键、缺键和未声明键拒绝；作者title独立提供，不写入第二份消息。CSS只使用已选择颜色/布局，不引用外部URL、字体和脚本；媒体未知时按字节保全，不猜可执行含义。资源名字不授予网络或磁盘权限。

构建先固定全部原件、检查消费键和外链，再形成目录树与内容摘要。路径必须相对、无父逃逸、链接逃逸和宿主等价冲突；不自动把邻近秘密或缓存打包。缺一个成员不能以空文件补齐。重新采用消息与样式必须一致切换，旧页面仍用其旧资源组；正在使用的文件按真实宿主保留。

验收包括全部引用解析、离线使用、敏感文件不在成员内、路径冲突拒绝、替换包失败保留已采用旧组。空目录若真是要求，需清单/容器真实保留，不能用占位文件冒充空目录。资源文件格式可解析不等于视觉或无障碍已通过。

## 本页规则字段与源码对应

`on`对每条Rule都是必需的Product主体。下表参数由复合定义在声明处提供默认，实例化到Rule时必须全部有准确值；Rule字段不再另存默认。所用形态为[同一字段类型合同](../结构化源码.md#规则值字段沿同一类型检查)。

| Rule | 其他必需字段／类型 | 完整作者根 |
|---|---|---|
| Definitions | packageName:Text | [Definitions](../../../examples/开发成品/model/definitions.json) |
| StaticValue | title:Text；historyLimit:Int | [StaticValue](../../../examples/开发成品/model/staticvalue.json) |
| Resources | 无 | [Resources](../../../examples/开发成品/model/resources.json) |

整数词元无损解码，布尔不能当Int，ListInt在实际Type里就是`list`的`Int`元素，不新增内置类型；正值、范围、字段间关系及硬性限制由上文完整规则处理。目标接口的精确类型在[公共边界文件](../../../examples/开发成品/公开边界.d.ts)，完整资源/失败含义仍由本页和[共同数据](共同数据与完整性.md)拥有。
