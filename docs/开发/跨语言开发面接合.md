# 跨语言开发面接合

本篇规定开发工具怎样消费已采用的跨语言/原生语义，不重新定义语言、IDE、执行器或六工具。搜索、编辑、重构、构建、调试、Profiler、Notebook、协作、Agent 与测试都消费同一作者源、绑定、结果和 operation；客户端能力差异不能建立第二业务事实源。

## 共同主链

workspace 固定源与未保存缓冲；semantics 解释调用、类型、效果、布局和实际控制；compiler 固定方法、目标成员和缺项；assurance 评价对应 Claim；application/entry 只投影本次目的所需结果；execution 只处理真实外部作用。短修改可以在同进程组合完成，不强制每步网络往返或新 sessionId。

## 搜索、补全与索引

文本搜索、精确引用、结构查询和动态近似分别标明覆盖。反射/特化查询的“全部成员”“不存在某候选”属于真实集合/负依赖，新成员必须触发相交失效。补全可以展示候选，只有固定源规则完成重载/访问/转换检查后才形成绑定；显示顺序不能决定调用。

## 重构与格式化

rename/move/extract/inline/签名变化绑定原声明、前像及真实保持观察。跨语言重构必须保留泛型实例、默认参数、私有最佳重载、资源捕获、外向 control flow、隐式转换、来源和清理。抽取函数不能把原 break/return 改成普通 return；固定地址对象不能先生成临时再移动。部分接受只在共同不变量仍成立时进行。

## 构建与目标

BSP/原生构建只拥有实际任务与结果。源生成、目标编译、链接、运行准备和发行不是同一成功状态。有限实例、原生 shim、设备内核、反射生成物和依赖必须进入产物闭包；类型检查通过不证明符号/ABI/运行供给存在。缓存绑定真实正/负依赖、目标和工具版本。

## 调试

断点、FrameRef、对象 view、协程帧、泛型特化、内联和生成 helper 绑定真实可执行世代与 source map。旧二进制不能用新源码假装精确定位；被优化掉/不可读的值返回 unavailable。表达式求值、getter、内存修改、热替换各自需要真实能力和作用准入；能展示对象不产生写权。

## 性能与 ObservationIR

观测绑定运行、输入、环境、方法、采样覆盖和时钟域；ObservationIR 是交换格式，不成为行为规范。更快可能来自少做工作、不同缓存、分配、误差或失败语义，不能据总耗时直接替换。硬 ABI、数值、进展、安全约束先满足，再比较同一可行集的成本。

## 重放、逆向与热替换

记录只覆盖实际捕获的输入、调度、时间、随机和外部通道；逆向计算不能撤销现实文件/设备/付款效果。热替换需处理旧对象布局、vtable、回调、协程帧、TLS、析构器和在途调用；无安全切面时保留旧模块，不先卸载再试。

## Notebook / REPL / 交互进程

文档单元、源码修订、执行身份和内核状态代分别绑定。重复执行或顺序改变使相交结果陈旧；文本相同不自动恢复旧运行值。输出结束、内核空闲、程序终止和资源关闭分别判断。内核重启使旧句柄/借用失效，但此前外部作用仍保留。

## 协作、Git 与远程工作区

CRDT/OT 只证明其支持域中的编辑收敛，不证明编译、业务不变量或发布准入。缓冲、工作树、index、commit 和远端 ref 保持各自身份；不自动 stage/stash/reset。远端写超时按 ref/operation readback，不能当成未发生。远程容器、端口、凭证和 native 进程是独立资源，不因客户端断开自动终结。

## Agent 与协议映射

人、AI、脚本消费同一结果。ProtocolMapping/ProjectionReceipt 只能说明字段如何投影和对应哪个来源，不能签发语义正确或执行权限。上下文按任务切片，不做可变全局 current-world；并行 Agent 可共享纯计算，但写入/预算/Effect 仍有准确 owner。协议装不下必要 partial/unknown/结算区别时必须拒绝或协商能力，不能映射成成功。

## 测试、供应链和运行维护

测试发现、执行、期望、snapshot/golden、Provider conformance 和结果评价分开；零测试/跳过/加载失败不算通过。SBOM、签名、VEX 分别证明组成、完整性/来源和特定漏洞状态，不相互代签。浏览器、移动端、设备和 SRE 工具继续使用真实宿主权限、驱动、资源和恢复合同；页面加载/设备连接/度量改善不等于用户目标完成。

所有流式结果使用[结果完成屏障](工具协议/客户端与并行会话.md#result-stream-completion)：只允许完整分区清除旧结果，旧请求/运行的晚到回调不能覆盖当前代。第二次修改始终从真实作者 owner 建新 candidate，旧运行和未结算作用保持原身份。
