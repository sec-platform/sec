# 表达证明与搜索边界

> **阅读范围**：理论与反例；不是运行产品承诺。



本篇按实际机制保存来源或理论论证，保留各条自己的版本、前提及采用边界；它不是另一个现行产品合同。

## 通用性与简化可以共存

### 表达能力、作者工作与全局最优不是同一个命题

保留一般计算能力，同时让某类或很多实际工程更短、更少重复决定，是允许且可以构造的设计目标。不能从“任意信息不能全部无损压缩”推出“通用工具不能比现有编程方式简洁”。图灵完备讨论理想资源下的可计算函数，不决定代码长度、作者成本、硬件适配、可分析性质或工程权限。有限主机与任务预算也不改变所讨论抽象语言的计算类别。

必须分别陈述：可表达的程序集合；对同一行为的作者长度；共享库与解释器成本；从意图到合格结果的总工作；运行时间/内存；支持的证明与保证。某些维度可以同时改善，某些有权衡；不能把它们机械写成通用性与简洁的零和关系。

### 一个保留通用性的构造

固定一种通用语言P及其解释。构造S：它既接受完整的P程序，又接受可以按确定规则转换到P的高层定义与组合。对任意P程序p，S保留对应的含义；高层表达也有明确降低含义。因此在相同计算模型下，S至少保留P的计算表达能力，不需要穷举业务种类。

若采用常数长度的模式前缀来选择底座解释器，随后原样承载程序p，则只需固定封装成本c，存在等义S表示，其长度不超过p的长度加c；`base(p)`只是这一构造的文字示意，不主张任意实际转义格式都有常数开销。若采用不破坏旧语法的保守扩展，原程序可以直接保留。这个构造只证明计算表达与高层简写可共存，不证明实际Gift已支持全部P宿主能力，也不证明类型、安全、跨目标和总使用成本同步继承。

新增的高层定义可以把重复模式表示为名称、参数及局部差异。对这些模式，作者表达可以明显缩短；没有收益的程序继续用原有表示。不能因此要求每个基础程序都附全量元数据，否则实际实现破坏了这项设计意图。Racket宏和MetaOCaml保守扩展提供具体机制参照，来源归[资料](../来源/语言编译与目标工具.md#语言编译与目标工具)。

### 计数反例究竟限制什么

固定解释器、共享词典和环境，要求用二进制描述精确区分全部长度为n的二进制结果。结果有2^n个，而长度严格小于n的描述总共只有1+2+…+2^(n-1)=2^n−1个。一个确定描述只能选择一个精确结果，所以不可能让所有这些结果都获得小于n比特的无损描述。

这是一项有限计数推导，不需要假设业务一定随机。它没有证明某个现有语言的写法已经最短，也没有排除对有大量冗余的代码普遍改进；并不禁止通过共享库、参数化、推导或更合适的表示缩短实际任务。若给每个结果临时新增一个字典条目，条目本身的内容与维护代价要计入，不能把省略的信息藏进不计成本的解码器。

### 不用最坏情况压低产品目标，也不用短表达冒领总成本

开发者没有提供、不受既有约束决定的业务差异，需要形成明确选择；若用户确实接受多种结果，则选择一个合法实现不要求补齐无关偏好。可推导的类型、连线、规范化和实现细节应尽量推导；稳定项目政策可避免反复选择；真正未定的意图不能因模型猜中一次就改成确定事实。

比较Gift和原生路线时，双方可以使用相同成熟库、相同可复用模式与同等正确性要求。调用一个标准功能比徒手实现它短，不能证明Gift独有优势。应另外检验定义能否持续编辑、跨产物能否消除重复维护、未预装需求能否保持一般表达，以及复杂局部是否能展开修改后继续由原作者源生成。

当前允许的强结论是“通用性与很多场景下的简化可共存”；“Gift在实际任务分布上更便宜”仍需对应证据；“对所有程序、所有成本同时严格最优”不能从上述构造推出。没有全局最优证明不构成放弃更强架构设计的理由。

## 不可判定性结论的适用范围与误用

### 必须撤销的错误推论

“不能普遍判定任意程序的非平凡行为性质”不推出“不能实现跨语言编译器”。“不能保证任意工程完整自动提升”不推出“不能把工程导入自身项目表示”。“不存在对所有问题都最优的求解器”不推出“不能根据用户明确写出的控制逻辑生成代码”。

从明确源码进行翻译，与从不完整要求中合成程序，是不同任务。不可解性分析、世界模型选择和候选搜索仅在具体任务确实需要时启用，不作为普通编译的统一前置。

### 应保留的边界

一般停机、全程序等价和完整静态依赖不可无条件解决；具体有限语言片段、明确语义的转换规则、受控输入快照和目标合法性则可以被实现并验证。编译器可以保留非终止行为，不需先证明终止。

无法判断一种构造是否安全可以触发专门诊断、保留原生区域或限制高风险动作。普通类型正确程序不应因为缺少社会选择理论或全球最优证明被拒绝生成。

### 正确的理论使用

每项理论记录模型假设、量词、所否定的性质及其与当前操作的映射。已知问题类不可判定不等于每个实例无解；在预算内没找到不等于不可满足；多个候选不等于无法选择。研究结论只修改真实依赖它的保证，不通过“终局架构”标题取得产品层权威。

### 理由与反证

理论研究的价值是阻止伪承诺。若它不再产生具体 bug、测试或边界，只让用户的工程语言消失，就是治理本身成为故障。继续攻击时必须同时攻击新防线的必要性，而不能永远只增加限制。

## 形式不可判定、自指与证明边界

<a id="1-根裁决-6"></a>

### 1. 根裁决

通用工程编译器不能对任意程序、任意需求和任意环境普遍决定下列问题：

- 程序是否终止；
- 两个任意实现是否对所有上下文等价；
- 某个非平凡语义性质是否成立；
- 任意并发或混合系统是否永远安全；
- 任意安全信息流性质是否成立；
- 任意系统定义是否包含全部真实依赖；
- 足够强的自描述验证系统是否能在自身内部证明自身一致性与完整可信。

因此，Gift 的根合同不能是：

```text
输入任何工程
→ 完全理解
→ 找到全部问题
→ 证明最优方案
→ 证明自身证明可靠
```

必须改为：

```text
输入一个声明的模型、语言、环境、资源和假设域
→ 依据已知定理、受支持语言片段和显式假设匹配可判定性画像；不能普遍分类的实例保留未知
→ 对可判定片段给出证明或反例
→ 对半判定片段给出单侧结果
→ 对近似片段给出 soundness/completeness 方向
→ 对不可判定或超预算片段保留结构化未知
```

### 2. 可判定性画像

每个分析、求解、优化和验证动作必须声明：

判定方法的准确字段由[实现选择与设计搜索](../../编译/实现选择与设计搜索.md)中的DecisionProcedureProfile唯一维护。本节只论证判定域、前提、保证方向、预算及未知的边界；规划声明证书类型，真实证书或反例属于准确运行后的结果与Evidence。

`decidabilityClass`只记录所选问题类的已知分类或分类未知，不容纳执行结果：

可判定性、分析方向、执行结果和假设是独立坐标，不建立一个互斥大枚举。有限/半判定的问题类只描述所选方法适用范围；具体调用仍记录证明、见证、有界结果、未知或失败。完整字段与方向见[证明结果的方向与组合](../../运行/验收/方法与独立证据.md#证明结果的方向与组合)。

系统不得把 `timeout`、`out-of-memory`、`solver-unknown`、`abstraction-gap`、`unsupported-theory` 和 `unsatisfied` 合并。

### 3. Rice 型边界对 Gift 的直接影响

任意非平凡程序语义性质在足够一般的程序类上都不能由一个总是终止且总是正确的算法决定。对 Gift 而言，这意味着：

- “该模块永远不泄漏秘密”不能对任意语言和任意环境由通用静态分析完全判定；
- “这个变更不影响任何用户行为”不能对任意程序完全判定；
- “这段代码没有隐藏依赖”不能仅靠一般程序文本完全判定；
- “两个语言后端完全等价”不能在无约束上下文中普遍判定；
- “此修复是最小且唯一正确修复”不能普遍判定。

正确设计不是放弃分析，而是记录[近似集合包含方向](../../运行/验收/方法与独立证据.md#证明结果的方向与组合)。过近似排除全部坏行为可支持安全，发现坏抽象行为需再具体化；欠近似的真实见证可反驳，但没有见证不能证明全域安全。名字含sound或complete不替代这些前提。

<a id="total-program-semantic-redundancy"></a>
#### 全部调用均正常结束仍不能完整判定语义冗余

固定纯总函数F(n,x)，n取Nat、x取Bool；公开合同只观察返回Bool及正常终止，无其他来源、效果或接受差别。定义`Red_x(F)⇔∀n，F(n,false)=F(n,true)`。这是全域值依赖，既不是词法上出现x，也不是某次调用的动态依赖。更丰富的公开时间、资源、错误、身份或控制观察须另行保持，不能借此定义删除。

沿原精确Int通用计算构造总谓词H(e,n)：从有限机器e的初态至多模拟n步，返回是否停止；停后可补齐剩余计数，H不读x。令`F_e(n,x)=H(e,n)∧x`。e到该有限源码的变换有效；每个F_e的每次调用都有限结束，计数器下降还给出统一终止理由，不需先判断e本身是否最终停止。

若e永不停止，H对全部n为false，故x冗余；若e在t步停止，n=t时两个x给出不同结果，故x不冗余。因此`Red_x(F_e)⇔e永不停止`。一个对这整个总计算源码类都准确、总终止地二选一判断冗余的过程，反转结果就决定停止，与[原停止不可决定证明](#complete-optimality-certificate-boundary)矛盾。该归约中的待分类程序全部正常结束，没有把发散隐藏在待分类源码里；额外知道它们全都总计算也不能解除矛盾。

有限源码及每次有限执行不等于输入/配置全集有共同有限界。固定n或原合同确实限定`0≤n≤N`时，只模拟到N即可判断该域冗余；实际有限硬件/profile若已给完整有效界，同样沿有限方法处理。本归约不能否定该有限域的能力，有限域也不能被用来静默替换原数学整数合同。

**接入必要信息量的具体关系。**取两个兼容含义状态`X={0,1}`，n仍是交付函数将来的输入。令两个源码决定为`y₀(n)=false`、`y₁(n)=H(e,n)`；准确接受关系R要求y对全部n都与F_e(n,x)相同。源码决定的索引即使有限，其跨状态资格仍含全域语义等价。共同背景/码本不能免费预装隐藏x。

e不停止时有一个共同决定覆盖两个x，最少零错误消息数为1、所需位数为0；e停止时两个必需函数在某个t不同，任何同一决定都不能满足两者，最少消息数为2、所需位数为1。允许更多函数候选也不能让一个函数同时等于两个不同函数。这给出`I_min(R)=0⇔Red_x(F_e)`，所以即使只有两个含义状态，也不能对全部该族统一准确取得其0/1最小值。有限索引不等于关系成员资格已可计算，不违反[有限准确关系上的码构造](#information-cost-construction-proof)的前提。

一位可行码却始终可直接构造：消息x解码为y_x，两个cell为单例，由定义立即保证正确，无须先判定e不停止。某具体e若有保持非停止状态的不变式，零位码可沿该证明取得；已知停止步t则给非冗余见证；有限n≤N继续有界分析。原任务已经给运行参数签名时正常生成参数化代码，不把未来n变成作者表单。

这里反证的是语义真值下的普遍完整冗余判定和必要信息最小化；**不是**已证明所有已接纳方案或完整6:3:1计划的最优不可取得。零位方案的真实性、其证据是否有限可得，以及构造/证明/运行/维护的完整成本不同；没有保持这些资格与费用的归约，不能把本结论升级为完整计划结论。

“无公开影响”“由现有内容推导”“相对工作者可机械处理”也不相同。一个派生值可以决定结果，却无需作者重复输入；值冗余不许可删除其来源求值的作用；确定程序仍可承担判断责任。按原工程B，确定选择a的控制量为`−log₂p(a|h)`，参考概率1/4时仍为2 bit，不能因输出唯一或AI确定执行就把全部认知记零。实际消简由原I4、编译值服务和Method消费适用推导/等价见证；未知不自动变成独立输入或零成本，已有合法源与未优化码继续可用。

### 4. 自指与自托管边界

Gift 最终会编译、修改和验证 Gift 自身。这会形成：

```text
compiler validates validator
validator validates compiler
policy authorizes policy migration
assurance system evaluates assurance system
```

纯内部闭环不能自动产生绝对信任。必须至少保留一种不由候选控制的外部根：

- 冻结的小型 proof checker；
- 独立实现的 translation validator；
- 可信旧代际；
- 多样化构建和双编译；
- 人工签发的不可逆迁移授权；
- 外部硬件或签名根；
- 可重演的公开证书。

即便如此，结论也只在假设下成立。

### 5. Gödel 型限制的工程含义

足够表达算术的形式系统无法同时在自身内部完成所有真命题证明，并以通常条件证明自身一致性。工程上应避免两种误读：

1. 不能由此推断“形式验证没用”；
2. 也不能宣称“只要把 Gift 元模型再扩一层，就能消除所有证明外部性”。

正确结构是无限回归的有界截断：

```text
Claim
→ Proof/Certificate
→ Small Checker
→ Checker Implementation Assurance
→ Toolchain/Hardware Assumptions
→ Physical Validation
→ Residual Trust
```

每层减少需要信任的表面，但不能把残余信任降为零。

### 6. 运行时监控也有不可证明边界

有限执行前缀不能普遍证明未来永远会发生的活性性质，例如“请求最终必定完成”。运行时监控适合：

- 已发生的安全违反；
- 有界时限；
- 可观测状态约束；
- 资源和权限边界；
- 需要触发降级的风险信号。

它不能单独证明：

- 无限未来活性；
- 未观测通道不存在；
- 所有潜在执行都安全；
- 所有对手都已覆盖。

### 7. 新的编译结果

结果采用[统一的证明方向与组合合同](../../运行/验收/方法与独立证据.md#证明结果的方向与组合)，不在理论章节重定义一套返回枚举。

所有下游必须保持分类，禁止只保存 `passed: boolean`。

### 8. 架构反转条件

若某个 Gift 子系统仍宣称对开放任意工程完成以下动作之一，则该设计必须被拒绝：

- 完整发现全部语义依赖；
- 完整证明所有非平凡行为性质；
- 自动证明自身完整可信；
- 对无限或未约束状态空间给出完全终止判定；
- 把近似分析结果展示为形式证明；
- 把模型内证明展示为物理现实的绝对保证。

### 9. 验证义务

- 每个分析器声明判定域和未知语义；
- 已知不可判定的是问题类别时，把 `UndecidableInDeclaredClass` 记录为类别边界；具体实例仍可有证明、反例或未知，不强制产生实例无解/拒绝；
- 超预算与逻辑不满足分离；
- sound overapproximation 通过漏报对抗测试；
- underapproximation 通过反例真实性验证；
- proof checker、模型翻译和 TCB 变化使旧证据陈旧；
- 自托管升级必须由旧根或外部根验证，候选不得自签完成。

### 10. 类别元数据不覆盖实例结论

`decidabilityClass` 描述给定语言与性质族有没有通用程序保证；`instanceResult` 描述本次对象获得了什么证据。两者正交：一般停机不可判定不阻止证明某个有界循环终止，也不阻止编译该程序。没有通用完备判定器不等于当前实例无解。

只在某个输出确实要求的保证无法由现有证据/方法在所需范围满足时，阻断该输出的相应保证。普通语法检查、明确 lowering 和已采纳模型生成不以这些研究画像全部完成为前置。

## 形式证明、可信计算基与物理现实

<a id="1-根裁决-7"></a>

### 1. 根裁决

形式证明是最高强度证据之一，但它证明的是：在某个形式系统、模型、解释、输入和假设下，结论可由规则推出。它不能自动证明：

- 规范就是用户真正需要的；
- 模型完整描述了物理环境；
- 源码到模型的翻译正确；
- 编译器、链接器、固件、硬件和设备没有未建模行为；
- 证明器和检查器没有实现缺陷；
- 侧信道、故障注入和供应链未越出模型；
- 操作员会按证明要求配置和使用系统。

因此 `formal-proof=true` 不能成为 Gift 顶层布尔完成状态。

### 2. AssumptionLedger

```text
AssumptionLedger = {
  logicalAxioms,
  modelAbstractions,
  environmentAssumptions,
  hardwareAssumptions,
  toolchainAssumptions,
  initializationAssumptions,
  configurationAssumptions,
  adversaryModel,
  excludedChannels,
  humanProcedureAssumptions,
  validityAndRevalidation,
  evidenceForAssumptions,
  residualUnknowns
}
```

每个顶层保证必须能够追到这份账本；假设变化只使依赖它的 Claim 陈旧。

### 3. TCB 不是一个文件清单

```text
TrustedComputingBaseGraph = {
  trustSubjects,
  trustReasons,
  dependencyEdges,
  configurationAndBuildClosure,
  hardwareAndFirmware,
  credentialAndSigningRoots,
  proofCheckers,
  bootstrapPath,
  updateAndRevocation,
  commonCauseClusters
}
```

文件摘要只证明字节身份，不证明：

- 这些字节就是实际执行对象；
- loader 没有选择另一份库；
- 微码、固件和硬件符合模型；
- 编译器没有植入自传播后门；
- 初始化和配置满足证明前提。

### 4. Trusting Trust 对自举的攻击

一个被篡改编译器可以在编译编译器自身时保留后门，即使源代码看起来干净。Gift 的自托管链必须支持：

- 多样化双编译；
- 独立工具链重建；
- 二进制或 translation validation；
- 可重复构建只能证明相同，不证明正确；
- 受信种子和种子来源保全；
- 候选不得修改并独自验证自己的 bootstrap oracle。

### 5. 证明范围必须绑定配置

相同项目不同配置可能走完全不同的代码和硬件路径。ProofCoverage 至少包含：

```text
architecture
platform
feature flags
build profile
memory model
compiler options
linked components
runtime configuration
device/DMA assumptions
initialization state
excluded features
```

未覆盖配置必须是 `unverified`，不能继承相邻配置的 proof badge。

### 6. 硬件和侧信道边界

功能正确和信息流证明通常基于抽象机器。真实系统还可能包含：

- cache/timing/channel；
- speculative execution；
- DMA；
- fault injection；
- microarchitectural state；
- power/EM/acoustic leakage；
- memory disturbance；
- clock/voltage/temperature effects；
- undocumented device behavior。

系统必须明确 `ExcludedPhysicalChannels`。声明“confidentiality proved”只能在相应观察模型内成立。

### 7. 小检查器也不是绝对根

小型证书检查器显著减少 TCB，但仍需：

- 源码和二进制一致性；
- 内存安全与整数语义；
- 解析器严格性；
- 证书与目标主体绑定；
- 拒绝未知算法和版本；
- 运行环境和硬件假设；
- 独立重演。

### 8. Proof 与现实保证组合

```text
Assurance =
  formal theorem
  + model-to-implementation conformance
  + binary/build provenance
  + configuration proof
  + physical environment evidence
  + adversarial testing
  + runtime monitoring
  + user/operational validation
  + residual assumption acceptance
```

这些分量不能相互替代。

### 9. 证明债务和演进

每次修改：

- 模型；
- 证明脚本；
- compiler；
- checker；
- configuration；
- hardware target；
- adversary model；
- external dependency；

都必须计算受影响 proof closure。证明维护成本进入架构成本，不能只计算运行性能。

### 10. 无法达成绝对信任时的输出

综合保证的结果与适用范围直接消费[方法与独立证据](../../运行/验收/方法与独立证据.md)的Claim、EvidenceUse和Verdict合同；本节不维护第二份AssuranceOutcome枚举。

高风险 Effect 只有在适用 policy 接受相应 outcome 时才可执行。

### 11. 验收

- 每个 proof 有 AssumptionLedger；
- proof badge 不能跨配置继承；
- candidate 不能独自替换 checker 和证明根；
- 二进制、配置和实际加载闭包可读回；
- 侧信道和硬件未覆盖范围明确；
- 多样化构建或 translation validation 覆盖关键自举；
- 绝对安全、绝对正确、零 TCB 等无条件措辞被禁止。

## 无普适最优、复杂度与搜索极限

<a id="1-根裁决-8"></a>

### 1. 根裁决

“为任何工程找到全局最优架构”必须先成为精确的数学命题，才能判断存在性、取得算法和证明责任。目标或候选尚未定义、当前计算昂贵、原文尚待核验，都不是全称不可能性证明。可能遇到的障碍需要分别核实：

1. **目标未定或不可比**：不同主体、时间尺度和法域可能采用不同价值序；偏序不必有共同最小者；
2. **候选覆盖与可用信息未证**：当前搜到的候选不是完整域，未来约束或隐藏信息也不能作为当前策略已知输入；
3. **取得或验证受限**：某些明确模型有不可计算性反证；有限但昂贵的搜索需要自己的复杂度与预算论证；
4. **特定最优者可能不存在**：须给所用成本及完整候选域的证明，不能从运行时间的定理直接否定作者负担的最优性。

Gift保留通用表达、完整组合及系统承担中间工作的目标。最优性结论按以下责任产生：

> 固定完整比较域、正确性、成本序及量词；有相称证明才签发最优，有反证则说明其精确范围，其余保留真实可行解与未完成的证明义务。有限域最优、非支配或满意解不能替代明确要求的全域证明。

### 2. 五种“最优”必须分开

```text
OptimalityKind =
  | LogicalOptimality          // 在形式模型和完整候选集内
  | ParetoNonDominance         // 没有已知候选在全部维度支配
  | RobustOptimality           // 在不确定集内最坏或后悔值较优
  | StatisticalOptimality      // 对声明分布或样本过程较优
  | InstitutionalLegitimacy   // 经有权主体按合法程序选择
```

任何一种都不能自动推出另外四种。

<a id="global-optimality-proof-obligations"></a>

#### 2.1 全域命题、存在性和有效取得

以下是对原[成本与偏好比较](../../编译/实现选择与设计搜索.md#preference-partial-order)的数学解释，不新增作者字段、IR或成本表。先固定需求域`S`、完整候选域`D(s)`、不可放松的正确性`OK(s,d)`，以及带明确主体、环境、时域和单位的成本`C_s(d)`与预序`≼_s`。令`E(s)={d∈D(s) | OK(s,d)}`；不满足硬条件的候选不以成本优势入选。`E(s)`为空时没有合格最优者，不能用空域全称式伪造交付。当前候选清单及搜索器能生成的范围，只有取得覆盖证明才可代替完整`D(s)`。

```text
共同最小 Least(s,d*)：
  d*∈E(s) 且 ∀d∈E(s), C_s(d*) ≼_s C_s(d)

非支配极小 Minimal(s,d*)：
  d*∈E(s)，且不存在d∈E(s)使
  C_s(d) ≼_s C_s(d*) 且非 C_s(d*) ≼_s C_s(d)

逐任务存在：        ∀s∈S, ∃d Least(s,d)
统一有效取得：      ∃总可计算F, ∀s∈S, Least(s,F(s))
固定架构逐任务最优：∃A, ∀s∈S, ∀B, C_s(A) ≼_s C_s(B)
```

最后一行的`A/B`必须来自同一明确的合格架构域，享有相同的合法可用信息；不能按真实隐藏意图提前换架构。架构内部若包含策略选择器，其可计算性、交互和维护代价也属比较对象。`∀s∃d`不能交换成`∃A∀s`。形式存在性定理、一个实际架构的比较定理、有效选取算法、逐实例具体证书是不同交付物；对哪个命题要求证明必须明示，不能默认互相蕴含。

有限非空候选域在成本预序下有非支配极小者，未必有共同最小者。无限域还可能只有未达到的下确界：成本集合`{1/n | n≥1}`每个成员都有更低者，没有最小值0。相反，非空自然数标量成本集合必有最小值；这只证明存在，不提供有效取得或可识别的终止判据。以下两组证明分别展示这些区别，均不宣称已替实际作者全生命周期成本选定指标。

#### 2.2 共同最小提问策略不存在，最坏成本最优却存在

固定三个私人意图`V={a,b,c}`，初始可见状态相同且无其他区分信息。每一步只能问一个二元成员问题“`v∈H`吗”，其中`H⊆V`；回答真实，每次成本为1。`D`取该渠道下对三个意图都正确有限结束、识别真实意图的**全部确定策略**。对策略`π`，以真实意图分别产生的路径深度组成成本，按逐坐标不劣比较：

```text
C(π) = (depth_a(π), depth_b(π), depth_c(π))
C(π) ≼ C(ρ) ⇔ ∀v∈V, depth_v(π) ≤ depth_v(ρ)
```

**定理与证明。** `D`没有共同最小策略。对任意`v`，先问“是否为v”，否则再二分剩余两值，是完整正确策略，且在`v`上的成本为1。因此若`π*`逐意图不劣于全部合法策略，它的三个深度都必须≤1。但一次二元回答至多产生两个不同结束叶，无法识别三个意图，矛盾。候选`π*`可以来自完整`D`的任意位置；证明使用三棵树作为必须同时达到的上界，不是仅比较三棵树就冒称所有策略无解。

**正向最优证明。** 改用明确的最坏路径成本`W(π)=max_v depth_v(π)`，全局最优值恰为2：高度1的二叉树最多两叶，给出下界2；上述两层树达到2，给出上界。这个结果覆盖同一完整`D`，不是只对已搜索样本最优。已指定分布的期望成本则是另一个命题。

二元渠道是这个数学模型的前提，不是产品限制；改成三元回答、增加合法可见事实、允许另一交互机制或改变成本序，须重新证明。该有限反例不能直接否定包含所有作者表达方式的完整产品域；它说明原[自适应提问](../../作者/组合/跨软件需求合同.md#author-question-reduction)的最坏路径结论不能换成“每个真实意图都同时最省”。

#### 2.3 准确最短描述存在，但没有全域有效选择器

取`S={0,1}*`及一个固定的最优通用部分可计算解码器`U`。这里“最优”指：对每个部分可计算解码器`V`，存在不依赖输出`x`的常数`c_V`，使`C_U(x)≤C_V(x)+c_V`；有限输出的普通描述复杂度为：

```text
E(x) = {p | U(p)停机且精确输出x}
C_U(x) = min{|p| | p∈E(x)}
```

每个`x`都可由某个程序打印，故`E(x)`非空；自然数良序保证最短长度及至少一个最短`p`存在。这里固定解码器与背景上下文，使用普通复杂度`C`，不混同前缀复杂度`K`。

**不可计算性证明。** 假设`C_U`可计算。定义`g(n)`为按长度再按字典序找到的第一个满足`C_U(x)>n`的字符串。长度≤`n`的程序只有有限个，而字符串无限多，故该搜索对每个`n`结束；在假设下`g`可计算。令另一个解码器读取`n`的二进制表示并输出`g(n)`。由`U`的最优性，有某个固定常数`c`使`C_U(g(n))≤⌊log₂n⌋+1+c`（`n≥1`）；对充分大的`n`，右边小于`n`，与`g`的定义矛盾。所以`C_U`不可计算。这是[已核原文](../来源/理论与待核线索.md#verified-description-optimality)中不可计算性命题在本符号下的证明。

**选择器推论。** 若同一个总可计算`F`对每个`x`输出一个准确最短`p`，运行`F(x)`后数其长度便计算了`C_U(x)`，矛盾。不需要统一的运行时间上界，也不需要再次执行`p`。保留已找到的更短程序可以从上方逼近描述复杂度，但一般不能识别何时已达到准确最短。

这没有证明作者总负担不可最优化。作者成本还有阅读、决定、关系维护、交互、等待和共享供给等；把本定理应用到它，必须给保持候选资格与成本关系的有效归约，证明实际最优结果可提取固定`U`下的最短`p`。没有这个桥梁，不能把“最简单”替换为描述长度。为每个`x`免费更换一个预藏`x`的解码器同样改变了模型，不能据此消掉真实上下文成本。

#### 2.4 全域具体最短证书与存在性定理不同

仍固定上述`U`，定义`Min_U(p,x) ≡ U(p)=x ∧ ∀q(|q|<|p| ⇒ U(q)≠x)`；后一关系表示不存在停机输出`x`的执行，包含发散，不是假定有一个可判定测试。

假设同一个证明系统`T`的定理可有效枚举；其中具体有限常量`p/x`及标准形式`Min_U(p,x)`可有效识别、提取；`T`对它证明的这些命题健全；并且对**每个**`x`都有某个具体`p`使`T`证明`Min_U(p,x)`。给定`x`，公平枚举定理直到遇到其具体`Min`证明，再输出`p`：全域覆盖保证结束，健全性保证准确最短，得到上一节不可能存在的选择器，矛盾。这个推论只用所列条件，不要求证明长度或搜索时间有已知界；单纯一致性不能替代所需健全性。

该反证不否定经典存在性定理`∀x∃p Min_U(p,x)`：每个描述集非空及自然数良序已经给出存在论证，一般经典存在证明并不提供有效最短见证提取。逐实例具体可枚举证书覆盖比这个存在命题更强。分别为各`x`采用不可有效统一的公理、使用不可枚举真理集、只证明有限候选子集内最短，均改变前提；不能说成已经交付上述统一有效证书系统，也不能由本反证否认某些具体最短证书可取得。

#### 2.5 通用解码器的加法常数最优确实可构造

有效枚举部分可计算解码器`V_i`，给索引`i`一个可解析的自分隔编码`e(i)`，定义`U(e(i)p)=V_i(p)`。模拟任一固定`V_i`只多付`|e(i)|`个比特，于是：

```text
∃U ∀V ∃c_V ∀x, C_U(x) ≤ C_V(x) + c_V
```

这是对全部部分可计算解码器的加法常数最优性构造，支持可证明的通用基础。常数可以依赖`V`，不得换成对所有`V/x`的零常数逐实例最优，也不保证有限使用中的常数可忽略。构造`U`不提供每个`x`的准确最短编码器；最短编码选择不可计算与这个正向存在定理完全相容。[原文定位](../来源/理论与待核线索.md#verified-description-optimality)给出具体版本与范围。

<a id="fixed-policy-optimality-proof"></a>

#### 2.6 固定优先级或权重后的最优存在与取得

采用明确的成本优先级或权重后，比较的是该政策下的最优，不再要求每个成本维度同时不劣于全部方案。政策仍沿原[Quality合同](../../作者/结构化源码.md)及[R5](../../编译/实现选择与设计搜索.md#preference-partial-order)取得，先固定硬条件、完整合格候选域`E(s)`、主体/工作负载、单位、方向、转换、优先级或权重及依据。任务政策可以复用，不能根据已搜到的候选改政策使当前方案成为最优，也不能用单个局部合同的权重合并未授权的其他主体或上层义务。

**尺度与权重共同定义取舍。** 已有合格数值成本`xⱼ`时，一种明确损失是`ℓⱼ=(xⱼ−rⱼ)/sⱼ`，`sⱼ>0`，并令`J=Σwⱼℓⱼ`、`wⱼ>0`；参考点、尺度、有效域、主体和使用周期先固定。这是已有`scoreRef`可以承载的一种定义，不把认知负担或必要信息强制定义成某种计数。若只换单位`x′ⱼ=aⱼxⱼ+bⱼ`、`aⱼ>0`，同步取`r′ⱼ=aⱼrⱼ+bⱼ`、`s′ⱼ=aⱼsⱼ`便有`ℓ′ⱼ=ℓⱼ`，权重保持不变。若改变的是已经归一化的损失`ℓ′ⱼ=aⱼℓⱼ+bⱼ`，一个准确保持构造是取共同`c>0`及`w′ⱼ=cwⱼ/aⱼ`，于是`J′=cJ+cΣ(wⱼbⱼ/aⱼ)`；末项与候选无关，所以全部排序及并列关系保持。参数不能随候选改变。有限十进制权重与正有理比例的商可用同一个正系数清除全部分母，得到准确可编码的正整数权重；仍须满足数值和资源资格。没有适用编码或误差证明时，近似除法不代签等价，也不因此新增权重协议。

逐项严格递增仅保证单项方向和Pareto支配，一般不保持加权取舍：两项等权时`P=(1,4)`、`Q=(2,2)`的和为5、4；只将第一项在非负域平方后，和为5、6，优选反转。基于当前候选池的min-max也可能暗改尺度：`P=(1,3)`、`Q=(2,1)`，权重为2、1，两候选范围归一后总分为1、2；加入被支配的`(101,3)`并重新归一，原两方案总分变为1、0.02。候选池相对政策可以明确采用，但不是原固定成本政策。相同理由，对`P=(t,b,i)`、`Q=(t+ΔT,b−ΔB,i)`，`ΔT,ΔB>0`，损失差为`w_TΔT/s_T−w_BΔB/s_B`，不同正权重可使其为正、负或零。三个最小化方向不唯一决定补偿率；可由既有接受或有效委派选择政策，但不能把这种价值选择说成由测量事实推导的唯一结论。

**有限维自然数词典序的存在性。** 固定有限`k≥1`，设完整可行成本像`A={C_s(d) | d∈E(s)}⊆ℕ^k`非空，每一项越小越好，按明确且彼此不同的优先级逐项比较。令`A₀=A`；第`i`步取`mᵢ=min{aᵢ | a∈Aᵢ₋₁}`，再令`Aᵢ={a∈Aᵢ₋₁ | aᵢ=mᵢ}`。自然数良序与归纳保证每个`Aᵢ`非空；有限`k`步后仍有实际成本向量`m∈Aₖ`。任取`a∈A`，若它与`m`不同，在第一个不同坐标`j`之前都相等，故`a∈Aⱼ₋₁`，从而`aⱼ>mⱼ`；因此`m`为整个`A`的词典序最小值，并由某个合格候选实际达到。这个证明不要求候选数有限，但也没有给计算各`mᵢ`的通用算法。

**固定正权重与自然数成本的存在性。** 对同一非空`A⊆ℕ^k`，固定有限严格正实数权重`wᵢ`，令`L(a)=Σwᵢaᵢ`。取一个`a⁰∈A`并令`M=L(a⁰)`。所有`L(a)≤M`的向量均满足`0≤aᵢ≤M/wᵢ`，所以这个非空次水平集只有有限个整数向量，必有达到的最小损失；其外所有损失大于`M`，不能更好。因此全域最小存在。当前规范十进制正权重是正有理数，亦可清除有限个权重的分母，把该自然数成本情形化成自然数标量的良序证明。一般实数权重的这项存在证明不签有效数值比较或可计算取得。

**有限值并不保证达到最优。** 若候选`dₙ`（`n≥1`）合格，唯一成本为`C(dₙ)=2⁻ⁿ`，权重为1，则所有成本都是严格正、有限且可精确十进制表示的有理数，仍没有最优候选：`dₙ₊₁`总更便宜；下确界0没有被达到。多个维度、正权重或明确优先级都不会自行消除这个反例。最大化自然数`n`的无上界候选域也没有最大者。不能为套用前两项定理，临时舍入、封顶、平移一个没有真实下界的损失，或删去合法候选；这些操作会改变原目标。

实际Quality合同的`priority`是比较次序元数据，不证明指标值属于自然数；`weightDecimal`精确为正也不证明`scoreRef`的输出具有统一固定网格或达到最优的性质。有限、无量纲、方向合格的损失仍可能具有上述无限下降序列。R5同层多准则的Pareto比较也不是第一项定理的逐项词典序。使用这些存在定理时，要证明实际成本像及政策确实满足前提；不满足前提只说明该定理不能代证，其他有据方法仍可证明相应任务的最优。

**存在、取得和最优证书分别完成。** 对全部任务证明存在，需要对每个任务给非空性及适用的达到最优条件；若目标还包括同一有效设计实际取得最优，须另给产生合格候选并结束的算法。固定优先级或权重不消除2.3中的选择器障碍：只有当实际比较确实包含该准确长度模型、并存在保持资格和成本关系的归约时，才能用其反证；不能因采用了排序或加权就直接判产品不可能，也不能因最优存在就签算法已完成。

最优证书继续属于原`OptimizationOutcome`及其证据：给实际合格的`d*`，证明在准确完整`E(s)`内没有政策上更优的候选。加权标量可以用覆盖全域的下界与`d*`相同政策下达到的值相等来证明；词典序则逐层给下界和达到见证，后层只在前层均取已证最优值的候选子域中证明。不同阶段的独立最小值若不能由同一候选共同达到，不能拼成证书。范围、转换、权重、优先级或资格前提改变时，回原依赖失效与方法选择，不新增一份成本注册表或证明协议。

这些证明不以删减开放表达、可变性、可选性或代码生成能力为前提。实际最优声明须把本模型与原需求/候选/作者总成本逐项对应；尚未建立这种对应时，保留全域证明义务，不宣称已证或已整体反证。以下无免费午餐、Blum及复杂度条目中尚无精确原文定位者，继续保持[待核线索](../来源/理论与待核线索.md#理论线索与使用边界)身份，不代替以上定理或成为能力禁用依据。

<a id="causal-cost-optimality"></a>
#### 2.7 同一信息下的完整路线最优

环境口径沿[已委派开发路线政策](../../产品/术语与质量属性.md#worker-time-cognition-information)确定。固定可见历史`h`及完整合法因果策略域`Π_h`，策略可以使用后续合法观察，不能读取尚不可得的环境。给定同一完整联合环境`e`和实际标量政策成本`J(π,e)`，最坏口径比较`sup_e J(π,e)`；有合格适用概率模型`P`时比较`E_P[J(π,e)]`。环境可以包含对策略动作的响应，概率模型须保留该因果关系及其诱导的轨迹，不把各方案不同的执行结果强制当同一独立样本。硬条件先行，两个口径都没有交换`∀e∃π`与`∃π∀e`。

**条件性共同最优反例。** 两环境`e0/e1`在提交前对全部合法观察、延迟和询问不可区分。任务要求消费一次性能力，最终恰提交`a/b`之一；两条直接固定路线均在两环境满足全部硬条件，且这是该任务的完整提交选择。内部组织和并行仍允许，但不能绕过该必需作用或复制能力。这是一个任务合同，不是全平台禁止探测、并发或重试；应用到真实任务还须证明实际执行边界保持它。

固定完整路线共同历时边界`t0≥0`及正的`β、ι`。在同一时间单位下，令动作残余时间`d_e(a),d_e(b)`在`e0`为`1,2`、在`e1`为`2,1`。模型明确要求所有合法路线满足下列**完整路线下界**（随机策略按每次执行），且两个直接固定策略在两个环境都达到对应时间及相同的`β、ι`：

```text
T(π,e) ≥ t0+d_e(π的最终动作)，B(π,e) ≥ β，I(π,e) ≥ ι
V_e(π_a) = (t0+d_e(a),β,ι)，V_e(π_b) = (t0+d_e(b),β,ι)
V_e0(π_a) = (t0+1,β,ι) = V_e1(π_b)
```

历时下界需要必经依赖与资源证明，不能累加并行时间或遗漏准备、生成、检查与收尾。`β/ι`是本模型给定或已证的下界及达到前提；独立判断必需、步骤费用非负或AI身份不证明真实认知/信息下界。预处理可能降低后续负担，仍须覆盖全部合法路线；不能把未知填零或删除低于假定下界的改进。

设政策严格保留逐分量改善：每项不大且至少一项严格小，就政策上严格更好。固定正权重与严格保序损失、或者包含全部三项的任意完整词典序满足这一条件；压平时间差的损失或丢掉该维度不自动满足。上述下界及见证给每环境实际达到的共同最小向量`v*=(t0+1,β,ι)`。在`e0`选`b`的策略被`v*`严格支配，所以政策最优必须选`a`；在`e1`则必须选`b`。相同可见历史的确定因果策略最终选择相同，矛盾。随机种子与环境无相关信息时，选择`a`的概率在两环境相同，逐环境概率1最优却分别要求概率1和0，也矛盾。两个比较用常量策略都不读取环境，逐环境采用不同见证没有给它们额外信息。

因此，在这些精确前提下，`∀e∃π Opt(π,e)`成立，而`∃π∀e Opt(π,e)`不成立。一般地，各兼容环境的最优策略所允许的下一动作交集非空，只是共同最优策略的必要条件；它们可能都允许同一开始动作，却在后继不可区分历史要求相反选择。全程仍须同一个合格继续策略，不能拼接不同环境的见证。原[共同观察策略](../../编译/有限抽象与观察策略.md)承担这项因果责任，不新增求解器。

这个条件反例不反驳已选择的最坏或期望政策。在本模型的准确加权标量下，令`g1=J(t0+1,β,ι)`、`g2=J(t0+2,β,ι)`，`g2>g1`。对确定策略，最坏成本至少为`g2`且任一直接固定路线达到，故完整域最坏最优为`g2`。给定准确分布`Pr(e0)=θ`，两直接路线期望分别为`θg1+(1−θ)g2`及`θg2+(1−θ)g1`，任意无新信息的随机混合与非负额外损失不能低于两端点的较小值。对随机种子取最坏、先对种子取期望再对环境取最坏、以及联合分布期望是不同政策，不能偷换。真实T/B/I若未取得上述完整下界、达到见证及映射，结论只保留为条件定理，不据此无条件否定全部任务目标。

风险聚合必须保持共同环境：同一路线两环境损失为`(1,0)`与`(0,1)`，等权时`sup_e(ℓ1+ℓ2)=1`，但`sup_eℓ1+sup_eℓ2=2`。后者在有据前提下可作上界，不能代签相同目标的准确值。期望仅在同一适用联合分布及可积条件下利用线性性。有限环境可完整枚举逐情景合成后取最大；有限有理分布可准确求和；一般域使用原合格方法及其完整覆盖、界或积分依据。环境上确界不必由某个情景达到；一个全域上界加任意逼近的下界依据仍可准确证明它，不能强加必须存在最坏情景的条件。风险值非有限、模型不完整或没有合格方法时保留相交比较缺项及已有可行路线，不能靠封顶、改分布或缩环境域得到最优。已取得有限风险值也不保证在完整策略域上存在最小者，仍须前节的候选达到与证书义务。

<a id="relational-cost-proof"></a>
#### 2.8 未知点值下的关系证明与风险保持

固定原任务、硬资格、完整路线、工作者/背景/周期及准确成本政策。令共享参数为`ξ∈Ξ`，完整合法联合模型为`M⊆E×Ξ`，非空切片`Eξ={e | (e,ξ)∈M}`保留真实依赖与策略动作的因果响应。`L_A(e,ξ)`、`L_B(e,ξ)`是原方法对完整路线损失的合格表示；符号式不免除每项定义、有限性、转换、权重、数值误差及覆盖资格。相同变量名、代码或模型名不证明真实成本相同。

若已证明在全部`M`上`L_A≤L_B`，固定任意`ξ`，`sup_e L_B`也是`L_A`的上界，故`sup_e L_A≤sup_e L_B`。若还有对所聚合域统一的`ε>0`使`L_A+ε≤L_B`，常数平移给`sup_e L_A+ε≤sup_e L_B`；风险有限时才据此签严格优势。不要求最坏情景达到，也不要求各风险点值已知。逐点严格则不一定保持严格最坏优势：在`e∈(0,1)`上，`L_A=e<L_B=(1+e)/2`，两者上确界都为1。对同一适用分布、可测且可积的损失，几乎处处的弱序及统一正间隔分别由积分单调性、线性性保持；无需各项独立。非负差在正概率集合严格为正也足以使期望严格改善，因为该集合是`{差≥1/n}`的可数并，至少一项概率为正。不同候选的实际轨迹可由共同环境诱导，但不能把不同分布擅当同一分布，或作`∞−∞`。

例如同一合格参数`u∈[10,20]`下，完整损失`L_A=u+1`、`L_B=u+2`的各自区间重叠，仍有全域关系`L_A+1=L_B`。证明不需要填实际`u`，也没有将未知的认知或信息成本置零。共享项的消去须尊重聚合：若`c(ξ)`有限且不依本次取`sup`的环境，可由`sup_e(c+f)=c+sup_e f`在风险比较中消去；共同但依环境的项一般不可如此删除。在两个环境上取`c=(u,0)`、`f_A=(0,2)`、`f_B=(1,1)`，则`sup f_A=2>1=sup f_B`，却有`sup(c+f_A)=u<u+1=sup(c+f_B)`。逐情景先证明`c+f_A≤c+f_B`再取`sup`仍合法；同一分布下的共同项期望相消则需相关项可积。

逐参数一致关系只是风险排序的充分路径。若`L_A(ξ)=ξ`、`L_B(ξ)=15`、`ξ∈[10,20]`，逐参数方向反转；若搜索前政策已将`ξ`纳入兼容环境取最坏，风险仍为20与15，可以判B更好。不得将这个结论改成每个真实`ξ`下B均更好，也不得为未知`ξ`补一个分布。条件风险与联合风险消费各自原模型，不交换量词或在结果出来后切换政策。

完整域证书也可直接证明关系：给同一合法信息下可实施的固定候选或因果策略`d*`，核它在每个允许`ξ`下合格，并证明`∀ξ∈Ξ ∀d∈Dξ, R(d*,ξ)≤R(d,ξ)`，其中`Dξ`是该参数下完整合格候选域、`R`是已选风险。于是`d*`在每个允许参数下达到该域政策最优，最优数值仍可未知。例如已证每个合法候选的完整损失为`H(e,ξ)+r_d(e,ξ)`、`r_d≥0`，同一个`d*`在完整域上达到`r_d*=0`，便可经上述保持证明取得证书；`H`无需点值。实质义务是这些关系的真实资格、完整覆盖与同一候选的达到，不能只写成假设就宣称实际目标已完成，也不能把`∀ξ∃dξ`换成这个共同策略。仅比较两个已搜方案不覆盖其外候选。关系、联合域、方法或政策变化沿原依赖失效；R5及原`OptimizationOutcome`消费证据，不新建符号成本或证明协议。

<a id="log-rational-cost-comparison"></a>
#### 2.9 对数有理成本的准确比较

对有限支持的信息成本，数值方法不必先以浮点近似计算每个对数。固定同一已合格模型、单位、尺度、支持和成本政策；若两候选的损失差可以准确整理为

```text
Δ = r + Σᵢ cᵢ log₂(aᵢ)
r、cᵢ ∈ ℚ，aᵢ ∈ ℚ且aᵢ>0，项数有限
```

取清除`r`及全部`cᵢ`分母的正整数`D`，构造正有理数`Q=2^(Dr) × ∏ᵢ aᵢ^(Dcᵢ)`。于是`DΔ=log₂Q`；`D>0`且对数严格递增，故`Δ`的正、零、负分别等价于`Q>1`、`Q=1`、`Q<1`。指数均为整数，负指数以准确倒数处理；将`Q`的分子分母分别作整数乘积并比较即可，不需要以误差不明的近似对数判相等。约分、因子共享或已证界可以减少中间体积，但须保持同一准确有理值。

例如准确有限概率的`Σ qᵢ log₂(qᵢ/pᵢ)`、有理时间损失、准确十进制权重及有理概率混合均可按定义展开为该形式。`qᵢ=0`的项按`0 log(0/p)=0`处理；`qᵢ>0,pᵢ=0`给无穷信息成本，不能将它补零或送入有限`scoreRef`。未知或不合格概率也不是准确有理参数。有限完整环境先逐环境形成成本，再由同一比较算法取最大；同一合格有限有理分布的期望保持该表达形式。无限支持、一般实数参数和积分不自动取得这项可判定性。

这是实际数值比较的终止算法与正确性推导：有限个准确整数/有理运算均有有限描述和终止方法。它不声称中间整数小、运行快或预算一定足够；取得参数、清分母、幂/积、检查及证明所需时间和内存均进入原完整路线。预算不足时可返回原相交未决或足够的可靠关系界，不能把截断数值签成准确排序。该结论只补数值方法资格，不证明所选信息模型就是现实智力负担，不证明候选域已完整，也不证明本次比较过程自身已达到全局最优。实际消费仍归[原R5及Method](../../编译/实现选择与设计搜索.md#preference-partial-order)，不新增数值协议或第二优化器。

<a id="information-cost-construction-proof"></a>
#### 2.10 判断控制量、语义码与实际构造的证明

本节证明[原工作者模型](../../产品/术语与质量属性.md#operational-worker-cost-model)的组合和信息下界；模型的现实适用资格不由数学恒等式产生。

**判断过程的链式分解。**有限完整判断过程中，P与Q具有相同初态和环境转移核，只分别采用π与p。路径概率的乘积相除时共同环境项抵消；对P取期望，得到`D_KL(P∥Q)=E_PΣₕD_KL(π(·|h)∥p(·|h))`。终结/停止属于过程；支持违反按扩展实数处理。可数或无限过程只有取得相称极限与可积性依据才推广，不能从有限代数直接套用。

将相邻判断A、B合块时，原联合条件分布给出

`D_KL(π(A,B|h)∥p(A,B|h)) = D_KL(π(A|h)∥p(A|h)) + E_{A∼π}D_KL(π(B|h,A)∥p(B|h,A))`。

所以准确分块保持期望控制量，不是节点越少负担越低；随机过程的该恒等式不是每条已实现路径的相等。对于摘要Y，完整KL还等于投影KL加上给定Y后的条件KL期望；后项非负。只见最终答案或隐藏中间判断只能得到下界，只有剩余项已证为0才可代替完整B。可逆重命名保留两分布和成本；丢失区别不继承这个结论。

<a id="semantic-reference-pushforward"></a>
**从描述参考形成语义参考。**固定同一背景、公开观察和单次判断责任。有限描述集合D上的准确参考质量r与候选质量s，须沿真实含义映射φ推前，才得到该语义行动域上的`p(a)=Σ_{φ(d)=a}r(d)`及`π(a)=Σ_{φ(d)=a}s(d)`。描述标签本身属于公开身份、来源或判断责任时不得合并；这里只商去合同确实不区分的描述。实际全过程还有其他判断、形成费用或后继时，所得量只是该语义投影的B_sem；完整B仍消费上面的条件残余，时间和信息费用也不消失。

准确有限的描述概率不保证其语义推前概率可统一取得。复用[原总程序冗余构造](#total-program-semantic-redundancy)的`F_e(n,x)=H(e,n)∧x`及其公开观察：所有Nat/Bool输入上的返回Bool和正常终止。固定生成规则G，在比较前固定的合法背景C_e中读取e，以各1/2产生`d₀=λ(n,x).false`与`d₁=λ(n,x).H(e,n)∧x`；e可机械嵌入封闭源码。G、权重及背景消费规则先固定，每次比较的e也先固定，不随候选或比较结果更换参考。所有描述均为纯总函数，候选始终选择d₀；在这个单次语义判断后终结的准确模型中，令a₀=φ(d₀)。

原归约已经证明：e不停止时两个描述同义，故`p(a₀)=1、B_sem=0`；e停止时在某个有限输入上不同，故`p(a₀)=1/2、B_sem=1`。参考支持始终覆盖候选，值始终有限。若某统一有效方法对全部这些输入都有限结束并准确判断`B_sem<1/2`或`p(a₀)>3/4`，便决定原已排除的Red谓词；即使只要求绝对误差≤1/4的有效B近似，也可用阈值1/2作同一决定。因此，有限、有效且概率准确的描述生成器不能自动签发全部总程序的准确语义参考或该数值比较。保留Red条件的符号式不是这个数值决定器。该推论不直接反证完整实际B或J可计算，更不从语义投影跳到完整计划最优；实际轨迹若必须区分两个标签，须按那个真实模型重新计算。

**可直接形成的准确分组。**取得D在本任务观察下的完整准确分组P，同组等义、异组确有区别时，逐组求`p_C=Σ_{d∈C}r_d`、`π_C=Σ_{d∈C}s_d`，再求`B_sem=Σ_{C:π_C>0}π_C log₂(π_C/p_C)`。正候选质量对应零参考质量时值为∞；其他准确有理概率沿原[对数有理比较](#log-rational-cost-comparison)处理。所有参考质量保留，不因硬过滤重新归一。原输入域本来完整有限、观察可有效精确比较且候选全总计算时，取得各描述的完整观察表并按表分组就是终止构造；其执行与证明费用仍须计入。无限域可消费适用规范化、等价证明和区分见证，不为此缩成有限输入，也不要求先判定一般程序全部等价关系。

**只取得部分等价依据时的界。**对确定候选d*，令E为已证明与它同义的描述，N为已证明不同的描述；依据须绑定同一背景及观察且不冲突。取`L=Σ_{d∈E}r_d`、`U=1−Σ_{d∈N}r_d`，则`L≤p(φ(d*))≤U`。L>0时直接得到`−log₂U≤B_sem≤−log₂L`；L=0不给有限上界，U=0则该候选的语义B为∞。冲突或L>U先处理依据冲突，不消费空区间。新鲜等价/区分依据可使L不减、U不增，不需完整商集；一般不声称所得界最紧。上述两描述实例仅凭自身等价已有`0≤B_sem≤1`；取得适用等价证明后收为0，取得真实区分见证后收为1。这些关系沿原Method/Evidence供R5消费；投影的上界不因形式相同变成含额外判断的完整B上界。

**零错误消息的准确最小数。**固定非空完整有限X、Y、R，且每个R(x)非空。令N为纤维`R⁻¹(y)`覆盖X所需的最少个数。任意n消息的零错误码，为每个消息取其共同可接受决定；这n个纤维覆盖X，所以`n≥N`。反之，一个N纤维覆盖令每个x编码为任一覆盖它的y索引，解码为该y，便得到N消息零错误码。因此最少消息数恰为N；固定长二元码的最坏位数为`⌈log₂N⌉`，N=1时为0。任意前缀码的最大长度L也至多容纳`2ᴸ`个码字，故同一下界成立，并由固定长构造达到。合法信息是否已经取得仍是原观察责任，这不是免费读取x的算法。

消息cells可以重叠；成对相交不保证全体有共同决定。取`R(1)={a,b}`、`R(2)={b,c}`、`R(3)={a,c}`，任意两者相交而三者共同交为空，故0 bit不足；a、b两个纤维覆盖全域，1 bit达到下界。默认贪心算法给可行覆盖但未必最小；计算一般I不以前置求解这个最小覆盖为条件。

准确派生内容`f(z)`在背景与z之后的条件码为空，不增加I；同一码字的可解析分块保持长度和。这个保持要求实际码本/语义关系相同；更换码本、丢失联合条件或免费新增解释库，均不能以“语义相同”继承成本。

**一个全部参数已定的实例。**固定四个语义方案00/01/10/11，参考先取第一位0/1的质量为3/4、1/4，再以各1/2取第二位并停止，完整参考质量为`(3/8,3/8,1/8,1/8)`。合法确定策略选择11时，B为`−log₂(1/8)=3 bit`，分两步与合块相同。若完整关系只接受每种含义自己的决定，四条消息采用两位码，I=2 bit，达到该关系下界。规定同一有限时钟模型中参考准备/读取1/2秒、两判断各1/2秒、编码/检查/结算1/2秒，串行且无其他周期义务，则T=2秒，按原默认政策J=23。它是完整给定的工程数学实例，时间与参考质量均非人/AI实测成绩，不证明原任务已全域最优。

<a id="finite-dominating-cover-optimality"></a>
#### 2.11 从真实成本界构造完整域最优的有限覆盖路线

固定原完整合格路线域E、同一合法信息及硬条件、环境域和风险政策，R为完整成本。已有真实合格incumbent`π₀∈E`，其风险上界`R(π₀)≤U<∞`。若能够有效构造有限`Q⊆E`并证明

`∀π∈E，R(π)≤U ⇒ ∃q∈Q，R(q)≤R(π)`，

且Q与π₀的资格和比较都有充分依据，则其最小者q*是**原完整E**上的最优。证明分两支：`R(π)>U`的任何π不优于π₀；其余π都有不劣q，而q*不劣于该q。这是由完整域覆盖到有限比较的归约，没有把原候选域改成已发现清单。并列最优可按原稳定政策选取，不要求唯一。

**时间界如何真正得到。**对最坏完整环境风险，若每个合法路线/环境都有合格增长下界`ℓ_T≥aT−b`，其中a>0，并有`ℓ_B≥b_B`、`ℓ_I≥b_I`，则按原默认权重，任意风险不超过U的π在每个环境都满足

`T(π,e)≤H=(U+6b−3b_B−b_I)/(6a)`。

原默认工程模型取线性时间损失、B/I非负，满足这个代数前提；其T若已对内部随机性取期望，上式只界定该期望，不能继而当作每条随机路径的期限。要从H推出有限事件数，还须完整路径本身有该界、真实正事件时间下界δ以及原资源条件；有限事件数也还不足以产生有限Q。

实际有限覆盖可这样构造：从原合法资源与观察条件取得有限位宽/存储、动作/观察字母表、并发和事件界；保留资格、T/B/I及信息可得时点所依赖的全部状态。逐层展开界内合法历史和因果选择，生成有限策略表示。每个原可能改进者必须映入其中，且代表具有原合法实现，并有保持硬要求、完整环境关系及不增加风险的证明；有界策略表本身不免费取得可执行资格或更快执行。实际原资源无此界、状态不能有效商化、合格性/比较尚不可判定或代表实现增加成本时，这条归约未完成，原域保持开放，继续其他方法。

**不能省略的前提及反例。**

- 正时间权重不保证增长下界：`ℓ_T=T/(1+T)`有界，有限成本不能排除任意长时间。
- 有限期望不保证路径界：`Pr(n)=2⁻ⁿ,n≥1`且T=n的期望为2，路径时间仍无界。外部期望或内部期望都不能直接使用逐路径有限化。
- 有限步数配免费任意长整数、无限词/库、零时oracle或无限并发仍可有无限选择；隐藏初始程序、背景和证明制作成本也会破坏归约。
- 候选有限不保证任意资格谓词可判定；有限随机动作的任意实数概率参数仍可形成连续策略域。把环境只取已测样本也不是完整环境覆盖。

这些反例精确否定相应推导，不证明原任务没有最优，也不禁止其表达或正常实现。能取得上下界相遇、符号全域证明或其他支配覆盖时，可直接用原证书，不强迫走有限枚举。

<a id="fair-proof-search-optimality"></a>
#### 2.12 公平证明搜索的健全性、条件完备性与全任务成本

固定同一完整域、硬条件、成本/风险及允许的健全证明基础。假设候选与证书均有有效有限描述、合格证书核验终止；原Method可对这些有限描述公平交错，算法归[原联合搜索](../../编译/实现选择与设计搜索.md#proof-directed-search-construction)。不用先决定每个候选的全部性质：已核资格的候选更新incumbent；证明不足只保留前沿，不能据此判其不合格。只有核得`OK(q) ∧ ∀π∈E：R(q)≤R(π)`，或等价完整覆盖、下界及达到证书，才报告原完整域最优。

**健全性。**被采用结论来自绑定同一准确任务/域/政策的合格证书；证书基础健全且实际解释映射成立时，该结论成立。公平性只安排取得依据的次序，不给未验证猜测增加可信度。

**条件完备性。**若存在该枚举可达的有限候选q和有限全域证书p，证书所需依赖均可合法取得且耗有限工作，并给搜索充分的公平资源，则候选/证书这对有限索引最终得到足够步骤，核验结束并发现它。此证明不要求统一已知的完成时限，也不声称所有真命题都有这种证书；实际operation预算结束仍返回原frontier与已有合法路线。停止、恢复和再次运行须沿同一准确basis保留进度，不能每次重启前缀破坏公平性。

**搜索者不能免计自己的工作。**设Σ为查找/证明/核验前缀。q对后续交付成本最优，不推出`Σ;q`从原任务起点也最优；Σ的时间、判断和信息取得均在完整成本中。准确历史h之后的继续路线证书，只说明以该已付历史为共同起点的最优，不能标作原h₀的全过程最优。要求全过程最优时，比较对象必须是包括创建、搜索、证书取得与检查、停止策略、实际交付及周期义务的**完整求解计划Q**，证书也量化同一完整计划域。

该证明可由固定Q的语义及独立有限推导取得，不要求先运行Q；但不能以“Q最终会找到自己的最优证书”为前提证明Q终止或最优，再把同一结论供给Q。候选最优、发现它的搜索程序、原起点的计划最优是不同主体。公平路线给出真实继续算法及上述条件完备性，没有签发全部任务都可达到、有效取得或有限可证的全称结论。

<a id="complete-optimality-certificate-boundary"></a>
#### 2.13 完整最优证书的正确性内容给出的准确反证

下面直接检验“每个允许任务都能给出具体全域最优的有限形式证书”，使用当前完整T/B/I，不把成本换成程序长度，也不另设一个用户必须要求的统一总生成器。

**实际任务族。**令e为参数合法的有限机器编码，`H(e,t)`表示它从固定初态运行至多非负整数t步已停止。[原精确Int通用机](../../领域/计算基础/通用计算与任务语义.md)已有真实配置、转移表及一步计算；增加计数器，最多模拟t步，便得到总定义且有限结束的Bool谓词H。[T2/T5](../../作者/组合/语义扩展与领域接合.md#independent-specification-translation)将它接入普通定义和完整Int量词的准确解释。因此可有效形成有限任务sₑ：正常交付Bool b，且`b=true ⇔ ∃t≥0：H(e,t)`。该量词解释不运行无限遍历。

每个固定e在经典解释下有唯一正确Bool，故有一个正确、正常结束的常量实现；这是逐实例存在，不是已取得`e↦b`的算法或每个实例的形式资格。任务取纯、无外部输入/观察/预言机的正常交付，外部环境为已固定单元素，最坏和期望口径重合。这是完整能力中的一族允许任务，不给其他任务加限制。固定实例的常量制作/交付和有限正支持参考/Bool语义码可有有限成本；若硬要求还包括完整证明，其证明取得是否有限不能由常量存在反推。

设以下四项同时成立：

1. 上述sₑ有效形成、身份和证书目标可有效匹配，解释保持真实命题。
2. 同一个健全证明基础的接受关系有效可枚举；证书、引理及解除假设的依据有限，不含随e免费添加的真值oracle或不可核验公理。终止的有限核验器是充分特例，半判定接受亦可公平交错。
3. 接受的完整最优证书绑定一个具体可实施路线，真实证明原OK与正常Bool交付，能从该有限见证有效取得b。只证`OK⇒最优`、保留未解除OK假设或依赖自身将来成功，不满足此项。
4. 对每个合法e，至少存在一份上述具体完整最优证书；不要求预先给定一个能找到它的统一生成器，也不给统一成本上界。

给定e，公平枚举所有有限证书及接受计算，直到取得准确匹配sₑ的接受证书；第2项使过程有效，第4项使它对每个e有限结束。按第3项取得b，第1项和健全性使b准确判定e是否停止。于是导出总的停止决定过程。若有这个决定器D，则程序K(x)可在D判定x以自身为输入会停止时循环，否则停止；令x为K自身编码即矛盾。无输入机器编码可有效包含该输入，因此同样矛盾。四项不能同时成立。

**有效取得结果的边界。**普通纯确定程序及已证明的正常返回直接满足第3项。若证书本身给出并证明具体b，也可直接提取。随机候选不能被悄悄删出完整比较域：实际执行可有效枚举正支持的有限前缀，且正常完成存在、所有合法正常路径零错误时，交错这些前缀可取得同一个正确b，归约仍成立。仅几乎处处正确而有不能有效辨认的零测错误路径、非有效数学随机核或外部oracle，不自动满足此提取桥；不能用“可随机”三个字省去它。实际可生成代码与任意数学策略继续按原合同区分。

**完整成本没有被免除。**最优证书仍须比较包含形成、搜索、证明、码本/背景、检查、交付及周期义务的真实完整路线。反证中的元层枚举不被宣称最优，也不替代被证路线的成本；它只需每个输入有限结束便产生决定器矛盾。归约使用最优证书的OK成分，不需要计算其风险或证明成本与长度同序，所以完整计入这些费用、改变正权重或在该单元素环境切换最坏/期望，均不解除此证书完备性矛盾。

准确结论是：在上述真实表达、健全有效有限证据及结果提取前提下，**逐任务具体完整最优证书的普遍完备性不成立**。它不反证裸的“每个任务各自存在达到的最优”，不证明每个任务都难，也不构成删除这些规格或拒绝普通程序编译的理由。仅`∀s∃q`的非构造存在定理不提供第4项的逐实例具体证书，不能被此反证混同。现有ProofObligation和Method的准确范围/未决合同没有承诺该完备性；原公平搜索继续对可达有限证书给条件完备性。由已知正确实现和取得其真实证明的区别，可准确记录未证，不以禁用完整量词或通用计算制造全域成功。

相关不可判定来源及本构造的独立推导范围见[来源记录](../来源/理论与待核线索.md#effective-certificate-boundary-sources)。实际消费者仍为原R5与证据接纳，不增证书协议或全局禁止规则。

<a id="complete-plan-attainment-construction"></a>
#### 2.14 从完整计划的真实取得过程证明最优值达到

本节给出两条正向存在证明，补足“成本有下界”与“某个完整计划实际达到最小值”之间的差额。固定同一任务起点h₀、有限且真实保有的共同背景C、工作者/工具、合法信息、硬条件、完整使用周期和原完整合格计划域E。有限描述d须确定**包含此前取得过程和未来条件行为的完整计划π**，或与其资格及风险相同的代表；仅描述最终生成的源码不够。真实缓存可以按已有身份复用，不强制重读，也不把本次答案、无限候选库或任意实数选择免费放进初态。

采用[原默认工程成本](../../产品/术语与质量属性.md#operational-worker-cost-model)时，B/I非负，故每个环境中的`J(π,e)≥6T(π,e)/(1秒)`。若π有一个真实发生、非随机且不随外部环境改变的取得前缀，耗时τ(π)，完整T包含该前缀，则最坏或合格期望风险均满足

`R(π)≥6τ(π)/(1秒)`。

取得之后的内部随机执行可以有无限支持及无界路径时间；这里只用实际共同前缀，不把期望总时间冒充逐路径上界。其他已接受成本政策应另取得相应正时间下界，不能直接复用本常数。

**构造一：真实取得时间给出有限描述界。**假设对每个π有固定有限字母表上的上述完整描述d，且实际取得过程统一满足`τ(π)≥α|d|−β`，其中α>0为每bit时间下界、β≥0为有限已有选择/缓存余量。已有真实合格计划π₀及`R(π₀)≤U<∞`。对任意可能不劣于π₀的计划，得到

`|d|≤⌊((U/6)·1秒+β)/α⌋`。

有界有限描述只有有限多个，每个描述确定同一完整计划的风险值；风险不超过U的非空子水平集因而只有有限多个不同风险值。取其中最小值及其真实见证，便是原完整E上的最优；风险高于U者不可能更好。证明不要求合格性可判定、风险可有效比较或能找到最短描述，所以它给出**达到存在性**，尚未给具体可计算选择或完整证书。此处用真实时间推出长度界，没有将原T/B/I目标改为程序长度。

α/β可以从一个明确的实际控制模型取得：固定接收者状态与有限缓存，直接选择头部至多b₀ bit；全部新增完整策略控制选择经过真实边界。若每个时长δ>0的间隔，所有端口合计只能区分有限字母表Γ中的一个符号，取`b=max(1,⌈log₂|Γ|⌉)`，把空闲、结束、并发及能被利用的时序信息一并编码，则一次耗时τ的真实控制历史可描述为

`|d|≤b₀+b(⌈τ/δ⌉+1)≤(b/δ)τ+b₀+2b`。

由此取`α=δ/b`、`β=δ(b₀/b+2)`。这是对已经发生的控制过程作数学编码，不要求产品再制作一份日志或经过新增加载器。短种子、自解压程序、已有库引用按实际短控制内容计；其生成、检查和运行时间仍在完整T内。该历史必须决定此前形成路线以及未来完整条件策略/随机核；只看到最后一个消息，或忽略另一端口、任意精确时间、隐藏初始参数和控制者自己的选择，均未证明覆盖全部计划。

**构造二：有限分支且无Zeno的取得树。**不必要求统一的α。把原真实取得过程表示为以固定有限初态为根的树A，每个节点只有有限个可区分后继；任意长字符串须经过其实际有限字母过程，不能作一个免费无限分支。节点累计前缀时间t(v)单调不减，并且每条无限路径的累计时间发散。允许有限段零时间步骤及越来越小的正步骤，只排除有界总时间内取得无限控制历史。每个完整π对应某个有限终态v，终态保留此前成本并确定未来完整策略；多计划合用终态须证明资格及风险相同，不能只靠相同最终产物。

对任意有限H，取节点集合`A_H={v:t(v)≤H}`。它前缀封闭且有限分支。如果它无限，从根起每次选择仍有无限后代的一个子节点，便得到一条无限路径，其每个节点时间均≤H，与时间发散矛盾。因此A_H有限。由上述风险下界，任何`R(π)≤U`的取得终态都在`A_{(U/6)·1秒}`中；非空风险子水平集再次只有有限多个值，故最小值达到。这比固定每bit时间假设更弱，仍不自动给A_H的可计算结束界、资格决定器或比较算法。

**完整计划身份必须保持。**固定元程序Σ以后随机生成q，候选是含该生成分布、搜索、核验及交付成本的Σ；每个分支q不能免费继承同一个Σ的期望费用而成为另一条已取得计划。改变随机核、固定某个分支或换成后来另选的算法，须在其自身完整形成路线中重新解释。只有“以后可以生成任何东西”的句柄没有确定策略，不能凭一个终态覆盖无限个不同风险值。取得本身若随机且只有有限期望，本节的共同前缀界不能直接套用；若更早有限控制内容已确定该完整随机取得程序，则该程序才是那个终态，后续随机生成继续计完整成本。

这些构造保留有限程序指称无限数学域、无界运行、普通递归以及真实随机生成的能力。数学上的任意实数随机核、无限初始表和连续精确控制是否有上述实际表示，仍需对应证明；不能因公式可写便假设已覆盖，也不能为套定理禁止原合法控制渠道。对每个实际任务，原Method须证明其**全部原可能改进计划**都满足选用的取得模型，或有保持资格和风险的完整映射；强加一个有成本的新加载步骤再只比较该子域不是这个证明。

当前完整T合同已经包含取得责任，本节进一步给出足以推出达到的实际模型及手工证明。它没有单凭“机器是数字的”证明一切人/AI/Provider路线均经过同一有限可区分、无Zeno边界，也没有证明每个原任务已有有限风险合格路线。取得模型覆盖、真实有限incumbent、有效选择和具体证书分别消费自己的依据；[2.13](#complete-optimality-certificate-boundary)的证书完备性反证与此存在定理可以同时成立。

<a id="total-normal-realization-boundary"></a>
#### 2.15 不要求证书也不能统一有限实现全部可满足规格

复用[2.13已经形成的准确规格族](#complete-optimality-certificate-boundary)sₑ，不另假定一种表达能力：正常交付Bool b，且b准确表示有限机器e是否最终停止。每个合法e都有一个正确、正常结束的常量实现，规格有限、准确、可满足；它没有私人原意缺失、待填字段或外部oracle。这是逐实例存在，不是有效取得哪一个常量。

设同一个有效系统G对每个sₑ都在有限工作后生成有限实际程序pₑ及必要固定依赖，并有统一有效的构建、执行和Bool读取办法；在该固定纯环境中pₑ正常返回正确b。G可以先创作、搜索库或调用任意合法有效工具，不要求最优性、形式证书、已知时限或统一运行时间界。这里取确定性有效过程；随机过程只有满足2.13所列有效零错误结果提取条件时，才沿同一桥取得结论，不能忽略该条件或禁用其他合法随机能力。

那么`e→构造sₑ→运行G取得pₑ→构建并运行pₑ→读取b`就是总有效的停止决定过程：生成和实际执行各自有限结束，b又按原义精确判定停止，与原停止不可决定性矛盾。因此，**原完整表达域、统一有效系统、每个准确可满足有限规格都有限取得正常正确实际代码，这三个承诺不能同时成立**。取消最优性和形式证书仍不解除这项矛盾；这比证书完备性边界少要求了两项前提。

pₑ无需是常量或可静态看出答案，正常执行足以提取。打印一个尚无执行实现的完整量词、无限搜索停止见证、给一个数学策略或还需补实现的AST，都没有满足本命题的实际正常交付。只给可修订猜测也不够：若有总的、准确表示最终交付的标记，又可等待该标记取得决定过程。允许部分任务持续保留创作前沿，或新来源提供准确全域信息，会改变总生成/固定信息前提；不得把这些变化伪装成原无条件承诺已经成立，也不能默认让作者提供停止真值来补这个oracle。

**正向生成继续按实际任务分流。**已有准确源码、普通算法体或具有真实构造算法的领域定义，按原固定绑定和逐构造降低正常生成；编译可以保留发散，不先决定任意程序终止性。关系要求已有合格实现方法时直接应用；含义完整而缺实现时由受委派系统沿原Method创作候选和资格材料。只要求正确实现的任务不额外等待全域最优证书；明确要求最优的原义务也不因此撤销。

原公平前沿对“存在枚举可达的有限候选及所需资格依据，依赖合法可得、核验有限、资源公平”给条件完备性；正确实现存在本身不保证这些依据也在某个有效基础中有限可得。有限预算结束保留原规格、合法结果和准确未完成范围，不能把整个类别判无解，不能用对所有任务返回unknown冒称处理闭合。开发者继续只负责顶层含义和独立公开决定，定义、实现、绑定和证明仍由系统承担；该反证不创设必须下钻的作者层，也不删除sₑ或完整量词。

<a id="finite-expectation-effective-comparison"></a>
#### 2.16 有限期望上界不保证有效尾界或准确比较

本构造检验成本比较本身，保留完整费用，不把它直接提升为完整计划域的最优选择反证。令F(e,n)表示有限机器e恰在第n步首次停止，n≥1；初态停止可统一加一个入口步。F是总定义的有界模拟。固定一个已接受的数学环境模型，环境提供有限自然数N，`Pr(N=n)=2⁻ⁿ`；每个允许环境都提供一个有限N。这里直接指定有限输入的分布，不用“几何采样几乎必然结束”偷换全部正常路径的交付保证；实际采样器若进入完整路线，其结束性质、费用与模型对应须另行取得。

定义额外等待`Dₑ(n)=2ⁿ秒·1_{F(e,n)}`。每个有限输入的模拟、参数形成和等待均有限；首次停止至多一次，因此

`E[Dₑ]=Σₙ 2⁻ⁿ·2ⁿ秒·1_{F(e,n)}=hₑ秒∈{0秒,1秒}`，

其中hₑ表示e是否最终停止。统一有限上界1秒的证明不需要知道hₑ。然而，一个对全部e给出该期望准确值、绝对误差小于1/4秒的近似，或与1/2秒准确比较的总有效方法，都会决定停止。期望尾在截断k后等于1秒，当且仅当首次停止步大于k；否则为0。若能统一有效给出尾小于1/2秒的k，模拟到k即可决定停止。因此**每个样本可计算且正常结束、期望有限并有已知统一上界，仍不足以给有效尾模数或所求风险比较**。

这是准确有时模型内的结论，不自行证明物理时钟、无限容量或人/AI成本模型的现实资格。完整T还包含取得e/N、模拟、参数传达、模型/证明形成及交付。若两条已绑定路线具有准确相同的共同完整成本Cₑ，一条再等待Dₑ，另一条再等待1/2秒，且共同时间有已证有限期望包络、B/I及其真实参考/条件码在两路线下相等，则默认风险为`R(Aₑ)=Cₑ+6hₑ`、`R(Bₑ)=Cₑ+3`，顺序同样不能统一有效取得。Cₑ的共同性及有限性须由完整历史对应证明，不能把模拟免费化或未知B/I填0；实际计时误差也须证明不改变该风险间隔。真实有限N≤K的模型不满足此无界构造的前提。

两路线不能有效比较，不推出原完整E不能有效选出最优：第三条路线可能在所有实例都更好。若要升级，必须另证真实不可绕过效果、提交信息、随机选择与B/I、完整计划共同下界及实际达到，覆盖全部原可行路线。本节没有取得这些前提，不虚构Provider或新增任务约束来制造产品全域反证。原方法仍可消费合格闭式关系、有效尾界、准确数值类或其他完整证书；该反例只否定上述不足条件能统一代替它们。

<a id="effective-acquisition-tree-selection"></a>
#### 2.17 有效局部呈示使取得树可穷尽并形成具体选择

复用[2.14的原完整取得树及有限性证明](#complete-plan-attainment-construction)，不另设候选池。新增的算法前提是：根和节点有有限有效表示；每个节点的**完整有限后继列表**可有效生成并结束；与已取得界`H=(U/6)·1秒`的比较`t(v)≤H`可决定，包含准确并列；终态可识别并解码为保留此前费用和未来完整策略的原计划。准确有理时间是时间比较的充分实例，仅可近似的实数不是。原取得空间覆盖与合格有限incumbent仍须保持。

算法从根开始维护队列。取出节点，若t>H则剪去整个子树；否则记录该节点、收取可识别终态，再将其完整有限后继加入队列。时间单调使剪枝不漏掉界内节点。2.14已证明界内节点有限，每个界内节点的后继又有限，所以需检查的外侧第一层节点也有限；每次局部处理结束，队列最终为空。**无需预先知道最大深度、节点数或统一完成时限**；原存在证明没有单独提供这些有效局部操作，现在的算法补足它们，不为缺少预知深度反复重审有限性。

随后对每个可能改进终态取得完整硬资格或终止的准确排除依据；未找到证明不能排除。对仍可能改进者取得完整风险的准确弱序，包括相等，或等价的完整支配/下界证书；[有限对数有理比较](#log-rational-cost-comparison)是一条已有充分类。后续运行具有无限支持时，合格闭式关系仍可满足比较合同；有限期望上界自身不能代替它。保留原E中每个风险≤U的计划或已证不劣代表，U以上者由真实incumbent排除。此时有限资格裁决和比较选出的具体计划就是原完整E的最优；稳定身份只在已证并列后选择，不制造相等。

该算法识别以原h₀为起点的最优完整计划，不给它免费附加本次穷尽/核验过程Σ。若实际运行Σ也属于所求全过程，比较对象必须是含Σ的完整求解计划，或准确声明当前已付历史h之后的残余最优；不能将`Σ;π*`自动标成原h₀全过程最优。原J5及成本owner继续拥有所有取得、搜索、证明、核验和交付费用。此处给出有效选择的充分输入合同与算法，没有证明同一遍历器自身在全部任务上具有最低全过程成本，也没有禁止未满足该合同的通用表达。

#### 2.18 公平取得的定量实例：服务预算与实际驱动工作分开

原[Method的加权倍增实例](../../编译/实现选择与设计搜索.md#proof-directed-search-construction)固定准确任务/basis、接受条件、可信核验器和有限只读输入。一个job由有限生产程序p及可信封装组成，工作包括初始化、候选/证明生产、真实检查、原目标降低和完整输出；生产程序打印success不取得采用资格。要求全域最优证书的请求保留那个接受条件，不能用第一份仅可行实现替代。只交错可恢复纯计算或已有真实隔离/恢复合同的工作；外部Need、权限、事实和作用不是免费可重放步骤。

取m位p的前缀描述`d=1^m0p`，长度`l=2m+1`，权重`w(d)=2^(-l)`。先读m个1及0，再读恰好m位，故解析可决定且描述前缀无歧义。所有描述的权重和为`Σ_{m≥0}2^m·2^{-(2m+1)}=Σ_{m≥0}2^{-m-1}=1`。非法程序由可信封装拒绝，不预先判断停机；每个有限生产程序仍有描述。这个内部码只分配取得配额，不是作者格式、必要信息I、智力B或完整路线成本的替代量。

阶段k枚举全部l≤k的描述，并给每个未完成job至多`2^(k−l)`个参考微步，保持其实际状态。每阶段服务预算至多`2^kΣ_{l≤k}w(d)≤2^k`。若某成功job从初始化至可信检查和所需完整输出共需W≥1微步，则`K=l+⌈log₂W⌉`阶段的单次预算已足够；此前保留的服务只会使它更早完成。到K全部job服务预算小于`2^(K+1)≤2^(l+2)W`。因此第一次合格成功不晚于任何可用有限见证给出的这个界；另一见证提前完成请求时，不承诺仍输出某个指定见证。见证不存在或所求证书不在该有效基础中可达时，本结论不制造它。

**服务微步不是整个调度器的实际工作。**令n≥1为固定输入位长，可变解释器/检查器及真实输入的读取也有归属。取`A_K=(n+K+1)2^(K+1)`。一种朴素顺序表示保存每job的程序、输入、带、头、计数和输出，按长度/二进制计数枚举描述，并扫描目录查找、更新、搬移状态。描述数及全部服务均小于`2^(K+1)`；固定参考机每步只增添有界带格，故包括各job输入副本的表示长度可界为`M≤a_sA_K`。枚举/初始化/计数及服务模拟宏操作可用宽界`E≤a_eA_K²`；若每个实际扫描宏的位机工作已证不超过`a_o(M+1)²`，则整个驱动工作有

`N₀≤cA_K⁴，c=a_ea_o(a_s+1)²`。

a_s须由实际字段/带编码和每步新增格数取得，a_e由有限控制和外层循环计数取得，a_o由实际扫描、复制、插入及头移动取得；例如内部循环具有表示长度界且至多两层时，可逐直线块计数并组合。任意精度运算、语义检查、证明器和原生调用不能整段塞入一个免费宏。这里给的是顺序实现构造及**需实际细化的系数合同**；当前已证的具体数值界是服务预算，不能在未取得这些系数和模型对应时宣称已有数值N₀或秒数。实际实现可更快，不要求采用朴素目录来取得资格。

N₀已经包含对服务的模拟，不能再加W重复计算。job本地完整输出已在W；控制器真正移交给消费者的一份副本若尚未计入，仅另计那一次。正常内存切换/保留在N₀内；额外持久化/恢复、真实丢失进度的重放、依赖服务、竞争工作和未计的输出，分别保留`C_state、L_replay、C_dep、C_other、C_out`，形成完整工作账。已有checkpoint的实际编解码/验证可以给C_state的界，不能以一个简单复制例子代签任意Provider恢复；旧已付成本不因basis变化而消失。

**定性公平不提供同一总工作或墙钟界。**若基础队列在总供给H中确实取得至少`θH−b`个驱动工作单位，θ>0，则完成N个基础驱动工作可由总供给`⌈(N+b)/θ⌉`保证；也可直接计实际C_other。只有“不长期饿死”时，额外工作与暂停可任意长，不能继承这个数值界。外部等待期间其他job可能消耗更多工作，须按实际账、固定输入的后继段或有据等待/份额界处理，不把最终存在有限W当成整个有等待过程的界。

实际时间、判断和信息的提升沿[原成本桥](#search-work-cost-lifting)。这条构造补原公平方法的取得界，不证明短程序更优、所有任务存在见证或搜索者自身在原起点全局最优；全部搜索/检查费用仍属于原完整计划。已有固定源、合格方法和fresh证据直接消费，不强制每次从通用枚举起步。

#### 2.19 从准确取得轨迹保持到完整T/B/I成本界

计数证明先通过真实执行细化接入原[工作者模型及资格](../../产品/术语与质量属性.md#worker-cost-model-qualification)：同一任务、起点/周期、工作者、背景、合法信息、判断参考和语义码；对应保持候选/证明/结果、错误、停止、观察、效果以及全部有成本工作。一个驱动调用不能隐去另一个AI、检查器或库的内部责任。这里只新增量化保持，时间组合仍由[原预算owner](../../编译/查询增量与性能.md#端到端预算的组合规则)承担。

**时间。**对每个外部环境e和内部实现u，设已细化事件类别a的次数为N_a，其在实际位宽/资源/调度范围内的合格耗时界为τ_a；A_T覆盖未包含的准备、背景/模型取得、等待、恢复、输出/检查/保存及周期义务。全部执行被覆盖时，

`T_raw(e,u)≤A_T(e,u)+ΣₐN_a(e,u)τ_a(e,u)`。

这是保守上界；串行且各项准确时才可取等式。并行沿真实依赖和资源收紧，不把全部工作者耗时之和冒称真实历时。单独CPU步数不界定外部等待，P99/均值不签逐执行上界。原profile取内部期望时，先逐执行保持再取同一E_u；τ随历史变化时保留E[N_aτ_a]，只有共同常数界才可提到期望之外。

**判断控制成本。**在全部真正判断历史h及π正支持上，若准确参考满足`p(a|h)≥ε_h>0`，则

`b(h)=Σₐπ(a|h)log₂π(a|h)+Σₐπ(a|h)log₂(1/p(a|h))≤β_h=log₂(1/ε_h)`，

因为第一项不大于0，第二项是每项不大于β_h的凸组合。令L为完整过程的真正判断次数，包含实际有判断责任的停止、失败、恢复和交接，原链式条件成立时，

`B(π,e)≤E_uΣ_{j=1}^Lβ_{h_j}`。

共同ε给`B≤log₂(1/ε)E_uL`；逐路径L≤L_max时可用相应常数界。对随机停止先截断到min(L,r)，再按原完整过程条件取非负单调极限，不需独立性或Wald假设。ε须真实覆盖，不能给未知支持加小正数；E L有限而ε_h任意趋近0时也未保证此加权和有限。有限期望判断数不代签每条合法路径终止。

L由实际语义判断模型取得；只有已证每个事件最多承担κ个判断时才可用L≤κN及单列残余。机械步骤不因此制造认知节点，确定性也不自动给B=0。这个界首先属于准确工程模型；用于更强的真实人/AI认知目标，还须原同值、方向或误差映射。

**新增作者信息。**固定准确已接受任务、实际背景及委派；若纯确定方法取得源码和证明，不读新独立事实、不等待新作者含义，且结果对原剩余兼容作者状态共同合格，则作者渠道可取同一解码决定，新增条件码为空，即`ΔI_author=0`。这不要求作者再编码一次派生源码，也不证明每个确定程序都能取得合格结果。真实查找、创作、核验和长源码的载体处理仍在T/B/资源里；不能把隐藏答案免费放入背景。

作者渠道零增量不等于完整I为0：原始输入、其他工作者或外部来源的新独立内容、必要背景/码本取得，继续按原主体和条件码形成U_I；重复同一事实不制造独立含义，实际接收/同步费用仍保留。只有全部新增内容满足相同条件时才有ΔI_total=0，此前的I仍然存在。

**完整政策与实际构造。**取得同一环境下的U_T、U_B、U_I后，原尺度给`J(π,e)≤U_J(e)=6U_T/(1秒)+3U_B/(1控制bit)+U_I/(1消息bit)`，再按固定政策取外部sup或合格联合期望。未覆盖阶段不能填0；分别有效的常数界之和可以是保守界，但不自动是同一情景达到的准确最坏值。

一个规定的有限画像可以完整给出这些输入：机械操作≤10,000次且各≤1微秒；另有真正判断≤20次且各≤1毫秒、全部正支持参考≥1/4；未计入前两类的背景/模型准备≤5毫秒、检查/保存≤5毫秒、全部外部等待≤10毫秒；高层输入已有2 bit，内部确定取得不引入新独立事实，且无其他周期义务。于是T≤0.050秒、B≤40 bit、I=2 bit，得到U_J=122.3。这是完整规定模型的手工界，不是设备或人/AI实测、B的精确值或最优性证明；实际任务只有在对应及覆盖成立后才使用它。

从2.18接入非线性计数界时，必须逐结果代入再聚合。不能把`E[Z⁴]`换成`(E Z)⁴`：Z以各1/2取2和4时，二者为136和81；更一般，`Pr(Z=2^j)=3·4⁻ʲ，j≥1`给E Z=3而E[Z⁴]=∞。没有相应矩界或逐路径共同界时，平均W/阶段数不产生有限完整期望成本。这只限制所求成本声明，不取消已经取得的合格源码或证明。

#### 2.20 固定环境核下的有限因果最优控制与实际降低

在原[共同因果策略](#causal-cost-optimality)和[工作者成本](../../产品/术语与质量属性.md#operational-worker-cost-model)内，可构造一个直接求解的完整有限控制方法。输入是准确的有限可见历史树，或有相同后继信息、资源、参考及成本的无环等价表示；它须覆盖所声明的整个控制问题，不能用截断无界行为取得。历史只含当时合法可得的信息，多工作者的私有信息不因合成模型而免费共享。未知外部环境继续原最坏政策；本节期望递推只使用已合格、适用且保留全部相关性的联合环境概率模型。

**硬资格与成本输入。**先按原硬量词形成可继续的终端、固定观察/机械节点及各判断节点的合法动作域。所有被硬合同量化的可能后继都须有合格继续，包括原合同仍量化的零概率路径。完整历史保留跨次预算、共享资源和承诺；合格策略域必须确能由局部合法动作及相容后继组成。未承接的跨分支概率约束、联合硬约束或分散信息限制，不允许拆开各子树独立最优后拼接。

候选与参考共用同一准确环境核`K_h(z|a)`，真正判断节点的参考`p_h`在比较前固定于原行动域。硬排除动作的候选质量为0，原p质量仍保留，不能重新归一化。支持未知不是0，不能加ε。每条转移有准确完整历时增量Δt和条件语义码增量Δi；默认尺度下取`r=6Δt/(1秒)+Δi/(1消息bit)`，真正判断的控制权重λ由原Quality读取，当前默认λ=3。时间增量须准确覆盖并行依赖、等待及全部费用，不将CPU累加当历时；机械步骤不因此制造判断。终端g包含尚需完成的准确费用，无未结义务时才可取0。

**逆拓扑形成。**硬不可行与成本无穷分别记录。合格终端取V=g；固定机械/观察节点只能按原K对`r+V(next)`取期望。在判断节点，对每个硬合法动作先求

```text
q_h(a) = Σ_z K_h(z|a)[r(h,a,z) + V(haz)]
F_h = {a : a硬合法，p_h(a)>0，q_h(a)<∞}
Z_h = Σ_{a∈F_h} p_h(a)·2^(−q_h(a)/λ)
V(h) = −λ log₂ Z_h
π*(a|h) = p_h(a)·2^(−q_h(a)/λ)/Z_h    (a∈F_h；其余取0)
```

求期望只对正概率后继相加，不计算`0·∞`；零概率后继的硬要求已由资格闭包独立核对。F非空时`0<Z≤1`，得到有限非负V；硬策略存在但F为空时，每个策略都触及零参考支持或无穷继续成本，准确最优扩展值为∞，不能据此说语义任务不可实现或送出有限Quality损失。这种后继仍保留一个真实硬合格继续见证；概率为0不能成为删除其硬路径实现的理由。参考`(1/2,1/2)`、硬资格只许第一动作且其q=0时，V=λ，正是1控制bit的费用；将剩余p归一化会错误删除它。

**局部恒等与全树证明。**本解析域允许每个判断节点取任意合法概率向量。由π*定义，对在F上的任意π有

`Σₐπ(a)q_h(a)+λKL₂(π∥p_h)=V(h)+λKL₂(π∥π*)`。

原p不因硬过滤改变。KL非负且零值当且仅当两个概率向量相同，故π*局部唯一最优；对p=0或q=∞动作给正质量的候选成本为∞。从终端逆推，固定核节点的后继最优值给所有继续的下界，判断节点用该恒等给所有局部核的下界，再由π*及相容后继同时达到。有限树保证归纳结束，原[KL链式式](#information-cost-construction-proof)保证局部和就是原B。因此V是该完整有限因果策略域从当前历史h起的最小成本。只有实际到达的判断历史受到局部唯一性约束，不能宣称全局策略文本唯一。原域只允许确定策略时，应求`min_a[q_h(a)+λlog₂(1/p_h(a))]`；更一般受限概率域须按其真实范围求解，解析全概率域不能强加给它。

**一个全部参数固定的模型。**初始准确语义消息为1 bit；共同准备历时1/4秒且无未计判断。随后只有一个判断，参考`p=(1/3,2/3)`，两动作均硬合格；模型规定选择、分派及检查保存共同用1/2秒，第二动作再用1/2秒，没有其他周期义务或新独立消息。于是`q=(3,6)`、λ=3，得到`Z=1/3`、`π*=(1/2,1/2)`及`V=3log₂3`。完整模型值为`J*=5/2+3log₂3`；直接回算为T=1秒、`B=(1/2)log₂(9/8)`、I=1，给同一个`7+(3/2)log₂(9/8)`。任意允许策略与它的差恰为`3KL₂(π∥(1/2,1/2))`，两个确定端点均多3。这是规定模型的手工最优证明，时间与参考并非设备或人/AI实测；真实代码、模型或表格的取得费用未在此模型给出时，仍按原完整路线另行承担。

**不能倾斜不可控的整条轨迹。**取只有一个必选动作的模型，p=π=1、B=0。随后环境按固定公平核给z=0或1，后者多等待1/2秒，新增非KL成本为0或3；其余共同完整费用为C。真实唯一因果策略值为`C+3/2`。若错误地在全部轨迹分布上自由最小化`E_P L+3KL₂(P∥Q)`，得到`P=(2/3,1/3)`及`C−3log₂(3/4)`；因为`(3/4)²>1/2`，后值严格更低。差额来自擅自改变外部公平核。实际因果轨迹必须满足`P(haz)=P(h)π(a|h)K_h(z|a)`，所以先按固定K取期望，再在动作上优化。该反例不改变原外部风险政策，也不允许将相关完整环境改成每节点独立选择的对手。

**解析核到普通代码。**上述正向模型的宏核可由一次合格公平位调用，再按位分支调用准确Method实现；位与实参按原语义各求值一次，调用的失败、取消、资源与目标资格继续原合同。一般有限核`π_i=k_i/2^b`可由b个合格公平位形成整数，再按累计整数阈值选择动作。系统沿普通调用/分支及原降低链形成这些函数，不增加采样Core原语、IR或作者输入表。公平必须在同一真实历史下条件成立并保持联合环境关系；源码中的`sample`名字不提供该能力。

**精确有理核也有硬终止边界。**参考`(1/2,1/2)`、两动作非KL成本为`(c,c+3)`时，解析核是`(2/3,1/3)`。若公平位是唯一随机源、其他计算确定，且原硬条件要求每条合法随机路径有限正常完成，取位/终结的二叉前缀树就没有无限路径。若深度无界，从有限分支中逐次选仍有无界后代的子节点将构造无限路径，矛盾。因此最大取位数b有限，补齐较短终结路径后，输出概率必为`k/2^b`，不能是1/3。这只否定该profile的无条件精确降低，不反证真实完整成本域必无最优。

允许几乎必然完成时，每轮取两位，00/01取第一动作、10取第二动作、11重来，可以精确实现`(2/3,1/3)`；轮数期望4/3、位数期望8/3，但永远11的零概率路径不终止。若每轮全部实际耗时相同为τ，采样期望为4τ/3；其他形成与交付费用仍保留。其他合格随机源及终止合同也继续可用，不能把这个公平位反例变成全平台禁令。一般解析指数/对数核亦不自动属于原[对数有理数值法](#log-rational-cost-comparison)的准确输入域，表示、比较及采样方法须分别取得资格。

**完整成本与原域接合。**宏动作核正确不保证完整B相同。实际细化含额外判断轨迹ξ时，原链式式给`B_full=KL₂(P_macro∥Q_macro)+E_{P_macro}KL₂(P(ξ|macro)∥Q(ξ|macro))`；只有共同细化使残余为0才继承准确B，否则保留真实残余，不以随机位或机械指令数代替它。无限拒绝过程另需支持、极限及相称可积性依据。采样、调度或等待若被环境观察并改变响应，须保持完整条件轨迹或重新纳入原K，单独输出边际相同不足以证明保持。

设F将模型策略译成真实继续计划。只有F保持原硬结果量词、合法信息和环境，完整风险有同值或相称排序证明，且每个原可能更优计划都有模型策略或不劣代表，才能把模型最优传到原完整继续域。求核、生成、检查、安装和采样费用依赖π时必须真实入模；采样开销一般可能依赖整个分布，不能未经证明拆成动作常数而继续套上式。当前h之前已付的相同费用可作为当前共同历史，却不能从原任务h₀的总账删除。`Σ;Fπ*`的全过程最优须覆盖Σ及其他原合法路线，不能从未来控制最优取得。该接合复用原J5/R5与[完整成本提升](#search-work-cost-lifting)，不新建最优控制协议。

本节的有限决策树与正则Bellman归属见[已核来源](../来源/理论与待核线索.md#information-cost-model-sources)；具体成本恒等、因果反例及公平位边界已在此直接推导。它给准确的正向控制构造及真实降低出口，不证明每个任务都具有这些有限模型/概率/覆盖条件，也不改变原全部表达能力或统一正常实现的既有反证。

### 3. 无免费午餐对通用优化器的攻击

若对所有可能问题分布平均，没有一个优化算法普遍优于其他算法。工程含义：

- 一个搜索器在 Web 工程上优秀，不证明在实时控制、数据库迁移或密码协议上优秀；
- 一个启发式只有绑定问题分布、候选生成器和损失函数才有意义；
- “通用最强规划器”必须被拆成带领域先验和可验证适用域的策略组合；
- 性能比较必须保留 benchmark 分布、训练污染、实例族和失败样本。

### 4. Blum 加速对“最终最快实现”的攻击

存在可计算问题，使得每个计算它的算法都可以被另一个算法任意显著加速；因此某些问题不存在稳定意义上的最佳算法。对 Gift：

- 不能为所有编译任务声称存在一个终局最优 pass pipeline；
- `best-known` 必须绑定时间、语料、硬件、成本模型和候选空间；
- 算法替换不一定收敛到终点，长期可能持续出现更优实现；
- 需要把算法身份、比较证据和退役条件作为演进对象，而不是冻结“永久最佳”。

### 5. 复杂度与状态爆炸

以下子问题在一般形式下可能是 NP-hard、PSPACE-hard、EXPTIME 或不可判定：

- 领域边界划分；
- 最小修改集合；
- 调度和资源分配；
- 测试最小覆盖；
- 多目标实现选择；
- 程序等价和超优化；
- 状态机组合与模型检查；
- 分布式合成；
- 依赖版本解析和兼容组合。

系统必须区分：

```text
exact-complete
exact-bounded
parameterized
approximation-with-ratio
heuristic-with-no-guarantee
anytime-with-bounds
unknown
```

### 6. 搜索预算是语义输入

搜索的实际字段与结果等级由[唯一搜索合同](../../编译/实现选择与设计搜索.md#7-搜索合同)及其相邻的优化结果合同维护，本页只说明论证责任。候选生成器、完整候选域、已探索/剪枝范围及见证、目标与单位、风险、时间/内存/Provider预算、当前候选、上下界、未探索前沿和可复现输入必须一起解释；不能用另一份同名字段表省掉搜索域或目标。

启发式排序可以改变先探索哪里，只有具有适用证据的剪枝才能缩小所声明的完整可行域；启发式方法、参数和随机输入属于可复现依据，其名称不提供完备性。最优性声称消费真实OptimizationOutcome与所绑定的域/证书，不能由调用者另填一个等级标签。

超预算时，保留已知非支配候选、已证明劣势或不可行的区域及其见证、当前可证上下界和未探索前沿。是否继续搜索可依据真实成本和潜在收益论证；没有模型或测量时保留未知，不制造一个精确的“额外搜索价值”分数。这些是原合同输出的论证与解释，不新增另一份候选结果格式，也不把当前最好候选标记为 `optimal`。

### 7. 多目标和社会选择的不可比性

安全、隐私、公平、可访问性、成本、速度、自治、可解释性和不同主体利益可能互相冲突。即使每个维度可测，也未必存在所有主体共同接受的排序。

Gift 必须在输出中区分：

- 逻辑不可行；
- 技术可行但规范冲突；
- 方案互不支配；
- 决策程序本身可被策略操纵；
- 需要合法的人类或制度裁决。

### 8. “最小改动”也可能不是最佳

最小文件 diff、最少行数或最少模块变化可能：

- 保留错误边界；
- 延长兼容债务；
- 增加未来迁移成本；
- 隐藏根因；
- 使安全证明更难；
- 造成更大的长期总成本。

因此修改优化对象应为：

```text
LifecycleChangeVector = {
  semanticDelta,
  implementationDelta,
  migrationDelta,
  verificationDelta,
  operationalDelta,
  retirementDelta,
  residualRisk
}
```

### 9. 修订后的决策流水线

```text
hard impossibility checks
→ non-compensable constraints
→ candidate generation with provenance
→ eligibility and assumption checks
→ infeasibility/undecidability classification
→ risk and uncertainty envelope
→ Pareto reduction only under comparable continuation boundaries
→ robust satisficing or reversible experiment
→ legitimate decision authority
→ post-decision monitoring and reversal
```

完整操作规则由[联合搜索](../../编译/实现选择与设计搜索.md#带边界状态的联合搜索与合法剪枝)拥有：可比较性包含剩余义务、公开观察、真实表示和未来成本关系，不仅是局部接口类型。一般程序的完整等价不被假设可判定；没有充分比较依据时保留候选或明确探索范围。

<a id="10-验收-4"></a>

### 10. 验收

- 搜索结果不使用无条件 `optimal`；
- 所有最优性声明绑定完整候选空间、正确性、成本序、量词和所证对象；共同最小、非支配、存在、有效取得及具体证书分别验收，不能用有界结论代签明确要求的全域证明；
- 增加新的候选生成器可以重新打开旧决策，但只失效依赖该候选完备假设的结论；
- 超时保留上下界和未探索前沿；
- 多目标冲突不能被隐藏权重自动解决；
- 不存在支配解时可输出 `NoDominantSolution`；
- 不可接受的规范冲突可输出 `ArchitectureRefused`。

## 跨语言语义保持、全抽象与隐式接口

<a id="1-根裁决-12"></a>

### 1. 根裁决

一个通用工程编译器不能无条件保证任意源语言和目标语言之间“完整语义等价”。原因包括：

- 目标上下文可观察源语言中不存在的行为；
- 内存模型、未定义行为、异常、并发、反射和 FFI 不同；
- 时间、资源、布局、地址、浮点、I/O 和错误语义不同；
- 安全性质取决于攻击者能否链接目标级上下文；
- 外部消费者可能依赖未声明行为；
- 语言中的抽象边界可能在低层被突破。

因此 `semantic-preserving` 必须始终带属性集合和上下文集合。

### 2. PreservationContract

```text
PreservationContract = {
  sourceSemanticsRef,
  targetSemanticsRef,
  sourceProgramClass,
  targetContextClass,
  preservedObservationKinds,
  reflectedObservationKinds,
  undefined/unspecified behavior policy,
  resourceAndTimingPolicy,
  concurrencyAndMemoryModel,
  FFIAndExternalEffects,
  securityAdversaryModel,
  proofOrValidationMethod,
  excludedFrontier
}
```

### 3. 多种保持性质

```text
PreservationKind =
  | FunctionalRefinement
  | TraceInclusion
  | TraceEquivalence
  | SafetyPreservation
  | RobustSafety
  | NoninterferencePreservation
  | ConstantTimeWithinModel
  | ResourceBoundPreservation
  | FailureSemanticsPreservation
  | FullAbstraction
```

Full abstraction要求在固定上下文及观察模型下保持并反射源/目标的不可区分关系；它与原结果、错误、顺序等功能保持分别判断，不能仅凭该标签推出后者。例如只有正常返回Bool的闭合程序，等价按返回值相同定义；翻译把所有返回值取反仍保持并反射程序对的等价，却违反原返回结果合同。需要共同保证时，同时核实际观察对应、功能保持及适用的上下文/链接依据；具体消费沿[性质保持](../../编译/性质保持与开放环境.md)，不把这些性质排成统一强弱等级，也不将FullAbstraction设为所有后端的默认合同。

### 4. 目标比源更有观察力

例如：

- 源语言抽象对象在目标中暴露地址或布局；
- 源语言原子操作被 lowering 为多个可观察步骤；
- 源语言无未定义行为，目标语言有；
- 源语言异常统一，目标平台区分信号、进程退出和设备故障；
- 源语言安全模块可被目标级恶意代码链接；
- 源语言大整数被映射为有限整数；
- 浮点重排改变边界结果。

正确方案是能力和上下文约束，而不是声称“IR 已统一所以等价”。

### 5. 隐式接口与 Hyrum 型效应

只要系统有足够多消费者，任何可观察行为都可能被依赖，即使它未写进正式 API：

- 输出顺序；
- 错误文本；
- 时延；
- 资源占用；
- 临时文件；
- 未记录字段；
- 并发时序；
- 容错行为；
- 安全边界外泄。

因此迁移前必须区分：

```text
DeclaredContract
ObservedBehavior
KnownConsumerDependency
UnknownExternalDependency
```

不能用“未文档化”推断“无人依赖”。

### 6. 语言特有语义不能被最低公分母吞掉

公共 IR 只承载真正共享语义。语言特有能力通过 typed extension 保留：

- Rust borrow/lifetime；
- Java class loading/reflection/memory model；
- TypeScript structural typing/runtime erasure；
- C/C++ undefined behavior、layout 和 ABI；
- Go goroutine/channel semantics；
- JavaScript event loop/prototype；
- SQL isolation and null semantics；
- GPU/SIMD memory spaces；
- hardware timing and interrupts。

如果目标后端不能表达某项源语义，输出 `UnsupportedPreservation` 或要求运行时机制，不能静默近似。

### 7. 跨语言 equivalence 的可判定边界

对任意程序的完全等价不可普遍判定。可用方法包括：

- 有界模型检查；
- translation validation；
- proof-carrying lowering；
- property-specific differential testing；
- metamorphic tests；
- reference interpreter；
- runtime assertions；
- abstraction relation；
- manual assumption acceptance。

结果必须保留方法强度。

### 8. 编译器 phase-ordering 与优化

不同 pass 顺序可影响性能、代码形态，甚至在缺陷或未定义行为下影响可观察结果。Pass Manager 必须：

- 声明 pre/postconditions；
- 证明或验证每次 lowering；
- 记录 pass 顺序和 revision；
- 对优化失败回退到正确基线；
- 不能把更快输出当作语义正确证据；
- 对不稳定优化保留独立 differential oracle。

### 9. 架构修订

TargetProgramIR 不再承诺是所有语言行为的终极统一语义。它是：

```text
SharedEngineeringSemantics
+ Domain/Language Semantic Extensions
+ PreservationObligations
+ TargetCapabilityRequirements
+ Explicit UnrepresentableFrontier
```

<a id="10-验收-7"></a>

### 10. 验收

- 每个后端声明 preservation kind 和 context；
- 未定义/未指定行为显式处理；
- FFI、内存模型、浮点和时间进入合同；
- 目标不能表达时拒绝或引入有证据的运行时；
- 跨语言测试不只比较文本输出；
- 外部未声明消费者进入迁移未知前沿；
- full abstraction 不被当作默认宣传语。
