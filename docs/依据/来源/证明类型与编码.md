# 证明类型与编码

> **阅读范围**：外部依据；保留原核查版本与证据边界。


本篇按实际机制保存来源或理论论证，保留各条自己的版本、前提及采用边界；它不是另一个现行产品合同。

## 证明、类型与编码边界

### CompCert manual，正确性与信任边界

**来源：** [CompCert manual](https://compcert.org/man/manual001.html)，正确性与信任边界。

**记录日期：** 2026-09-07、2026-09-08。

**支持的命题：** CompCert在规定源语言、目标与可观察行为模型及信任前提下证明编译保持。

**采用条件与边界：** 适用前提成立时可继承该结论；它不证明源已满足用户要求、不覆盖SEC新前端或全部时间和内存，也不使任意程序性质可判定。有限测试不等于这类形式证明。

**使用与维护位置：** [保证证据与验收][owner-assure]、[目标源码组织与生成策略][owner-target]。

### AGREE官方说明

**来源：** [AGREE官方说明](https://loonwerks.com/tools/agree.html)。

**记录日期：** 2026-09-07。

**支持的命题：** 特定架构模型中使用组件假设和保证作组合推理。

**排除项与适用限制：** 任意语义域或循环都可用同一个算法完整解决。

**使用与维护位置：** [共享语义关系与能力][owner-sem]、[保证证据与验收][owner-assure]。

### Lamport：A High-Level View of TLA+

**来源：** [A High-Level View of TLA+](https://lamport.azurewebsites.net/tla/high-level-view.html)，页面自述最后修改2021-08-10。

**读取日期与范围：** 2026-09-09，读取HTML中状态、行为、Init/Next、公平性、性质与细化部分；未据此读取其链接的PDF或执行TLA+工具。

**支持的命题：** 行为可作为状态序列描述；下一步允许发生什么与必须取得进展不同；不同抽象层可以通过明确的状态投影和性质连接。概率、多条行为之间的性质不等于单条状态轨迹的普通谓词。

**采用条件与边界：** 支持需求形状、状态/时间与非空进展的分责。不是要求全部SEC程序改为TLA+，不承诺一般性质可判定或自动生成实现；设备时间、资源和额外观察需进入实际模型。相交语义/观察域变化时复核，稳定逻辑命题可复用。

**使用与维护位置：** [跨软件意图合同](../../作者/组合/跨软件需求合同.md#cross-software-intent-contract)、[完整实例](../../../examples/连续开发/全工程连续开发.md#cross-software-author-example)、[保证证据与验收][owner-assure]。

### Alloy：文件系统模型与结构关系

**来源：** [Alloy Online Tutorial — File System](https://alloytools.org/tutorials/online/maintext-FS-1.html)。

**读取日期与范围：** 2026-09-09，读取对象/字段、parent/contents的关系约束、量化、可达性与树形约束；页面未给出本次使用的固定发行版本，不推导当前安装状态。

**支持的命题：** 声明parent和contents两个字段，不自动使二者相容；需要明确关系约束。共享数据结构还要说明可达、环和基数；约束模型可以欠约束或过约束。

**采用条件与边界：** 支持“字段和图并不自己产生结构含义”，用于逆关系、帧和跨对象检查；不把Alloy选成SEC默认求解器，不以有限实例分析代签全部运行规模、时序或资源。关系域、边重数和分析范围变化时重新判断。

**使用与维护位置：** [共享语义关系与能力](../../作者/共同语义关系.md)、[跨软件意图合同](../../作者/组合/跨软件需求合同.md#cross-software-intent-contract)、[完整实例](../../../examples/连续开发/全工程连续开发.md#cross-software-author-example)。

**采用条件与边界：** 继承记录覆盖相关定义，不表示全文证明已复核，也不表示SEC已完成TLA+证明或模型检查。

**使用与维护位置：** [保证证据与验收][owner-assure]、[理论边界与反例][owner-theory]。

### SMT-LIB Ints，2.7页面，最后更新2026-01-16

**来源：** [SMT-LIB Ints](https://smt-lib.org/theories-Ints.shtml)，2.7页面，最后更新2026-01-16。

**记录日期：** 2026-09-07。

**支持的命题：** 非零除数采用欧几里得商余；与SEC向零截断不同，因此模型到求解器要有明确映射。

**排除项与适用限制：** 求解器正确就证明翻译正确；把未定义/未约束div0解释成业务值。

**使用与维护位置：** [验证方法与故障设计][owner-verify]、[语言体系与开发规格][owner-lang]。

### Unicode17.0第3章D76

### Dafny Reference，活动手册

**来源：** [Dafny Reference](https://dafny.org/latest/DafnyRef/DafnyRef)，活动手册。

**记录日期：** 原函数命题2026-09-07；frame、modifies和require/ensure定义性相交内容复核于2026-09-09。不是固定发行版本或本地安装事实。

**支持的命题：** 函数值的requires/reads及eta包装；总/部分箭头、归纳数据类型。Frame描述可读取/修改的位置；写入后恢复与不发生写入是不同条件；require/ensure的先后可能影响表达式定义性。

**采用条件与边界：** 用于精确区分NoWrite与终态等值、要求含义与检查方案。SEC没有采用Dafny全部语法/类型/验证器，也不由读到手册宣称SEC具有证明；没有重审整本手册或运行示例。改变heap/别名、异常和可观察写入模型时重核适用性。

## 有限逻辑与统一合成目标

**读取日期：** 2026-09-10。以下均读取原始HTML页面的指定部分，未下载页面链接的PDF标准、运行求解器或声明本机安装版本。

**Alloy Quantifiers。** [官方教程](https://alloytools.org/tutorials/online/sidenote-quantifiers.html)说明all在空域上为真、some在空域上为假，并展示嵌套量化。用于核对有限结构的量词、空域与作用域，不将教程建议的嵌套深度变成SEC的固定语法配额，不把有限模型分析推成无限行为保证。

**SyGuS Specification Language。** [官方HTML页](https://sygus-org.github.io/language/)的max2例将候选文法与针对同一待合成函数的语义约束分开。用于校准“一份实现必须满足全部接受条件”，不采用其文本语法为SEC作者入口，不证明任意开放需求均可自动合成。页面所链接标准的版本号不代表本包已实现该标准。

**SemGuS Front-End Language。** [官方语言说明](https://www.semgus.org/language)的语义定义、元数据和Synthesis Objective Specification分别说明产生式含义、realizable注记不得用作求解真值、以及一个待合成项须满足全部约束。页面同时区分例子约束与逻辑量化条件。用于防止多样例不同程序、标签自证和逻辑模型冒充完整实现；这里未采用其命令语言，也没有使用页面后半部命令式程序例作SEC动态语义依据。

**SEC的实际取舍。** 有限条件/量化的结构表示、优先级未知处理及禁止选择性删偏好，是本规范给出的设计决定；外部材料不替它们签发正确性或性能结论。精确字段由[结构源](../../作者/结构化源码.md#finite-requirement-composition)拥有，联合算法由[实现选择](../../编译/实现选择与设计搜索.md#scoped-realization)拥有。
