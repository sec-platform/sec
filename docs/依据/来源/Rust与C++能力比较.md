# Rust 与 C++ 能力比较索引

> 研究定位索引，不是第二套规范。详细差额、替代路线、硬边界与验收已经融合到[原生能力映射](../../编译/原生映射/README.md)；来源、版本和稳定性见[映射依据](Rust与C++映射依据.md)。

核心裁决：Rust 不是“C++ 减去 64 个有用能力”；另一种设计能完成业务也不等于固定 API/ABI、地址、布局、进展、数值环境或工具链条件下无损替代。已有成熟能力足够时直接采用，真实硬条件仍不满足时才新增局部语义或报告缺项。
