本目录保存供SEC设计、实现选型和边界判断使用的来源命题。来源支持到什么范围、SEC决定采用什么以及实际实现了什么，分别记录；不把参考目录变成另一份语言或产品规范。

## 研究结论的保存复用与失效协议

维护对象是**来源中的具体命题及其工程使用点**，不是只列URL，不按助手轮次整理。全部来源采用同一规则，CUE、语言规范、编译器、包工具、存储、协议、设计方法与备选资料没有不同待遇。每次修改或审查一项机制，执行者主动检查相交来源；用户点名某项资料不是触发维护的必要条件。

### 记录的最小完整含义

每组记录保留原始定位、实际读取/记录日期及版本角色、支持的命题、采用条件与排除推论、使用与维护位置。已有语义、算法、代价和反例只在其拥有者完整维护，来源条目不复制它们。一个来源可支持几个不同命题；几篇网页若复制同一原始材料，仍是一条来源链。

**记录日期不等于最后语义审查日期，更不等于当前安装版本。** 原记录缺日期就明确保留未记录；不能通过本次整理给所有旧材料补一个“已复核今天”。URL里的latest/master、活动文档和工作草案需在记录中保留该角色，不伪称固定发行。实际版本无公开证据时，只用它已支持的机制，不凭搜索摘要填版本。

“使用与维护位置”表示哪个规范使用该命题、比较或反例并承担相交复核，不等于该外部软件已经采用。仅供备选比较的记录由D理由维护；产品实际调用或生成依赖由对应Adapter/Binding负责。源文件、普通函数和作者提示不需要逐次携带这一目录。

### 每次变更执行的R0—R7

| 阶段 | 正常动作与形成的结果 | 不充分时怎样继续 |
|---|---|---|
| R0 提取实际变化 | 从要求、语义、接口、目标、运行假设和本次动作取得变化集；不是只取关键词 | 当前范围不明先从已取得要求恢复，不能要求用户重复提醒 |
| R1 取得相交命题 | 按本目录的使用位置、机制主题及实际入链取来源；补查更小替代、失败与不兼容记录 | 没有来源不立即认为错误，也不假设成熟常识已验证；登记所缺命题 |
| R2 分清复用状态 | 比较原版本/前提/用途和当前需求，判断可复用、需重新判断适用、需外部复核、被反证或仅有线索 | 未读、不可访问、旧测试、活动版本和精确规范是不同状态 |
| R3 定向取得原始材料 | 对确有变化、实际采用或决定性不确定的内容读取相应章节；保留真实版本、范围及共同来源 | 访问失败只说明未取得；允许完成不依赖该事实的设计，不宣称当前能力已证实 |
| R4 重新裁决使用 | 先判命题是否仍成立，再判是否足以支持SEC当前用途；形成采用、拒绝、条件适用或具体未知 | 上游文档变化不自动改用户要求；同URL没有变化也不能免除用途变化的审查 |
| R5 同步消费者 | 改相交规范、例子、图、D决定和U剩余；保留独立错误/边界；删除竞争的旧规则 | 不能只在来源条目末尾追加“新结论”，而保留调用方旧假设 |
| R6 做目录自检 | 检查本次新增/修改命题以及全目录的来源、日期缺口、归属和去向；合并真正重复 | 结构通过不证明所有命题正确；既存未知仍保留，不能新建空日期或虚假采用 |
| R7 交付准确范围 | 说明本次实际外部复核、继承范围、已定设计及真实残余；下一任务按同一规则启动 | 没有部署后台进程就不说全天监控；文档链接不等于客户端已经自动读取 |

当前实现方式是已有Markdown来源段落、实际消费者与文档变更检查；无需先开发ReferenceManager、全量爬虫、规则数据库或永久检索日志。自动化可派生索引并检查结构，具体命题的适用与相反证据仍按实际方法裁决。该流程作用于设计工作，不进入用户程序每个函数的运行路径。

### 不同信息怎样触发复核

| 来源或变化 | 默认处理 |
|---|---|
| 固定版规范、数学定义，前提和用途均未变 | 复用原命题与理由，不无故重读全文 |
| 固定规范相同，但新增回调、控制出口、目标、资源或安全假设 | 重新核适用性；用新的区分反例检查，必要时读取相交原文 |
| 活动API、发行支持、弃用、安全公告或实际工具选择 | 在实际采用或作当前事实声明前外部核验；不沿用旧“当前版本” |
| 安装、权限、设备、网络、性能和执行结果 | 由真实环境与方法取得；网上规范和模型判断不代签 |
| 来源移动、撤回、矛盾或只剩摘要 | 保留已取得的历史范围；重新定位原材料，降低无依据的新断言 |
| 技术备选未采用且没有相交用途变化 | 保留比较理由，不为防遗忘把它加入发行和实现队列 |
| 新的来源与旧来源同源 | 合并来源链与独立命题，不把转载和重复读取算作第二份验证 |

对语法和语言机制，修改一个构造要检查绑定、类型、效果、退出、清理、阶段和目标这些实际交点。对上游库，修改其调用也要检查输入域、配置、ABI、默认、错误及生命周期。未修改的稳定命题无需在每轮联网复核；“必须主动管全部资料”不等于每轮无理由重搜全部互联网。

已有[HTTP缓存或条件请求](https://www.rfc-editor.org/rfc/rfc9110.html)只能减少传输；不能单凭304、弱ETag或页面没变就认证字节身份、命题正确或用途适配。原始秘密与私有工程不为了核资料发送给公共服务。


## 来源记录的适用范围

本目录承接已有资料记录，不表示所有页面已在同一时点重新核验。记录日期只说明材料范围；未记录日期的条目明确标识。活动页面中的版本或“当前”仅属于原记录，实际采用必须核对所需版本和环境。“排除项与适用限制”中，正向断言列出该来源不足以支持的结论，否定句保留其字面限制；不能反向解释成SEC应当满足的要求。

完整网页、逐轮检索过程、失败查询、旧仓库快照和打包统计不进入规范。精确来源和当前采用理由足以让后来工作按条件复用；特定实验、事故或迁移事实由其实际证据承担。


## 采用与复用的责任

平台原语由适配层消费；可替换机械能力用明确的提供者合同接入；只提供设计启发的机制不自动引入软件依赖；用户目标程序的库不自动成为 SEC 控制面的依赖。实际引入代码、模板或图表前，检查对应许可、通知和分发条件。来源目录本身不签发安装、实现、组合正确或工作区写入资格。
