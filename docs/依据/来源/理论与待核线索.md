| Alexander Shen，[Around Kolmogorov complexity: basic notions and results](https://arxiv.org/pdf/1504.04955)，arXiv:1504.04955v1，2015-04-20 | §3 Theorem 1及§4构造，PDF第3—4页（索引2—3）；§6 Theorem 3，PDF第5—6页（索引4—5） | 存在相对于全部部分可计算解码器、仅差依赖比较解码器的加法常数的最优解码器；普通复杂度不可计算。不是逐实例零常数最优，也不提供可计算的最短编码选择器。 |

## 理论线索与使用边界

下列线索只有在取得精确命题、模型和原始定位后，才能作为决定性依据。没有逐项文献定位的条目属于待定位知识，不冒充已阅读原论文。数学约束必须使用其前提；一般不可判定性不能直接推出具体编译、导入或转换不可完成。

这些线索的共同维护位置是[理论边界与反例](../理论/README.md)和[验证方法](../../运行/验收/方法与独立证据.md)。目录的“机制”列是待精确核验的摘要，不能因列了学者或定理名就作为阻止工程、缩小目标或增加门禁的决定性依据。实际消费者需要该命题时，按R0—R7取得模型、条件和原始定位，再转为已记录命题；未取得时继续保留线索身份。

### 1. 计算、学习与优化边界

| 来源 | 机制 |
| --- | --- |
| Rice 型程序性质不可判定结果及其抽象解释推广 | 一般非平凡程序语义性质不能同时获得总终止和完全正确的判定器；sound approximation 必然可能产生假阳性 |
| Manuel Blum，算法加速理论 | 存在没有最终近似最优算法的可计算问题，否定普遍“终局最快实现” |
| Wolpert 与 Macready，无免费午餐理论 | 优化器优势依赖问题分布和先验，不存在跨所有目标分布的普遍优越搜索器 |
| E. Mark Gold，极限识别 | 从有限或受限正例中不能对广泛语言类普遍识别真实生成规则 |
| 混合系统 reachability 研究 | 即使线性混合系统的一般可达性也可不可判定，实际工具依赖有界、近似或 delta-decision |

### 2. 分布式与协调边界

| 来源 | 机制 |
| --- | --- |
| Fischer–Lynch–Paterson | 完全异步且一个进程可故障时，确定性共识不能保证终止 |
| CAP 形式结果 | 分区发生时，强一致与每请求可用不能无条件同时保证 |
| 不可靠 failure detector 研究 | 沉默不能可靠区分崩溃、延迟和分区 |
| Chandy–Lamport 一致切面 | 分布式系统可记录一致全局切面，但这不是同一物理瞬间的直接读取 |
| 协同攻击与共同知识研究 | 不可靠通信下有限消息交换不能普遍产生协调所需的共同知识 |

### 3. 形式验证与可信根

| 来源 | 机制 |
| --- | --- |
| Gödel 不完备性 | 足够强的形式系统不能在自身内部完成所有真命题证明，并不能以通常方式完全自证一致性 |
| seL4 proof assumptions | 高强度机器证明仍依赖汇编、硬件、boot、DMA、配置和未建模侧信道等假设 |
| Ken Thompson，Trusting Trust | 被污染的编译器可以在源码干净时继续传播后门，要求多样化自举和二进制验证 |
| CompCert 与 translation validation 研究 | 可对特定语言、编译器和性质证明语义保持，但范围和外部环境必须精确绑定 |

### 4. 控制、复杂性和组织

| 来源 | 机制 |
| --- | --- |
| Ashby 必要多样性定律 | 调节者需要足够响应多样性，但这不等于无限策略或完全控制 |
| Conant–Ashby Good Regulator | 有效调节器必须包含被调系统的某种模型，模型遗漏会限制控制能力 |
| Bode 灵敏度积分与水床效应 | 在受限控制系统中，某些区间的抑制会转移为其他区间的放大 |
| Rohrs 等自适应控制反例 | 未建模动态可以使理论上良好的自适应控制器失稳 |
| Perrow 正常事故理论 | 交互复杂与紧耦合会产生难以预测和隔离的组合事故 |
| Herbert Simon 有限理性 | 决策者受信息、计算和认知限制，现实中常只能满意化而非全局优化 |

### 5. 社会选择、博弈与指标

| 来源 | 机制 |
| --- | --- |
| Arrow 不可能性 | 多主体偏好聚合无法无条件同时满足一组自然公平条件 |
| Gibbard–Satterthwaite | 足够丰富的确定性社会选择规则通常可被策略操纵 |
| Myerson–Satterthwaite | 私有信息双边交易中，效率、激励相容、个体理性和预算平衡不能普遍同时满足 |
| Goodhart/Campbell 系列效应 | 指标成为控制目标后会被操纵并失去与真实目标的稳定关系 |
| performative prediction / strategic classification | 预测和政策改变参与者行为，使数据分布与模型目标反身变化 |

### 6. 安全、隐私、公平与语义保持

| 来源 | 机制 |
| --- | --- |
| 公平性不兼容结果 | 不同公平指标在常见条件下不可同时满足 |
| 差分隐私下界和无普适最优机制 | 隐私、精度和查询族之间存在结构性成本，通用最优机制通常不存在 |
| 全抽象与 robust compilation 研究 | 跨语言安全/行为保持依赖目标上下文和攻击者模型，不存在无条件统一语义保持 |
| Spectre/Retbleed 等 | 微架构观察通道可以突破架构级抽象和既有缓解假设 |
| seL4 confidentiality assumptions | 信息流证明只覆盖模型可见通道，不能自动排除 timing channel |
