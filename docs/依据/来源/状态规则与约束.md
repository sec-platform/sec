# 状态规则与约束

> **阅读范围**：外部依据；保留原核查版本与证据边界。


本篇按实际机制保存来源或理论论证，保留各条自己的版本、前提及采用边界；它不是另一个现行产品合同。

## 状态、规则与活动

### SCXML 1.0 Recommendation，2015-09-01；勘误页，页面最近更新2016-12-28

**来源：** [SCXML 1.0 Recommendation，2015-09-01](https://www.w3.org/TR/2015/REC-scxml-20150901/)；[勘误页](https://www.w3.org/2015/08/scxml-errata.html)，页面最近更新2016-12-28。

**记录日期：** 2026-09-08。

**支持的命题：** 层级/正交、冲突、内外转移、历史、微步和run-to-completion有明确不同规则；附录D为informative。

**采用条件与边界：** 基本拓扑和次序作机制参照。SEC选择精确事件名、纯计划及相关性完成通知，因此不声称与完整SCXML等价；使用新数据模型、错误或invoke时重新核相交规范。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[编译内核与生成][owner-comp]。

### W3C实现报告，版本2015-03-10

**来源：** [W3C实现报告，版本2015-03-10](https://www.w3.org/Voice/2013/scxml-irp/)。

**记录日期：** 2026-09-08。

**支持的命题：** 目标是实现性和互操作；明确不作实现符合性测试；断言与数据模型转换有范围。

**采用条件与边界：** 复用同域断言和正常/负面样例设计，不将旧项目结果认证SEC；测试许可和实际使用方式按原链接处理，本文不复制测试包。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[验证方法与故障设计][owner-verify]。

### Sismic 1.6.3执行语义

**来源：** [Sismic 1.6.3执行语义](https://sismic.readthedocs.io/en/1.6.3/execution.html)。

**记录日期：** 2026-09-08。

**支持的命题：** 同源竞争可报非确定错误；正交动作的次序与SCXML不全相同。

**采用条件与边界：** 作为强竞争解释检验“所有状态机都可互换”的错误。采用具体引擎时验证其语义，不根据名称或功能清单认定符合。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[宿主生态与技术约束][owner-host]。

### Qt SCXML总览、生成工具、SCXML符合范围，活动页面标Qt 6.11.2

**来源：** [Qt SCXML总览](https://doc.qt.io/qt-6/qtscxml-index.html)、[生成工具](https://doc.qt.io/qt-6/qscxmlc.html)、[SCXML符合范围](https://doc.qt.io/qt-6/qtscxml-scxml-compliance.html)，活动页面标Qt 6.11.2。

**记录日期：** 2026-09-08。

**支持的命题：** 可动态加载或生成C++类；实际支持的数据模型、invoke、表达式和I/O有界。

**采用条件与边界：** 可作为选定Qt/C++画像的成熟实现，不强迫TS/Java引入Qt。页面标签不等于SEC已安装版本；发生版本或使用能力变化时局部复核。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[宿主生态与技术约束][owner-host]。

### XState invoke、guards，文档站顶部标v6 alpha

**来源：** [XState invoke](https://stately.ai/docs/invoke)、[guards](https://stately.ai/docs/guards)，文档站顶部标v6 alpha。

**记录日期：** 2026-09-08。

**支持的命题：** 状态拥有调用生命周期；短暂进入后离开的状态不启动相应调用；guard是同步纯判断。

**采用条件与边界：** 用于检查生命周期和回调接口，不默认采纳alpha实现。停止接收Promise结果与物理I/O停止是两个承诺；真实停止由提供者和资源协议承担。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[本地流背压与事件时间][owner-stream]。

### Camunda DMN命中政策（读取页面标8.9）

**来源：** [Camunda DMN命中政策](https://docs.camunda.io/docs/components/modeler/dmn/decision-table-hit-policy/)（读取页面标8.9）。

**记录日期：** 2026-09-07。

**支持的命题：** Unique与First不同，多个相同结果也不使Unique成立。

**排除项与适用限制：** SEC已支持全DMN，或本文所有自定求值规则由DMN自动提供。

**使用与维护位置：** [事务应用与交付作者规格][owner-tx]、[层级状态与事件反应][owner-state]。

### Temporal Side Effects

**来源：** [Temporal Side Effects](https://docs.temporal.io/develop/go/workflows/side-effects)。

**记录日期：** 2026-09-07。

**支持的命题：** 记录非确定结果与回放再执行区别。

**排除项与适用限制：** 普通函数必须写历史，或它认证任意外部副作用一次。

**使用与维护位置：** [层级状态与事件反应][owner-state]、[持久化提交与恢复][owner-rec]。

### Temporal Retry Policy

**来源：** [Temporal Retry Policy](https://docs.temporal.io/encyclopedia/retry-policies)。

**记录日期：** 2026-09-07。

**支持的命题：** 活动与工作流重试责任分开，策略不是无限安全重发。

**排除项与适用限制：** SEC采用其所有默认预算，或重试必然成功。

**使用与维护位置：** [权限执行与资源管理][owner-exec]、[持久化提交与恢复][owner-rec]。
