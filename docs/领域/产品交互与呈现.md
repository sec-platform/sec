# 产品交互、呈现与媒体空间边界

本篇拥有生成产品按需使用的交互领域语义，不拥有Gift开发工作台布局，也不要求所有产品采用统一ViewTree、GUI或特定框架。原生React/Compose/Flutter等来源可以继续拥有实际组件；现有[有限交互成品](../作者/成品/交互应用.md)保留自己的离线默认、状态、保存和平台差异。以下公共区别只在实际产品选择它们时进入依赖，具体方法、目标、资源和证据由原拥有者取得。

<a id="product-input-and-validation"></a>
## 输入、校验与真实动作

呈现区域、路由、表单、动作、设备输入、焦点、校验及到产品状态的有型绑定各有准确实例身份。视图标签、DOM位置或路由字符串不是业务对象身份；呈现的绑定也不获得实现绑定的写权。作者定义修订、用户会话状态、未保存草稿和真实服务状态分开拥有。

输入关联控件、输入代及当前值基础；数值/日期/单位按选定codec与locale解析，原编辑串与合法值分开。暂时非法的草稿不能自动改零或空。文本模型身份、模型版本、IME组合代、选区/光标、行列编码与视口布局修订也分开；临时合成不是已提交正文。未经目标策略允许不在组合中提交、重复保存或拆写字符串。位置范围说明UTF-8/UTF-16/标量/行列及行末约定，并绑定实际文本版本；像素坐标不能当永久文本位置。

局部/远端校验、补全、语言服务、搜索与数据结果绑定请求、文档/输入版本、读取范围和提供者会话代。编辑后旧结果只能作为旧观察，不得覆盖新有效性或抢回焦点。用户接受的预览计划与实际提交的计划是同一代；提交前仍核资源前像，不点击后重算另一批编辑。取消撤采用资格不证明远端停止，关闭面板也不撤销已发出的业务动作。

动作按真实命令状态区分未发送、已受理、实际应用、部分与未知。只保存一个字段不清空整个表单宣称成功；重开按原命令身份和回执恢复，不重放按钮点击。独立产品使用自己的真实命令/日志拥有者，经Gift执行的动作才沿相应Gift操作取得授权与结算，不能为形式统一伪造操作事实。

<a id="product-accessibility-and-locale"></a>
## 焦点、可访问性与地区化

目标映射语义角色、可访问名称/说明、状态、键盘操作、焦点顺序/模态约束、替代输入和错误关联。布局优化若改变阅读顺序、焦点、可交互区域或状态播报就是可观察变化；批渲染/事件合并不能只以最后画面相同证明中间提交或辅助反馈可删。列表虚拟化换绑主体时不得沿用旧草稿或确认；异步焦点恢复按对应语义目标，目标不存在时执行明确回退。隐藏控件不能代替服务端授权。

实际可访问性要求绑定设备、键盘/辅助技术、标准版本及覆盖。自动扫描、静态标签、真实屏幕阅读或键盘任务是不同依据，不以一个role/aria属性签发全体可用。SSR/hydration核初态、资源、locale与事件绑定，不匹配时不能静默接上错误控件。目标缺必要输入方式时报告相交缺项或已接受替代。

地区化绑定翻译/插值/复数、脚本、字体、历法、数字/单位/货币、排序、RTL与缺项回退。locale不自动选择法域、策略、币种、时区或身份。Instant、LocalDate与显示时间分型；无效或歧义本地时间按准确规则拒绝或选择，时区数据库版本属于日程解释。切换locale不能静默重解释持久金额或编辑串，显示排序也不改变业务身份或规范顺序。

<a id="product-media-timeline"></a>
## 媒体时间与连续性

媒体方法固定容器/codec版本、采样/帧率、timebase、颜色空间/范围、声道、压缩损失与同步来源。展示、到达和解码时间不同；变帧率不能由平均fps重建时间戳，位宽相同不证明颜色相同，样本数相同不证明时长/声道相同。

缓冲上界、背压、丢帧、降码率、重采样和质量/延迟由接受合同固定。有损变换不能作为性能优化暗改质量；实时与离线可以有不同恢复目标。跨设备在真实fence前不释放缓冲；seek、断流、codec重配和epoch区分旧新时间线。恢复从有资格关键帧/音频边界及完整状态继续，不把已经直播输出重播而不标重复。素材许可、设备权限和解码器依赖各自检查，代码生成不创造权利，mock帧不能证明实际编码质量。

<a id="product-spatial-geometry"></a>
## 空间、几何与渲染资源

空间输入固定坐标系、手性/轴/单位、变换方向、对象身份、拓扑、精度和退化域。地理或随时间变化的参考框架还固定基准、投影、参考历元与变换适用域；单位与数值相同不证明同一位置，不同Provider各自最新也不证明同一空间/时间切面。点、向量、法线、齐次与地理坐标分别解释；复合顺序不由shader布局决定。几何布尔/碰撞/最近点的容差与退化处理由实际问题固定，不能通用硬编码epsilon。视觉相似不证明几何关系、遮挡顺序或CAD拓扑正确。

场景所有权树与共享引用/实例分开，复制实例不自动复制可变资源。缓冲、纹理、材质和shader有版本、寿命与同步，重配后旧资源等真实最后使用结束再释放。实时画面近似、物理碰撞精度和制造拓扑各有独立主张。缺特性、device-lost或精度不足时使用已接受回退或拒绝，不以占位图标目标完成；坐标/单位迁移保留原精度、对象修订和新旧观察对应。物理用途另读[模型族](仿真/模型族与适用边界.md)和[制造寿命](物理对象制造与寿命.md)。

## 再次修改与资格

交互框架和目标适配承担结构、行为、可访问性、资源/效果、错误与来源映射；无法表达的原生事件保留其真实边界，不变成unknown后输出stub。原生源与工作台私有模型不得同时手写同一事实。布局、预处理、地区资源、codec、设备、坐标或规则变化时仅沿真实消费者重评，但不能用纯状态测试或页面预览代签真实renderer、IME、键盘/辅助技术、重连、媒体/几何后端或发布效果。
