# 学习数据、模型与采用生命周期

本篇拥有按需采用的学习领域合同，区分数据/特征、训练、推理、评估、监测和模型采用。它不新增所有工程必须安装的训练框架、模型服务或全局管理器，也不让模型自由补完确定性编译。有限精确算法仍由[模型、概率与优化成品](../作者/成品/模型概率与优化.md)拥有；数量/随机由[定量合同](计算基础/定量合同与误差传播.md)拥有，实际授权、资源、作用结算与证据接纳继续沿原运行合同。

<a id="learning-data-and-feature-basis"></a>
## 数据、特征与模型的准确来源

数据集绑定真实成员或可重建读取切面、schema、单位、样本单位、时间/来源、允许用途、标注依据、缺失/筛选规则与训练/验证/评估分割。名称或URL不足以重建数据集；大数据可以用范围明确的不可变清单、分区和受信摘要，不强制每次复制全量。

特征绑定变换定义、参数及其拟合数据、预处理版本和输入输出类型。拟合均值、分词、归一化和标签生成也有真实读集，不能只保存最终权重。先在全部样本上拟合均值再划分数据，与只在训练分区拟合具有不同信息基础；同主体、时间和预处理泄漏不能靠文件名分开。

模型修订绑定结构、权重/编码、训练或提供者来源、输入输出、预处理、目标与设备要求、许可和已取得的支持；可变 `latest` 指针不构成准确模型身份。外部服务仅承诺不透明版本时如实保留其有限保证，不虚构权重可取得、可复现或每次调用使用同一内部模型。模型版本相同但分词器/特征版本不同不构成同一推理。

原样本、向量、索引、诊断、权重与日志的用途、披露和保留分别按真实来源与政策判断。删原文不自动消除成员推断或派生泄漏；权重字节未变也不证明授权持续有效。来源撤销影响后续使用与资格，历史对象仍保留其原前提及合法事故/恢复责任。

<a id="learning-operation-contracts"></a>
## 训练、推理、评估与监测

训练固定数据/分割/特征、模型初态、超参数、优化方法、目标函数、停止条件、随机来源、数值/设备/工具链解释及预算。输出候选模型、训练/停止观察和真实产物来源；正常提前停止、预算耗尽、数值故障、读取失败、条件收敛及质量不合格分别表示。函数成功不证明泛化或产品目标成立。

推理固定准确模型/预处理、输入域与批次、输出解释、近似/随机/质量条件、延迟/费用和拒绝/回退规则。预测、置信或校准说明、域外拒绝、缺数据和模型故障不压成一个分数。分数只有在相应模型/数据/校准前提下支持限定主张，不默认是真实概率。缓存共享需要实际确定性、读集、用途和隐私条件；同种子不能替代线程、设备、算法和环境确定性依据。

评估固定总体与样本框、指标/分母/单位、切片、基线、统计与不确定性解释、数据和方法。训练指标不能代签未见数据表现；同错标注或同模拟标签训练的多个模型给出相同答案，不是独立真实性依据。总平均不能掩盖被要求的分群质量、安全或公平条件。

监测绑定真实运行分布、测量覆盖、窗口、告警规则与外部观察。漂移或域外输入使相交资格重评，可以按已接受策略转已核规则/旧模型或交接；告警本身不批准重训、收集新用途数据或更新线上模型。延迟、内存和吞吐分别绑定工作负载与目标，不能靠一个总分替代独立硬条件。

<a id="learning-adoption-and-recovery"></a>
## 候选采用、在途请求与恢复

训练完成只产生候选。采用绑定不可变模型包、依赖、schema、分群依据及目标资格；版本切换独立确认输入输出兼容、在途请求、资源/状态和回退。新模型引用不把旧会话缓冲或旧评估无条件迁给新模型；新源码也不热改旧实例。无源可取时报告准确缺项或有限服务资格，不以同名近似模型隐藏替换。

检查点保存方法真正需要的参数、优化器/调度状态、随机状态、数据位置及解释绑定。只有权重不等于完整恢复点；恢复兼容由实际方法与模型、数据和环境判断。重跑纯局部计算与重发计费训练、部署或外部调用按各自原作用合同处理。数据、标签或特征变更沿真实读集失效相关主张与评估，保留旧修订的历史解释。

回滚模型只恢复指定模型和配置，不撤销已经发出的判断、订单或设备动作。事故纠正保留真实影响及后续路径；授权撤销不能被匿名字符串或旧缓存绕过。隐私、现场安全和认证由相应真实专业/权威依据决定，本篇不签发训练数据许可、监管资格或任何框架/硬件的运行支持。

## 消费与验证范围

作者定义、实现选择、目标/制品、运行采用与保证分别消费以上合同，不复制一份可独立漂移的模型当前状态。评估至少能区分预处理泄漏、权重/特征错配、域外输入、同源标签、选择/停止、检查点恢复、版本切换及回滚后既有效果。哪些需要运行证据由准确实例决定；本文存在不证明真实模型、数据、指标或部署已经取得。因果推断另读[实验识别](仿真/测量校准与实验.md#causal-identification-and-intervention)。
