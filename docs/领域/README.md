目录记录已定义语义族，不是意图的封闭集合。新目标保留原内容、所需观察及未确定含义；能无损组合时复用，无法保留独立区别时回原语言/领域扩展。接入、保全与多角色路由见[信息分类](../信息/信息类别与生命周期路由.md)；原文可保全不等于可执行。[四种能力](计算基础/通用计算与任务语义.md#四种经常被混淆的能力)区分计算表达、语义扩展、目标实现与保证；有限画像的严格拒绝只限制该画像使用，不删除原意图，也不强迫改成另一含义。原文可保存、程序可编码或目录有同名领域均不证明要求已被解释或满足。
