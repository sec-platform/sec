# 仿真模型族与适用边界

不同模型族可以共享时间、输入、资源和观察接口，不因此共享全部推进、状态或验证语义。[仿真规范入口](README.md)区分正式机制与下列适用性目录。方法名仅指候选路线，不证明已经接入或验证。

以下逐族图展开本篇已列对象、方法选择、失败与验证边界，不为这些候选方法补造已发布算法或已取得保证。运行统一消费[接受步、检查点与退出责任](时间推进与状态恢复.md#simulation-progress-and-checkpoints)；实际设备作用另走[现实控制入口](联合仿真与现实控制.md#real-control-response-boundary)。各族的模型检查通过、数值／统计结果、实际设备符合与任务用途资格分别判断。

```mermaid
flowchart TB
  model["固定本族模型、初态、时间、方法、用途与当前支持范围"] --> admit["原运行入口核权限、资源、预算、取消及方法恢复资格"]
  admit --> attempt["按下列准确模型族推进；不因同一接口混用不同算法"]
  attempt --> accepted["只发布该族完整接受切面及准确结果／未决范围"]
  attempt -->|失败／取消／耗尽| retained["保留最后接受切面、真实原因与仍在使用的资源"]
  accepted --> last["核求解器、设备、通信、观察及历史的真实最后使用"]
  retained --> last
  last -->|实际停止或合法移交| release["释放相交资源；可恢复状态按原检查点合同保留"]
  release --> report["结果资格、恢复能力、现实效果与资源退出分别报告"]
```
