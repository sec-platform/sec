# 扩展语义的实施选择与适配边界

本篇给原开放领域作具体的当前实施选择，供原U009、U028—U030、U038—U041、U049、U066引用；不建立另一门语言。有限既有合同继续由原领域规范拥有。共同扩展走MethodSpec、UseBinding与LoweringResult，原生程序可以直接提供见证。选择一条算法和边界不等于已经证明所有数学前提、取得实际硬件或运行符合性。

## 1. 高级类型、生成器和资源

结构意图的名义类型、主体/值角色、闭合默认、公开主体及有限逻辑组合保持。原生供给内的高阶泛型、trait/typeclass、装饰器、反射、生成器和协程首先由其实际语言前端解释；公共边界暴露能准确消费的签名、效果、资源与行为，不把这些构造先重写成新的.sec文本。原计算画像仍采用显式秩一泛型、有限实例化和双向检查，无隐式let泛化；不能将该局部限制施加给保全的全部原生源。

原生生成器边界明确为“创建句柄不等于执行主体；next/send/throw/close按实际协议改变一次状态”。每实例只允许其协议认可的在途推进数；暂停持有资源直到实际结束/关闭/移交；send值、产出、最终返回、业务异常与取消分别有类型。需要JS Iterator或其他语言专用yield语义就保留其准确合同，不用通用Task假装等价。复杂借用跨暂停时，只有资源真实寿命覆盖暂停和恢复才准入；不能提升父栈Borrow到永久句柄。

无GC目标的循环对象采用两条明确方法：可静态证明独占树/无环拥有图时使用确定析构；任意循环对象限定到显式区域/arena，外部引用是拥有区域或带代际验证的句柄，区域内边不各自重复持有区域。销毁区域前停止准入并核实际外部/在途借用。需要任意单对象回收且保留强循环时，选择真实追踪GC或显式打断/弱边方法；不能仅引用计数而声称无泄漏。区域释放不能抢先释放设备仍在使用的缓冲。

## 2. 动态状态拓扑和异步状态

有限层级/正交状态继续用原run-to-completion宏步和私有后继。动态拓扑不原地修改已执行的定义：请求新结构，固定所有状态/事件/计时的对应；进入安全切面后暂停相交事件准入并缓存有界新事件；转换活动状态、历史和未结算活动；校验新拓扑；实际拥有者切换后按明示顺序重放缓冲。缺映射的状态由已接受的退出/初始化策略处理，缺必要策略则拒绝切换并保留原运行。

跨节点不将“宏步”宣称全局原子。需要强序时采用一个真实协调日志/权威拥有者及明确故障模型；分布式参与者按版本和幂等执行实际外部动作，失败可保留未完成成员。离线自治采用独立状态及明确合并规则，不同时宣称全局单序。SCXML互操作先选定可映射状态、事件、数据及I/O集合；不认识的可保全，但不能通过全SCXML兼容声明。硬截止另按第4节，不由状态图决定。

## 3. 递归关系、删除与隐私

默认精确关系执行采用有限活动域、bag/set与顺序分别规定；正递归要求单调推导并求最小固定点。含否定时选择**可分层**规则：负依赖必须指向较低层，低层封存后才计算上层；否定中的变量必须先在正域中被绑定，不能由缺席推导无界取值。负循环拒绝精确画像。非单调聚合只在相应递归分量外或已有可证明单调的有界格方法中使用。无限增生规则不能因每一步成功就宣布可结束，预算退出保留未完成。

首次正确实现可对受影响SCC从本次准确输入重新求值；成熟差分方法合格后再替换。删除必须从底或采用健全的支持计数/推导维护，不能只保留旧可达项而自证。源混合版本、越权行和排序缺失各按原数据合同拒绝或减弱声明。SQL方言复用真实数据库语义，NULL/三值逻辑、排序、时区、重复、数值和事务隔离不能默默改成中立默认。

隐私统计不是返回一个噪声值就完成。每种方法需固定相邻数据集关系、敏感度/裁剪、噪声分布、隐私预算与组合规则、随机源及数据权限。预算由真实拥有者在结果披露前原子扣取；失败/重试是否已披露按记录查回，不能重复采样多次选最好看结果。没有合格预算拥有者不提供累计隐私保证，仍可提供被明确允许的非隐私精确任务。具体数据的裁剪范围和预算是接受政策/事实输入，不代用户编造。

## 4. 分布式事件时间、在线迁移和硬实时

精确前沿需要每个来源声明“未来不会再出现低于该下界的事件”的真实依据。协调器固定成员代与每源消费位置；只有相关数据和该位置的控制记录均已接纳，才发布相应前沿。成员加入先追至已声明切面，再参与后续前沿；退出必须实际关闭该源未来输入资格并结算已接纳数据。仅静默超时的源不能当作正无穷，否则迟到事件会被错误丢弃。无可靠下界时用估计水位及明示修正/丢失合同，不称精确最终。

状态迁移选择带屏障的快照加后继日志：固定拓扑与算子版本，屏障前输入/状态/输出承诺在同一实际提交域结算，后继输入缓冲并带序列；新拥有者先恢复、对齐位置，再经围栏接管。跨存储不能原子提交时，只能采用真实事务参与或可查回/幂等的较弱交付，不用“exactly-once”名称代替。旧实例不能在接管后继续发布；故障中间保留旧/新两边的资源和交付状态。

硬实时只在明确画像内启用：固定任务集合或有可证明上界的准入；实际WCET、周期/最小到达间隔、截止、抖动、阻塞、调度与硬件干扰输入齐备。选定单处理器可抢占固定优先级、截止不大于最小到达间隔（D≤T）且无自挂起的有限方法时，可迭代检查 R_i^(k+1)=C_i+B_i+Σ_{j∈hp(i)}ceil((R_i^k+J_j)/T_j)C_j，所有量为时间，C是最坏执行、B是保守阻塞、J是到达抖动、T是最小到达间隔；从C_i+B_i开始求最小固定点；D_i在本画像中从名义到达时刻起算，R_i从实际释放起算，故收敛且J_i+R_i≤D_i才接纳。若另一接口的截止从实际释放起算，应使用对应截止及准入方法，不能重复计入J_i。中断、DMA、缓存、GC、频率变化及I/O若未计入，不能使用该证明。另一个调度画像必须提供自己的可调度性方法，不把此公式套所有系统。

Linux SCHED_DEADLINE需要运行时间、截止和周期等实际参数，且存在带宽准入/行为条件；能设置调度器不证明真实WCET或应用截止成立。TS协调层可以管理非硬实时工作，硬期限路径由符合上述条件的实际核和驱动承担；绝不以平均benchmark替硬界。无法取得证明输入就拒绝硬保证，但明确允许的软实时任务可继续。该拒绝保留要求，不把硬需求静默降成偏好。

## 5. 数值、复数、隐式求导和统计梯度

精确整数继续独立于机器浮点。数值画像固定格式、舍入、非有限值、误差准则、坐标/单位和允许优化。快速数学优化、向量重排和GPU混合精度只有在所请求误差及错误行为被保持时可采用，不用相同函数名默许改变。

复数默认按两个实值分量处理：一般f: C^n→C^m的导数是实线性映射，JVP/VJP遵循所选实内积；只有真实全纯前提成立时才可用一个复解析导数简化。涉及conj、abs和复数损失时不得默套全纯规则；Wirtinger形式需明确对z与conj(z)的分量及其回传约定。零点和分支切线按原不可微/未定结果处理，不填虚假零导数。

隐式层由F(x,y)=0定义。在选定解的邻域，需F可微、J_y可逆及真实解/残差判据。方向导数通过 J_y·dy=−J_x·dx 求解；标量损失的反向可解 J_y^T·λ=∂L/∂y，再按列梯度取 ∇_x L=∂_x L−J_x^T·λ。实际近似解只有残差小并不足以控制导数误差，还需稳定性/条件界或准确的不保证声明。奇异、多解、分支更换、未收敛分别返回，不使用旧分支导数掩盖。

随机计算显式提供种子/流身份和算法版本，但并行重排仅在随机流分配规则保证时保持样本。统计梯度选择两条方法：可重参数化且相应可微/交换条件成立时使用路径梯度；否则在可微对数密度、参数无关支撑集（或显式计算边界项）和可积/微分积分交换条件下使用得分估计E[f(x)∇θ log pθ(x)]，另计f本身的θ依赖。基线/方差减少和采样数需保留其偏差与独立性条件。有限样本不证明无偏或全分布保证；停止、置信区间和异常值按统计方法输出。

分布/广义导数不自动塞成普通F64：使用明确的测试函数空间、作用定义和符号/数值表示合同。当前普通AD入口遇到Dirac项、跳变或未选分布画像时报告不支持的导数类型；确需这种结果由专门分布方法返回相应对象，而不是将它默转0或NaN。原值仍按原错误优先合同执行。此选择使不支持的数学可定位，不宣称已定义所有未来分布运算。

## 6. 调试中的求值、热替换和重放

默认观察只使用提供者确实支持的被动读取。getter、pretty-printer、任意表达式或运行内存修改若可能执行目标代码，就是单独的有作用操作，绑定暂停代、会话、当前权限和影响范围；未知响应不能再次求值当查询。不能保证被动读取时返回缺能力而非执行后再标“只读”。

热替换只在供给同时给出代码兼容、状态/栈转换和真实安全切面时执行；默认新产物启动新实例，旧运行留在旧版本。纯确定性重放可以在隔离环境消费准确输入和已捕获非确定来源；外部副作用以记录替身表示，不能重播收费、写盘或远端消息并称时间倒流。没有完整输入与观察记录时明确不能复现，不依赖模型猜测旧现场。

## 7. 实施与证据的分界

这些选择明确了此前开放范围的当前方法、拒绝点和替代路线；具体原生前端、借用证明、设备WCET、统计政策、数学正则性、数据预算和运行符合性仍须实际输入或实现。原U不因这里有公式就关闭。未知现实事实不能由选择一个默认数值消除。
