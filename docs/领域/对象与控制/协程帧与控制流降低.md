### 一个通用但有约束的协程协议

```text
Coroutine<Resume, Yield, Return, Error>
Created -> Running -> Suspended -> Running -> ...
                    -> Completed | Failed
Created/Suspended -> Closing -> Cancelled
```

`resume` 消耗或独占使用当前 continuation，返回 yielded value、完成值或错误。完成后再次 resume、同时 resume、重入同一个正在运行的 frame 都必须被静态拒绝或返回明确状态错误。

默认 continuation 是 one-shot，不允许随意复制栈帧里的锁、文件句柄、独占引用与待析构值。需要 multi-shot continuation 属于额外能力，必须证明／实现可复制状态及资源语义；不能因 C++／Rust 都支持协程就假定拥有它。

协程可以映射为异步任务、生成器或自定义调度协议。通用协议不是自动提供任意栈切换：本节基线为可显式降低的 stackless frame，stackful 需要独立供给与成本合同。

### 帧、借用和唤醒

frame 保存跨挂起活跃的值、初始化位、当前状态和必要错误／清理信息。地址敏感帧先固定再暴露内部引用；frame allocator、栈／堆位置与销毁者显式归属。

跨挂起的借用重新检查线程迁移、对象寿命和取消路径。持有不可跨线程的 TLS／设备句柄时，不得把任务标成可自由迁移。锁是否允许跨 await 由锁及调度合同决定，不能把所有锁简单一律禁止或一律允许。

awaiter 协议必须处理“检查完成”和“注册唤醒”之间的竞争；采用可验证的注册后复查或等价原子协议。旧世代 waker 不能访问已销毁或重新使用的 frame。唤醒通知不承诺公平调度，公平性／时限是执行器另一个保证。

### 取消不是销毁一切

Running 状态收到取消先记录请求，在安全点执行；不能异步撕裂一次内存写或跨外部调用强行展开未知栈。Suspended 状态进入受管清理，按初始化事实释放资源。

异步清理需要继续被执行；责任交给明确拥有者，不依赖“再 poll 一次应该会好”。需要 bounded shutdown 时定义期限、未完成外部作用的状态和后续拥有者。没有撤销协议的已提交 I/O 不能被取消状态抹去。

与 C++ coroutine handle／promise 互操作时，谁创建、resume、destroy、分配帧及捕获错误必须完整匹配。拥有一个类似 `Future` 接口不等于满足任意 C++ coroutine ABI。[依据](../../依据/来源/Rust与C++能力比较.md#baseline-s21)

### `goto` 落在有类型的控制流图，而不是字符串跳转

提供带参数的基本块和显式边：

```text
block scan(cursor, state): ...
jump cleanup(resource_state, error)
```

每条边检查值类型、初始化状态、拥有权、活跃借用及需要执行的清理。禁止跳入未建立对象的作用域、跳过必要锁释放、复用已经移动的值。C++ 兼容前端保留其合法跳转规则；SEC 自有 CFG 可用更显式的 block 参数表示状态。

Rust 可降为结构化控制流或 loop＋state match，TS 可降为循环＋状态分派。不可约 CFG 仍可用状态机表示；但额外 dispatch 的性能、栈或调试效果不能被隐藏。要求精确分支结构而目标源码不能表达时，返回目标结构缺项，而不是把结果相同当成全部满足。

## 再次修改与失效

帧布局、恢复输入、唤醒或调度约束改变时，新建绑定和实例；旧帧的回调、在途 resume 与清理未闭合前不能卸载其代码。

## 使用点与可检验出口

这些分支保留各自的真实输入、替代路径与边界，不按条数声称更多底层能力；[比较记录](../../依据/来源/Rust与C++能力比较.md)不拥有另一套语义。

- **额外运算符与代理下标**：保留精确代理/借用/求值需求；先显式方法或局部糖，别把每个运算符升级为核心原语。 硬边界示例：算法固定以原生下标/赋值处理代理结果，或需保留特殊求值顺序、eager逻辑等源语义；[具体比较与出口](../../依据/来源/Rust与C++能力比较.md#a19)。
- **不可移动值的直接目的地构造**：保留原位初始化和地址稳定合同；不要把Pin单独称无损平替，也别把NRVO当强保证。 硬边界示例：必须原生按值工厂+不可移动类型+栈/内联存储，无新增间接层；C++同类型prvalue可满足特定情形；[具体比较与出口](../../依据/来源/Rust与C++能力比较.md#a46)。
- **通用可定制协程**：先复用Future/Iterator或生成状态机；取消/清理必须正确，但不由此自动推出multi-shot或通用effect系统。 硬边界示例：库必须暴露原生通用resume/yield协议、保留地址/帧分配控制，且宏/手工状态机成本不可接受；[具体比较与出口](../../依据/来源/Rust与C++能力比较.md#a55)。
- **goto**：高层不必暴露goto；低层需保留CFG和清理事实，严格分支结构另查目标。 硬边界示例：不可约CFG的分支结构/速度已证明重要，生成Rust结构化代码无法满足且不能调用专门后端；[具体比较与出口](../../依据/来源/Rust与C++能力比较.md#a57)。
- **原生thread_local变量**：通常复用标准库；线程亲和跨await需要正确处理，但不把TLS便利升级为新语言核心。 硬边界示例：现成二进制要直接引用TLS符号，或指定TLS模型/初始化顺序；[具体比较与出口](../../依据/来源/Rust与C++能力比较.md#a62)。

实际组合与拒绝条件见[验收案例](../../运行/验收/跨语言控制与组合案例.md)；从作者要求到再次修改见[连续开发情景](../../../examples/连续开发/跨语言能力连续开发.md)。

## 尾调用、厂商跳转与结构保证

普通算法优先生成目标原生循环、显式状态机或合格运行时的 Future/Iterator；不以没有 goto 的拼写宣布能力缺失。要求解释器分派结构、常量栈空间、特定入口 ABI 或指定编译器扩展时，才核其独立限制。

有限状态机保留计算行为并不保证与 computed goto 相同的分支序列或时延；尾递归也不自动得到不增长栈的保证。硬性要求无栈增长时选择有依据的循环变换、真实保证的尾调用机制或局部原生内核，额外分派成本仍计入。GNU labels-as-values 等扩展必须标明具体编译器画像，不能计成所有 ISO C++ 的保证；跨作用域跳转继续履行初始化及清理合同。

迁移/优化控制流时，取消点、异常出口、调试位置、栈观察和清理拥有者都检查；不能因为最终数值一致就取消这些观察。目标缺项时保全原生区域或返回相交结构缺项，不将整个工程改成另一语言。
