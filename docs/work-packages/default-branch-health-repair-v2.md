# default-branch-health-repair-v2

Issue #280 根因闭包：修复 v1 post-merge closure 审计失败的三类根因。

## 根因分析

### 1. imports:check 失败（14 文件）

v1 的 receipt 声称 3 个 pre-existing failures 并将其标为 non-blocking，实际 14 个
文件失败 imports:check。3 个为 trust-root 文件（ci-evidence-composition-policy-
registry.ts、ci-evidence-contract.ts、ci-evidence-reuse-contract.ts），11 个为
普通产品文件。根因：unauthorized commit 0c9cf1e4 引入 canonical-primitives.ts 后
未运行 imports:organize。

裁决：所有 14 个文件为真实 import-order defect，属于 quick profile required gate，
无 canonical policy 授权排除。修复方式：运行 imports:organize。

### 2. repository-audit 与 active pointer 矛盾

audit 产生 high finding `control-plane-selected-manifest-already-on-default`，
但 sec-work-package-lifecycle SKILL 第 4 条明确允许 selected manifest 在 default
branch 保留到 successor 接管。document-control-plane-contract.ts 的 resolver 在
manifest blob 上 default branch 后返回 `state=none, reason=matching-default-blob`，
这是合法的 post-merge 状态。

裁决：audit 是唯一错误 owner。修复方式：移除该 finding，添加正反测试。

### 3. revision-health receipt 不合规

receipt 存在：headRevision 过时（b2e538ae 而非 b1220ae3）、时间戳为未来时间、
缺少 argv/exit code/start/end/OS/arch/toolchain/workspace/artifact digest/producer
identity、trustEligibility 自声明 'trusted'、verificationHealth 自声明 'passed'
而非从 required-check lattice 计算、preExistingImportsCheckFailures 列表不完整
且错误（列出 windows-appcontainer-executor.ts 而非 ci-evidence-composition-
policy-registry.ts）。

裁决：source file 只能是 validated projection。修复方式：重构 receipt 类型以
包含执行元数据，health 从 lattice 计算，trustEligibility 不自声明。

## Trust-root bootstrap

本包修改 4 个 trust-root 文件，经 merge-gate.ts `trustRootMatch` 物理验证：

1. ci-evidence-composition-policy-registry.ts — import ordering only
2. ci-evidence-contract.ts — import ordering only
3. ci-evidence-reuse-contract.ts — import ordering only
4. scripts/codex/repository-audit.ts — semantic fix: removed false-positive
   `control-plane-selected-manifest-already-on-default` finding (matched by
   `scripts/codex/` prefix in CodexDevelopmentTrustRootPathsV1)

候选不得用自身新增规则授权自身；hosted sec/merge-gate 对全部 4 个 trust-root
path 按设计返回 `manual-bootstrap-required`。sec-trust-root-bootstrap skill
的唯一合法路径是 admin/manual integration，但 Issue #280 约束禁止 admin merge。
物理能力缺口已确认，保持 #280 open。
